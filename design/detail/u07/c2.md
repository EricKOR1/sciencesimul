**상세판** design/detail/u07/s2.md · **공통 규칙** design/detail/u07/common.md. **분리 이유**: 9과07-01의 두 번째 활동(행성을 지구형/목성형으로 구분)을 탐구 활동 '망원경을 이용하여 행성 관측하기' + '태양계 천체 자료 수집 및 분석하기'로 깊이 다룸. 앞 차시에서 '행성'의 뜻을 배운 뒤 행성 8개만 비교.
**탐구 질문**: "망원경으로 본 행성들은 어떻게 다를까? 행성들을 두 무리로 나눌 수 있을까?"
**범위**: "자세한 특징은 다루지 않는다" → 비교 항목은 질량·반지름·평균 밀도·위성 수·고리·표면 상태만. 제외: 대기 성분 세부, 내부 층 구조, 형성 과정, 금성 위상, 공전 주기 계산. 안전 1줄: 망원경으로 태양을 보지 않는다.
**장면**: STEP1 망원경: 왼쪽 해 진 뒤 하늘(지평선 실루엣, 밝은 점 금성·화성·목성·토성), 오른쪽 원형 접안 창(비네팅, 미세한 대기 흔들림). 점을 누르면 망원경이 0.6초 회전, [초점] 슬라이더로 블러(반지름∝|오차|)→선명. 목성: 띠·대적점 + 일직선 위 갈릴레이 위성 4개 x=a·sin(2πt/P)(a=5.9/9.4/15.0/26.4 목성 반지름, P=1.77/3.55/7.15/16.7일). 토성: 기울어진 고리(앞쪽 고리가 행성을 가리고 행성 그림자가 고리에). 화성: 붉은 원반 + 흰 극관. [다음 날 밤]은 위성이 0.8초 미끄러짐. STEP2 분석판: 행성 칩 8개 트레이 + 그래프(x 반지름(지구=1) 0~12, y 평균 밀도 0~6 g/cm³, 물 1 g/cm³ 점선). 칩을 끌면 축까지 십자 안내선, 정답 근처(Δx≤0.6, Δy≤0.35)면 스냅 + 찌그러졌다 펴지는 바운스 + 글로우, 아니면 트레이로 복귀 + "자료표 값 확인". STEP3 탐사선: 지구형은 낙하산 착지 + 먼지 입자 20개, 목성형은 구름 띠가 위로 스치며 점점 짙어지고 바닥 없음 → 탐사선이 사라지며 "단단한 표면이 없어요". 고리: 목성·천왕성·해왕성 희미, 토성 뚜렷.
**컨트롤(≤3)**: STEP1 [초점] + [🌙 다음 날 밤], STEP2~4 캔버스 끌기·누르기 + [↺ 되돌리기].

**STEP1 관찰 '망원경으로 본 행성'(관측)** features scope, focus. M1 task 목성·토성·화성을 각각 초점 오차 ≤10 %로 1초 유지(3개). M2 task 목성을 보며 [다음 날 밤] 3번 이상. M3 quiz 네 점의 정체: [목성 둘레를 도는 위성✔/목성 뒤의 먼 별/렌즈 먼지/소행성] — 1610년 갈릴레이 발견. summary: 행성의 모양·무늬·고리·위성 관측.
**STEP2 분석 '행성 자료 분석'(분석)** features table, graph. M1 task 칩 8개 모두 스냅. M2 task 점을 눌러 색(주황↔파랑) 지정 → {수·금·지·화}/{목·토·천·해}로 정확히 나뉘면 성공(색 배정 무관). M3 quiz [반지름이 큰 무리는 평균 밀도가 작다✔/큰 무리는 밀도도 크다/밀도가 같다/관계없다] → 지구형·목성형 이름 붙이기.
**STEP3 설명 '두 무리의 특징'(특징)** features probe, rings. M1 task 지구형 1개 + 목성형 1개에 탐사선 투하 → 암석 표면 vs 주로 수소·헬륨 기체(단단한 표면 없음 → 밀도 작음). M2 quiz 토성 밀도 0.69 g/cm³의 뜻: [물보다 밀도가 작다✔/가장 무거운 행성/암석으로 되어 있다/지구보다 질량이 작다(→약 95배)]. M3 quiz 고리가 있는 행성: [목성형 행성 모두✔/토성만/지구형 모두/없다]. summary 비교표: 지구형 = 질량·반지름 작다, 평균 밀도 크다, 위성 없거나 적다, 고리 없다, 단단한 암석 표면 / 목성형 = 질량·반지름 크다, 평균 밀도 작다, 위성 많다, 고리 있다, 주로 기체.
**STEP4 적용 '행성 판정하기'(적용)** M1 quiz 외계 행성 X(반지름 1.3배, 밀도 5.0, 고리 없음)→지구형✔. M2 quiz(figure 궤도도) 지구형 행성의 위치→소행성대 안쪽✔. M3 task 꼬리표 6개(밀도 크다/작다, 고리 있다/없다, 위성 많다/없거나 적다)를 2열 표에 모두 바르게.
**자료(NASA, 반올림)** 질량·반지름(지구=1)·밀도·위성: 수성 0.055·0.38·5.43·0 / 금성 0.82·0.95·5.24·0 / 지구 1·1·5.51·1 / 화성 0.11·0.53·3.93·2 / 목성 318·11.2·1.33·95개 이상 / 토성 95·9.45·0.69·270개 이상 / 천왕성 14.5·4.01·1.27·28개 이상 / 해왕성 17.1·3.88·1.64·16. 위성 수는 계속 바뀌므로 '많다/적다'로 채점하고 "(2025년 무렵)" 표기. 오개념: 크면 밀도도 크다, 토성만 고리, 목성형에도 땅이 있다. 미션 11.
