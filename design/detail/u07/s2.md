## m1-planet-types · 지구형 행성과 목성형 행성 [9과07-01 뒷부분]
**분리 이유**: 9과07-01의 두 번째 활동(행성 구분)을 탐구 활동 '망원경을 이용하여 달, 행성 관측하기'와 '태양계 천체 자료 수집 및 분석하기'로 깊이 있게 다룬다. 앞 차시(구성 천체)에서 '행성'의 뜻을 배운 뒤 행성 8개만 자료로 비교한다.
**탐구 질문(STEP1)**: "망원경으로 본 행성들은 서로 어떤 점이 다를까? 행성들을 두 무리로 나눌 수 있을까?"
**범위**: 해설 "자세한 특징은 다루지 않는다" → 비교 항목은 질량·반지름·평균 밀도·위성 수·고리·표면 상태 6가지만. 제외: 행성 대기 성분 세부, 내부 구조 층, 형성 과정(눈선 등), 금성 위상, 공전 주기 계산. 고려 사항: 태양을 망원경으로 보지 않도록 안전 문구 1줄.

### 화면·애니메이션 (우주 스타일, 두 캔버스)
- STEP1 **망원경 시야**: 왼쪽은 해 진 뒤 하늘(지평선 실루엣, 밝은 점 4개: 금성·화성·목성·토성), 오른쪽은 둥근 접안렌즈 창(비네팅 + 미세한 대기 흔들림). 하늘의 점을 누르면 망원경이 그쪽으로 0.6초 easeInOut 회전. **초점 손잡이**(슬라이더): 흐림(가우시안 블러 반지름 ∝ |초점 오차|) → 선명. 목성: 띠 무늬·대적점 + 일직선 위 갈릴레이 위성 4개(위치 x = a·sin(2πt/P), a = 5.9/9.4/15.0/26.4 목성 반지름, P = 1.77/3.55/7.15/16.7일). 토성: 기울어진 고리(앞쪽 고리가 행성을 가리고 행성 그림자가 고리에 드리움). 화성: 붉은 원반 + 흰 극관. [🌙 다음 날 밤] 버튼으로 하루씩 넘기면 위성이 부드럽게 미끄러짐(0.8s).
- STEP2 **자료 분석판**: 행성 칩 8개(작은 그라데이션 행성 아이콘) 트레이 + 그래프(x: 반지름(지구=1) 0~12, y: 평균 밀도 0~6 g/cm³, 연한 격자, 물 1 g/cm³ 기준선 점선). 칩을 끌면 칩 아래 십자 가이드선이 축까지 따라감, 정답 근처(Δx≤0.6, Δy≤0.35)에 놓으면 스냅 + 찌그러졌다 펴지는 바운스 + 점 글로우. 틀리면 트레이로 미끄러져 돌아가고 "자료표의 값을 다시 확인" 말풍선.
- STEP3 **탐사선 투하**: 행성 단면 클로즈업. 지구형: 탐사선이 낙하산으로 내려가 암석 표면에 착지(먼지 퍼짐 입자 20개, 착지 흔들림). 목성형: 구름 띠가 위로 스쳐 지나가며 점점 짙어지는 그라데이션, '바닥'이 나오지 않음 → 탐사선이 짙은 대기 속으로 사라짐 + "단단한 표면이 없어요". 고리는 행성별로 그림(목성·천왕성·해왕성 희미한 고리, 토성 뚜렷).
- 컨트롤(≤3): STEP1 [초점] 슬라이더 + [다음 날 밤] 버튼, STEP2~4 캔버스 끌기/누르기 + [↺ 칩 되돌리기].

### STEP 1 · 관찰 · '망원경으로 본 행성' (short '관측') · features: scope, focus
- M1 task '행성 3개 관측': 목성·토성·화성을 각각 선택해 초점 오차 ≤10 %로 1초 유지. check: 3개 모두. status ✅⬜. explain: 행성마다 크기·색·무늬가 다르고 토성은 고리가 뚜렷하다.
- M2 task '목성 둘레의 점': 목성을 보며 [다음 날 밤]을 3번 이상. check: nights≥3. explain: 네 점의 위치가 밤마다 바뀐다.
- M3 quiz '네 점의 정체': [목성 둘레를 도는 위성✔ / 목성 뒤의 먼 별 / 렌즈의 먼지 / 소행성대의 소행성]. 피드백: 먼 별이라면 밤마다 목성과 같이 움직이지 않음 등. explain: 갈릴레이가 1610년에 처음 발견한 목성의 큰 위성 4개.
summary: 망원경으로 보면 행성의 모양·무늬·고리·위성을 볼 수 있다. 태양은 필터 없이 절대 보지 않는다.

### STEP 2 · 분석 · '행성 자료 분석' (short '분석') · features: table, graph
intro: 🔗 관측한 차이를 숫자 자료로 비교해요.
- M1 task '그래프에 점 찍기': 칩 8개를 (반지름, 밀도) 위치에. check: 8개 스냅. status n/8.
- M2 task '두 무리로 묶기': 점을 눌러 색(주황 A ↔ 파랑 B) 지정. check: {수·금·지·화} / {목·토·천·해}로 정확히 나뉨(색 배정은 무관). hint: 그래프에서 서로 가까이 모인 점끼리.
- M3 quiz '두 무리의 차이': [반지름이 큰 무리는 평균 밀도가 작다✔ / 반지름이 큰 무리는 밀도도 크다 / 두 무리의 밀도는 같다 / 반지름과 밀도는 관계없다]. explain: 반지름(질량)이 작고 밀도가 큰 무리 = 지구형 행성, 반지름(질량)이 크고 밀도가 작은 무리 = 목성형 행성.
summary: 그래프 미니 그림 + 두 무리 이름.

### STEP 3 · 설명 · '두 무리의 특징' (short '특징') · features: probe, rings
intro: 🔗 왜 목성형 행성은 크면서도 밀도가 작을까? 탐사선을 보내 봐요.
- M1 task '탐사선 보내기': 지구형 1개 + 목성형 1개에 탐사선 투하 완료. check: 둘 다. explain: 지구형은 암석으로 된 단단한 표면, 목성형은 주로 수소·헬륨 같은 가벼운 기체로 되어 있어 단단한 표면이 없다 → 밀도가 작다.
- M2 quiz '토성의 밀도 0.69 g/cm³': [물보다 밀도가 작다✔ / 가장 무거운 행성이다 / 암석으로 되어 있다 / 지구보다 질량이 작다]. 피드백: 토성 질량은 지구의 약 95배.
- M3 quiz '고리가 있는 행성': [목성형 행성 모두✔ / 토성만 / 지구형 행성 모두 / 하나도 없다]. 피드백: 목성·천왕성·해왕성 고리는 희미해 망원경으로 잘 안 보일 뿐.
summary: 비교표 — 지구형: 질량·반지름 작다, 평균 밀도 크다, 위성 없거나 적다, 고리 없다, 단단한 암석 표면 / 목성형: 질량·반지름 크다, 평균 밀도 작다, 위성 많다, 고리 있다, 주로 기체.

### STEP 4 · 적용 · '행성 판정하기' (short '적용') · features: none
- M1 quiz '외계 행성 X': 반지름 지구의 1.3배, 평균 밀도 5.0 g/cm³, 고리 없음 → 지구형 행성과 비슷✔ (오답: 목성형/판단 불가/위성).
- M2 quiz '태양계 지도에서'(figure: 소행성대 표시 궤도도): 지구형 행성 위치 → 소행성대 안쪽(태양 가까이)✔.
- M3 task '특징 표 완성': 꼬리표 6개(밀도 크다/작다, 고리 있다/없다, 위성 많다/없거나 적다)를 2열 표에 끌어 넣기. check: 6개 모두 정답 칸.
