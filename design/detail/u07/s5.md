## m1-constellation-change · 지구의 공전과 별자리 변화 [9과07-03 뒷부분]
**분리 이유**: 앞 차시(자전·일주 운동, 하루 단위)에 이어 공전에 의한 1년 단위 변화를 따로 다룬다. 같은 '우주에서 보는 관점'을 쓰되 변인은 '날짜(월)' 하나만 둔다(시각은 한밤중으로 고정).
**탐구 질문(STEP1)**: "왜 계절마다 밤하늘에 보이는 별자리가 달라질까?"
**범위**: 해설 "지구의 자전과 공전을 우주에서 바라보는 관점으로 설명한다." 고려 사항 "천체 관측 프로그램, 앱 등을 적절하게 활용" → 가상 천체 관측 창. 성취기준의 '밤하늘 천체에 호기심을 가진다' → STEP4 관측 계획. 제외: 세차 운동, 별자리(점성술) 운세, 연주 시차(별과 우주 단원), 계절 변화의 원인(초등에서 학습, 여기서는 다루지 않음), 항성일 계산.

### 화면·애니메이션 (우주 스타일, 두 캔버스)
- **우주 창(북극 위에서 본 공전 모형)**: 가운데 태양(방사 글로우), 점선 공전 궤도(월 눈금 1월~12월), 지구(낮/밤 반쪽, 밤 쪽 한가운데 '한밤중 관측자' 표지). 바깥 고리에 **황도 12궁** 별자리를 30° 간격, 시계 반대 방향 순서로: 궁수(0°)·염소·물병·물고기·양·황소·쌍둥이·게·사자·처녀·천칭·전갈(330°). 별자리는 밝은 점 + 가는 연결선 + 이름. 황소와 쌍둥이 사이 바깥쪽에 오리온자리(황도 밖이라 점선 테두리)도 표시. 지구의 태양 둘레 각도 θE(m월 초) = 180° + 30°(m−1).
  - 지구에서 바깥쪽으로 뻗는 청록 점선 = **한밤중 시선**: 닿는 별자리가 청록 글로우로 강조. 지구→태양 연장선이 닿는 별자리는 태양 빛에 묻혀 흐릿하게 + "낮이라 보이지 않음".
  - 지구 끌기: 궤도에 구속, 손가락 각도를 임계 감쇠 스프링으로 부드럽게 따라감. 월이 바뀔 때마다 틱 소리 + 월 이름표가 살짝 튀어오름(scale 1→1.15→1). [▶ 공전 재생]은 한 달에 1.2초, 시계 반대 방향.
  - STEP3 **태양의 길**: 지구에서 본 태양의 위치가 고리 위에서 이동한 자취(주황 호 + 월마다 작은 해 아이콘 + 진행 방향 화살표).
- **하늘 창('한밤중 남쪽 하늘', 가상 천체 관측 앱 느낌)**: 밤 그라데이션 + 지평선 실루엣, 방위 '동·남·서'. 한밤중 시선 기준 ±60° 안의 별자리를 가로로 배치(x = 중앙 − Δ각×k, 동쪽이 왼쪽). 월이 바뀌면 별자리가 오른쪽(서쪽)으로 미끄러짐(0.6초 easeInOut). 비교 모드에서는 지난달 위치가 반투명 유령 + 곡선 화살표 "서쪽으로 약 30°".
- **[☀️ 햇빛 가리기]**(STEP3): 낮 하늘의 눈부심을 지워 태양 뒤의 별자리를 보여 주는 '플라네타륨 모드'(실제로는 볼 수 없음을 문구로 명시).
- 컨트롤(≤3): [📅 월] 슬라이더(1~12월), [▶ 공전 재생], [☀️ 햇빛 가리기].

### STEP 1 · 관찰 · '계절마다 다른 밤하늘' (short '관찰') · features: sky, month
- M1 task '네 계절의 한밤중 하늘': 봄(3~5월)·여름(6~8월)·가을(9~11월)·겨울(12~2월)에서 각각 한 달 이상 0.5초 머물기. check: 4계절. status: 계절 칩 + 지금 보이는 별자리 이름.
- M2 task '한 달 뒤 같은 시각': 비교 모드에서 1월 → 2월로 옮겨 쌍둥이자리가 이동하는 모습 보기. check: m → m+1 이동 1회 이상.
- M3 quiz '이동 방향과 크기': 같은 시각에 본 별자리는 한 달 뒤 → [서쪽으로 약 30°✔ / 동쪽으로 약 30° / 제자리 / 서쪽으로 약 1°]. explain: 하루 약 1°, 한 달 약 30°, 1년이면 한 바퀴 → 같은 별자리가 1년 뒤 같은 시각에 같은 자리.
summary: 계절별 한밤중 남쪽 하늘 대표 별자리(봄 사자, 여름 전갈·궁수, 가을 물병·물고기, 겨울 쌍둥이·오리온), 같은 시각 별자리는 하루 약 1°씩 서쪽으로.

### STEP 2 · 모형 · '공전하는 지구' (short '모형') · features: space
intro: 🔗 별자리가 매달 서쪽으로 밀리는 까닭을 우주에서 내려다봐요.
- M1 task '겨울·여름 밤하늘 만들기': 지구를 끌어 한밤중 시선이 쌍둥이자리에(θE 180°±12°), 그다음 궁수자리에(θE 0°±12°) 닿게. check: 둘 다.
- M2 quiz '별자리가 바뀌는 까닭': [지구가 공전하면서 한밤중에 바라보는 방향이 바뀌기 때문✔ / 별자리가 지구 둘레를 돌기 때문 / 지구가 자전하기 때문 / 계절마다 별자리가 새로 생기기 때문]. 피드백: 자전은 하루 동안의 변화(앞 차시).
summary: 지구는 태양 둘레를 1년에 한 바퀴(하루 약 1°) 서→동으로 공전 → 밤에 향하는 쪽이 달라져 계절별 별자리가 바뀐다.

### STEP 3 · 설명 · '태양의 연주 운동' (short '연주') · features: suntrack, noglare
intro: 🔗 지구가 움직이면, 지구에서 본 태양의 '배경 별자리'도 바뀔까?
- M1 task '태양의 길 따라가기': 공전 방향으로 3달 이상 연속 이동하며 태양이 지나는 별자리 3개 확인. check: 연속 3달 전진.
- M2 quiz '태양의 이동': 별자리 사이에서 태양은 → [서쪽에서 동쪽으로 하루 약 1°씩✔ / 동쪽에서 서쪽으로 1시간에 15°씩 / 서쪽에서 동쪽으로 1시간에 15°씩 / 움직이지 않는다]. 피드백: 15°/시는 일주 운동.
- M3 quiz '사자자리를 지나는 태양'(figure: 9월 모형 SVG): 한밤중 남쪽 하늘의 별자리 → [물병자리✔ / 사자자리 / 처녀자리 / 게자리]. 피드백: 사자자리는 태양과 같은 방향이라 낮에 떠 있어 보이지 않는다.
summary: 태양이 별자리 사이를 서→동으로 1년에 한 바퀴 도는 것처럼 보이는 운동 = 연주 운동, 그 길 = 황도, 황도의 12개 별자리 = 황도 12궁. 한밤중 남쪽 별자리 = 태양이 있는 별자리의 정반대.

### STEP 4 · 적용 · '밤하늘 관측 계획' (short '계획') · features: planner
- M1 task(manual) '내 생일 달의 밤하늘': 생일 달을 고르고, 그 달 한밤중에 볼 수 있는 별자리를 고리에서 눌러 '관측 카드' 만들기. check: 누른 별자리 = 그 달 태양 별자리의 정반대(아니면 "태양과 같은 쪽은 낮이에요" 등 문자열).
- M2 quiz '6개월 뒤': 오늘 한밤중 남쪽에 사자자리 → 6개월 뒤 같은 시각 → [물병자리✔ / 사자자리 / 처녀자리 / 아무것도 안 보임].
- M3 quiz '여름엔 오리온이 어디에?': [태양과 같은 방향에 있어 낮에 떠 있기 때문✔ / 여름에는 사라졌다가 겨울에 다시 생겨서 / 여름에는 지구에서 멀어져서 / 여름밤에는 구름이 많아서]. explain: 별자리는 늘 그 자리에 있다 → 관측 앱으로 오늘 밤 하늘을 찾아보자(호기심).
summary: 관측 계획 카드 + "천체 관측 앱으로 오늘 밤 하늘 확인하기".

### 자료값(월 초 기준, 교과서식 12등분 모형)
태양이 지나는 별자리/한밤중 남쪽 별자리: 1월 궁수/쌍둥이, 2월 염소/게, 3월 물병/사자, 4월 물고기/처녀, 5월 양/천칭, 6월 황소/전갈, 7월 쌍둥이/궁수, 8월 게/염소, 9월 사자/물병, 10월 처녀/물고기, 11월 천칭/양, 12월 전갈/황소(오리온은 12~1월 한밤중 남쪽). 실제 하늘(적경)과 대조해 확인한 값. 실제 별자리 경계는 크기가 제각각이고 태양은 11월 말~12월 중순 뱀주인자리도 지난다 → 화면 각주 "실제 별자리 크기는 서로 달라요". 공전 주기 약 365일, 하루 약 1°. 오개념: 별자리가 계절마다 생기고 사라진다, 별자리 변화는 자전 때문, 태양은 별자리 사이를 동→서로, 15°/시와 1°/일 혼동. 미션 수 10.
