**상세판** design/detail/u07/s5.md · **공통 규칙** design/detail/u07/common.md. **분리 이유**: 9과07-03의 공전 부분. 앞 차시와 같은 '우주에서 보는 관점'을 쓰되 변인은 날짜(월) 하나, 시각은 한밤중으로 고정.
**탐구 질문**: "왜 계절마다 밤하늘에 보이는 별자리가 달라질까?"
**범위**: 해설 "지구의 자전과 공전을 우주에서 바라보는 관점으로 설명한다", 고려 사항 "천체 관측 프로그램, 앱 등을 적절하게 활용" → 가상 관측 창. '밤하늘 천체에 호기심을 가진다' → STEP4 관측 계획. 제외: 세차 운동, 점성술 운세, 연주 시차(별과 우주 단원), 계절 변화의 원인, 항성일 계산.
**장면**: 우주 창 = 가운데 태양(글로우), 점선 공전 궤도(1~12월 눈금), 지구(낮/밤, 밤 쪽 가운데 '한밤중 관측자'). 바깥 고리에 **황도 12궁** 30° 간격, 시계 반대 방향 순서 궁수(0°)·염소·물병·물고기·양·황소·쌍둥이·게·사자·처녀·천칭·전갈(330°); 별 점 + 연결선 + 이름. 황소·쌍둥이 사이 바깥에 오리온(황도 밖, 점선 테두리). 지구 각도 θE(m월 초)=180°+30°(m−1). 지구에서 바깥으로 뻗는 청록 점선 = **한밤중 시선** → 닿는 별자리 청록 글로우; 지구→태양 연장선의 별자리는 햇빛에 묻혀 흐릿 + "낮이라 보이지 않음". 지구는 궤도에 구속해 끌기(임계 감쇠 스프링), 월이 바뀔 때 틱 + 월 이름표 튀어오름(1→1.15→1). [▶ 공전 재생] 한 달 1.2초, 반시계. STEP3 **태양의 길**: 지구에서 본 태양 위치 자취(주황 호 + 월별 해 아이콘 + 방향 화살표). 하늘 창 = '한밤중 남쪽 하늘'(관측 앱 느낌): 밤 그라데이션 + 지평선, '동·남·서'. 한밤중 시선 ±60° 안 별자리를 가로 배치(동쪽이 왼쪽), 월이 바뀌면 오른쪽(서쪽)으로 0.6초 미끄러짐. 비교 모드: 지난달 위치 반투명 유령 + 곡선 화살표 "서쪽으로 약 30°". [☀️ 햇빛 가리기]: 태양 뒤 별자리를 보여 주는 플라네타륨 모드("실제로는 볼 수 없어요").
**컨트롤(≤3)**: [📅 월 1~12], [▶ 공전 재생], [☀️ 햇빛 가리기](STEP3부터).

**STEP1 관찰 '계절마다 다른 밤하늘'(관찰)** features sky, month. M1 task 봄(3~5)·여름(6~8)·가을(9~11)·겨울(12~2)에서 각각 한 달 이상 0.5초 머물기(계절 칩 + 보이는 별자리 이름). M2 task 비교 모드에서 1월→2월 이동(쌍둥이자리가 서쪽으로 미끄러짐, m→m+1 1회 이상). M3 quiz 같은 시각의 별자리는 한 달 뒤: [서쪽으로 약 30°✔/동쪽으로 약 30°/제자리/서쪽으로 약 1°] — 하루 약 1°, 1년이면 제자리. summary: 계절별 한밤중 남쪽 별자리(봄 사자, 여름 전갈·궁수, 가을 물병·물고기, 겨울 쌍둥이·오리온).
**STEP2 모형 '공전하는 지구'(모형)** features space. M1 task 한밤중 시선이 쌍둥이자리(θE 180°±12°), 그다음 궁수자리(θE 0°±12°)에 닿게. M2 quiz 별자리가 바뀌는 까닭: [지구가 공전하며 한밤중에 바라보는 방향이 바뀌어서✔/별자리가 지구 둘레를 돌아서/지구가 자전해서(→하루 변화)/계절마다 새로 생겨서]. summary: 지구는 1년에 한 바퀴(하루 약 1°) 서→동 공전 → 밤에 향하는 쪽이 바뀜.
**STEP3 설명 '태양의 연주 운동'(연주)** features suntrack, noglare. M1 task 공전 방향으로 연속 3달 이상 이동하며 태양이 지나는 별자리 3개 확인. M2 quiz 별자리 사이의 태양: [서→동으로 하루 약 1°✔/동→서로 1시간 15°/서→동으로 1시간 15°/안 움직임] — 15°/시는 일주 운동. M3 quiz(figure 9월 모형) 태양이 사자자리를 지날 때 한밤중 남쪽: [물병자리✔/사자자리(낮에 떠 있음)/처녀자리/게자리]. summary: 연주 운동, 황도, 황도 12궁, 한밤중 남쪽 = 태양 별자리의 정반대.
**STEP4 적용 '밤하늘 관측 계획'(계획)** features planner. M1 task(manual) 생일 달을 고르고 그 달 한밤중에 볼 별자리를 고리에서 눌러 관측 카드 만들기(정답 = 태양 별자리의 정반대; 오답 문자열 "태양과 같은 쪽은 낮이에요" 등). M2 quiz 오늘 한밤중 남쪽 사자자리 → 6개월 뒤: [물병자리✔/사자자리/처녀자리/아무것도 안 보임]. M3 quiz 여름에 오리온이 안 보이는 까닭: [태양과 같은 방향이라 낮에 떠 있어서✔/여름엔 사라졌다 다시 생겨서/멀어져서/구름 때문]. explain: 별자리는 늘 그 자리 — 관측 앱으로 오늘 밤 하늘 찾아보기.
**자료(월 초 기준, 교과서식 12등분)** 태양/한밤중 남쪽: 1월 궁수/쌍둥이, 2월 염소/게, 3월 물병/사자, 4월 물고기/처녀, 5월 양/천칭, 6월 황소/전갈, 7월 쌍둥이/궁수, 8월 게/염소, 9월 사자/물병, 10월 처녀/물고기, 11월 천칭/양, 12월 전갈/황소(오리온 12~1월). 실제 하늘(적경)과 대조 확인. 실제 별자리 크기는 제각각(태양은 11월 말~12월 중순 뱀주인자리도 지남) → 각주 "실제 별자리 크기는 서로 달라요". 오개념: 별자리가 생기고 사라진다, 변화는 자전 때문, 태양이 별자리 사이를 동→서로, 15°/시·1°/일 혼동. 미션 10.
