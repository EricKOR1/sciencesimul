## m1-diurnal-motion · 지구의 자전과 일주 운동 [9과07-03 앞부분]
**분리 이유**: 9과07-03은 '자전 → 하루 동안의 겉보기 운동(일주 운동)'과 '공전 → 1년 동안의 별자리 변화'라는 시간 규모(하루/1년)와 모형(도는 지구/태양 둘레를 도는 지구)이 다른 두 현상이다. 한 화면에 넣으면 시각·날짜 두 변인이 섞여 혼란스러우므로 이 차시는 자전만, 다음 차시 m1-constellation-change가 공전을 다룬다.
**탐구 질문(STEP1)**: "밤새 별들은 어떻게 움직일까? 별이 정말 움직이는 걸까?"
**범위**: 해설 "관측자의 위치(고위도, 저위도, 중위도)에 따른 일주운동은 다루지 않는다. 지구의 자전과 공전을 우주에서 바라보는 관점으로 설명한다." → 관측 장소는 서울(북위 약 37.5°) 하나로 고정(위도 조절 없음), STEP3에서 '북극 위에서 본 지구' 모형으로 설명. 제외: 천구 좌표(적경·적위) 용어, 항성일/태양일 구분, 고위도·저위도 비교, 별의 실제 운동.

### 화면·애니메이션 (우주 스타일, 두 캔버스)
- **하늘 창(지구에서 본 하늘)**: 서울, 1월 중순 밤. 실제 계산: 시각 t → 항성시 LST = 7.7h + (t−24h)×1.0027, 시간각 H = LST − 적경, 위도 37.5°로 고도·방위 계산. 남쪽 보기: 방위 90°(동)~270°(서)를 가로로 펼친 원통 투영, 북쪽 보기: 270°~90°(북 0° 중앙). 하늘색은 태양 고도에 따라 밤 #070d1f → 박명 보라/주황 → 낮 #7ec8ff로 부드럽게, 별 밝기는 하늘 밝기에 반비례로 사라짐. 지평선 산 실루엣 + 작은 천문대 돔, 방위 글자 '동·남·서'/'서·북·동'. 별: 등급에 따라 크기·글로우, 1초 주기 미세 반짝임. **별 궤적**: 지난 3시간 위치를 꼬리 선으로 그리고 끝으로 갈수록 투명. 시계: 바늘이 부드럽게 도는 큰 시계 + "21:00".
- **사진 모드(STEP2)**: 북쪽 하늘 장노출 사진 렌더(같은 계산으로 노출 T시간 동안의 호를 오프스크린에 누적 → 북극성 둘레 동심 호, 밝은 별은 굵고 색 있는 호). **각도기 도구**: 반투명 원형 각도기, 중심이 북극성에 자석 스냅(±12px), 두 팔(끝 손잡이)을 끌어 호의 양 끝에 맞추면 사이 각을 실시간 표시(부채꼴 채움 애니메이션).
- **우주 창(STEP3, 북극 위에서 본 지구)**: 북반구 원반(북극이 중심, 대륙은 방위 등거리 투영의 단순 경로, 바다 방사 그라데이션), 오른쪽에서 햇빛 → 밤 쪽 반 어둡게(부드러운 명암 경계 띠), 북위 37.5° 원 위 서울 핀 + 작은 사람(남쪽 = 바깥쪽을 바라보는 시야 부채꼴). 원반 둘레 바깥 고리에 먼 별(오리온자리·시리우스·북두칠성 방향 표지). 원반을 손가락으로 돌리면 반시계 방향 회전(관성 + 임계 감쇠 스프링으로 부드럽게 멈춤), 1시간(15°)마다 틱 소리. 시야 부채꼴이 고리 위 별을 지나가면 하늘 창에서 같은 별이 같은 색 글로우로 동→서 이동(연결 강조). '자전 방향: 서 → 동(시계 반대 방향)' 회전 화살표.
- 컨트롤(≤3): [남쪽 하늘 | 북쪽 하늘] 세그먼트, [🕘 시각] 슬라이더(18:00~06:00) + [▶ 재생](1시간/2초). STEP2는 시각 대신 [📷 노출 시간] 1~6시간.

### STEP 1 · 관찰 · '밤하늘의 움직임' (short '관찰') · features: sky, clock
- M1 task '남쪽 하늘 지켜보기': 남쪽 보기에서 시각을 3시간 이상 진행. check: 남쪽 보기 누적 ≥3h. explain: 오리온자리가 남동쪽에서 떠올라 남쪽을 지나 서쪽으로 → 동에서 서로 움직인다.
- M2 task '움직이지 않는 별': 북쪽 보기에서 1시간 이상 진행한 뒤 거의 움직이지 않는 별(북극성)을 누르기(±18px). check: 탭 성공.
- M3 quiz '북쪽 하늘의 별': [북극성을 중심으로 시계 반대 방향으로 돈다✔ / 시계 방향으로 돈다 / 북극성 쪽으로 모인다 / 움직이지 않는다].
summary: 별은 동쪽에서 떠서 서쪽으로 진다. 북쪽 하늘의 별은 북극성 둘레를 시계 반대 방향으로 돈다.

### STEP 2 · 탐구 · '일주 운동 측정' (short '측정') · features: photo, protractor
intro: 🔗 별의 움직임을 사진으로 기록해 빠르기를 재요.
- M1 task '호의 각도 재기': 노출 2시간 사진에서 각도기로 한 호의 각도 측정. check: 측정값 30°±3° (manual 확인 버튼, 아니면 "호의 끝에 팔을 더 정확히" 문자열).
- M2 task '노출 4시간': 노출을 4시간으로 바꿔 다시 측정. check: 60°±3°.
- M3 quiz '1시간에 몇 도?': [약 15°✔ / 약 1° / 약 30° / 약 360°]. 피드백: 1°는 다음 차시(공전)에서 나오는 하루 이동량이라 헷갈리기 쉬움. explain: 24시간에 한 바퀴(360°) → 1시간에 15°.
summary: 일주 운동 = 하루에 한 바퀴, 1시간에 약 15°.

### STEP 3 · 모형(설명) · '우주에서 보기' (short '모형') · features: space
intro: 🔗 별이 움직인 걸까, 우리가 움직인 걸까? 북극 위 우주에서 지구를 내려다봐요.
- M1 task '하루 돌려 보기': 지구를 돌려 관측자가 밤 → 해 뜰 무렵 → 정오 → 해 질 무렵을 차례로 지나게. check: 4지점 순서대로 통과(역방향 회전은 진행으로 치지 않음). 하늘 창에서 해가 동쪽에서 떠 남쪽을 지나 서쪽으로 짐.
- M2 quiz '동→서의 까닭': [지구가 서쪽에서 동쪽으로 자전하기 때문✔ / 별들이 실제로 지구 둘레를 돌기 때문 / 지구가 태양 둘레를 공전하기 때문 / 별이 바람에 밀려서]. 피드백: 달리는 기차에서 창밖 나무가 뒤로 가는 것처럼 겉보기 운동.
- M3 quiz '북극성의 비밀': [지구 자전축을 북쪽으로 늘인 방향 가까이에 있기 때문✔ / 가장 밝은 별이라서 / 가장 가까운 별이라서 / 북극성도 지구와 함께 돌아서]. 피드백: 북극성은 가장 밝은 별이 아니다.
summary: 일주 운동 = 지구 자전(서→동, 하루 1바퀴) 때문에 천체가 동→서로 도는 것처럼 보이는 겉보기 운동.

### STEP 4 · 적용 · '움직임 예측' (short '예측') · features: predict
- M1 task(manual) '3시간 뒤 북두칠성': 21시 북쪽 하늘에서 반투명 북두칠성 유령을 북극성 둘레로 돌려 24시 위치 예측. check: 회전각 45°±7°(시계 반대 방향). 확인 후 실제 위치로 0.8초 애니메이션 비교.
- M2 quiz '남쪽 별 2시간 뒤': 21시 남쪽 하늘의 별 → 23시에는 [서쪽으로 약 30° 이동✔ / 동쪽으로 30° / 제자리 / 서쪽으로 약 2°].
- M3 quiz '해와 달도?': 해와 달이 동쪽에서 떠서 서쪽으로 지는 까닭 → [지구의 자전✔ / 태양과 달이 하루에 한 번 지구를 돌아서 / 지구의 공전 / 달의 위상 변화]. explain: 지구에서 보이는 모든 천체가 같은 일주 운동을 한다(다음 차시: 공전).
summary: 예측 규칙 정리.
