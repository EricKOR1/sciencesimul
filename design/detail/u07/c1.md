**탐구 질문**: "태양계에는 태양과 행성 말고 어떤 천체들이 있을까?"
**범위**: 해설 "태양, 행성, 왜소행성, 소행성, 위성, 혜성을 개괄적으로 학습하며, 자세한 특징은 다루지 않는다" → 정의 수준(무엇의 둘레를 도는가·둥근가·꼬리)만. 제외: 행성별 자세한 특성, 케플러 법칙, 카이퍼 벨트·오르트 구름 용어, 혜성 꼬리 2종, 거리 계산.
**장면**: 위에서 본 태양계(우주 배경). 거리 r=46+92·√AU px(압축), 크기 과장 + "크기와 거리는 실제와 달라요". 태양: #fff7d6→#ffcf5a→#ff9a2e 코어 + 일렁이는 글로우. 행성: 그라데이션 공 + 태양 반대쪽 명암, 토성 고리(뒤쪽 반은 행성 뒤). 달·목성 위성 4개가 각자 공전. ▶재생 시 반시계, 각속도∝a^-1.5(지구 8초/바퀴). 소행성대 2.2~3.3 AU에 불규칙 돌 350개(안쪽 빠름), 그 안에 둥근 세레스. 명왕성·에리스는 해왕성 밖 기운 타원. 혜성: e≈0.85 타원, 코마 글로우 + 테이퍼 그라데이션 꼬리 **항상 태양 반대쪽**, 길이∝1/r²(최대 160px, 목성 밖 0), 끝에서 먼지 입자. 천체를 누르면 글로우 링 + **천체 카드**(확대 렌더 + 종류 배지 + 특징 1~2줄, scale .85→1 easeOutBack). [안쪽|전체] 전환은 카메라 줌 0.8초.
**컨트롤(≤3)**: [안쪽 태양계|전체 태양계], [▶ 공전 재생]; 나머지는 캔버스 터치·끌기.

**STEP1 관찰 '태양계 둘러보기'(short 관찰)** features map, cards. M1 task 천체 카드 모으기: 6종 각 1장 이상(check 6종, status 칩, hint "혜성·명왕성은 '전체' 보기"). M2 quiz 스스로 빛나는 천체: [태양✔/목성(가장 커서)/달(밤에 밝아서)/혜성(꼬리가 빛나서)] — 피드백: 반사광. explain: 태양 = 유일한 별, 태양계 질량의 약 99.8 %. summary: 태양계 = 태양 + 행성 8 + 왜소행성·소행성·위성·혜성.
**STEP2 탐구 '분류 기준 찾기'(분류)** features sorter. 분류 열쇠(질문 상자 화살표 연결): Q1 무엇의 둘레를 도나? 행성→위성 / 태양→Q2 둥근가? 아니요→Q2b 태양 가까이에서 꼬리? 예 혜성·아니요 소행성 / 예→Q3 궤도 주변 천체를 치웠나? 예 행성·아니요 왜소행성. 카드를 놓으면 질문 상자를 차례로 통과(0.3초/칸) 후 바구니에 바운스, 틀리면 갈린 질문이 빨갛게 깜빡이고 카드 복귀. M1 task 6장(달·화성·명왕성·베스타·핼리 혜성·가니메데) 모두 정답. M2 quiz 가니메데(5,268 km)가 수성(4,879 km)보다 큰데 위성인 까닭: [목성 둘레를 돌아서✔/빛을 못 내서/둥글지 않아서/작아서]. M3 quiz 명왕성: [둥글고 태양 둘레를 돌지만 궤도 주변 천체를 치우지 못해서✔/태양 둘레를 안 돌아서/둥글지 않아서/위성이 없어서] — 2006년 국제천문연맹 결정. summary: 분류 열쇠 + 6종 정의 한 줄씩.
**STEP3 모형 '소행성과 혜성'(소천체)** features belt, comet. M1 task 소행성이 가장 많은 곳 누르기(탭 반지름 2.2~3.3 AU) → 화성과 목성 궤도 사이, 불규칙한 모양. M2 task 혜성을 궤도에 구속해 끌기: 목성 밖→근일점→다시 r>2.5 AU(status: 거리·꼬리 막대). explain: 얼음+먼지, 태양열로 기체가 되어 코마·꼬리, 멀어지면 사라짐. M3 quiz 꼬리 방향(SVG 3위치): [항상 태양 반대쪽✔/움직이는 방향의 뒤쪽/아래쪽/태양 쪽] — 피드백: 멀어질 때는 꼬리가 앞장선다.
**STEP4 적용 '새 천체 분류하기'(적용)** 탐사 일지 figure. M1 quiz 에리스(해왕성 밖, 둥글다, 주변에 비슷한 천체 많음)→왜소행성✔. M2 quiz 유로파(목성 둘레, 얼음 표면)→위성✔. M3 quiz 아포피스(약 340 m 불규칙, 태양 둘레, 2029년 4월 13일 지구에서 약 3만 2천 km 접근)→소행성✔ + 지구 근접 천체 감시.
