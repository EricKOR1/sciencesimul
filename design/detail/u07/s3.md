## m1-sun-activity · 태양 표면과 태양 활동 [9과07-02]
**한 차시로 둔 이유**: '표면·대기 현상 → 활동이 활발해질 때의 변화 → 지구에 미치는 영향'이 하나의 원인-결과 사슬이라 4단계 한 흐름으로 다룬다.
**탐구 질문(STEP1)**: "태양의 표면은 어떻게 생겼고, 태양에서 일어나는 일이 지구에 어떤 영향을 줄까?"
**범위·안전**: 고려 사항 "태양의 흑점, 일식 등을 관찰할 때는 눈으로 직접 보지 않고 필터 등을 사용하도록 지도한다" → STEP1 첫 미션을 '필터 끼우기'로. 정성적으로 다룸. 제외: 차등 자전, 자기장 물리, 핵융합 세부, 자전 주기 계산, 태양 내부 구조 층.

### 화면·애니메이션 (우주 스타일, 두 캔버스, 단계마다 보기 전환)
- **광구 보기(STEP1)**: 태양 관측 망원경 시야(원형, 비네팅). 필터 없으면 접안부에 뚜껑 + 경고 표지(눈부신 화면은 그리지 않음). 필터를 끼우면 뚜껑이 열리며 원반이 0.6초 페이드인. 원반: 주연 감광(중심 #fff3cf → 가장자리 밝기 60 % #f2972a). **쌀알 무늬**: 오프스크린에 만든 보로노이 세포 텍스처 3장(밝은 중심·어두운 경계)을 6초 주기로 교차 페이드 → 끓어오르듯 살아 움직임. 확대 렌즈(누른 곳 3배 원형 돋보기). **흑점**: 암부(#2b1408)+반암부(방사형 줄무늬 #7a3e12). 구면 좌표로 배치: x = R·sinλ·cosφ, 폭 ∝ cosλ(가장자리에서 납작해짐 → 공 모양이 돈다는 단서). [관측일] 1~14일: 하루 13°씩 동(왼쪽)→서(오른쪽), 0.5초 보간. 원반 옆에 '동/서/북/남' 방위.
- **대기 보기(STEP2)**: 관측 창 밖으로 넓은 하늘. 광구 위에 전체 화면 '눈부심'(블룸) 오버레이. 학생이 **가리개 원판**(달 모양, 반지름 = 광구)을 끌어 덮으면 덮인 비율 c에 따라 눈부심 α = 1−c, 코로나 α ∝ c⁴: 진주빛 흰 줄기(방사형 노이즈 광선 #eef4ff, 천천히 일렁임), c>0.97이면 가장자리 붉은 고리(채층, #ff4d6d)와 **홍염**(붉은 고리·불꽃 모양 3개, 4초 주기로 솟았다 가라앉음)이 나타남. 위치 맞으면 '딸깍' 자석 스냅(±4px).
- **활동 보기(STEP3)**: 왼쪽 태양 원반(그해 흑점 수 N에 비례해 흑점 무리 수, 플레어 섬광 빈도 ∝ N: 흑점 곁에서 0.3초 하얗게 번쩍 + 고리 퍼짐, 코로나 반지름 ∝ 1+N/250), 오른쪽 그래프(연평균 흑점 수 1985~2024, 막대 + 매끈한 선, 현재 연도 막대 강조).
- **지구 영향 보기(STEP4)**: 왼쪽 작은 태양 → 오른쪽 지구(낮/밤 명암) + 자기장선(쌍극자 곡선, 태양 쪽이 눌린 모양). 태양풍 입자 점들이 흐름. [⚡ 태양 폭풍] 누르면 플레어 섬광 → 커다란 입자 구름이 3초에 걸쳐 지구로(화면 표시 "실제로는 1~3일"), 자기장선을 따라 극지방으로 미끄러져 **오로라 커튼**(초록·붉은 세로 그라데이션 물결) 켜짐, 인공위성 아이콘 흔들림·지직, 통신 전파 끊김 표시, 송전탑 불꽃.
- 컨트롤(≤3 보이게, 단계별 보기에 맞춰 숨김): [🕶️ 태양 필터] 토글, [📅 관측일] 또는 [📆 연도] 슬라이더(보기별 하나), [⚡ 태양 폭풍] 버튼. 자유 탐구에서는 [광구|대기|활동|지구] 세그먼트.

### STEP 1 · 관찰 · '태양의 표면' (short '표면') · features: scope, filter, days
- M1 task '안전하게 관측하기': 필터를 켠 뒤에만 시야가 열림. check: 필터 ON. explain: 태양은 맨눈·망원경·선글라스로 직접 보면 실명 위험 → 태양 필터·투영법.
- M2 task '광구 살펴보기': 돋보기로 쌀알 무늬와 흑점을 각각 눌러 이름표 붙이기. check: 둘 다. explain: 광구 = 태양의 표면(약 6000 °C). 쌀알 무늬 = 광구 아래 대류(밝은 곳: 뜨거운 기체가 올라옴, 어두운 경계: 식은 기체가 내려감). 흑점 = 주위보다 온도가 낮아(약 4000 °C) 어둡게 보임.
- M3 quiz '흑점이 움직인 까닭'(관측일 1→7일 그림): [태양이 자전하기 때문✔ / 지구가 공전하기 때문 / 흑점이 태양 표면을 기어 다녀서 / 흑점이 식어서]. 피드백: 여러 흑점이 함께 같은 방향으로 이동하고 가장자리에서 납작해짐 → 공 모양 태양이 돌고 있다.
summary: 광구, 쌀알 무늬, 흑점(어두운 까닭·이동 → 자전).

### STEP 2 · 관찰 · '태양의 대기' (short '대기') · features: occulter
intro: 🔗 광구가 너무 밝아 그 바깥의 희미한 대기는 보이지 않았어요. 광구를 가려 볼까요?
- M1 task '광구 가리기': c ≥ 0.98을 1초 유지. explain: 개기 일식 때 달이 광구를 가리는 것과 같다.
- M2 task '대기 이름표': 채층·코로나·홍염을 눌러 이름표 3개. check: 3개. explain: 채층 = 광구 바로 위 얇은 붉은 대기층, 코로나 = 그 바깥으로 멀리 퍼진 진주색 대기(100만 °C 이상), 홍염 = 고온의 기체가 대기로 솟아오르는 현상.
- M3 quiz '평소에 코로나가 안 보이는 까닭': [광구가 너무 밝아서✔ / 밤에만 생겨서 / 개기 일식 때만 생겨서 / 지구 대기가 막아서]. 피드백: 코로나는 늘 있다.
summary: 채층·코로나·홍염 그림 표.

### STEP 3 · 분석 · '태양 활동의 변화' (short '활동') · features: years, graph
- M1 task '극대기 찾기': 그래프에서 흑점 수가 가장 많은 해 무리 3개를 누르기(1989~1991, 2000~2002, 2012~2014, 2023~2024 중 3곳). check: 3곳.
- M2 quiz '주기': 극대기 사이 간격 → [약 11년✔ / 약 1년 / 약 27일 / 약 100년].
- M3 quiz '흑점이 많을 때의 태양': [홍염·플레어가 자주 일어나고 코로나가 커진다✔ / 흑점이 많아 태양이 어두워지고 활동이 약해진다 / 태양의 크기가 커진다 / 아무 변화가 없다]. explain: 흑점 수가 많을 때 = 태양 활동이 활발한 시기. 플레어 = 흑점 부근의 폭발로 많은 에너지가 순간 방출. 태양풍(전기를 띤 입자의 흐름)도 강해진다.
summary: 흑점 수는 약 11년 주기. 활발할 때 흑점↑ 홍염·플레어↑ 코로나 커짐, 태양풍↑.

### STEP 4 · 적용(추론) · '지구에 미치는 영향' (short '영향') · features: earth, storm
- M1 task '태양 폭풍 관찰': 연도 2024에서 [⚡ 태양 폭풍]을 눌러 입자가 지구에 도달하고 오로라가 켜질 때까지 보기. check: 도달 이벤트.
- M2 task(manual) '영향 고르기': 카드 6장 중 옳은 4장(오로라가 자주·더 낮은 위도에서 보임, 장거리 무선 통신 장애(델린저 현상), 인공위성 고장·GPS 오차, 송전망 고장으로 정전) 선택 후 확인. 오답 카드(계절이 바뀐다, 달의 모양이 바뀐다)는 피드백 문자열.
- M3 quiz '2024년 5월의 오로라': 우리나라에서도 오로라가 관측된 까닭 → [태양 활동이 활발한 시기에 강한 태양 폭풍이 지구에 도달해서✔ / 지구 자전이 빨라져서 / 개기 일식이 일어나서 / 달이 지구에 가까워져서].
summary: 태양 활동↑ → 자기 폭풍, 오로라, 통신 장애, 위성·GPS·전력망 피해. 사례: 1989년 3월 캐나다 퀘벡 대정전(약 9시간), 2022년 2월 인공위성 수십 기 추락, 2024년 5월 국내 오로라 관측.
