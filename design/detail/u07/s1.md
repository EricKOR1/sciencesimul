## m1-solar-members · 태양계 구성 천체 [9과07-01 앞부분]
**분리 이유**: 9과07-01은 ① 태양계 구성 천체(태양·행성·왜소행성·소행성·위성·혜성)의 특징 알기와 ② 행성을 지구형/목성형으로 구분하기(탐구 활동 '태양계 천체 자료 수집 및 분석하기')라는 서로 다른 두 활동으로 이루어진다. ①은 공간 모형(태양계 지도), ②는 자료 표·그래프가 필요해 한 화면에 섞으면 복잡해진다(9과07-04를 위상/식으로 나눈 것과 같은 방식). 이 차시는 ①만, 다음 차시 m1-planet-types가 ②를 다룬다.
**탐구 질문(STEP1)**: "태양계에는 태양과 행성 말고 어떤 천체들이 있을까?"
**범위**: 해설 "태양, 행성, 왜소행성, 소행성, 위성, 혜성을 개괄적으로 학습하며, 자세한 특징은 다루지 않는다." → 정의 수준 특징만(무엇의 둘레를 도는가, 둥근가, 꼬리). 제외: 행성별 자세한 특성(→다음 차시), 케플러 법칙, 오르트 구름·카이퍼 벨트 용어, 혜성 꼬리 2종 구분, 실제 거리 계산.

### 화면·애니메이션 (m1-moon-phase와 같은 우주 스타일, wide 800×600 / tall 520×846 두 캔버스)
- 배경: 방사형 그라데이션(#17264f→#070d1f) + 씨앗 난수 별 120개 반짝임. 태양 중심, 행성 궤도는 점선 원. 거리는 √AU 압축(r=46+92·√AU px), 크기는 과장(표시 "크기와 거리는 실제와 달라요").
- 태양: 코어 #fff7d6→#ffcf5a→#ff9a2e 방사 그라데이션 + 바깥 글로우(알파 0→) + 3초 주기 가장자리 일렁임(노이즈 반지름 ±1.5px).
- 행성: 방사 그라데이션 공 + **태양 반대쪽 반이 어두운 명암선**(매 프레임 태양 방향으로 회전), 부드러운 그림자. 토성 고리(타원, 뒤쪽 반은 행성 뒤에 그림). 지구 옆 달, 목성 옆 4위성(작은 점, 각자 공전).
- 공전: ▶재생 시 반시계 방향, 각속도 ∝ a^-1.5(지구 1바퀴 8초). 정성적 표현만.
- 소행성대: 화성~목성 사이(2.2~3.3 AU) 작은 불규칙 돌 350개(크기·밝기 무작위, 안쪽이 조금 빠름). 세레스는 그 안의 '둥근' 큰 점. 명왕성·에리스는 해왕성 바깥 기운 타원 궤도.
- 혜성(핼리 모형): 긴 타원 궤도(e≈0.85). 코마 글로우 + 꼬리 = 테이퍼 다각형 그라데이션(코마 쪽 #cfe8ff α0.9→끝 α0), **항상 태양 반대 방향**, 길이 ∝ 1/r²(최대 160px, 목성 궤도 밖에서는 0), 꼬리 끝 먼지 입자가 흩날림.
- '전체/안쪽' 보기 전환 시 카메라 줌 0.8초 easeInOutCubic. 천체를 누르면 글로우 링 + **천체 카드**가 튀어나옴(scale .85→1, easeOutBack 250ms): 확대 렌더링 + 종류 배지 + 특징 1~2줄.
- 컨트롤(≤3): [안쪽 태양계 | 전체 태양계] 세그먼트, [▶ 공전 재생] 토글. 나머지는 캔버스 터치.

### STEP 1 · 관찰 · '태양계 둘러보기' (short '관찰') · features: map, cards
intro: 탐구 질문 + "태양계 지도를 둘러보며 천체를 눌러 카드를 모아 봐요."
- M1 task '천체 카드 모으기': 6종류(태양·행성·왜소행성·소행성·위성·혜성) 중 각 1개 이상 카드 열기. check: 6종 모두 수집. status: 6칸 ✅/⬜. hint: "혜성·명왕성은 '전체 태양계' 보기에서 찾아요." explain: 태양계는 태양과 그 둘레를 도는 여러 천체로 이루어져 있다.
- M2 quiz '스스로 빛나는 천체': 스스로 빛을 내는 것은? [태양✔ / 목성(가장 커서) / 달(밤에 밝아서) / 혜성(꼬리가 빛나서)]. 피드백: 목성·달은 햇빛 반사, 혜성 꼬리도 햇빛을 받아 빛남. explain: 태양은 태양계에서 유일하게 스스로 빛을 내는 별, 태양계 전체 질량의 약 99.8%.
summary: 태양계 = 태양 + 행성 8개 + 왜소행성·소행성·위성·혜성. 태양만 스스로 빛을 낸다.

### STEP 2 · 탐구 · '분류 기준 찾기' (short '분류') · features: sorter
intro: 🔗 카드 모음 → "무엇을 기준으로 나눌까?" 분류 열쇠(질문 3개)를 따라가요.
- 장면: 지도 위에 반투명 판 + **분류 열쇠**(질문 상자 3개가 화살표로 연결): Q1 "무엇의 둘레를 도나요?"(행성 둘레→위성) → Q2 "둥근 모양인가요?"(아니요→소행성/혜성: Q2b "태양에 가까워지면 꼬리가 생기나요?") → Q3 "궤도 주변의 다른 천체를 끌어당겨 치웠나요?"(예→행성, 아니요→왜소행성). 카드를 끌어 놓으면 카드가 질문 상자를 차례로 '통과'하는 경로 애니메이션(0.3s/칸) 후 바구니에 쏙(바운스). 틀리면 카드가 되돌아오며 어느 질문에서 갈렸는지 빨간 깜빡임.
- M1 task '천체 분류하기': 카드 6장(달, 화성, 명왕성, 베스타, 핼리 혜성, 가니메데)을 알맞은 바구니에. check: 6장 모두 정답. status: n/6.
- M2 quiz '수성보다 큰 위성?': 가니메데(지름 5,268 km)는 수성(4,879 km)보다 큰데 왜 위성? [목성 둘레를 돌기 때문✔ / 스스로 빛을 못 내서 / 둥글지 않아서 / 크기가 작아서]. explain: 분류 기준은 크기가 아니라 '무엇의 둘레를 도는가'.
- M3 quiz '명왕성은 왜?': [태양 둘레를 돌고 둥글지만, 궤도 주변 천체를 치우지 못해서✔ / 태양 둘레를 돌지 않아서 / 둥글지 않아서 / 위성이 없어서]. explain: 2006년 국제천문연맹이 왜소행성으로 분류.
summary: 분류 열쇠 표(행성·왜소행성·소행성·위성·혜성 정의 한 줄씩).

### STEP 3 · 모형 · '소행성과 혜성' (short '소천체') · features: comet, belt
intro: 🔗 소행성·혜성은 작은 천체 → 어디에 있고 어떻게 움직일까?
- M1 task '소행성대 찾기': 소행성이 가장 많이 모인 곳을 누르기. check: 탭 위치 반지름이 2.2~3.3 AU 띠 안. explain: 대부분 화성과 목성 궤도 사이(소행성대), 모양이 불규칙.
- M2 task '혜성 따라가기': 혜성을 궤도를 따라 끌어(궤도 매개변수에 구속) 목성 밖 → 태양 가까이(근일점) → 다시 바깥으로. check: 근일점 통과 + 다시 r>2.5 AU. status: "태양과의 거리: 멀다/가깝다 · 꼬리 길이 막대". explain: 얼음이 태양열로 기체가 되어 코마와 꼬리가 생기고, 멀어지면 사라진다.
- M3 quiz '꼬리의 방향'(figure: 궤도 위 혜성 3곳 SVG): [항상 태양 반대쪽✔ / 항상 움직이는 방향의 뒤쪽 / 항상 아래쪽 / 태양 쪽]. 피드백: 자동차 배기가스처럼 뒤로 끌리는 게 아님 — 멀어질 때는 꼬리가 앞장선다.
summary: 소행성대 위치, 혜성 = 얼음+먼지, 긴 타원 궤도, 태양 가까이에서 꼬리(태양 반대 방향).

### STEP 4 · 적용 · '새 천체 분류하기' (short '적용') · features: none (탐사 일지 figure)
intro: 🔗 분류 열쇠를 새로 발견된 천체에 적용.
- M1 quiz '에리스': 해왕성 바깥, 태양 둘레, 둥글다, 주변에 비슷한 천체 많음 → 왜소행성✔ (오답: 행성/소행성/혜성 + 피드백).
- M2 quiz '유로파': 목성 둘레, 얼음 표면 → 위성✔.
- M3 quiz '아포피스': 지름 약 340 m 불규칙한 바위 덩어리, 태양 둘레를 돌며 2029년 4월 13일 지구에서 약 3만 2천 km까지 접근 → 소행성✔. explain: 지구 가까이 오는 소행성은 망원경으로 감시한다.
summary: 탐사 일지 정리 + "밤하늘에서 행성은 별처럼 보이지만 스스로 빛나지 않는다".

### 값·오개념
값: 태양 지름 약 139만 km(지구의 약 109배), 질량 99.8 %; 소행성대 2.2~3.3 AU; 세레스 약 940 km; 명왕성 약 2,377 km; 핼리 혜성 주기 약 76년(다음 2061년). 오개념: 크면 행성/작으면 위성, 혜성 꼬리=진행 반대 방향, 행성·달도 스스로 빛남, 명왕성은 사라졌다(→분류만 바뀜). 미션 수 10.
