**상세판** design/detail/u07/s4.md · **공통 규칙** design/detail/u07/common.md. **분리 이유**: 9과07-03 = 자전→하루 동안의 겉보기 운동(일주 운동) + 공전→1년 동안의 별자리 변화. 시간 규모(시각/날짜)와 모형이 달라 한 화면에 두 변인이 섞이면 혼란 → 이 차시는 자전만, 다음 차시 m1-constellation-change가 공전.
**탐구 질문**: "밤새 별들은 어떻게 움직일까? 별이 정말 움직이는 걸까?"
**범위**: 해설 "관측자의 위치(고위도, 저위도, 중위도)에 따른 일주운동은 다루지 않는다. 지구의 자전과 공전을 우주에서 바라보는 관점으로 설명한다." → 관측지는 서울(북위 약 37.5°) 고정(위도 조절 없음), STEP3에서 북극 위 우주 시점으로 설명. 제외: 적경·적위 용어, 항성일/태양일, 위도 비교.
**장면**: ① 하늘 창: 서울, 1월 중순 밤. 실제 계산 LST=7.7h+(t−24h)×1.0027, H=LST−적경, 위도 37.5°로 고도·방위. 남쪽 보기 = 방위 90°~270° 원통 투영, 북쪽 보기 = 270°~90°. 하늘색은 태양 고도에 따라 밤 #070d1f→박명 보라·주황→낮 #7ec8ff, 별은 하늘이 밝아지면 사라짐. 산 실루엣 + 천문대 돔, 방위 글자. 별 크기·글로우는 등급별, 지난 3시간 **궤적 꼬리**(끝으로 갈수록 투명). 바늘이 부드럽게 도는 시계. ② 사진 모드: 같은 계산으로 노출 T시간 호를 오프스크린에 누적한 북쪽 하늘 장노출 사진, **각도기**(중심이 북극성에 ±12px 자석 스냅, 두 팔 끝 손잡이를 끌면 사이 각 실시간 + 부채꼴 채움). ③ 우주 창: 북극 중심 북반구 원반(단순 대륙, 바다 그라데이션), 오른쪽 햇빛 → 밤 쪽 어둡게(부드러운 경계), 북위 37.5° 원 위 서울 핀 + 작은 사람(남쪽 = 바깥쪽 시야 부채꼴). 바깥 고리에 먼 별 방향 표지(오리온·시리우스·북두칠성). 원반을 끌면 반시계 회전(관성 + 임계 감쇠), 15°마다 틱. 시야 부채꼴이 고리의 별을 지나면 하늘 창의 같은 별이 같은 색 글로우로 동→서 이동(연결 강조). 회전 화살표 '자전: 서→동'.
**컨트롤(≤3)**: [남쪽 하늘|북쪽 하늘], [🕘 시각 18:00~06:00] + [▶ 재생](1시간/2초). STEP2는 시각 대신 [📷 노출 시간 1~6시간].

**STEP1 관찰 '밤하늘의 움직임'(관찰)** features sky, clock. M1 task 남쪽 보기에서 시각을 누적 3시간 이상 진행(오리온이 남동→남→서쪽으로). M2 task 북쪽 보기에서 1시간 이상 진행 후 거의 안 움직이는 별(북극성) 누르기(±18px). M3 quiz 북쪽 하늘의 별: [북극성 중심 시계 반대 방향✔/시계 방향/북극성 쪽으로 모임/움직이지 않음]. summary: 동에서 떠서 서로 짐, 북쪽은 북극성 둘레를 시계 반대 방향.
**STEP2 탐구 '일주 운동 측정'(측정)** features photo, protractor. M1 task(manual) 노출 2시간 사진에서 호의 각 30°±3°(아니면 "팔을 호의 끝에 더 정확히"). M2 task 노출 4시간 → 60°±3°. M3 quiz 1시간에: [약 15°✔/약 1°(→다음 차시의 하루 이동량)/약 30°/360°] — 24시간에 360°.
**STEP3 모형(설명) '우주에서 보기'(모형)** features space. M1 task 지구를 돌려 관측자가 밤→해 뜰 무렵(아래)→정오(오른쪽)→해 질 무렵(위)을 순서대로 통과(역회전은 진행으로 치지 않음); 하늘 창에서 해가 동→남→서. M2 quiz 동→서로 보이는 까닭: [지구가 서→동으로 자전해서✔/별이 실제로 지구 둘레를 돌아서/지구가 공전해서/별이 바람에 밀려서] — 달리는 기차의 창밖 비유. M3 quiz 북극성이 거의 안 움직이는 까닭: [자전축을 북쪽으로 늘인 방향 가까이에 있어서✔/가장 밝아서/가장 가까워서/지구와 함께 돌아서] — 북극성은 가장 밝은 별이 아니다. summary: 일주 운동 = 자전(서→동, 하루 1바퀴) 때문에 천체가 동→서로 도는 것처럼 보이는 겉보기 운동.
**STEP4 적용 '움직임 예측'(예측)** features predict. M1 task(manual) 21시 북쪽 하늘의 반투명 북두칠성을 북극성 둘레로 돌려 24시 위치 예측: 시계 반대 방향 45°±7°, 확인 후 실제 위치로 0.8초 비교 애니메이션. M2 quiz 21시 남쪽 별의 23시 위치: [서쪽으로 약 30°✔/동쪽 30°/제자리/서쪽 2°]. M3 quiz 해와 달이 동→서로 지는 까닭: [지구의 자전✔/해·달이 하루 한 번 지구를 돌아서/지구의 공전/달의 위상 변화].
