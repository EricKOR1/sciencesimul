**상세판** design/detail/u07/s3.md · **공통 규칙** design/detail/u07/common.md. **한 차시**: 표면·대기 현상 → 활동이 활발할 때의 변화 → 지구 영향이 하나의 원인-결과 사슬.
**탐구 질문**: "태양의 표면은 어떻게 생겼고, 태양에서 일어나는 일이 지구에 어떤 영향을 줄까?"
**범위·안전**: 고려 사항 "태양의 흑점, 일식 등을 관찰할 때는 눈으로 직접 보지 않고 필터 등을 사용하도록 지도한다" → 첫 미션 = 필터 끼우기(필터 없으면 접안부 뚜껑 + 경고, 눈부신 화면은 그리지 않음). 정성적. 제외: 차등 자전, 자기장 물리, 핵융합, 자전 주기 계산, 내부 구조.
**장면(단계별 보기)**: ① 광구: 원형 시야, 주연 감광(#fff3cf→가장자리 60 % #f2972a). 쌀알 무늬 = 오프스크린 보로노이 텍스처 3장 6초 교차 페이드(끓어오르듯). 누른 곳 3배 돋보기. 흑점 암부 #2b1408 + 방사형 반암부, 구면 배치 x=R·sinλ·cosφ, 폭∝cosλ(가장자리에서 납작). [관측일] 1~14일: 하루 13°씩 동(왼쪽)→서(오른쪽), 0.5초 보간. ② 대기: 광구 위 눈부심 오버레이. **가리개 원판**(반지름 = 광구)을 끌어 덮은 비율 c → 눈부심 α=1−c, 코로나 α∝c⁴(진주빛 방사 줄기 일렁임), c>0.97이면 붉은 채층 고리 + 홍염 3개(4초 주기로 솟았다 가라앉음), ±4px 스냅. ③ 활동: 왼쪽 원반(흑점 무리 수∝N, 플레어 섬광 빈도∝N: 흑점 곁 0.3초 번쩍 + 고리 확산, 코로나 반지름∝1+N/250), 오른쪽 연평균 흑점 수 막대 + 매끈한 선(현재 연도 강조). ④ 지구: 작은 태양 → 지구(낮/밤) + 쌍극자 자기장선(태양 쪽 눌림), 태양풍 입자 흐름. [⚡ 태양 폭풍]: 플레어 섬광 → 입자 구름 3초에 지구 도달("실제로는 1~3일") → 자기장선 따라 극지방 → 초록·붉은 오로라 커튼 물결, 인공위성 지직, 전파 끊김, 송전탑 불꽃.
**컨트롤(≤3)**: [🕶️ 태양 필터], [📅 관측일] 또는 [📆 연도](보기별 하나), [⚡ 태양 폭풍]. 자유 탐구는 [광구|대기|활동|지구] 세그먼트.

**STEP1 관찰 '태양의 표면'(표면)** features scope, filter, days. M1 task 필터 ON(그 전에는 시야 잠김) — explain: 맨눈·망원경·선글라스 금지, 태양 필터·투영법. M2 task 돋보기로 쌀알 무늬·흑점에 이름표 2개 — explain: 광구 = 표면(약 6000 °C), 쌀알 무늬 = 광구 아래 대류(밝은 곳 상승·어두운 경계 하강), 흑점 = 주위보다 온도가 낮아(약 4000 °C) 어둡게 보임. M3 quiz 흑점이 이동한 까닭(1→7일 그림): [태양이 자전해서✔/지구가 공전해서/흑점이 기어 다녀서/흑점이 식어서] — 단서: 여러 흑점이 함께 이동, 가장자리에서 납작.
**STEP2 관찰 '태양의 대기'(대기)** features occulter. M1 task c≥0.98을 1초 유지(개기 일식 때 달이 광구를 가리는 것과 같음). M2 task 채층·코로나·홍염 이름표 3개 — 채층 = 광구 바로 위 얇은 붉은 층, 코로나 = 멀리 퍼진 진주색 대기(100만 °C 이상), 홍염 = 고온 기체가 솟아오르는 현상. M3 quiz 평소 코로나가 안 보이는 까닭: [광구가 너무 밝아서✔/밤에만 생겨서/일식 때만 생겨서/지구 대기가 막아서].
**STEP3 분석 '태양 활동의 변화'(활동)** features years, graph. M1 task 흑점 수 극대기 3곳 누르기(1989~91, 2000~02, 2012~14, 2023~24 중). M2 quiz 주기: [약 11년✔/1년/27일/100년]. M3 quiz 흑점이 많을 때: [홍염·플레어가 잦고 코로나가 커진다✔/흑점 때문에 태양이 어두워지고 활동이 약해진다/태양이 커진다/변화 없다] — 플레어 = 흑점 부근 폭발로 에너지 순간 방출, 태양풍(전기를 띤 입자 흐름) 강해짐.
**STEP4 적용(추론) '지구에 미치는 영향'(영향)** features earth, storm. M1 task 2024년에서 태양 폭풍 → 오로라 켜질 때까지(도달 이벤트). M2 task(manual) 카드 6장 중 옳은 4장(오로라가 잦고 낮은 위도에서도 보임, 장거리 무선 통신 장애(델린저 현상), 인공위성 고장·GPS 오차, 송전망 고장·정전) 선택; 오답(계절 변화, 달의 모양 변화)은 문자열 피드백. M3 quiz 2024년 5월 우리나라 오로라 관측의 까닭: [태양 활동이 활발한 시기에 강한 태양 폭풍이 도달해서✔/자전이 빨라져서/개기 일식/달이 가까워져서]. summary 사례: 1989년 3월 캐나다 퀘벡 대정전(약 9시간), 2022년 2월 인공위성 수십 기 추락, 2024년 5월 국내 오로라.
