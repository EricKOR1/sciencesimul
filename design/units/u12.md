## `m2-photosynthesis` · 🌿 광합성과 환경 요인
- 성취기준 [9과12-01] 광합성 과정을 이해하고, 환경 요인과 광합성의 관계를 탐구하는 실험을 설계할 수 있다.
- 카드 설명(desc): 검정말이 내는 기포로 광합성을 측정하고, 빛의 세기·이산화 탄소·온도와 광합성의 관계를 탐구하는 실험을 설계해요.
- 태그: 광합성, 엽록체, 변인 통제 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 광합성 · 빛의 세기 · 실험 설계 · 적용

### 설계
범위: 광합성 과정(이산화 탄소 + 물 → (빛에너지, 엽록체) 포도당 + 산소), 환경 요인(빛의 세기, 이산화 탄소 농도, 온도)과 광합성의 관계를 탐구하는 실험 설계(변인 통제). 디지털 도구로 데이터 얻고 해석. 빛·CO₂는 증가하다가 일정해지고, 온도는 적정 온도(약 30~35 °C)에서 최대 후 감소.
탐구 질문: "식물은 어떤 조건에서 광합성을 더 활발하게 할까?"
① [관찰] 광합성 — 잎 확대 → 엽록체에서 이산화 탄소·물이 들어가 포도당·산소가 생기는 입자 애니메이션(재료/산물 라벨). 검정말 + 탄산수소 나트륨 용액(이산화 탄소 공급)에 빛 → 산소 기포. 미션: 재료·산물 카드 맞추기(manual), 퀴즈.
② [실험] 빛의 세기 — 전등 거리 슬라이더 → 1분당 기포 수 측정 → 그래프(가까울수록 증가, 어느 정도 이상이면 일정). 미션: 4개 거리 측정(task), 퀴즈.
③ [탐구] 실험 설계 — 이산화 탄소 농도 또는 온도의 영향을 알아보는 실험: 바꿀 변인 1개, 같게 할 변인 선택(manual 판정), 실행해 그래프 확인(온도는 적정 온도에서 최대).
④ [적용] 비닐하우스 농부 — 빛·온도·CO₂ 조건을 설정해 수확을 최대로(task), 퀴즈(밤에 비닐하우스 CO₂ 공급이 소용없는 까닭).
애니메이션: 기포 파티클(bubble), 빛줄기, 입자 이동, 그래프 점 생성.

## `m2-plant-respiration` · 🫧 광합성과 호흡
- 성취기준 [9과12-02] 식물의 호흡과 광합성의 관계를 이해하고, 호흡과 광합성 과정에서 출입하는 에너지와 물질의 변화를 분석할 수 있다.
- 카드 설명(desc): BTB 용액 실험으로 빛이 있을 때와 없을 때 식물의 기체 출입을 비교하고, 광합성과 호흡의 물질·에너지 변화를 분석해요.
- 태그: 호흡, BTB 용액, 기체 교환 / 단계 이름(steps → 각 STEP의 short와 맞출 것): BTB 실험 · 낮과 밤 · 비교 · 적용

### 설계
범위: 식물의 호흡(포도당 + 산소 → 이산화 탄소 + 물 + 에너지; 살아 있는 모든 세포에서 낮밤 항상)과 광합성(빛이 있을 때)의 관계, 출입하는 물질과 에너지 변화 분석(광합성: 빛에너지 → 양분에 저장된 화학 에너지 / 호흡: 양분 → 생명 활동 에너지 방출). BTB: 파란색(CO₂ 적음, 염기성) – 초록색(중성) – 노란색(CO₂ 많음, 산성).
탐구 질문: "식물은 밤에도 숨을 쉴까?"
① [실험] BTB 실험 — 시험관 A(검정말 + 초록 BTB, 빛), B(검정말, 어둠), C(검정말 없음, 빛). 시간 진행 → A 파랗게(광합성으로 CO₂ 감소), B 노랗게(호흡으로 CO₂ 증가), C 변화 없음(대조군). 미션: 실험 실행(task), 퀴즈(C의 역할).
② [탐구] 낮과 밤 — 잎의 기공에서 기체 출입 화살표: 낮(빛 강함) 광합성량 > 호흡량 → 산소 방출·CO₂ 흡수, 밤 호흡만 → 산소 흡수·CO₂ 방출. 빛 슬라이더로 두 양 비교. 미션: 출입 기체가 바뀌는 빛 세기 찾기(task), 퀴즈.
③ [설명] 비교 — 광합성 vs 호흡 표(장소: 엽록체/미토콘드리아, 시기, 물질, 에너지) 채우기(manual), 퀴즈.
④ [적용] 퀴즈 — 밤에 화분을 침실에 두면? (식물 호흡으로 CO₂ 약간 증가 — 실제 영향은 매우 작음을 설명), 낮에 식물도 호흡한다 오개념.
애니메이션: BTB 색 서서히 변화(mix), 기공 열림, 기체 분자 화살표 흐름, 낮밤 하늘 전환.

## `m2-plant-products` · 🥔 광합성 산물의 이동과 저장
- 성취기준 [9과12-03] 광합성 산물의 저장과 이용 과정을 이해하고, 모형으로 설명할 수 있다.
- 카드 설명(desc): 잎에서 만든 양분이 녹말로 저장되었다가 설탕으로 바뀌어 체관으로 이동하고, 여러 기관에 저장되어 에너지원으로 쓰이는 과정을 모형으로 표현해요.
- 태그: 녹말, 체관, 저장 기관 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 녹말 확인 · 이동 · 저장 · 이용

### 설계
범위(해설): 광합성 산물은 생명 활동에 필요한 에너지원임을 강조. 과정: 포도당 → 녹말(잎에 일시 저장) → 주로 밤에 설탕으로 바뀌어 체관을 통해 이동 → 뿌리·줄기·열매·씨에 녹말·포도당·설탕·단백질·지방 등으로 저장 → 호흡의 에너지원, 몸을 구성. 아이오딘-아이오딘화 칼륨 용액: 녹말 → 청람색.
탐구 질문: "잎에서 만든 양분은 어디로 가서 어떻게 쓰일까?"
① [실험] 녹말 확인 — 빛을 받은 잎과 은박지로 가린 잎(하루 전)을 탈색 후 아이오딘 반응 → 빛 받은 부분만 청람색. 미션: 실험 실행(task), 퀴즈.
② [모형] 이동 — 식물 전체 모형에서 낮/밤 전환: 낮 잎에 녹말 알갱이 쌓임, 밤 설탕 입자가 체관(잎→줄기→뿌리·열매)을 따라 흐르는 애니메이션. 물관(위로 물)과 구별. 미션: 체관 경로 따라 양분 보내기(task), 퀴즈(양분은 물관이 아니라 체관).
③ [탐구] 저장 — 저장 기관 카드: 감자(줄기에 녹말), 고구마(뿌리에 녹말), 벼(씨에 녹말), 포도(열매에 포도당), 사탕수수(줄기에 설탕), 콩(씨에 단백질), 땅콩·깨(씨에 지방). 미션: 짝짓기(manual).
④ [적용] 이용 — 산물은 식물 자신의 호흡(에너지)과 생장에 쓰이고, 우리가 먹는 식량 에너지의 근원. 정보 그림(먹이 → 에너지) 완성 퀴즈.
애니메이션: 낮밤 하늘, 입자 흐름(경로 따라 이동), 아이오딘 색 번짐.
