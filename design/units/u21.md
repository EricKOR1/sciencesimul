## `m3-cell-division-why` · 🧫 세포분열이 필요한 까닭
- 성취기준 [9과21-01] 개체의 생장에 세포분열이 필요한 이유를 세포의 표면적과 부피의 관계로 추론할 수 있다.
- 카드 설명(desc): 크기가 다른 우무 조각에 색이 스며드는 실험으로 세포의 표면적과 부피의 관계를 알아내고, 생물이 자라는 데 세포분열이 필요한 까닭을 추론해요.
- 태그: 세포분열, 표면적과 부피, 물질 교환, 생장 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 우무 실험 · 표면적과 부피 · 세포의 크기 · 생장

### 설계
범위: 세포가 커지면 부피 증가가 표면적 증가보다 커서 부피에 대한 표면적의 비(표면적 ÷ 부피)가 작아짐 → 세포막을 통한 물질 교환(산소·영양소 흡수, 노폐물 배출)이 효율적이지 않음 → 세포는 어느 정도 커지면 분열 → 생물의 생장은 주로 세포 수의 증가.
우무 실험: 페놀프탈레인을 넣은 우무 정육면체(한 변 1·2·3 cm)를 묽은 수산화 나트륨 수용액에 10분 담금 → 바깥부터 붉게 물듦(약 0.25 cm 깊이) → 전체 중 물든 비율: 1 cm 약 88 %, 2 cm 약 58 %, 3 cm 약 42 %. 보안경·장갑 안내 한 줄.
표: 한 변 1·2·3 cm → 표면적 6·24·54 cm², 부피 1·8·27 cm³, 표면적 ÷ 부피 6·3·2.
탐구 질문: "코끼리의 세포는 생쥐의 세포보다 훨씬 클까?"(답: 세포 크기는 비슷하고 세포 수가 훨씬 많음)
① [실험] 우무 실험 — 세 조각을 용액에 담그고 시간 진행 → 바깥부터 붉게 물듦, 10분 후 반으로 잘라 단면 비교. 미션: 담그고 자르기(task), 퀴즈(물든 비율이 가장 큰 조각).
② [분석] 표면적과 부피 — 표 빈칸 채우기(manual) → 막대그래프, 퀴즈(크기가 커질수록 표면적 ÷ 부피는?).
③ [모형] 세포의 크기 — 세포 모형을 키우면 세포막으로 들어온 물질 입자가 중심까지 충분히 가지 못해 중심부 '부족' 표시 → 분열시키면 두 세포 모두 충분. 미션: 키웠다가 분열시켜 회복(task), 퀴즈.
④ [적용] 생장 — 코끼리와 생쥐 세포 비교, 생장 = 세포 수 증가, 뿌리 끝(생장점)에서 세포분열이 활발(다음 차시 '세포분열 관찰하기'로 연결). 퀴즈 2~3개.
애니메이션: 아이소메트릭 정육면체, 색이 스며드는 approach, 칼로 자르는 tween, 세포가 커지고 둘로 나뉘는 spring, 입자 확산.

## `m3-mitosis-meiosis` · 🧬 염색체와 세포분열
- 성취기준 [9과21-02] 염색체와 유전자의 관계를 이해하고, 체세포분열과 생식세포 형성과정의 특징을 염색체 행동을 중심으로 해석할 수 있다.
- 카드 설명(desc): 염색체와 유전자의 관계를 알고, 체세포분열과 생식세포 형성 과정에서 염색체가 어떻게 움직이는지 모형으로 비교해 그 의미를 해석해요.
- 태그: 염색체, 유전자, 체세포분열, 생식세포 형성 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 염색체와 유전자 · 체세포분열 · 생식세포 형성 · 비교와 의미

### 설계
범위(해설): 체세포분열과 생식 세포 형성 과정은 염색체의 행동을 중심으로 간단하게, 분열 과정의 단순 암기보다 분열의 생물학적 의미 이해에 중점. 고려: 증강 현실·가상 현실 등 실감형 자료 활용 → 확대·회전되는 입체풍 염색체 모형. 탐구 활동: 세포분열 관찰하기(양파 뿌리 끝 가상 현미경 시야).
염색체 = DNA + 단백질, 유전자 = 유전 정보를 담은 DNA의 특정 부분. 분열 전 DNA가 복제되어 염색체는 두 가닥(염색 분체)으로 이루어짐. 상동 염색체: 모양·크기가 같은 한 쌍(하나는 아버지, 하나는 어머니에게서 받음). 사람 체세포 46개(23쌍) = 상염색체 22쌍 + 성염색체 1쌍(여자 XX, 남자 XY).
체세포분열: 복제 → 세포 가운데 배열 → 염색 분체 분리 → 딸세포 2개, 염색체 수·유전 정보가 모세포와 같음 → 생장, 재생. 시기 이름(전기·중기·후기·말기)은 작은 이름표로만, 암기 요구 없음.
생식세포 형성: 상동 염색체가 짝을 지었다가 첫 번째 분열에서 분리(염색체 수 절반) → 두 번째 분열에서 염색 분체 분리 → 생식세포 4개(사람 23개). 의미: 수정해도 자손의 염색체 수가 세대마다 일정(23 + 23 = 46).
탐구 질문: "부모의 특징은 어떻게 자녀에게 전해지고, 염색체 수는 왜 세대가 지나도 변하지 않을까?"
① [모형] 염색체와 유전자 — 세포 → 핵 → 염색체 → DNA → 유전자로 확대(줌 인), 사람 염색체 카드 일부에서 상동 염색체 짝 맞추기(manual, 4쌍), 성염색체 XX/XY. 미션 2개, 퀴즈.
② [모형] 체세포분열 — 염색체 2쌍(4개) 세포를 단계 진행 → 딸세포 2개, 염색체 수 카운터(4 → 4). 가상 현미경 시야에서 분열 중인 세포 찾기 탭(task), 퀴즈(46 → 46).
③ [모형] 생식세포 형성 — 같은 세포에서 상동 염색체를 양쪽으로 끌어 나누기(task: drag) → 두 번째 분열 → 4개 세포(염색체 2개씩), 퀴즈(사람 생식세포의 염색체 수 23).
④ [설명] 비교와 의미 — 비교표 채우기(manual: 분열 횟수 1/2, 딸세포 수 2/4, 염색체 수 그대로/절반, 상동 염색체 짝짓기 없음/있음, 역할 생장·재생/생식), 정자 23 + 난자 23 → 수정란 46 애니메이션, 퀴즈(생식세포가 체세포분열로 만들어진다면? → 세대마다 두 배).
애니메이션: 줌 인 전환, 색 막대 염색체(상동은 같은 모양·다른 색조), 방추사 당김 spring, 세포막이 잘록해지며 나뉨, 핵막 fade.

## `m3-development` · 🐣 수정과 발생
- 성취기준 [9과21-03] 수정란으로부터 개체가 발생하는 과정을 모형으로 표현할 수 있다.
- 카드 설명(desc): 수정란이 난할을 거듭하며 세포 수는 늘지만 세포 하나의 크기는 작아지는 과정을 모형으로 표현하고, 발생의 첫 단계를 이해해요.
- 태그: 수정, 수정란, 난할, 발생 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 수정 · 난할 · 난할의 특징 · 발생 모형

### 설계
범위(해설): 발생 과정은 수정란의 초기 발생에서 난할만 간단하게. 수정(정자 + 난자 → 수정란, 23 + 23 = 46), 발생 = 수정란이 세포분열을 거쳐 하나의 개체가 되는 과정.
난할: 수정란의 초기 세포분열(체세포분열) — 세포가 자라지 않고 분열을 빠르게 거듭 → 세포 수는 늘고 세포 하나의 크기는 작아지며, 전체 크기는 수정란과 거의 같음, 염색체 수는 변하지 않음. 다루지 않음: 상실배·포배·낭배 등 용어, 착상 이후 태아 발달의 세부.
고려: '모형으로 표현' → 학생이 디지털 점토 모형을 단계별로 만들어 순서대로 놓기.
탐구 질문: "하나의 수정란이 어떻게 수많은 세포로 이루어진 몸이 될까?"
① [관찰] 수정 — 정자들이 난자를 향해 헤엄 → 하나만 들어감 → 핵이 합쳐져 수정란(염색체 23 + 23 = 46). 미션: 수정시키기(task), 퀴즈.
② [모형] 난할 — 분열 버튼으로 1 → 2 → 4 → 8 → 16 → 32세포, 세포 수 카운터·세포 하나 크기 게이지·전체 크기 게이지(거의 일정). 미션: 32세포까지(task), 퀴즈.
③ [분석] 난할의 특징 — 분열 횟수에 따른 세포 수(2배씩), 세포 하나의 부피(절반씩), 전체 부피(일정) 그래프 해석, 보통의 체세포분열과 비교(난할은 세포가 자라지 않고 바로 다음 분열). 미션: 표 완성(manual), 퀴즈(난할에서 염색체 수는 46 그대로).
④ [적용] 발생 모형 — 디지털 점토 모형(수정란, 2세포, 4세포, 8세포, 많은 세포 덩어리)을 순서대로 놓기(manual), 개구리 알 난할 사진 카드 순서 퀴즈, 이후 세포들이 모양과 기능이 다른 세포로 바뀌어 조직·기관을 이룬다(중1 생물의 구성 단계 연결) 한 문장.
애니메이션: 정자 꼬리 사인파 헤엄, 수정막 링 퍼짐, 구가 잘록해지며 둘로 나뉘는 spring, 세포 수 롤링, 전체 경계 원 고정.

## `m3-human-heredity` · 👪 사람의 유전
- 성취기준 [9과21-05] 사람의 유전 형질과 유전 연구 방법을 알고, 가계도를 분석하여 사람의 유전 현상을 설명할 수 있다.
- 카드 설명(desc): 사람의 유전을 연구하기 어려운 까닭과 연구 방법을 알아보고, 가상 가족의 가계도를 분석해 ABO식 혈액형과 적록 색맹의 유전을 설명해요.
- 태그: 가계도, ABO식 혈액형, 적록 색맹, 유전 연구 방법 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 연구 방법 · 가계도 읽기 · 혈액형 유전 · 적록 색맹

### 설계
범위: 사람의 유전 연구가 어려운 까닭(한 세대가 길다, 자손 수가 적다, 자유로운 교배 실험을 할 수 없다, 형질에 환경과 여러 유전자가 영향). 연구 방법: 가계도 조사, 쌍둥이 연구(1란성: 유전자가 같아 차이는 환경 영향 / 2란성), 집단 조사, DNA·염색체 분석.
고려: 단일 유전자가 아닌 형질이 많음에 유의하고 과학적으로 입증된 내용만 → 귓불 모양·혀 말기·보조개처럼 단일 유전자 형질로 잘못 알려진 예는 쓰지 않음. 가계도 분석에서 개인 정보 유출 방지 → 모두 가상의 가족(이름 대신 1~10 번호), 학생 가족 정보 입력 기능 없음.
ABO식 혈액형: 대립유전자 A, B, O. A와 B는 O에 대해 우성, A와 B 사이에는 우열이 없음. 유전자형 AA·AO(A형), BB·BO(B형), AB(AB형), OO(O형). 예: AO × BO → A형·B형·AB형·O형 각 1/4.
적록 색맹: X 염색체에 있는 열성 유전자(X'). 남자 X'Y → 색맹, 여자 X'X' → 색맹, X'X → 정상(보인자). 아들은 X 염색체를 어머니에게서 받으므로 남자에게 더 많이 나타남.
탐구 질문: "완두처럼 교배 실험을 할 수 없는 사람의 유전은 어떻게 연구할까?"
① [관찰] 연구 방법 — 완두와 사람 비교 카드(세대 시간, 자손 수, 교배 실험) → 어려움 정리, 연구 방법 4가지와 사례 짝짓기(manual), 1란성·2란성 쌍둥이 형성 애니메이션. 퀴즈.
② [탐구] 가계도 읽기 — 기호(□ 남자, ○ 여자, 색칠 = 형질이 나타남, 가로선 = 부부, 세로선 = 자녀), 가상 형질 ㉠ 가계도에서 정상 부모 사이에 형질이 나타난 자녀를 찾아 열성 판단. 미션: 기호 해석(task), 판단 퀴즈.
③ [분석] 혈액형 유전 — 유전자형 → 혈액형 표, 가상 가계도에서 물음표 구성원의 유전자형 추론(manual: A형 × B형 부모 → O형 자녀 → 부모는 AO, BO), 퍼넷 사각형으로 확률(멘델 차시 연결). 퀴즈.
④ [분석] 적록 색맹 — 성염색체 XX/XY, 가상 가계도에서 외할아버지 → 어머니(보인자) → 아들 전달 경로 추적, 보인자 찾기(task: 탭), 퀴즈 2개(남자에게 더 많은 까닭).
애니메이션: 가계도 노드 순차 등장, 염색체 아이콘이 전달 경로를 따라 이동 하이라이트, 퍼넷 사각형 칸 채움, 쌍둥이 분리.
