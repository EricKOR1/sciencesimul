## 개념 위계와 차시 흐름
선수: 중3 m3-chemical-equation·m3-reaction-heat(화학 반응, 발열·흡열), 중1 m1-diffusion·m1-gas-charles(온도와 분자 운동), 통합과학2 h1-redox-oxygen·h1-acid-base·h1-neutralization(여러 가지 화학 반응), h1-enzyme(효소의 역할), 일반선택 화학 hc-molarity(몰 농도), hc-dynamic-eq(정반응 속도 = 역반응 속도)·hc-eq-life(암모니아 합성의 촉매), 단원 49(hx-vapor-boiling 에너지 분포와 문턱 에너지), 단원 51(hx-thermochem 엔탈피 도표·ΔH, hx-spontaneity 자발성 ≠ 빠름).
차시 흐름: ① 반응 속도의 표현(농도 변화량 ÷ 시간, 평균·순간 속도, 계수와 속도, 센서 측정 설계) → ② 반응 속도식(v = k[A]ᵐ[B]ⁿ, 초기 속도법) → ③ 1차 반응의 반감기(자료 해석, 일정한 반감기, 사례 조사·발표)
→ ④ 유효 충돌과 활성화 에너지(충돌 모형, 방향·에너지 두 조건, 에너지 도표) → ⑤ 농도·온도와 반응 속도(시계 반응 실험, 충돌 횟수와 문턱 에너지 이상 분자의 비율) → ⑥ 촉매와 반응 속도(활성화 에너지를 낮춤, 효소, 환경 문제 해결).
'속도를 숫자로 잰다(①) → 농도와 속도의 정량 관계(②) → 시간 척도로서의 반감기(③) → 입자 충돌로 속도를 설명(④) → 설명으로 조건 변화를 예측(⑤⑥)'. 앞부분은 거시적 자료 해석, 뒷부분은 입자 모형 해석으로 짜여 ②의 속도 상수 k 가 ⑤⑥에서 왜 바뀌는지(온도·촉매)를 ④의 활성화 에너지로 이어서 설명한다.
고려 사항: 해설에 따라 반감기는 자료(농도–시간 표·그래프) 해석으로 찾으며 적분 속도식([A] = [A]₀e^(−kt) 등)·ln 계산은 유도하지 않는다(1차 반응의 반감기가 일정함은 자료 비교로 확인하고, 0차·2차 반응과는 '반감기 변화 양상' 정도로만 대비). 속도식은 실험 자료(초기 속도법)로 구하며 반응 차수는 0·1·2차 정수만, 반응 메커니즘·속도 결정 단계·아레니우스 식은 다루지 않는다. 온도·촉매의 영향은 활성화 에너지 이상의 에너지를 가진 분자 비율(그림)으로 정성 설명. 센서(기체 압력·부피, 온도, 흡광도 또는 색 변화)를 이용한 실시간 데이터 수집·저장·처리를 반영. 촉매·효소 차시는 생태전환교육(토양·수질·대기 오염 해결)과 연결. 실험에는 보호 장구·폐액 처리 안내.

## `hx-rate-measure` · ⏱️ 반응 속도의 표현
- 성취기준 [12물에04-01] 화학 반응 속도를 반응물의 농도로 표현할 수 있음을 알고, 자료 해석을 통하여 반응 속도식을 구할 수 있다.
- 카드 설명(desc): 센서로 반응물 농도가 줄어드는 모습을 재서 평균 속도와 순간 속도를 구하고, 반응식의 계수에 따라 물질마다 속도가 다름을 알아요.
- 태그: 반응 속도, 평균 속도, 순간 속도, 센서 측정 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 센서 측정 · 평균·순간 · 계수와 속도 · 측정 설계

### 설계
범위: 반응 속도 = 단위 시간당 반응물의 농도 감소량 또는 생성물의 농도 증가량(v = |Δ[농도]| ÷ Δt, 단위 mol/(L·s) = M/s). 평균 속도(시간 간격 평균)와 순간 속도(그래프 접선의 기울기, 간격을 줄여 접근), 반응 속도는 시간이 지나며 감소(반응물 농도가 줄기 때문). 균형 반응식 aA → cC 에서 v = −(1/a)Δ[A]/Δt = (1/c)Δ[C]/Δt (계수로 나눠 물질에 관계없이 하나의 속도로 표현). 탐구 활동: 센서(기체 압력·부피, 흡광도, pH·전도도, 질량)를 이용한 반응 속도 측정 실험 설계·수행.
다루지 않음: 미분 표기, 적분 속도식, 속도식(다음 차시).
자료: 2H₂O₂(aq) → 2H₂O(l) + O₂(g) (소량의 KI 용액을 넣어 분해), 100 mL, 25 °C. [H₂O₂] (M) t = 0, 20, 40, 60, 80, 100 s: 0.80, 0.64, 0.51, 0.41, 0.33, 0.26. 평균 속도(M/s): 0~20 s 0.0080, 20~40 0.0065, 40~60 0.0050, 60~80 0.0040, 80~100 0.0035 (점점 감소). 순간 속도(접선): t = 0 s 약 0.0089 M/s, t = 60 s 약 0.0046 M/s. 산소 부피 센서: 처음 20 s에 H₂O₂ 0.016 mol 분해 → O₂ 0.0080 mol → 25 °C 24.5 L/mol 로 196 mL (산소 부피에서 H₂O₂ 농도 계산: [H₂O₂] = 0.80 − (2 × V_O₂ ÷ 24.5) ÷ 0.100).
계수와 속도: N₂ + 3H₂ → 2NH₃ 에서 Δ[NH₃]/Δt = +0.0040 M/s 일 때 H₂는 −0.0060 M/s, N₂는 −0.0020 M/s 로 변하고, 반응 속도 v = 0.0020 M/s (물질별 변화 속도를 각 계수로 나눈 값). H₂O₂ 분해에서 O₂ 생성 속도는 H₂O₂ 소모 속도의 1/2.
센서 선택표: 기체 발생(H₂O₂ 분해, Mg + 산) → 기체 압력·부피 센서, 색이 있는 물질(I₂, 과망가니즈산 이온) → 흡광도(색도) 센서, 산·염기 소모 → pH 센서, 이온 수가 변하는 반응 → 전도도 센서, 기체가 빠져나가는 반응(CaCO₃ + 2HCl) → 질량 감소(전자저울).
탐구 질문: "반응이 얼마나 빠른지를 숫자로 나타내려면 무엇을 얼마 동안 재야 할까?"
① [실험] 센서 측정 — H₂O₂ 분해 장치(플라스크 + 기체 부피 주사기 또는 압력 센서). 시간–O₂ 부피 그래프가 실시간으로 그려지고, 부피를 [H₂O₂] 값으로 바꾼 표를 자동 기록(record). 미션: 100 s까지 측정(task), [H₂O₂] 표 6점 채우기(manual), 퀴즈(시간이 지나며 그래프 기울기가 완만해지는 까닭 → 반응물 농도 감소).
② [분석] 평균·순간 — 농도–시간 그래프에서 구간을 고르면 평균 속도 계산, 구간을 점점 줄이면 접선의 기울기(순간 속도)에 가까워짐을 슬라이더로 확인. 0 s과 60 s에서 접선을 그어 순간 속도 비교. 미션: 5개 구간 평균 속도 계산(task), t = 0 s 접선 기울기 읽기(task), 퀴즈(평균 속도가 순간 속도와 같아지려면 구간을 어떻게? / 오개념: 반응 속도는 반응하는 동안 일정하다 X).
③ [모형] 계수와 속도 — N₂ + 3H₂ → 2NH₃ 입자 모형 반응기: 10 s 동안 NH₃ 분자 수 변화 카운터와 H₂, N₂ 감소 카운터, 몰 농도 변화 표시 → 물질별 변화율 비율 = 계수비(1 : 3 : 2) → v = 변화율 ÷ 계수. 미션: NH₃ 생성 속도가 주어졌을 때 H₂, N₂ 소모 속도 계산(task), 퀴즈(H₂ 소모 속도가 NH₃ 생성 속도의 몇 배? → 3/2배).
④ [설계] 측정 설계 — 반응 5가지 카드(H₂O₂ 분해, Mg + HCl, CaCO₃ + HCl, I₂ 소모 반응, 중화 반응)마다 알맞은 센서와 측정 시간 간격을 고르는 실험 설계(manual), 안전 카드(보안경, 장갑, 환기). 선택 이유를 한 줄 고르기. 미션: 3개 반응에 센서 맞게 고르기(task), 퀴즈(CaCO₃ + 2HCl 반응 속도를 질량 센서로 재는 까닭 → CO₂가 빠져나가 질량 감소).
애니메이션: 플라스크 기포와 주사기 눈금 approach, 시간–농도 그래프가 그려지며 구간 막대가 접선으로 수렴, 입자 반응기에서 N₂·H₂ 분자가 NH₃로 바뀌며 카운터 변화, 센서 연결선 점등.

## `hx-rate-law` · 🧾 반응 속도식
- 성취기준 [12물에04-01] 화학 반응 속도를 반응물의 농도로 표현할 수 있음을 알고, 자료 해석을 통하여 반응 속도식을 구할 수 있다.
- 카드 설명(desc): 농도를 하나씩 바꾼 초기 속도 자료에서 반응 차수를 찾아 v = k[A]^m[B]^n 속도식과 속도 상수를 구해요.
- 태그: 속도식, 반응 차수, 초기 속도법, 속도 상수 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 농도의 영향 · 초기 속도법 · 속도식 완성 · 차수의 의미

### 설계
범위: 반응 속도와 반응물 농도의 관계식 = 반응 속도식 v = k[A]ᵐ[B]ⁿ (k: 속도 상수, m, n: 각 반응물에 대한 차수, m + n: 전체 반응 차수). 실험 자료(초기 속도법: 한 반응물의 농도만 바꿔 처음 속도를 비교)에서 m, n 찾기 — 농도를 2배로 할 때 속도 변화가 1배 → 0차, 2배 → 1차, 4배 → 2차. 반응 차수는 반응식의 계수와 무관하며 실험으로만 결정. k의 단위는 차수에 따라 달라짐(1차 s⁻¹, 2차 M⁻¹s⁻¹, 3차 M⁻²s⁻¹). k는 온도·촉매에 따라 변하고 농도에는 무관.
다루지 않음: 적분 속도식, 메커니즘(단계 반응), 속도 결정 단계, 분수 차수·음수 차수.
자료 A — 2NO(g) + 2H₂(g) → N₂(g) + 2H₂O(g) (일정 온도), 초기 속도 v₀ (M/s): 실험 1 [NO] 0.10, [H₂] 0.10 → 1.2×10⁻³; 실험 2 [NO] 0.20, [H₂] 0.10 → 4.8×10⁻³ (4배 → NO 2차); 실험 3 [NO] 0.10, [H₂] 0.20 → 2.4×10⁻³ (2배 → H₂ 1차). 속도식 v = k[NO]²[H₂], k = 1.2×10⁻³ ÷ (0.10² × 0.10) = 1.2 M⁻²s⁻¹. 예측: [NO] 0.30, [H₂] 0.10 → 1.08×10⁻² M/s(9배). 계수는 H₂가 2인데 차수는 1 → 계수 ≠ 차수.
자료 B — A + B → C: 실험 [A], [B], v₀: (0.10, 0.10, 2.0×10⁻³), (0.20, 0.10, 4.0×10⁻³), (0.10, 0.30, 2.0×10⁻³) → v = k[A] (B는 0차), k = 2.0×10⁻² s⁻¹. 
자료 C — 2NO₂(g) → 2NO(g) + O₂(g): [NO₂] 0.10, 0.20, 0.30 → v₀ 5.4×10⁻³, 2.16×10⁻², 4.86×10⁻² → v = k[NO₂]², k = 0.54 M⁻¹s⁻¹.
탐구 질문: "반응물의 농도를 2배, 3배로 늘리면 반응 속도는 몇 배가 될까? 그 규칙을 식으로 쓸 수 있을까?"
① [관찰] 농도의 영향 — 가상 반응기에서 한 반응물 농도를 1, 2, 3배로 바꾸며 초기 속도를 막대로 비교. 반응기 3개(0차, 1차, 2차 반응물)의 막대가 각각 1배, 2배(3배), 4배(9배)로 변함. 입자 모형에서 충돌 수 카운터. 미션: 세 반응기에서 농도 2배 속도 변화 기록(task), 퀴즈(농도 2배 → 속도 4배인 반응물의 차수 → 2차).
② [탐구] 초기 속도법 — 자료 A 표에서 변인 하나만 바뀐 두 실험을 짝지어 비교(실험 1·2: NO만 2배 → 속도 4배; 실험 1·3: H₂만 2배 → 속도 2배)하는 '짝 고르기'. 차수 m = log(속도 비)/log(농도 비)는 쓰지 않고 '2배 → 몇 배' 대응표로 읽기. 미션: 실험 쌍 2개 고르고 NO, H₂ 차수 구하기(manual), 퀴즈(실험 2·3을 비교해서는 차수를 바로 구하기 어려운 까닭 → 두 농도가 동시에 바뀜).
③ [분석] 속도식 완성 — v = k[NO]²[H₂] 쓰기, 실험 1 값으로 k = 1.2 M⁻²s⁻¹ 계산(단위 확인), 새 농도에서 속도 예측(0.30, 0.10 → 1.08×10⁻²). 자료 B로 0차 반응물 확인(농도를 바꿔도 속도 일정 → 속도식에서 빠짐). 미션: 자료 A 속도식과 k 구하기(task), 예측 계산(task), 퀴즈(k는 농도가 바뀌면 달라진다 X → 온도 일정하면 일정).
④ [적용] 차수의 의미 — 자료 C로 연습 후 '반응식 계수 = 차수?' 점검: 2NO + 2H₂ (H₂ 계수 2, 차수 1), 2NO₂ (계수 2, 차수 2), 자료 B(B의 차수 0). 오개념 퀴즈 3개(계수를 그대로 차수로 쓰기, 전체 차수 합 구하기, 농도를 3배로 늘렸을 때 1차/2차 속도 배수). 미션: 자료 C 속도식 구하기(task), 퀴즈 2개.
애니메이션: 반응기 입자 밀도가 농도에 따라 변하며 충돌 섬광 카운터, 속도 막대 approach, 실험 표의 행 두 개가 하이라이트로 짝지어짐, 속도식 칸 채움 도장.

## `hx-half-life` · ⌛ 1차 반응의 반감기
- 성취기준 [12물에04-02] 1차 반응의 반감기가 반응물의 농도에 의존하지 않음을 이해하고, 1차 반응의 반감기가 활용되는 사례를 조사·발표할 수 있다.
- 카드 설명(desc): 농도–시간 자료에서 반감기를 읽어 1차 반응의 반감기는 처음 농도와 상관없이 일정하다는 것을 확인하고, 방사성 동위 원소와 약물 사례에 써요.
- 태그: 반감기, 1차 반응, 자료 해석, 탄소 연대 측정 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 반감기 찾기 · 농도와 반감기 · 남는 양 · 사례 발표

### 설계
범위: 반감기 t₁/₂ = 반응물의 농도가 처음의 절반으로 줄어드는 데 걸리는 시간. 1차 반응(v = k[A])의 반감기는 처음 농도와 관계없이 일정하고, 속도 상수 k가 클수록 짧다. 해설: 적분 속도식 유도는 다루지 않으며 자료 해석(농도–시간 그래프·표)으로 반감기를 찾는다 → ln, 지수 식, t₁/₂ = 0.693/k 사용하지 않음. 남은 양 = 처음 × (1/2)ⁿ (n = 경과 시간 ÷ 반감기). 1차 반응이 아닌 반응(0차·2차)은 반감기가 일정하지 않다는 대비만 자료로 제시. 사례 조사·발표: 방사성 동위 원소의 붕괴(1차 반응과 같은 규칙), 약물의 체내 반감기.
자료 1(1차 반응 A → B, 25 °C): [A] t = 0, 40, 80, 120, 160 s → 1.00, 0.50, 0.25, 0.125, 0.0625 M → t₁/₂ = 40 s. 처음 농도 2.00 M (2.00 → 1.00 : 40 s), 0.40 M (0.40 → 0.20 : 40 s) 에서도 40 s. 반감기 n회 후 남는 비율 50, 25, 12.5, 6.25 %. k 큰 반응 사례: 반감기 10 s 반응 vs 100 s 반응.
자료 2(대비): 2차 반응 — 1.00 → 0.50 M: 40 s, 0.50 → 0.25: 80 s, 0.25 → 0.125: 160 s(반감기가 계속 2배). 0차 반응 — 1.00 → 0.50: 40 s, 0.50 → 0.25: 20 s, 0.25 → 0.125: 10 s(반감기가 점점 절반). 분류 게임용 곡선 3개.
이유 설명(유도 없이): 1차 반응은 속도가 농도에 비례 → 농도가 절반이 되면 속도도 절반 → '남은 양의 절반을 쓰는 데 걸리는 시간'이 처음과 같다.
사례 자료: 탄소-14 반감기 5730 년(유물 속 ¹⁴C 비율 25 % → 2회 → 11460 년, 12.5 % → 3회 → 17190 년). 아이오딘-131 8 일(갑상선 치료·검사): 24 일 후 12.5 %, 40 일 후 3.1 %. 약물(예: 반감기 6 시간): 24 시간 후 6.25 %가 남음. 우라늄-238 약 45억 년(암석 나이). 과산화수소 분해 등 1차 화학 반응도 같은 형식.
탐구 질문: "반응이 절반 진행되는 데 걸리는 시간이 시작할 때 양과 상관이 없는 반응이 있을까?"
① [분석] 반감기 찾기 — 자료 1 곡선(농도–시간)에서 농도가 1.00 → 0.50 → 0.25로 줄어드는 시간 간격을 가로 막대로 표시. 반감기 구하는 법: 절반이 되는 시각 읽기. 미션: 곡선에서 1.00→0.50, 0.50→0.25 시간 구하기(task), 퀴즈(처음 1.00 M에서 0.25 M까지 걸리는 시간 → 80 s).
② [탐구] 농도와 반감기 — 처음 농도를 2.00 M, 1.00 M, 0.40 M으로 바꾸어 같은 반응 곡선 3개를 겹침 → 모두 40 s 간격에서 절반이 됨(곡선은 세로 크기만 다른 상사). 이어서 곡선 3개(1차, 2차, 0차)를 분류: 반감기가 일정하면 1차. 속도–농도 모형(입자 수가 줄면 속도도 같은 비율로 감소)으로 이유 설명. 미션: 처음 농도 3가지에서 반감기 비교(task), 곡선 분류(manual), 퀴즈(1차 반응의 반감기는 처음 농도가 클수록 길다 X).
③ [예측] 남는 양 — 시간 슬라이더로 반감기 횟수 n 선택해 남는 입자(그림 100개 중) 확인, (1/2)ⁿ 비율. 문제: 이 반응에서 120 s 후 남는 비율(12.5 %), 6.25 %가 되는 시간(160 s), k가 2배인 반응의 반감기(짧아짐: 약 20 s). 미션: 남은 양 3문제(task), 퀴즈(반감기가 지나면 나머지 절반이 모두 반응한다 X).
④ [발표] 사례 발표 — 사례 카드 5장(탄소 연대 측정, 갑상선 질환 I-131, 약물 복용 간격, 우라늄 지질 연대, 식품의 보관 기한) 중 2장을 골라 반감기와 남은 비율 표를 완성하고 발표 틀(사례·반감기·활용·한계)을 채움. 계산 예: 탄소-14 25 % → 11460 년. 미션: 사례 2개 완성(manual), 퀴즈(약물 투여 간격을 반감기에 맞추어 정하는 까닭).
애니메이션: 농도 곡선이 그려지며 절반 높이 가로선과 시간 막대 tween, 입자 100개가 반감기마다 절반씩 사라짐(fade), 세 곡선 겹침, 탄소-14 유물 비율 막대와 연도 눈금, 발표 카드 뒤집기.

## `hx-collision` · 💥 유효 충돌과 활성화 에너지
- 성취기준 [12물에04-03] 화학 반응에서 유효 충돌과 활성화 에너지의 의미를 알고, 화학 반응이 일어나기 위한 조건에 관심을 가질 수 있다.
- 카드 설명(desc): 분자 충돌이 모두 반응으로 이어지지 않는 까닭을 방향과 에너지 두 조건으로 보고, 활성화 에너지를 에너지 도표에서 읽어요.
- 태그: 유효 충돌, 활성화 에너지, 에너지 도표, 충돌 이론 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 충돌 모형 · 유효 충돌 · 에너지 장벽 · 반응 조건

### 설계
범위: 화학 반응은 입자(분자)의 충돌로 일어나지만 모든 충돌이 반응으로 이어지지는 않는다. 유효 충돌 = 반응이 일어나는 충돌: 조건 두 가지 — ① 알맞은 방향(반응하는 원자 쪽이 맞부딪힘), ② 활성화 에너지 이상의 에너지. 활성화 에너지(Eₐ) = 반응이 일어나기 위해 반응물이 넘어야 하는 최소 에너지 장벽. 에너지 도표(반응 경로–에너지)에서 Eₐ(정반응) = 반응물 수준에서 꼭대기까지의 높이, ΔH = 생성물 수준 − 반응물 수준, Eₐ(역반응) = Eₐ(정반응) − ΔH. 꼭대기의 불안정한 중간 상태를 '활성화물(전이 상태)'이라 이름만 소개. 반응이 일어나기 위한 조건에 관심: 점화, 마찰, 가열, 빛.
다루지 않음: 충돌 이론의 정량 식(충돌 빈도 × 방향 인자 × e^(−Eₐ/RT)), 반응 메커니즘, 아레니우스 식.
자료: 상온의 기체 분자 하나는 초당 약 10¹⁰회 충돌. 모든 충돌이 반응한다면 반응은 순식간에 끝나지만 실제로는 대부분 충돌이 튕겨나감(예시: Eₐ ≈ 100 kJ/mol 반응은 실온에서 충돌 약 10¹⁷~10¹⁸회 중 1회가 에너지 조건을 충족 — 예시 값으로 표기). 반응 예시 CO(g) + NO₂(g) → CO₂(g) + NO(g): C 쪽이 NO₂의 O에 닿아야 반응(C가 N쪽에 부딪히면 튕김). 에너지 도표 두 개: 발열 Eₐ = 50 kJ, ΔH = −30 kJ → Eₐ(역) = 80 kJ. 흡열 Eₐ = 90 kJ, ΔH = +40 kJ → Eₐ(역) = 50 kJ.
일상: 성냥은 마찰열이 활성화 에너지를 공급하는 점화, 메테인과 산소 혼합 기체는 불꽃 없이는 반응하지 않음(자발적이지만 Eₐ 장벽, 단원 51), 상온의 H₂와 O₂ 혼합 기체는 안정, 종이는 불을 붙여야 타고 한번 타면 반응열이 다음 분자의 Eₐ를 공급.
탐구 질문: "분자들이 쉴 새 없이 부딪히는데도 왜 대부분의 충돌은 반응을 일으키지 못할까?"
① [모형] 충돌 모형 — 반응기 속 분자 입자들이 움직이며 충돌 카운터가 올라가고, 반응이 일어난 충돌과 튕긴 충돌이 색으로 구별. 충돌 수는 매우 큰데 반응한 수는 훨씬 적음(10 s 동안 충돌 100,000회 중 반응 20회). 미션: 충돌 카운터 읽기(task), 퀴즈(충돌하면 반드시 반응한다 X → 대부분 튕겨 나감).
② [탐구] 유효 충돌 — 두 분자(CO와 NO₂)를 끌어 방향과 속도를 정해 충돌시키는 실험: 같은 속도에서 방향이 맞을 때/틀릴 때, 같은 방향에서 속도가 느릴 때/빠를 때의 결과. 두 조건이 모두 맞을 때만 반응(새 결합이 생김). 미션: 4가지 조합 시도(task), 퀴즈(빠르게 부딪히기만 하면 반응한다 X → 방향도 필요).
③ [모형] 에너지 장벽 — 공이 언덕을 넘는 비유 + 에너지 도표: 충돌 에너지가 Eₐ보다 크면 장벽을 넘음. 발열(Eₐ 50, ΔH −30), 흡열(Eₐ 90, ΔH +40) 도표에서 Eₐ와 ΔH를 화살표로 읽고 역반응의 Eₐ 구하기. 미션: 두 도표에서 Eₐ, ΔH 읽기(task), 역반응 Eₐ 계산(task), 퀴즈(발열 반응인데 가열이 필요한 까닭 → Eₐ 장벽).
④ [적용] 반응 조건 — 사례 카드 6장(성냥 점화, 메테인 불꽃 점화, 철이 서서히 녹슮, 상온의 H₂ + O₂ 혼합, 광합성에 빛, 폭죽)에서 Eₐ를 어떻게 공급하는지 연결(manual). Eₐ가 큰 반응은 상온에서 느리고 작은 반응은 빠름 비교(Eₐ 슬라이더로 시뮬레이션: 같은 충돌 수에서 반응 횟수 변화). 미션: 카드 연결(manual), Eₐ 슬라이더로 반응 횟수 비교(task), 퀴즈(ΔH가 큰 음수인 반응은 항상 빠르다 X).
애니메이션: 분자 입자 충돌(튕김/결합 spring), 방향이 맞을 때 결합 형성 tween, 에너지 도표에서 공 입자가 언덕을 오르다 되돌아가거나 넘어감, 활성화물 순간 글로우, Eₐ 슬라이더에 따라 장벽 높이 approach.

## `hx-rate-factors` · 🌡️ 농도·온도와 반응 속도
- 성취기준 [12물에04-04] 농도, 온도, 촉매에 따라 반응 속도가 달라짐을 이해하고, 일상생활에서 각각의 예를 찾아 화학의 유용성을 인식할 수 있다.
- 카드 설명(desc): 시계 반응 실험으로 농도와 온도가 반응 속도에 미치는 영향을 측정하고, 충돌 횟수와 활성화 에너지 이상 분자의 비율로 설명해요.
- 태그: 농도, 온도, 시계 반응, 에너지 분포 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 농도 효과 · 온도 효과 · 충돌로 설명 · 생활 속 예

### 설계
범위: 농도·온도에 따라 반응 속도가 달라짐을 실험으로 확인하고 입자 모형으로 설명(촉매는 다음 차시). 농도↑ → 단위 부피 속 입자 수↑ → 단위 시간당 충돌 횟수↑ → 유효 충돌 횟수↑ → 속도↑ (속도식에서 v = k[A]ᵐ…). 온도↑ → 평균 운동 에너지↑ → 활성화 에너지 이상의 에너지를 가진 분자의 비율이 크게 증가(충돌 횟수 증가는 부수적) → 유효 충돌 비율↑ → 속도↑(속도 상수 k 증가). 에너지 분포 곡선(가로: 분자의 운동 에너지, 세로: 분자 수 비율)에서 Eₐ 오른쪽 면적이 온도가 높을수록 훨씬 커짐. 탐구 활동: 농도·온도와 반응 속도의 관계를 탐구하는 실험.
다루지 않음: 아레니우스 식 계산, 접촉 면적(고체 가루) 효과(퀴즈 보조 카드 한 장으로만), 반응 차수와 농도의 관계 반복.
실험 자료(Na₂S₂O₃ + 2HCl → 2NaCl + S↓ + SO₂ + H₂O: 황 앙금으로 흐려져 바닥의 × 표시가 안 보이는 데까지 걸린 시간 t, 속도 ∝ 1/t): 농도 20 °C — Na₂S₂O₃ 0.20 M 20 s, 0.15 M 27 s, 0.10 M 40 s, 0.05 M 80 s → 속도(1/t) 0.050, 0.037, 0.025, 0.0125 s⁻¹ (농도에 비례, 0.10 M 기준 농도 2배 → 시간 1/2). 온도 0.10 M — 10 °C 160 s, 20 °C 80 s, 30 °C 40 s, 40 °C 20 s, 50 °C 10 s → 10 °C 상승마다 속도 약 2배.
충돌 설명 수치(예시, Eₐ ≈ 50 kJ/mol): 온도 10 K 상승(298 K → 308 K) 시 분자의 충돌 횟수는 약 2 %(평균 속력 ∝ √T → 1.017배) 늘지만 Eₐ 이상 에너지를 가진 분자 비율은 약 2배(예: 3 % → 6 %) → 속도 증가는 대부분 문턱 에너지 이상 분자 비율 증가 때문.
안전: SO₂가 소량 발생하므로 환기가 되는 곳에서 실험하고 보안경을 착용, 폐액은 중화 후 폐수 처리. 생활 사례: 냉장·냉동 보관(온도↓ → 부패 반응 느림), 압력솥(온도↑), 높은 산에서 밥이 설익음(끓는점↓), 산소 100 % 환경에서 불이 더 격렬(농도↑), 밀가루 먼지 폭발·코팅 실험(농도·표면적 보조), 체온이 오르면 대사 증가, 더운 날 우유가 빨리 상함.
탐구 질문: "같은 반응인데도 농도를 높이거나 온도를 올리면 왜 더 빨라질까?"
① [실험] 농도 효과 — 시계 반응 모의 장치: 비커 바닥의 × 표시, Na₂S₂O₃ 농도 선택(0.05~0.20 M) 후 HCl 첨가 → 용액이 서서히 흐려져 × 표시가 사라지는 시간 측정. 농도–1/t 그래프에 점 4개 → 원점을 지나는 직선. 입자 돋보기: 농도가 높을수록 입자가 촘촘해 충돌 카운터가 늘어남. 미션: 농도 4가지 시간 측정(task), 그래프 점 찍기(task), 퀴즈(농도를 2배로 하면 흐려지는 시간이 1/2이 되는 까닭).
② [실험] 온도 효과 — 같은 반응을 10~50 °C 수조에서 측정, 온도–시간(또는 1/t) 그래프: 10 °C 상승마다 시간이 1/2로 단축(속도 약 2배). 온도계와 입자 속도(화살표 길이)가 함께 커짐. 미션: 온도 5개 측정(task), 퀴즈(30 °C에서 시간이 40 s이면 50 °C에서 예상 시간 → 약 10 s).
③ [모형] 충돌로 설명 — 에너지 분포 곡선 + Eₐ 선: 온도 슬라이더를 올리면 곡선이 오른쪽으로 납작해지며 Eₐ 오른쪽 면적(색)이 커짐(3 % → 6 %). 같은 시각 입자 반응기에서 총 충돌 횟수 증가는 작은데 유효 충돌 카운터는 크게 증가. 농도는 곡선의 높이(전체 입자 수)를 키워 면적이 비례해 커짐. 미션: 온도 +10 K에서 Eₐ 이상 비율 읽기(task), 퀴즈(온도가 올라 속도가 빨라지는 가장 큰 이유 → Eₐ 이상 분자의 비율 증가 / 오개념: 충돌 횟수 증가가 주 원인 X).
④ [적용] 생활 속 예 — 사례 카드 8장(냉장고, 압력솥, 산소 호흡기 속 불, 높은 산에서의 밥, 여름철 음식 부패, 불씨에 바람 불기, 열대 vs 극지방 식물 성장, 체온 상승)을 '농도 효과/온도 효과' 상자에 분류(manual). 퀴즈 2개(불씨를 부채질해 일으키는 원리 → 산소 농도↑, 냉동실에 음식을 보관하는 이유).
애니메이션: 비커 용액이 흐려지며 × 표시가 사라지는 fade, 시간 타이머 롤링, 입자 속도와 충돌 섬광(농도·온도 슬라이더에 연동), 에너지 분포 곡선 변형 tween과 Eₐ 오른쪽 면적 하이라이트, 그래프 점이 날아와 직선에 놓임.

## `hx-catalyst` · 🧬 촉매와 반응 속도
- 성취기준 [12물에04-04] 농도, 온도, 촉매에 따라 반응 속도가 달라짐을 이해하고, 일상생활에서 각각의 예를 찾아 화학의 유용성을 인식할 수 있다.
- 카드 설명(desc): 촉매와 효소가 활성화 에너지를 낮춰 반응을 빠르게 하는 모습을 실험과 에너지 도표로 이해하고, 환경 문제를 해결하는 데 어떻게 쓰이는지 찾아봐요.
- 태그: 촉매, 효소, 활성화 에너지, 환경 문제 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 촉매 실험 · 에너지 도표 · 효소 · 환경과 촉매

### 설계
범위: 촉매 = 자신은 소모되지 않고 반응의 활성화 에너지를 낮추는 새 경로를 제공해 반응 속도를 빠르게 하는 물질. 도표: 촉매를 쓰면 Eₐ가 낮아지고(정·역반응 모두), ΔH와 반응물·생성물의 에너지는 변하지 않음(생성되는 양·평형 위치는 그대로, 평형에 도달하는 시간만 짧아짐: 화학 평형 연결). 효소 = 생체 촉매(기질 특이성, 최적 온도·pH, 고온에서 변성). 고려 사항: 생태전환교육과 연계해 토양·수질·대기 오염 등 환경 문제를 촉매·효소로 해결하는 사례(자동차 삼원 촉매, 폐수 처리 미생물 효소, 효소 세제, 광촉매 TiO₂ 등)를 다루고 지속가능한 지구에 대한 책임감을 갖게 한다. 농도·온도 차시와 함께 04-04 의 세 가지 요인(농도, 온도, 촉매) 정리 표를 완성.
다루지 않음: 촉매의 반응 메커니즘(중간체), 균일/불균일 촉매 분류의 상세, 미하엘리스–멘텐 식.
자료: 3 % H₂O₂ 10 mL의 분해(2H₂O₂ → 2H₂O + O₂)에서 30 s 동안 발생한 O₂ 부피 — 촉매 없음 0 mL(거의 변화 없음), KI 용액 12 mL, MnO₂ 0.50 g 25 mL, 간 조각(카탈레이스 효소) 45 mL. 반응 후 MnO₂ 질량 0.50 g(변화 없음, 소모되지 않음). 에너지 도표: Eₐ(촉매 없음) 75 kJ → Eₐ(촉매) 50 kJ, ΔH = −196 kJ(2H₂O₂ 분해, 변함 없음), Eₐ(역) = 271 → 246 kJ. 에너지 분포 곡선에서 낮아진 Eₐ 오른쪽 면적이 커져 유효 충돌 비율↑.
효소 활성(카탈레이스의 상대 속도) — 온도 10, 20, 30, 37, 45, 55, 65 °C → 1.0, 2.0, 3.8, 5.0(최대), 3.5, 0.5, 0(변성 후 활성 상실). 일반 촉매는 온도가 오르면 계속 빨라지지만 효소는 최적 온도(사람 약 37 °C) 이후 급감.
환경 사례: 자동차 배기가스 삼원 촉매(Pt, Pd, Rh): 2CO + 2NO → 2CO₂ + N₂ 등으로 유해 기체(CO, NO, 미연소 탄화수소)를 CO₂, N₂, H₂O 로 전환. 효소 세제: 낮은 온도(30 °C)에서도 단백질·지방 얼룩 분해 → 에너지와 세제 절약. 광촉매 TiO₂: 빛을 받아 유기 오염 물질 분해. 폐수·토양 처리 미생물 효소. 플라스틱 분해 효소(연구 중). 한계 카드: 귀금속 자원, 촉매 독(납), 효소는 온도·pH에 민감.
탐구 질문: "상온에서는 거의 일어나지 않던 반응이 소량의 가루나 간 조각으로 갑자기 빨라지는 까닭은 무엇일까?"
① [실험] 촉매 실험 — H₂O₂ 분해 장치: 촉매 없음/KI/MnO₂/간 조각 4가지 선택, 기체 부피 센서 그래프로 O₂ 발생 비교(30 s 동안 0, 12, 25, 45 mL). 반응 후 MnO₂를 걸러 질량 측정(0.50 g → 0.50 g). 미션: 4가지 조건 실험(task), MnO₂ 질량 확인(task), 퀴즈(촉매는 반응하면서 소모된다 X / 촉매를 넣으면 O₂가 더 많이 생긴다 X → 속도만 변함: 같은 양의 H₂O₂면 최종 부피 같음).
② [모형] 활성화 에너지 — 에너지 도표에서 촉매 유무를 토글: Eₐ가 75 → 50 kJ 로 낮아지고 ΔH(반응물·생성물 수준)는 그대로. 에너지 분포 곡선에서 Eₐ 오른쪽 면적(유효 충돌 비율) 증가. 정반응·역반응이 함께 빨라지므로 평형 도달 시간만 단축됨을 hc-dynamic-eq 의 평형 그래프로 확인(평형 농도는 그대로). 미션: 토글로 Eₐ 변화 읽기(task), ΔH 변화 확인(task), 퀴즈(촉매가 반응의 ΔH를 바꾸나 → 바꾸지 않음 / 평형 상수는? → 그대로).
③ [분석] 효소 — 효소의 기질 특이성(자물쇠–열쇠 모형: 기질이 활성 부위에 꼭 맞을 때만 반응), 온도 슬라이더 10~65 °C에서 상대 속도 그래프(37 °C 최대, 55 °C 이후 급감, 열에 의한 모양 변형(변성)). 일반 촉매 곡선(MnO₂)과 비교. 미션: 최적 온도 찾기(task), 변성 후 냉각해도 회복 안 됨 확인(task), 퀴즈(효소는 높은 온도에서 더 빠를 것이다 X: 변성).
④ [적용] 환경과 촉매 — 환경 문제 카드(배기가스, 폐수 속 유기물, 세탁 폐수, 실내 공기 오염, 플라스틱 폐기물)를 해결 방법 카드(삼원 촉매, 미생물 효소, 효소 세제, 광촉매, 플라스틱 분해 효소)에 연결(manual), 각 방법의 한계 카드 선택. 마지막에 04-04 정리표(농도↑: 입자 밀도↑ → 충돌↑, 온도↑: Eₐ 이상 분자 비율↑, 촉매: Eₐ↓) 완성(manual). 미션: 문제–해결 연결(manual), 정리표 완성(manual), 퀴즈(삼원 촉매가 공기를 깨끗이 하는 방식 → 유해 기체를 무해한 기체로 빠르게 전환).
애니메이션: 플라스크 O₂ 기포와 주사기 눈금, MnO₂ 알갱이 반응 후 그대로, 에너지 도표의 언덕이 낮아지는 tween, 에너지 분포 곡선 면적 하이라이트, 효소 활성 부위에 기질이 맞물림, 높은 온도에서 효소가 풀려 모양 변형, 자동차 배기관 안 촉매에서 유해 분자가 무해 분자로 변환.
