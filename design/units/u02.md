- 카드 설명(desc): 가상 현미경으로 세포를 관찰하고, 세포 구조의 역할과 세포 모양으로 하는 일을 추리해요.
- 태그: 세포, 현미경, 세포 소기관 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 현미경 · 세포 구조 · 구조와 기능 · 모양과 기능

### 설계
범위(해설): 세포 구조는 세포벽, 세포막, 핵, 엽록체, 미토콘드리아만. 세포의 특징은 생명 활동을 유추할 수 있는 세포(적혈구, 신경세포, 상피세포).

② [탐구] 세포 구조 찾기 — 확대된 식물·동물 세포 그림(입체감, 세포질 흐름 애니메이션). 탭하면 이름 라벨. 미션: 식물 세포에서 5가지 찾기, 동물 세포에 없는 2가지(세포벽, 엽록체) 고르기, 퀴즈(엽록체가 있는 세포는?).
③ [설명] 구조와 기능 — 각 구조를 탭하면 기능 애니메이션: 핵(유전 물질, 생명 활동 조절 — 신호 파동), 세포막(물질 출입 조절 — 작은 입자 통과/큰 입자 막힘), 세포벽(모양 유지·보호 — 식물 세포 단단함), 엽록체(광합성 — 빛 입자 흡수→양분 반짝임), 미토콘드리아(양분을 분해해 에너지를 얻음 — 에너지 불꽃). 미션: 기능 카드 끌어 맞추기(manual), 퀴즈.
④ [적용] 모양과 기능 — 적혈구(가운데 오목한 원반: 산소 운반에 유리, 좁은 혈관 통과), 신경세포(긴 돌기: 자극을 멀리 전달), 상피세포(납작하고 빽빽: 몸 표면 보호). 미션: 세포→하는 일 연결, 퀴즈("세포는 모양이 모두 같다" 오개념).

## `m1-organization` · 🧩 생물의 구성 단계
- 성취기준 [9과02-02] 생물의 유기적 구성 단계를 이해하고, 동물과 식물을 비교하여 분석할 수 있다.
- 카드 설명(desc): 세포가 모여 조직, 기관을 거쳐 하나의 생물이 되는 구성 단계를 확대·축소하며 알아보고 동물과 식물을 비교해요.
- 태그: 조직, 기관, 기관계, 조직계 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 확대 탐험 · 동물 · 식물 · 비교

### 설계
범위: 동물 = 세포 → 조직 → 기관 → 기관계 → 개체 / 식물 = 세포 → 조직 → 조직계 → 기관 → 개체. 식물에는 기관계가 없고 조직계(표피·관다발·기본 조직계)가 있다. 식물 기관: 뿌리·줄기·잎(영양 기관), 꽃·열매(생식 기관).
탐구 질문: "수많은 세포는 어떻게 모여 하나의 생물이 될까?"
① [관찰] 확대 탐험 — 사람과 나무를 한 단계씩 확대/축소하는 줌 슬라이더(개체 ↔ 세포). 단계 이름 라벨이 나타남. 미션: 사람을 세포 단계까지 확대하기, 퀴즈(모든 생물은 세포에서 시작).
② [탐구] 동물의 구성 단계 — 카드 정렬: 근육 세포 → 근육 조직 → 위 → 소화계 → 사람(정답 시 블록이 차례로 합쳐지는 애니메이션). 조직 예(상피·근육·신경·결합 조직), 기관계 예(소화계·순환계·호흡계·배설계·신경계). 미션: 순서 맞추기(manual), 분류 퀴즈("심장은 어느 단계?" → 기관).
③ [모형] 식물의 구성 단계 — 잎 세포 → 표피 조직 → 표피 조직계 → 잎 → 식물; 관다발 조직계(물관·체관) 강조. 미션: 순서 맞추기, 퀴즈(식물에만 있는 단계: 조직계 / 식물에 없는 단계: 기관계).
④ [적용] 비교 — 동물과 식물 구성 단계 비교표 채우기, 분류 게임(심장·혈액?·꽃·관다발 조직계 등 → 단계). 혈액처럼 애매한 예는 피하고 확실한 예만.
애니메이션: 연속 줌(scale tween)과 단계 라벨 전환, 카드가 블록으로 쌓이며 합쳐지는 효과.

## `m1-variation` · 🐞 변이와 생물다양성
- 성취기준 [9과02-03] 생물다양성을 이해하고, 변이와 생물다양성의 관계를 추론할 수 있다.
- 카드 설명(desc): 같은 종 사이의 변이를 관찰하고, 환경에 따라 살아남는 변이가 달라져 생물다양성이 생기는 과정을 추론해요.
- 태그: 생물다양성, 변이, 환경 적응 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 다양성 · 변이 · 환경과 변이 · 다양성 형성

### 설계
범위: 생물다양성 = 일정한 지역에 사는 생물의 다양한 정도: 유전적 다양성(같은 종 안 형질의 다양함), 종 다양성, 생태계 다양성. 변이 = 같은 종의 개체 사이에 나타나는 형질의 차이. 변이와 생물다양성 관계를 추론(환경에 알맞은 변이를 가진 개체가 더 많이 살아남아 자손을 남기고, 오랜 시간 쌓이면 서로 다른 생물이 됨). '자연선택'·'진화' 같은 용어는 쓰지 않고 '환경에 적응'으로 설명.
탐구 질문: "같은 종류의 생물인데 왜 생김새가 조금씩 다를까?"
① [관찰] 생물다양성의 세 가지 — 장면(바지락 껍데기 무늬들 / 숲·갯벌·사막 / 여러 종의 곤충) 탭 → 유전적·생태계·종 다양성 분류(manual), 퀴즈.
② [탐구] 변이 관찰 — 무당벌레 30마리(날개 점 개수·무늬 다름)를 탭해 점 개수별 막대그래프 채우기(task: 20마리 이상 기록), 퀴즈(변이 뜻; 함정: "다른 종끼리의 차이").
③ [실험] 환경과 변이 — 섬 2곳 모형: A섬(크고 단단한 씨앗) / B섬(작은 씨앗·곤충). 부리 두께가 다양한 새 무리를 넣고 '세대 진행' 버튼 → 먹이에 맞는 부리를 가진 새가 더 많이 살아남아 자손(부모와 비슷한 부리 ±작은 변이). 세대별 부리 두께 분포 그래프가 두 섬에서 서로 다르게 변함(애니메이션). 미션: 20세대 진행(task), 퀴즈(왜 섬마다 부리가 달라졌나).
④ [적용] 다양성 형성 — 오개념 퀴즈: "목이 긴 기린은 높은 잎을 먹으려 노력해서 목이 길어졌다"(X, 이미 있던 변이 중 환경에 맞는 것이 살아남음), 사례 적용 퀴즈.
애니메이션: 새가 씨앗을 쪼는 동작, 세대 전환 페이드, 분포 막대가 부드럽게 이동.

## `m1-classification` · 🗂️ 종과 생물의 분류
- 성취기준 [9과02-04] 종의 개념과 분류 체계를 이해하고, 생물을 계 수준에서 분류할 수 있다.
- 카드 설명(desc): 생물학적 종의 뜻을 알고, 분류 단계를 쌓아 본 뒤 여러 생물을 5계로 분류해요.
- 태그: 종, 분류 단계, 5계 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 종의 뜻 · 분류 단계 · 5계 기준 · 계 분류

### 설계
범위(해설): 종은 생물학적 종 개념만(자연 상태에서 짝짓기를 하여 생식 능력이 있는 자손을 낳을 수 있는 무리), 분류 체계는 5계(원핵생물계, 원생생물계, 균계, 식물계, 동물계)만.
탐구 질문: "지구의 수많은 생물을 어떻게 정리할 수 있을까?"
① [관찰] 종의 뜻 — 짝짓기 실험 모형: 말×당나귀 → 노새(생식 능력 없음 → 말과 당나귀는 다른 종), 진돗개×삽살개 → 생식 능력 있는 강아지(같은 종). 미션: 두 쌍 실험(task), 퀴즈(생김새가 비슷하면 같은 종? 함정).
② [탐구] 분류 단계 — 종 < 속 < 과 < 목 < 강 < 문 < 계, 상자가 겹겹이 커지는 애니메이션. 호랑이 예(표범속·고양잇과·식육목·포유강·척삭동물문·동물계). 미션: 단계 순서 맞추기, 퀴즈(가장 많은 생물을 포함하는 단계).
③ [설명] 5계 분류 기준 — 이분 검색표 흐름도 애니메이션: 핵막이 없다 → 원핵생물계(대장균 등 세균) / 핵막이 있다 → 광합성·세포벽·다세포·운동 여부 → 원생생물계(짚신벌레, 아메바, 미역·김·다시마 — 조직 발달 X), 균계(곰팡이, 버섯, 효모 — 광합성 X, 균사), 식물계(광합성, 세포벽, 기관 발달), 동물계(광합성 X, 세포벽 X, 운동). 미션: 기준 카드 순서 맞추기, 퀴즈(버섯은 식물? 함정).
④ [적용] 계 분류 게임 — 10장의 생물 카드(대장균, 짚신벌레, 미역, 푸른곰팡이, 표고버섯, 효모, 고사리, 소나무, 해파리, 참새)를 5계 상자로 끌어 넣기(manual, 틀린 카드는 흔들림 + 이유).
애니메이션: 상자 겹치기 줌, 카드 끌기 들림·스냅(outBack), 검색표 경로 하이라이트.

## `m1-biodiversity` · 🌱 생물다양성의 보전
- 성취기준 [9과02-05] 생물다양성 보전의 필요성을 이해하고, 생물다양성 유지를 위한 방안을 조사하고 실천할 수 있다.
- 카드 설명(desc): 먹이 그물 놀이로 생물다양성이 줄어들 때의 문제를 확인하고, 생물다양성을 지키는 방안을 찾아 실천해요.
- 태그: 생물다양성 보전, 먹이 그물, 실천 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 먹이 그물 · 위협 요인 · 보전 방법 · 실천

### 설계
범위: 생물다양성 보전의 필요성(생태계 안정, 자원, 생명 존중), 위협 요인(서식지 파괴, 외래종 유입, 남획, 환경 오염, 기후변화), 보전 방안(개인·사회). 탐구 활동 '생물다양성 보전 놀이', 생태전환교육.
탐구 질문: "생물 한 종이 사라지면 생태계에는 어떤 일이 생길까?"
① [관찰] 먹이 그물 — 단순한 생태계(종 4개)와 복잡한 생태계(종 10개) 먹이 그물. 한 종을 탭해 없애면 연결된 종들의 개체 수 그래프가 변함. 미션: 두 생태계에서 같은 종 제거해 비교(task), 퀴즈(다양할수록 안정).
② [탐구] 위협 요인 — 시나리오 카드(숲에 도로 → 서식지 단절, 황소개구리·뉴트리아·큰입배스 → 외래종, 무분별한 포획 → 남획, 폐수 → 오염, 수온 상승 → 기후변화) → 원인 맞히기(manual), 개체 수 감소 애니메이션.
③ [설명] 보전 방법 — 같은 시나리오에 해결책 적용: 생태 통로, 보호 구역 지정, 외래종 관리, 종자 은행·복원 사업, 오염 줄이기 → 개체 수 회복 애니메이션. 미션: 해결책 짝 맞추기, 퀴즈.
④ [적용] 실천 — 개인(일회용품 줄이기, 쓰레기 분리, 외래 생물 함부로 버리지 않기)과 사회(법·국제 협약, 보호 구역) 분류 게임 + 나의 실천 다짐 선택.
애니메이션: 먹이 그물 노드가 흔들리며 사라짐, 연결선이 끊기는 효과, 개체 수 곡선 부드러운 변화.
