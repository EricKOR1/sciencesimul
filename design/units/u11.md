## 개념 위계와 차시 흐름
■ 중2 Ⅳ. 물질의 구성 — 개념 위계와 차시 순서

[선수 개념]
• 초3~4 '물체와 물질'·'물질의 세 가지 상태': 물체는 물질로 이루어지고, 물질은 고체·액체·기체로 존재한다.
• 초5~6 '용해와 용액'(성취기준 적용 시 고려 사항의 연계 단원): 용질이 눈에 보이지 않을 만큼 작게 나뉘어 고르게 퍼진다 → '물질은 아주 작은 입자로 이루어져 있다'는 생각의 바탕. 같은 학년군의 지시약(페놀프탈레인 용액은 염기성에서 붉은색)·연소(산소는 물질이 타는 것을 돕는다) → 1차시 기체 확인, 3차시 동족 원소 실험을 해석하는 도구.
• 중1 Ⅳ '물질의 상태 변화'[9과04-01~03]·Ⅵ '기체의 성질': 물질은 운동하는 입자로 이루어져 있고 입자 모형으로 나타낸다 → 이 단원에서 그 '입자'가 원자·분자·이온임을 구체화한다.
• 중2 Ⅰ '물질의 특성'[9과08-02]: 순물질과 혼합물 → 1차시에서 순물질을 다시 원소와 화합물로 나눈다.

[단원 차시 순서와 연결]
1차시 💧 원소와 화합물 [9과11-01] (신규) — 물의 전기 분해(물은 수소와 산소로 분해된다) → 더 이상 분해되지 않는 기본 성분 = 원소, 두 가지 이상의 원소가 결합한 물질 = 화합물(분해 실험으로 분류, 혼합물과 구별) → 원소 기호·화학식(원소의 종류와 원자 수) → 지구 환경 물질(CH₄, O₃, CO₂, SO₂, N₂, Hg)을 화학식으로 쓰고 원소·화합물로 구분(생태전환교육). 원자는 '원소를 이루는 아주 작은 입자' 수준으로만 나오고, '분자'라는 낱말은 쓰지 않는다.
2차시 ⚛️ 원자의 구조 [9과11-02] (기존) — 1차시에서 처음 만난 원자의 속: 원자핵(양성자·중성자)과 전자, 원자는 전기적으로 중성, 양성자 수가 원소를 결정. 1차시의 거시적 정의(분해되지 않는 기본 성분)를 미시적 정체(양성자 수)로 설명한다. (질량수·동위 원소 제외)
3차시 🗂️ 주기율표 [9과11-03] (신규) — 2차시의 '양성자 수'를 기준으로 원소를 배치(원자 번호 = 양성자 수) → 주기(가로줄)·족(세로줄) → 같은 족 원소의 유사성 탐구(1족: 물과의 반응, 18족: 안정성, 다른 족 원소와 비교) → 주기율표에서 성질이 비슷한 원소를 찾고 처음 보는 원소의 성질 예상. (반응의 구체적 설명·원리·원소의 주기성 제외)
4차시 🔬 원자와 분자 [9과11-04 앞부분] (신규) — 1차시 화학식(H₂O, O₂)과 3차시 '18족은 거의 반응하지 않는다'를 이어받아 물질을 이루는 입자를 구별: 물방울을 끝까지 나누어 찾은 분자(물질의 성질을 나타내는 가장 작은 입자) → 원자로 존재하는 물질(18족 기체, 금속)과 분자로 존재하는 물질 → 원소(종류)와 원자·분자(입자) 세기 → 원자·분자·이온으로 분류하며 '전하를 띤 입자 = 이온'을 처음 만난다.
5차시 ⚡ 이온의 형성 [9과11-04 뒷부분] (기존) — 2차시의 '원자는 전기적으로 중성'을 토대로 전자를 잃으면 양이온, 얻으면 음이온 → 이온의 이동 실험(탐구 활동)으로 이온이 전하를 띠고 있음을 확인. 4차시 소금 속 (+)·(−) 입자가 어떻게 생기는지 설명한다.

[순서를 정한 까닭]
• 성취기준 순서(11-01 → 11-02 → 11-03 → 11-04)를 그대로 따른다. 11-01이 원자 구조보다 앞서는 것은 교육과정 순서다. 1차시는 거시 현상(분해)으로 원소를 정의하고 원자는 '입자'라는 수준으로만 써서 2차시와 겹치지 않게 한다.
• [9과11-04]는 '물질을 이루는 입자는 원자, 분자, 이온 등으로 존재할 수 있음을 알고'와 '이온은 전하를 띠고 있음을 설명'의 두 부분이다. 기존 m2-ion은 뒷부분만 다룬다. 내용 체계의 내용 요소 '분자'를 다루는 차시가 없어서 앞부분을 4차시로 나누고, 성취기준 문장 순서(알고 → 설명)대로 m2-ion 앞에 둔다.
• 3차시(주기율표)를 4차시 앞에 두면 '18족 원소는 거의 반응하지 않는다 → 원자 하나하나로 따로 존재한다'로 자연스럽게 이어진다.

[이후 연계]
• 중2 Ⅶ '전기와 자기': 전하·전기력, 전류의 모형(전자 개념은 2차시가 선수).
• 중3 Ⅰ '화학 반응의 규칙성': 화학 반응식과 계수(분자 모형·화학식 활용), 질량 보존(원자의 배열만 바뀜), 일정 성분비(화학식의 근거), 기체 반응 법칙(물 전기 분해의 부피비).
• 고1 '통합과학1' 물질과 규칙성: 원소의 주기성과 그 원리(원자가 전자), 화학 결합. 이 단원에서는 다루지 않는다.

### 1. 교육과정 범위 (반드시 지킬 것)
- 적용 시 고려 사항 인용: '생태전환교육과 연계하여 우리 주변의 물질 중 지구 환경에 영향을 미치는 물질을 중심으로 화학식으로 표현하고, 이 물질을 원소 또는 화합물인지 구분하도록 한다.' → STEP 3·4에서 화학식으로 쓰는 물질은 모두 환경과 관련된 물질로 고른다: H₂O, O₂, CO(Co와 비교), CH₄, O₃, CO₂, SO₂, N₂, Hg.
- 연계(고려 사항): '초등학교 5∼6학년군 ‘용해와 용액’ … 과 연계된다.' + 중2 Ⅰ '물질의 특성'의 순물질·혼합물[9과08-02] → 순물질을 원소와 화합물로 다시 나눈다.
- 포함: 원소 = 물질을 이루는 기본 성분으로 더 이상 다른 물질로 분해되지 않는 것 / 화합물 = 두 가지 이상의 원소가 결합하여 만들어진 물질(분해하면 성분 원소로 나뉨) / 원소 기호(첫 글자 대문자 + 둘째 글자 소문자) / 화학식 = 원소 기호와 숫자로 물질을 이루는 원소의 종류와 원자 수를 나타낸 식 / 화학식 속 원소 기호의 종류로 원소·화합물 구분.
- 다루지 않음: ① '분자'라는 낱말과 정의(→ 4차시 원자와 분자). 이 차시에서는 '산소 원자 2개가 결합한 입자'처럼 말로 표현 ② 원자의 속 구조(→ 2차시) ③ 화학 반응식·계수(2H₂O)·성분 원소의 질량비(→ 중3 [9과16]) ④ 물 전기 분해 기체 부피비 2 : 1의 의미(→ 중3 기체 반응 법칙). 그림은 실제처럼 (−)극 쪽이 2배 모이게 그리되 미션·퀴즈로 묻지 않음 ⑤ 이온식, 원소 기호의 역사.
- '원자'는 STEP 3에서 '원소를 이루는 아주 작은 입자' 수준으로만 소개(속 구조는 다음 차시).

### 3. STEP 1 · 관찰 — 물을 분해해 보자 (phase '관찰', short '물의 분해', icon ⚡)
- features: electro, gastest.
- intro: 탐구 질문 + '물에 전기를 흘려 보내면 어떤 일이 일어나는지 관찰해 봐요.' + 안전 메모: 물에 전류가 잘 흐르도록 수산화 나트륨을 조금 녹였어요(수산화 나트륨은 분해되지 않고 전류만 잘 흐르게 해요). 피부에 닿으면 위험하니 보안경과 장갑을 써요.
- 장면 electro:

- 조작(3):
  ① '🥽 보안경 쓰기': 처음 1회. 누르면 왼쪽 위 작은 아이콘으로 날아가 줄어든다. 안 쓰고 전원을 누르면 토스트 '🥽 보안경을 먼저 써요!'.
  ② '⚡ 전원 켜기/끄기': 사이드 버튼 + 캔버스 스위치 탭.
  ③ 기체 확인 도구: 미션 2 setup에서 S.toolsOn = true(자유 탐구에서는 항상). 두 시험관 모두 4 mL 이상이면 실험대 왼쪽에 🔥 성냥불, 🪵 꺼져 가는 향불이 떠오르며 등장(NEW 링).
- 애니메이션:
  - 전원 ON: LED 번짐 빛, 작은 '보글' 소리. 전극 표면의 임의 위치에서 기포가 생긴다. 반지름 0.6 → 2.6 px로 0.3~0.8 s 동안 자라 떨어져 나와 위로 올라간다(45~75 px/s, 위로 갈수록 살짝 빨라짐, 좌우 흔들림 1.5 px·6 Hz). 기체층에 닿으면 수면에 작은 물결 호가 생기고 흡수된다.
  - 생성 속도 (−)극 : (+)극 = 2 : 1(1.2 mL/s : 0.6 mL/s, 시뮬레이션 시간). 기체 부피만큼 시험관 속 수면(오목한 메니스커스)이 내려간다. 시험관 위에 값 칩 '(−)극 12.0 mL'.
  - 전원 OFF: 새 기포 생성은 멈추고, 이미 생긴 기포는 끝까지 올라간다.
  - 기체 확인(도구를 시험관으로 끌어 놓기): ⓐ 시험관이 0.6 s 동안 수조 밖으로 들려 올라온다(입구를 엄지로 막은 아이콘) ⓑ 결과 연출 ⓒ 시험관이 물을 채운 채 제자리로 돌아간다. 그 시험관 기체는 소모되며, 전원 ON이면 3배속으로 다시 모인다. 기체가 4 mL 미만이면 '기체를 더 모아요' 툴팁 후 도구가 돌아간다.
    - (−)극 + 성냥불: 입구를 아래로 한 채 불을 대면 주황·파랑 섬광(반지름 0 → 40 px, 0.18 s) + 충격파 링 + 말풍선 '퍽!'(scale 0 → 1.25 → 1) + 짧은 '퍽' 소리(노이즈 80 ms, 저역 필터). 결과 칩 '퍽 소리를 내며 탐 → 수소'.
    - (+)극 + 향불: 시험관을 입구가 위로 오게 뒤집고(0.5 s) 향불을 넣으면 불씨가 어두운 주황 → 밝은 노랑으로 살아나며 불꽃이 자라난다(0.4 s) + 불티 + '화르륵' 소리. 결과 칩 '불씨가 다시 타오름 → 산소'.
    - 엇갈린 조합(기록은 남김): (+)극 + 성냥불 → 불꽃이 잠깐 더 크고 밝게 탄다(퍽 소리 없음). (−)극 + 향불 → 불씨가 어두워지고 연기만 난다(살아나지 않음).
- 미션:
  1. task '기체 모으기'. goal: 보안경을 쓰고 전원을 켜서 두 시험관에 기체가 모이는 모습을 관찰하세요. check: power && vNeg ≥ 10 && vPos ≥ 5 (mL), hold 0.3. status: '(−)극 쪽 기체 ○ mL · (+)극 쪽 기체 ○ mL'(전원이 꺼져 있으면 '⚡ 전원을 켜 보세요'). hint: 오른쪽 전원 장치의 스위치를 눌러요. 두 전극에서 무엇이 생기는지 보세요. focus 'power'. explain: 전원을 켜자 두 전극에서 기포가 생겨 시험관 위쪽에 기체가 모였어요. 물에서 새로운 기체가 생겨난 거예요. 이 기체들은 무엇일까요?
  2. task '기체의 정체'. goal: 🔥 성냥불과 🪵 꺼져 가는 향불로 두 시험관의 기체를 확인하세요. check: found.H && found.O ((−)극 + 성냥불 '퍽'과 (+)극 + 향불 '다시 타오름'을 모두 관찰), hold 0.4. status: 두 줄 '(−)극 기체: ? / (+)극 기체: ?'이 결과로 바뀐다(엇갈린 결과는 회색 작은 글씨). hint: 수소는 불을 대면 '퍽' 소리를 내며 타고, 산소는 꺼져 가는 불씨를 다시 타오르게 해요. focus 'tools'. explain: (−)극에서는 수소, (+)극에서는 산소가 생겼어요. 물이 성질이 전혀 다른 두 물질로 나뉘었어요!
  3. quiz '물은 기본 성분일까?'. goal: 이 실험 결과로 알 수 있는 것은?
     - ① 물은 원소이고, 전기가 물을 수소와 산소로 바꾸었을 뿐이다. 피드백: 물에서 수소와 산소가 나왔다면 물은 그보다 더 기본적인 성분으로 이루어져 있다는 뜻이에요.
     - ② [정답] 물은 수소와 산소로 분해되므로 더 이상 분해되지 않는 기본 성분이 아니다.
     - ③ 물속에 원래 섞여 있던 수소 기체와 산소 기체가 빠져나온 것이다. 피드백: 물은 수소와 산소의 혼합물이 아니에요. 물은 불을 끄지만 수소는 '퍽' 타고, 산소는 불씨를 살려요. 성질이 전혀 달라요. 전원을 끄면 기체도 더 생기지 않았죠?
     - ④ 물이 끓어서 생긴 수증기가 모인 것이다. 피드백: 물은 끓지 않았어요. 수증기는 '퍽' 소리를 내며 타지 않고 불씨도 살리지 못해요.
     - answer: 1 (0부터 셈). explain: 물은 전기로 수소와 산소로 분해돼요. 그러니 물은 기본 성분이 아니에요. 그럼 수소와 산소는 더 분해될까요? 다음 단계에서 확인해요!
- recap: 물을 전기 분해하면 (−)극에서 수소, (+)극에서 산소가 생겨요. 물은 더 기본적인 성분으로 나뉘는 물질이에요.
- summary: 표 [(−)극 | 수소 | 불을 대면 '퍽' 소리] [(+)극 | 산소 | 꺼져 가는 불씨가 다시 타오름] + 식 상자 '물 → 수소 + 산소 (물은 분해된다)' + note '⚠️ 수산화 나트륨은 피부에 닿지 않게!'.

### 4. STEP 2 · 탐구 — 원소와 화합물 (phase '탐구', short '원소·화합물', icon 🔬)
- features: decomp, sort.
- intro: 🔗 앞 단계에서 물이 수소와 산소로 분해되는 것을 보았어요. → 그럼 수소와 산소도 더 분해될까요? 여러 물질을 분해 장치에 넣어, 분해되는 물질과 분해되지 않는 물질로 나누어 봐요.
- 장면 decomp:
  - 왼쪽 선반(x 16~196): 물질 6개(2열 × 3행, 각 80×86, 이름 14px; 화학식·원소 기호는 아직 쓰지 않음). 수소(무색 기체병 + 마개), 산소(무색 기체병), 구리(붉은 금속 조각), 물(비커), 염화 나트륨(흰 정육면체 결정 더미), 산화 은(검은 갈색 가루 접시). 시험한 병에는 작은 배지(✔ 분해됨 / ✖ 분해 안 됨).
  - 가운데 분해 장치(x 230~530, y 90~380): 금속 받침 위 유리 돔, 안에 가열 코일과 전극 2개. 앞면 LCD '여러 방법(가열·전기 분해)으로 분해를 시도하는 장치 · 공기 차단'. 돔 위 투입구(점선 원), 장치 아래 '생긴 물질' 받침(칩 2칸).

  - 조작(3): 물질 끌기(선반 → 장치 → 상자), '🔬 분해하기'(사이드), '↺ 처음 상태로'.
- 분해 연출(1.6~2.4 s, LCD에 '가열 중… / 전기 분해 중…'):
  - 공통: 코일이 어둡게 → 주황으로 달아오른다(글로 반경 증가 + 위로 사인으로 일그러지는 반투명 아지랑이 띠). 이어서 전극 사이에 파란 전기 불꽃(지그재그 3~4줄, 0.08 s마다 새로 그림).

- 미션:

  2. quiz '공기는 화합물일까?'. goal: 공기에는 질소, 산소, 아르곤, 이산화 탄소 등이 들어 있어요. 공기는 어떤 물질일까요?
     - ① 여러 원소로 이루어져 있으니 화합물이다. 피드백: 공기 속 질소와 산소는 서로 결합하지 않고 섞여 있을 뿐이에요. 결합해야 화합물!

     - ③ [정답] 여러 순물질이 결합하지 않고 섞여 있는 혼합물이다.
     - ④ 공기에서 질소와 산소를 얻을 수 있으니 화합물이다. 피드백: 공기에서 질소·산소를 얻는 것은 섞인 것을 끓는점 차이로 분리하는 것이지 분해가 아니에요.
     - answer: 2. explain: 원소와 화합물은 모두 한 가지 물질로 된 순물질이에요. 화합물은 원소가 결합해 성질이 전혀 다른 새 물질이 된 것이고(물은 수소·산소와 성질이 달라요), 혼합물은 섞인 물질이 각자의 성질을 그대로 지녀요.
- recap: 더 이상 분해되지 않는 기본 성분이 원소, 두 가지 이상의 원소가 결합한 물질이 화합물이에요.
- summary: 분류 나무(HTML ul): 물질 → 순물질 [원소: 수소, 산소, 구리 | 화합물: 물, 염화 나트륨, 산화 은] / 혼합물 [공기, 소금물] + 정의 2줄 + note '분리(혼합물을 나눔) ≠ 분해(화합물이 성분 원소로 나뉨)'.

### 5. STEP 3 · 모형 — 화학식으로 나타내기 (phase '모형', short '화학식', icon 🧩)
- features: formula.
- intro: 🔗 앞 단계에서 물은 수소와 산소, 두 가지 원소가 결합한 화합물임을 알았어요. → 원소를 이루는 아주 작은 입자를 원자라고 해요(원자의 속 구조는 다음 차시에서!). 원소마다 원자의 종류가 다르고, 원소는 원소 기호로 나타내요. 원소 기호와 숫자로 물질을 나타낸 식이 화학식이에요.
- 장면 formula:
  - 왼쪽 입자 모형 무대(x 20~420, y 40~470): 연보라 원형 스포트라이트. 가운데 공 모형이 y축으로 천천히 회전(15°/s) + 아래 접지 그림자(회전에 따라 폭이 바뀜) + 범례 칩('● H 수소 ● O 산소').

- 상호작용 연출:
  - 타일을 누르면 복제 타일이 다음 빈 슬롯으로 포물선 비행(0.35 s) 후 착지 바운스. 동시에 모형 속 그 원소의 원자들에 맥동 후광(1.2 s 주기)과 번호표 ①②가 붙어 개수를 셀 수 있다.
  - 모형에 없는 원소면 슬롯이 빨갛게 흔들리고 '모형에 이 원자가 없어요' 후 사라진다.
  - 이미 들어간 원소 타일을 또 누르면 새 슬롯 대신 그 슬롯 숫자가 +1 되고 말풍선 '같은 원소는 한 번만 쓰고 개수는 숫자로!'.

- 미션:

  2. task '원소도 화학식으로: 산소'. goal: 산소 기체를 이루는 입자 모형이에요. 화학식으로 나타내 보세요. 타일 O, H, N. check: O2, hold 0.5. hint: 산소 원자 몇 개가 결합해 있나요? explain: 산소 기체는 산소 원자 2개가 결합한 입자로 이루어져 있어 O₂로 나타내요. 원소도 화학식으로 나타내요. 헬륨(He)처럼 원자가 하나씩 떨어져 있거나, 철(Fe)처럼 한 종류의 원자가 끝없이 모여 있는 원소는 원소 기호를 그대로 화학식으로 써요. explain 안에 작은 SVG 2개(He 공이 띄엄띄엄 / Fe 공이 촘촘히).
  3. quiz 'CO와 Co'. figure: SVG 카드 2장. 왼쪽은 검정 C + 빨강 O 공 모형 'CO 일산화 탄소: 연료가 불완전 연소할 때 생기는 유독한 기체', 오른쪽은 푸른 은빛 금속 덩어리 'Co 코발트: 배터리 재료로 쓰이는 금속'. goal: 화학식 CO와 Co에 대한 설명으로 옳은 것은?
     - ① 둘은 같은 물질을 다르게 쓴 것이다. 피드백: 대문자는 새 원소 기호의 시작이에요. CO는 C와 O, 기호 두 개예요.
     - ② [정답] CO는 탄소와 산소로 이루어진 화합물이고, Co는 코발트라는 한 가지 원소이다.
     - ③ CO는 원소이고 Co는 화합물이다. 피드백: 거꾸로예요. 원소 기호가 몇 종류인지 세어 보세요.
     - ④ 둘 다 두 가지 원소로 이루어진 화합물이다. 피드백: Co의 o는 소문자예요. 둘째 글자는 소문자로 써서 기호 하나를 이뤄요.

- recap: 화학식은 원소 기호와 숫자로 물질을 이루는 원소의 종류와 원자 수를 나타내요.
- summary: 규칙 상자 ① 원소 기호: 첫 글자 대문자(+ 둘째 글자 소문자) ② 원자 수는 오른쪽 아래 작은 숫자, 1은 생략 ③ 기호 종류 1개 → 원소(O₂, He, Fe), 2개 이상 → 화합물(H₂O, CO). 이 차시 원소 기호 표: H 수소, He 헬륨, C 탄소, N 질소, O 산소, S 황, Cl 염소, Na 나트륨, Fe 철, Co 코발트, Cu 구리, Ag 은, Hg 수은. note: 라틴어 이름에서 온 기호 Na(Natrium), Fe(Ferrum), Cu(Cuprum), Ag(Argentum), Hg(Hydrargyrum).

- 물 전기 분해: (−)극 수소, (+)극 산소, 부피 약 2 : 1(그리기만). 수산화 나트륨(또는 황산 나트륨)은 전류를 돕는 물질이다.
- 수소: 불을 대면 '퍽'. 산소: 꺼져 가는 불씨를 다시 타오르게 한다.
- 화합물 ≠ 혼합물(화합물은 순물질이고, 성분 원소와 성질이 다르다). 분리 ≠ 분해.
- O₂, O₃, N₂, Hg, He, Fe는 원소다(아래첨자는 원자 수일 뿐). CO ≠ Co.
- 학생의 화학식 입력은 원소 순서와 무관하게 정답으로 처리하고, 관례 순서(H₂O, CO₂, CH₄, SO₂)로 정렬해 보여 준다.
- '분자' 낱말, 계수 표기, 반응식을 쓰지 않는다. 염화 나트륨 분해는 녹인 염화 나트륨(약 801 °C)의 전기 분해로, 공장에서 하는 일로 소개한다.
- 메테인 수치에는 '약'을 붙인다(IPCC 100년 기준 근삿값).

### 8. 자유 탐구(완료 후)
- 모든 장면을 고를 수 있다. 지구 환경 장면에서 모든 버블과 보너스(일산화 탄소 CO, 암모니아 NH₃: 질소 비료·축산에서 나와 미세먼지 생성에 관여)로 화학식을 만들 수 있다.

     - ③ 나트륨, 마그네슘, 알루미늄. 피드백: 3주기에 나란히 있는 원소예요. 족은 세로줄이에요.
     - ④ 수소, 헬륨. 피드백: 1주기의 두 원소예요. 수소는 1족, 헬륨은 18족이에요.
     - answer: 1. explain: 리튬·나트륨·칼륨은 모두 1족이에요. 같은 족 원소는 성질이 비슷할까요? 다음 단계에서 실험으로 확인해요!
- recap: 주기율표의 가로줄은 주기, 세로줄은 족이에요.
- summary: '주기 = 가로줄(1~7) / 족 = 세로줄(1~18)' + 예: 나트륨 3주기 1족, 네온 2주기 18족, 칼륨 4주기 1족.

### 5. STEP 3 · 실험 — 같은 족 원소의 성질 (phase '실험', short '같은 족', icon 🧪)
- features: lab.
- intro: 🔗 앞 단계에서 리튬·나트륨·칼륨이 같은 1족임을 알았어요. → 같은 족 원소는 성질도 비슷할까요? 1족 원소를 물에 넣고, 18족 기체 속에 달군 철솜을 넣어 비교해요. 비교를 위해 다른 족 원소도 함께 시험해요. + 안전: ⚠️ 1족 금속은 물과 격렬하게 반응해요. 실제로는 선생님 시범(쌀알만 한 조각, 보안경)이나 영상으로 관찰하고, 칼륨은 특히 위험해요.
- 장면 lab: 미션 1·2는 water 실험대, 미션 3은 gas 실험대(미션 setup에서 전환).
  - water: 비커 4개(중심 x 120, 290, 460, 630, 폭 130, 높이 150, y 270~420). 각 비커에 무색 물 + 라벨 '물 + 페놀프탈레인 용액'. 위쪽 시료 접시(y 110~190)에 석유에 담긴 금속 조각 4개: 리튬·나트륨·칼륨(은백색 덩어리, 석유 광택), 마그네슘(회백색 리본 조각). 조각 아래 위치 표 '2주기 1족', '3주기 1족', '4주기 1족', '3주기 2족'. 조각을 끌어 비커 위에 놓으면 핀셋이 집어 떨어뜨린다.
  - gas: 집기병 4개(뚜껑 있는 유리 원통; 라벨 + 위치: 산소 '2주기 16족', 헬륨 '1주기 18족', 네온 '2주기 18족', 아르곤 '3주기 18족'; 병 속에는 그 기체만). 왼쪽에 알코올램프(불꽃 흔들림)와 손잡이 달린 철솜. 철솜을 불꽃 속에 끌어 두면 '달굼' 막대가 차오르며 빨갛게 달아오른다(1.2 s). 달군 철솜을 병 입구에 놓으면 뚜껑이 열리고 안으로 들어간다. 식으면 다시 달궈야 한다.
  - 결과표(사이드 카드, 13px 이상): 1족 표 [원소 | 기체 발생 | 용액 색], 18족 표 [기체 | 철솜의 변화]. 관찰 후 타자 효과로 채워진다.
  - 조작(2): 시료(또는 철솜) 끌기, '↺ 새 비커 / 새 집기병'.
- 반응 연출(관찰 사실만, 원리 설명 없음):
  - 리튬: 물에 떠서 둥둥(진폭 2 px). 아래에서 꾸준한 잔기포(초당 15개). 천천히 떠다니며(15 px/s) 12 s 동안 작아진다. 조각 둘레에서 분홍(#ff4fa3) 번짐이 퍼진다(겹친 반투명 원 여러 개가 노이즈로 일그러지며 퍼지는 잉크 효과). 비커 전체가 점점 연분홍이 된다.
  - 나트륨: 닿자마자 녹아 반짝이는 은색 공이 된다(정육면체 → 구, 0.4 s). 수면 위를 빠르게 미끄러진다(110 px/s, 벽에서 튕김). '쉬익' 소리, 드물게 노란 불티, 지나간 자리에 분홍 꼬리. 6 s 뒤 사라진다.
  - 칼륨: 녹으며 곧바로 연보라 불꽃(흰 중심 → #c9a0ff → 투명, 흔들림)과 함께 매우 빠르게 움직인다. '타닥' 소리, 끝에 작은 '톡' 튐. 4 s. 분홍.
  - 마그네슘: 가라앉아 바닥에 놓인다(감쇠 낙하). 10 s 동안 아주 작은 기포 1~2개뿐, 색 변화 없음.
  - 공통: 움직이는 금속 둘레에 수면 물결 링, 결과표 기록, 비커 유리 반사광.
  - 산소 + 달군 철솜: 흰빛 섬광과 함께 불꽃을 튀기며 탄다(선형 불티 80개: 중력·감속·수명 0.6~1.2 s). 철솜이 검게 오그라들고 '파지직' 소리.
  - 헬륨·네온·아르곤 + 달군 철솜: 불꽃 없이 빨간 빛이 2 s 동안 서서히 식어 회색이 된다 → '변화 없음'.
- 미션:
  1. task '1족 원소를 물에'. goal: 리튬, 나트륨, 칼륨(1족)과 마그네슘(2족)을 각각 페놀프탈레인 용액을 떨어뜨린 물에 넣고 관찰하세요. check: 4가지 모두 시험(각 반응을 2.5 s 이상 지켜봄), hold 0.3. status: 결과 4줄(예 '나트륨: 기체 ✔ · 붉게 ✔'). hint: 접시의 금속 조각을 끌어 비커 위에 놓아요. 1족 원소끼리 무엇이 같은지 보세요. focus 'tray'. explain: 리튬, 나트륨, 칼륨은 모두 물과 반응해 기체가 생기고 페놀프탈레인 용액이 붉게 변했어요(용액이 염기성이 됨). 같은 3주기인 마그네슘은 거의 변화가 없었어요.
  2. quiz '결과로 추론하기'. goal: 이 실험으로 추론할 수 있는 것은?
     - ① [정답] 1족 원소인 리튬, 나트륨, 칼륨은 물과 반응하는 비슷한 성질이 있다.
     - ② 양성자 수가 비슷한 나트륨(11)과 마그네슘(12)은 성질이 비슷하다. 피드백: 두 원소는 물에서 아주 다르게 행동했어요. 같은 주기라고 성질이 비슷한 것은 아니에요.
     - ③ 금속은 모두 물과 격렬하게 반응한다. 피드백: 마그네슘도 금속이지만 찬물과 거의 반응하지 않았어요.
     - ④ 1족 원소는 물과 반응하는 모습이 완전히 똑같다. 피드백: 반응의 세기는 조금씩 달랐어요(칼륨이 가장 격렬). 그래도 물과 반응해 기체가 생기고 용액이 붉어지는 성질이 비슷해요.
     - answer: 0. explain: 같은 족 원소는 성질이 비슷해요. 1족 금속은 공기 중의 산소·수분과도 잘 반응해서 석유 속에 보관해요.
  3. task '18족 기체와 달군 철솜'. setup: gas 실험대로 전환. goal: 철솜을 알코올램프로 달군 뒤 산소, 헬륨, 네온, 아르곤이 든 집기병에 차례로 넣어 비교하세요. check: 4개 모두 시험, hold 0.3. status 4줄. hint: 철솜을 불꽃에 대어 빨갛게 달군 다음 집기병 입구로 끌어 놓아요. 식으면 다시 달궈요. explain: 철솜은 산소 속에서는 불꽃을 튀기며 탔지만, 헬륨·네온·아르곤 속에서는 아무 변화가 없었어요. 18족 원소는 다른 물질과 거의 반응하지 않는(안정한) 비슷한 성질이 있어요.
- recap: 같은 족 원소는 성질이 비슷해요. 1족(수소 제외)은 물과 잘 반응하고, 18족은 다른 물질과 거의 반응하지 않아요.
- summary: 결과 표 2개 + '같은 족 원소(동족 원소) = 성질이 비슷한 원소' + note '반응의 세기는 조금씩 달라요. 수소는 1족이지만 금속이 아니어서 1족 금속과 성질이 달라요.'

### 6. STEP 4 · 적용 — 성질이 비슷한 원소 찾기 (phase '적용', short '원소 찾기', icon 🕵️)
- features: detective.
- intro: 🔗 앞 단계에서 같은 족 원소는 성질이 비슷하다는 것을 실험으로 확인했어요. → 이제 주기율표에서 성질이 비슷한 원소를 찾고, 처음 보는 원소의 성질도 예상해 봐요.
- 미션:
  1. task '원소 탐정'. 장면 table + 위쪽 '단서 카드' 배너. 단서 2문제를 차례로 보인다: ⓐ '단서 ① 물에 넣으면 기체가 생기고 페놀프탈레인 용액을 붉게 만드는 금속 · 단서 ② 4주기' → K. ⓑ '단서 ① 다른 물질과 거의 반응하지 않는 기체 · 단서 ② 2주기' → Ne. goal: 단서에 맞는 원소를 주기율표에서 찾아 누르세요. check: 2문제 정답, hold 0.2. 틀린 칸 피드백: Ca → '칼슘은 4주기 2족이에요. 단서 ①은 어느 족의 성질일까요?' / Ar → '아르곤도 18족이지만 3주기예요.' / H → '수소는 1족이지만 금속이 아닌 기체예요.' / 그 밖 → '○주기 ○족이에요'. hint: 단서 ①로 족(세로줄)을, 단서 ②로 주기(가로줄)를 정해요. explain: 성질이 비슷한 원소는 같은 족에 있어요. 주기율표에서 같은 족을 찾으면 성질이 비슷한 원소를 쉽게 찾을 수 있어요.
  2. quiz '처음 보는 원소, 루비듐'. setup: 37번 Rb 칸이 밝아지며 깜빡인다(1족 강조 띠와 함께). goal: 루비듐(Rb)은 5주기 1족 원소예요. 루비듐을 물에 넣으면 어떻게 될까요?
     - ① 같은 5주기인 제논(Xe)처럼 거의 반응하지 않는다. 피드백: 같은 주기라고 성질이 비슷하지 않아요. 같은 족을 보세요.
     - ② [정답] 같은 1족인 나트륨, 칼륨처럼 물과 반응해 기체가 생기고 용액이 붉어진다.
     - ③ 마그네슘처럼 물과 거의 반응하지 않는다. 피드백: 마그네슘은 2족이에요.
     - ④ 원자 번호가 커서 물에 넣어도 아무 변화가 없다. 피드백: 원자 번호가 크다고 반응하지 않는 것은 아니에요. 같은 족 원소의 성질을 떠올려 보세요.
     - answer: 1. 정답 뒤 캔버스 인셋(작은 비커)에서 루비듐이 가라앉으며 격렬한 기포와 분홍 번짐(3 s). explain: 루비듐은 1족이라 물과 잘 반응해요. 실제로는 칼륨보다 더 격렬해요. 족을 보면 처음 보는 원소의 성질도 예상할 수 있어요.
  3. task '안전한 비행선'. 장면 airship: 하늘(구름 패럴랙스 2겹), 가운데 빈 비행선(외피 주름), 아래에 기체 탱크 2개 '수소 H(1주기 1족)', '헬륨 He(1주기 18족)'. 탱크를 비행선에 끌어 놓으면 채우기 연출(외피가 부풀며 주름이 펴지고 줄을 당기며 떠오름, 1 s). 사이드 버튼 '⚡ 번개 시험': 하늘에 번개(지그재그 빛 + 화면 0.1 s 번쩍).
     - 수소: 새어 나온 수소에 불이 붙어 외피에 불길이 번지는 짧은 연출(사람 없음, 1.2 s) → 말풍선 '⚠️ 수소는 공기 중에서 불이 붙으면 잘 타요(1937년 힌덴부르크호 사고)' → 비행선 초기화.
     - 헬륨: 번개가 쳐도 아무 일 없음 → 초록 체크, 비행선이 천천히 날아간다.
     - goal: 비행선에 넣을 기체를 골라 채우고 번개 시험을 통과하세요. check: gas = He && 번개 시험 통과, hold 0.3. hint: 18족 원소의 성질을 떠올려 보세요. explain: 헬륨은 18족 원소라 다른 물질과 거의 반응하지 않아 불이 붙지 않아요. 그래서 오늘날 비행선과 풍선에는 헬륨을 써요. 네온(네온사인), 아르곤(전구 속, 용접할 때 공기를 막는 기체)도 18족의 안정한 성질을 이용해요.
     - 조작(2): 탱크 끌기, '⚡ 번개 시험'.
- recap: 주기율표에서 같은 족을 찾으면 성질이 비슷한 원소를 찾고, 처음 보는 원소의 성질도 예상할 수 있어요.
- summary: 표 '같은 족 → 성질이 비슷': 1족(Li, Na, K, Rb …) 물과 잘 반응 / 18족(He, Ne, Ar, Kr …) 거의 반응하지 않음 + 이용 예(헬륨 비행선·풍선, 네온사인, 전구·용접의 아르곤).

### 7. 정확성·오개념 체크리스트
- 원자 번호 = 양성자 수(질량수·동위 원소는 언급하지 않음). 원소는 118종.
- 1족: 리튬·나트륨·칼륨은 물보다 밀도가 작아 뜬다(0.53, 0.97, 0.86 g/cm³). 나트륨(녹는점 98 °C)·칼륨(63 °C)은 녹아 공 모양이 되고, 칼륨은 연보라 불꽃을 낸다. 루비듐(1.53 g/cm³)은 가라앉는다 → '물에 뜬다'를 1족의 공통 성질로 가르치지 않는다.
- 생기는 기체·물질의 이름, 반응식, 반응 세기 차이의 이유는 다루지 않는다(관찰상 '세기가 조금 다르다'만).
- 18족은 '다른 물질과 거의 반응하지 않는다(안정하다)' 수준으로 다룬다.
- 수소는 1족에 있지만 비금속 기체라 1족 금속과 성질이 다르다.
- 같은 주기 ≠ 비슷한 성질(Na–Mg, Rb–Xe).
- 전자 껍질·원자가 전자로 족을 설명하지 않는다(카드 원자 그림에 껍질 원 금지).
- 마그네슘은 찬물과 '거의' 반응하지 않는다('전혀'라고 쓰지 않음).
- 철솜 실험의 대조군은 산소만 쓴다. 질소·이산화 탄소 병은 쓰지 않는다(반응성이 작은 다른 기체와 혼동 방지).

### 1. 교육과정 범위 (반드시 지킬 것)
- 포함: 분자 = 원자가 결합하여 만들어진 입자로, 물질의 성질을 나타내는 가장 작은 입자 / 원자 상태로 존재하는 물질: 18족 기체(원자가 하나씩 따로), 금속(수많은 원자가 규칙적으로 배열) / 분자로 존재하는 물질: 원소(O₂, N₂)와 화합물(H₂O, CO₂, CH₄) 모두 / 원소(성분의 종류)와 원자·분자(입자)의 구별 / 이온으로 존재하는 물질(염화 나트륨: (+)전하·(−)전하를 띤 입자가 번갈아 규칙적으로 배열) — '이온 = 전하를 띤 입자' 수준.
- 성취기준 해설 인용: '[9과11-04] 이온의 경우 원자가 전기적으로 중성임을 토대로 전자를 잃으면 양이온이 되고, 전자를 얻으면 음이온이 된다는 수준에서 다룬다.' → 이온이 생기는 과정은 다음 차시(m2-ion)에서 다룬다. 여기서는 전하를 띤 입자라는 것과 이온으로 이루어진 물질이 있다는 것만. 탐구 활동 '전기력을 이용한 실험으로 이온의 이동 관찰하기'도 m2-ion이 맡는다.
- 다루지 않음: 공유·이온·금속 결합의 원리 / 분자 모양(결합각) 설명(그림은 실제 모양으로 그리되 말로 가르치지 않음) / 화학 반응식과 계수(2H₂O 같은 분자 수 표기 → 중3 [9과16-02]); 분자 수는 '물 분자 3개'처럼 말로 쓴다 / '단원자 분자'라는 용어 / 이온식 쓰기, 이온 이름 외우기 / 아보가드로수·몰.

### 3. STEP 1 · 관찰 — 물질의 성질을 가진 가장 작은 입자 (phase '관찰', short '분자', icon 💧)

- intro: 탐구 질문 + '잎 위의 물방울을 1/10 크기로 계속 나누며 확대해 봐요. 아무리 작아져도 물일까요?' + '1차시에서 물의 화학식은 H₂O였죠?'

  - 처음: 초록 잎(그라디언트 + 잎맥 곡선) 위 물방울(지름 180 px: 가장자리가 진한 굴절 radial, 왼쪽 위 흰 하이라이트, 아래쪽 밝은 집광점, 잎에 진한 그림자). 왼쪽 아래 축척 막대(물방울 지름과 같은 길이) + 값. 오른쪽 위 정보 칩 3줄: '물방울 지름', '물 분자 수 약 ○', 배지 '여전히 물 ✔'.

     - ① 헬륨과 산소는 모두 원소이므로 둘 다 원자로 존재한다. 피드백: 산소는 원소이지만 산소 원자 2개가 결합한 분자(O₂)로 존재해요.
     - ② [정답] 헬륨은 원자가 하나씩 따로 존재하고, 산소는 산소 원자 2개가 결합한 분자로 존재한다.
     - ③ 헬륨은 화합물이라서 분자로 존재한다. 피드백: 헬륨은 한 가지 원소로 된 물질이에요.
     - ④ 산소 분자 속에는 헬륨 원자가 들어 있다. 피드백: 산소 분자는 산소 원자로만 이루어져 있어요.
     - answer: 1. explain: 헬륨, 네온, 아르곤 같은 18족 원소는 다른 원자와 거의 결합하지 않아 원자 하나하나가 따로 존재해요(주기율표 차시의 18족 안정성!). 같은 원소라도 산소는 원자 2개가 결합한 분자로 존재해요.
- recap: 물질은 원자로 존재하기도 하고(헬륨, 구리), 원자가 결합한 분자로 존재하기도 해요(산소, 물, 이산화 탄소).
- summary: 표(물질 | 화학식 | 입자 | 모습): 헬륨 He 원자 따로따로 / 구리 Cu 원자 규칙적으로 끝없이 / 산소 O₂ 분자 / 이산화 탄소 CO₂ 분자 / 물 H₂O 분자.

### 5. STEP 3 · 모형 — 원소, 원자, 분자 구별하기 (phase '모형', short '세어 보기', icon 🔍)
- features: lens, build.
- intro: 🔗 앞 단계에서 물질에 따라 원자로, 또는 분자로 존재한다는 것을 알았어요. → 원소, 원자, 분자는 헷갈리기 쉬워요. 원소는 성분의 '종류', 원자와 분자는 '입자'예요. 렌즈를 바꿔 끼우며 세어 봐요.
- 장면 count:
  - 왼쪽 투명 상자(x 40~420, y 60~440, 둥근 유리 상자 + 반사광): 분자가 느리게(30 px/s) 떠다니며 회전한다. 세기 쉽도록 서로 겹치지 않게 약하게 밀어낸다.
  - 렌즈(사이드 segmented 3칸): '🫧 분자' '⚪ 원자' '🎨 원소'. 전환할 때 0.3 s 크로스페이드.
    - 분자 렌즈: 분자마다 반투명 연보라 껍질(볼록 껍질 + 6 px 여유) + 분자를 따라다니는 번호 ①②③.
    - 원자 렌즈: 원자마다 얇은 고리 + 번호 1, 2, 3 …
    - 원소 렌즈: 같은 원소의 원자에 같은 색 테두리. 오른쪽 범례 '수소 ● · 산소 ● → 2종류'(번호 없음).
  - 오른쪽 분자 조립대(미션 2, x 450~784): 원자 바구니 2개(C 검정, O 빨강; 누르거나 끌면 원자 하나가 튀어나옴), 가운데 점선 조립 원(지름 160). 조립 원 안에 C 1개 + O 2개가 모이면 원자들이 스프링 이징으로 O–C–O 직선 자리로 끌려와 결합 빛(0.4 s)을 낸다. 완성 분자는 상자로 날아가 떠다닌다. 남는 원자는 조립 원 둘레를 맴돌고 '↺ 비우기'로 되돌린다.
  - 조작(3): 렌즈, 원자 바구니(끌기), '↺ 비우기'.
- 미션:
  1. quiz '물 분자 3개 세기'. setup: 상자 = H₂O 3개. goal: 상자 속 물질의 분자 수, 원자 수, 원소의 종류 수는? 렌즈를 바꿔 끼우며 세어 보세요.
     - ① 분자 3개, 원자 3개, 원소 2종류. 피드백: 원자 렌즈로 세어 보세요. 분자 하나에 원자가 3개씩!
     - ② [정답] 분자 3개, 원자 9개, 원소 2종류.
     - ③ 분자 9개, 원자 9개, 원소 3종류. 피드백: 원자 9개가 3개씩 결합해 분자 3개를 이뤄요. 원소는 수소와 산소 두 종류예요.
     - ④ 분자 3개, 원자 9개, 원소 9종류. 피드백: 원소는 입자의 개수가 아니라 종류예요.
     - answer: 1. explain: 물 분자 3개 = 원자 9개(수소 원자 6 + 산소 원자 3), 원소는 수소와 산소 2종류예요. 원소는 종류로, 원자·분자는 개수로 세요.
  2. task '이산화 탄소 분자 2개 만들기'. setup: 상자를 비운다. goal: 원자 바구니에서 원자를 꺼내 이산화 탄소(CO₂) 분자 2개를 조립해 상자에 넣으세요. check: 상자 속 CO₂ = 2 && 조립 원 비어 있음, hold 0.4. status '탄소 원자 ○ · 산소 원자 ○ 사용 / 완성 분자 ○/2'. hint: CO₂ 분자 하나 = 탄소 원자 1개 + 산소 원자 2개. 2개를 만들려면 원자가 모두 몇 개 필요할까요? focus 'build'. explain: CO₂ 분자 2개 = 원자 6개(탄소 2 + 산소 4), 원소는 탄소와 산소 2종류예요.
  3. quiz '물 분자 속에는?'. figure: H₂O 공 모형 SVG 1개. goal: 물 분자 1개에 대한 설명으로 옳은 것은?
     - ① 3종류의 원소로 이루어져 있다. 피드백: 원자는 3개지만 원소(종류)는 수소와 산소 2가지예요.
     - ② 수소 분자(H₂) 1개와 산소 원자 1개가 결합해 있다. 피드백: 물 분자 속에 수소 분자가 따로 들어 있지 않아요. 수소 원자 2개가 각각 산소 원자와 결합해 있어요.
     - ③ [정답] 2종류의 원소, 3개의 원자로 이루어져 있다.
     - ④ 원자 2개로 이루어져 있다. 피드백: H₂O의 2는 수소 원자 수예요. 산소 원자 1개도 있어요(1은 생략).
     - answer: 2.
- recap: 원소는 성분의 종류, 원자와 분자는 입자예요. 물 분자 1개는 원소 2종류, 원자 3개로 이루어져 있어요.
- summary: 비교 표(원소 | 원자 | 분자 × 뜻 · 세는 법 · 예) + 예 '물 분자 3개 → 분자 3, 원자 9, 원소 2 / 이산화 탄소 분자 2개 → 분자 2, 원자 6, 원소 2'.

### 6. STEP 4 · 적용 — 원자·분자·이온 (phase '적용', short '입자 분류', icon 🧂)
- features: ion.
- intro: 🔗 앞 단계에서 원소·원자·분자를 구별해 세어 보았어요. → 그런데 소금(염화 나트륨) 속에는 분자가 없대요! 입자 현미경으로 들여다보고 우리 주변 물질을 원자·분자·이온으로 분류해 봐요.
- 장면 scope + 세 번째 상자 '이온으로 존재'(아래에서 미끄러져 올라오며 NEW 링). 시료 7개: 헬륨 풍선(He), 구리 전선(Cu), 산소통(O₂), 물(H₂O), 이산화 탄소(CO₂), 가스레인지 연료 메테인(CH₄), 소금(NaCl, 흰 정육면체 결정).
  - 소금 창: 3×3×3 정육면체 격자(27개)가 천천히 회전(3D 투영, 깊이순). 작은 보라 공(r 12)과 큰 초록 공(r 20)이 번갈아 놓인다(Na⁺ 102 pm : Cl⁻ 181 pm 비율). 격자가 창 밖으로 계속 이어지는 느낌을 준다. 처음 볼 때 공마다 '+'·'−' 배지가 0.05 s 간격으로 톡톡 나타나고 캡션: '(+)전하를 띤 입자와 (−)전하를 띤 입자가 번갈아 규칙적으로 배열해 있어요. 이렇게 전하를 띤 입자를 이온이라고 해요.'
  - 메테인 창: CH₄ 정사면체 분자 8개가 기체처럼 운동.
- 조작(3): 시료 끌기/탭, 칩 끌기, '↺'.
- 미션:
  1. task '원자·분자·이온 분류'. goal: 소금을 먼저 관찰한 뒤, 일곱 가지 물질을 원자·분자·이온으로 존재하는 물질로 분류하세요. check: 7개 모두 바른 상자, hold 0.3. status '분류 ○/7'. 틀릴 때(소금 → 분자): '소금 속에는 따로 떨어진 분자가 없어요. (+)·(−)전하를 띤 입자가 번갈아 이어져 있어요.' hint: 원자가 따로 있는지, 원자가 결합한 덩어리(분자)인지, 전하(+, −)를 띤 입자인지 보세요. explain: 헬륨·구리는 원자로, 산소·물·이산화 탄소·메테인은 분자로, 염화 나트륨은 이온으로 이루어져 있어요. 물질을 이루는 입자는 원자, 분자, 이온 등으로 존재할 수 있어요.
  2. quiz '원소·화합물과 입자'. goal: 다음 중 옳은 것은?
     - ① 원소는 모두 원자로 존재한다. 피드백: 산소(O₂)는 원소이지만 분자로 존재해요.
     - ② 화합물은 모두 분자로 존재한다. 피드백: 염화 나트륨은 화합물이지만 이온으로 이루어져 있어요.
     - ③ [정답] 원소인 산소는 분자로, 화합물인 염화 나트륨은 이온으로 존재한다.
     - ④ 염화 나트륨은 나트륨 원자 1개와 염소 원자 1개가 결합한 분자이다. 피드백: 화학식 NaCl은 두 입자가 1 : 1로 들어 있다는 뜻이에요. 소금 속에는 따로 떨어진 분자가 없어요.
     - answer: 2. explain: 원소인지 화합물인지(성분)와 원자·분자·이온 중 어떤 입자로 존재하는지(입자)는 서로 다른 기준이에요. 그런데 이온은 어떻게 전하를 띠게 될까요? 👉 다음 차시 ⚡ 이온의 형성에서 알아봐요!
- recap: 물질을 이루는 입자는 원자, 분자, 이온 등으로 존재해요. 이온은 전하를 띤 입자예요.
- summary: 3칸 표(원자로 존재: 헬륨, 네온, 구리 / 분자로 존재: 산소, 물, 이산화 탄소, 메테인 / 이온으로 존재: 염화 나트륨) + note '이온이 생기는 과정은 다음 차시에서 배워요.'

### 7. 정확성·오개념 체크리스트
- 분자 정의 문구를 모든 곳에서 같게 쓴다: '원자가 결합하여 만들어진 입자로, 물질의 성질을 나타내는 가장 작은 입자'.
- 18족 기체는 '원자가 하나씩 따로 존재'로 표현한다. 출판사에 따라 '원자 1개로 된 분자'라고도 하므로, 헬륨을 '분자로 존재'로 고르게 하는 문항은 만들지 않는다.
- 금속은 원자가 규칙적으로 끝없이 배열한다(분자 없음). 소금(NaCl)은 분자가 없고 이온이 1 : 1로 배열한다.
- 물방울이 작아져도 분자 하나의 크기는 그대로다(개수만 줄어듦). 분자 수 값은 위 표대로 쓰고 '약'을 붙인다.
- 계수 표기(2H₂O, 2CO₂)를 쓰지 않는다. 이온은 '전하를 띤 입자' 수준으로만 다룬다(전자를 잃고 얻는 과정과 이온식은 다음 차시).
- 분자 모양은 실제대로 그린다(H₂O 굽음 104.5°, CO₂ 직선, CH₄ 정사면체, O₂ 원자 2개). 모양 이름과 각도는 말하지 않는다.

### 8. 자유 탐구(완료 후)
- 모든 장면을 고를 수 있다. 현미경에 시료를 자유롭게 넣고, 조립대에서 H·N 바구니까지 열어 H₂O, NH₃ 등을 자유롭게 조립한다.
