## `m3-science-careers` · 🔬 과학 관련 직업과 미래
- 성취기준 [9과23-01] 과학과 관련된 직업의 종류와 하는 일을 조사하고, 과학기술의 발달로 생기는 미래 사회의 직업 변화를 예상할 수 있다.
- 카드 설명(desc): 여러 과학 관련 직업이 하는 일과 쓰이는 과학 지식을 탐색하고, 과학기술의 발달로 줄어들거나 새로 생길 미래 직업을 예상해요.
- 태그: 과학 관련 직업, 미래 사회, 직업 변화 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 직업 탐색 · 직업 속 과학 · 미래의 변화 · 새 직업 설계

### 설계
범위: 과학 관련 직업의 종류와 하는 일 조사, 과학기술의 발달로 생기는 미래 사회의 직업 변화 예상. 탐구 활동: 다양한 직업 속 과학 탐색하기, 미래 사회에서 과학의 역할과 새로운 과학 직업 토의하기. 고려: 직업군별 조사 보고서를 바탕으로 발표·토론.
직업 카드 예(16장 내외): 물리·공학(반도체 공학자, 로봇 공학자, 신재생 에너지 기술자), 화학(신약 개발 연구원, 화장품 연구원, 신소재 공학자), 생명(생명 공학 연구원, 수의사, 식품 연구원, 의사), 지구·우주(기상 예보관, 지진 연구원, 해양 연구원, 천문학자), 융합(데이터 과학자, 기후변화 대응 전문가). 각 카드: 하는 일, 쓰는 과학 지식(중학교 단원 연결), 필요한 역량.
미래 변화(예상임을 표시): 인공지능·로봇 자동화로 단순 반복 업무는 줄고, 인공지능 윤리 전문가, 로봇 정비 기술자, 스마트 팜 전문가, 탄소 중립·재생 에너지 전문가, 디지털 헬스케어 전문가 등이 늘어날 것으로 예상.
탐구 질문: "과학을 배우면 어떤 일을 할 수 있고, 미래에는 어떤 직업이 생길까?"
① [관찰] 직업 탐색 — 분야 필터가 있는 직업 카드 도감, 카드를 뒤집어 하는 일 보기. 미션: 4개 분야 카드 열람(task), 퀴즈.
② [탐구] 직업 속 과학 — 직업 ↔ 쓰이는 중학교 과학 개념 짝짓기(manual: 기상 예보관 ↔ 기단과 전선, 반도체 공학자 ↔ 전기, 신약 개발 연구원 ↔ 화학 반응, 지진 연구원 ↔ 지권, 식품 연구원 ↔ 소화와 영양소), 퀴즈.
③ [분석] 미래의 변화 — 과학기술 카드(인공지능, 로봇, 기후 위기 대응, 우주 개발, 생명 공학)를 켜면 미래 도시 장면이 바뀌고, 직업 카드를 줄어듦/늘어남/새로 생김으로 분류(manual), 퀴즈(직업 변화의 원인).
④ [적용] 새 직업 설계 — 미래 문제(폭염 도시, 우주 쓰레기, 고령 사회, 플라스틱 쓰레기) 선택 → 필요한 과학 지식·기술 선택 → 나만의 미래 직업 카드 완성(manual, 입력 내용은 이 기기에만 저장).
애니메이션: 카드 뒤집기(scaleX tween), 짝짓기 연결선, 미래 도시 장면 전환, 카드 발급 burst.

## `m3-my-science-path` · 🧭 나의 진로와 과학 학습
- 성취기준 [9과23-02] 자신의 진로와 관련 있는 과학 분야를 조사하고, 진로 선택을 위하여 필요한 과학 학습을 계획할 수 있다.
- 카드 설명(desc): 나의 관심 분야를 찾고, 기술·공학·사회·예술·문학 직업에서도 필요한 과학을 조사해 진로를 위한 나만의 과학 학습 계획을 세워요.
- 태그: 진로, 과학 학습 계획, 고등학교 과학 과목 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 나의 관심 · 모든 직업 속 과학 · 고등학교 과학 · 학습 계획

### 설계
범위(해설): 과학과 직접 관련된 직업에서 과학의 역할뿐 아니라 기술, 공학, 사회, 예술, 문학 분야 등의 직업에서 필요한 과학 학문을 조사해 과학의 중요성과 유용성을 깨닫고 과학 학습 계획을 세움. 고려: 원하는 진로를 먼저 정하고 비슷한 진로의 학생들이 모둠 조사·발표.
직업 예: 건축가(힘의 평형·재료·지진 → 물리·지구과학), 과학수사관(지문·DNA → 생명과학·화학), 조향사(향 물질 → 화학), 음향 엔지니어(소리의 파동 → 물리), 무대 조명 디자이너(빛의 합성 → 물리), 미술품 복원가(물감 성분·빛 → 화학·물리), SF 작가(과학 지식으로 개연성 있는 세계 → 모든 분야), 요리사(화학 변화·열 → 화학), 스포츠 과학자(운동·에너지·인체 → 물리·생명과학), 기후 정책 담당자(기후 자료 → 지구과학).
2022 개정 고등학교 과학 과목: 공통 — 통합과학1·2, 과학탐구실험1·2 / 일반 선택 — 물리학, 화학, 생명과학, 지구과학 / 진로 선택 — 역학과 에너지, 전자기와 양자, 물질과 에너지, 화학 반응의 세계, 세포와 물질대사, 생물의 유전, 지구시스템과학, 행성우주과학 / 융합 선택 — 과학의 역사와 문화, 기후변화와 환경생태, 융합과학 탐구.
개인 정보: 흥미 검사 결과와 계획은 저장하지 않거나 이 기기(localStorage)에만 저장, 이름 입력 없음.
탐구 질문: "내가 꿈꾸는 직업에는 어떤 과학이 필요할까?"
① [관찰] 나의 관심 — 좋아하는 활동 8문항 선택 → 관심 영역 레이더 차트(탐구, 만들기, 돌봄, 표현, 자연, 자료 분석), 관심 직업 3개 고르기. 미션 2개(task).
② [탐구] 모든 직업 속 과학 — 과학과 멀어 보이는 직업 카드에 필요한 과학 분야(물리·화학·생명·지구) 태그 붙이기(manual), 퀴즈.
③ [설명] 고등학교 과학 — 과목 지도(공통 → 일반 선택 → 진로 선택·융합 선택), 직업 카드를 고르면 관련 과목 경로가 빛남. 미션: 내 직업의 과목 경로 만들기(task), 퀴즈(모든 학생이 배우는 과목: 통합과학).
④ [적용] 학습 계획 — 로드맵(중3 → 고1 → 고2·3 → 진로) 위에 학습 활동 카드(과목, 독서, 탐구 활동, 동아리, 체험) 배치해 나만의 과학 학습 계획 완성(manual), 완성 카드 보기.
애니메이션: 레이더 차트 tween, 과목 노드 경로 glow, 카드 드래그 snap, 로드맵 길이 자라남, 완성 시 burst.
