## `m2-digestion` · 🍙 소화와 소화 효소
- 성취기준 [9과13-01] 소화계의 구조와 기능을 이해하고, 소화 과정을 소화 효소의 작용과 관련지어 추론할 수 있다.
- 카드 설명(desc): 음식물이 소화 기관을 지나며 소화 효소로 분해되는 과정을 따라가고, 침의 소화 작용을 실험해요.
- 태그: 소화 효소, 아밀레이스, 흡수 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 영양소 · 침의 소화 · 소화 효소 · 흡수

### 설계
범위(해설): 소화 과정은 아밀레이스, 펩신, 트립신, 라이페이스 등 대표적인 효소 중심으로 간단하게. 아밀레이스(침·이자액): 녹말 → 엿당; 엿당은 소장에서 포도당으로; 펩신(위액): 단백질 분해; 트립신(이자액): 단백질 분해 → 최종 아미노산; 라이페이스(이자액): 지방 → 지방산 + 모노글리세리드; 쓸개즙은 지방 소화를 돕지만 효소가 아님. 흡수: 소장 융털(수용성 → 모세 혈관, 지용성 → 암죽관). 영양소 검출: 녹말-아이오딘(청람), 당-베네딕트(가열 시 황적색), 단백질-뷰렛(보라), 지방-수단Ⅲ(선홍).
탐구 질문: "밥은 어떻게 우리 몸의 에너지가 될까?"
① [관찰] 영양소 검출 — 음식 시료에 검출 용액을 떨어뜨려 색 변화로 영양소 확인(task: 3가지 검출), 퀴즈.
② [실험] 침의 소화 — 녹말 용액 + 물 / + 침, 35~40 °C 물중탕 → 아이오딘(청람→감소)·베네딕트(황적색) 비교. 미션: 실험(task), 퀴즈(침 속 아밀레이스가 녹말을 엿당으로).
③ [설명] 소화 효소 — 소화관 지도(입-식도-위-소장-대장, 간·쓸개·이자)를 따라 음식 입자가 이동하며 효소 카드가 작용하는 장소에 놓기(manual: 효소↔장소↔분해 대상).
④ [적용] 흡수 — 소장 융털 확대: 포도당·아미노산 → 모세 혈관, 지방산·모노글리세리드 → 암죽관 분류(manual), 퀴즈(융털이 흡수에 유리한 까닭: 표면적 넓음).
애니메이션: 분자 사슬이 효소에 의해 끊어지는 애니메이션, 연동 운동, 색 반응.

## `m2-circulation` · ❤️ 순환계와 혈액 순환
- 성취기준 [9과13-02] 순환계의 구조와 기능을 이해하고, 혈액의 순환 경로를 종합하여 발표할 수 있다.
- 카드 설명(desc): 심장과 혈관의 구조를 알아보고, 혈액이 몸과 폐를 도는 체순환·폐순환 경로를 직접 따라가며 완성해요.
- 태그: 심장, 혈관, 체순환, 폐순환 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 심장 · 혈관과 혈액 · 순환 경로 · 종합

### 설계
범위: 심장(우심방·우심실·좌심방·좌심실, 판막: 역류 방지), 혈관(동맥: 벽 두껍고 탄력, 정맥: 벽 얇고 판막, 모세 혈관: 한 층 세포 → 물질 교환), 혈액(혈장: 물질 운반, 적혈구: 산소 운반(헤모글로빈), 백혈구: 식균 작용, 혈소판: 혈액 응고). 체순환: 좌심실 → 대동맥 → 온몸 모세 혈관 → 대정맥 → 우심방 / 폐순환: 우심실 → 폐동맥 → 폐 모세 혈관 → 폐정맥 → 좌심방. 동맥혈·정맥혈.
탐구 질문: "심장에서 나간 혈액은 어디를 거쳐 다시 돌아올까?"
① [관찰] 심장 — 박동하는 심장 모형(심방 수축 → 심실 수축, 판막 열림/닫힘, 혈액 흐름). 미션: 네 방 이름 붙이기(manual), 퀴즈(판막의 역할).
② [탐구] 혈관과 혈액 — 혈관 세 종류 단면 비교, 혈액 현미경(적혈구·백혈구·혈소판 탭). 미션: 구조-기능 짝(manual), 퀴즈(물질 교환이 일어나는 혈관).
③ [모형] 순환 경로 — 몸 전체 지도에서 혈액 방울을 끌어 체순환과 폐순환 경로 완성(산소가 많은 혈액 빨강, 적은 혈액 파랑으로 색 전환). 미션: 두 경로 완주(task), 퀴즈(폐정맥에 흐르는 혈액 = 동맥혈).
④ [적용] 종합 — 경로 순서 카드 배열(manual), 퀴즈(운동할 때 심장 박동이 빨라지는 까닭).
애니메이션: 심장 박동(scale pulse), 판막 개폐, 혈구 흐름 입자, 색 전환(산소 교환).

## `m2-breathing` · 🫁 호흡계와 호흡 운동
- 성취기준 [9과13-03] 호흡계의 구조와 기능을 이해하고, 호흡 운동의 원리를 나타내는 모형을 만들 수 있다.
- 카드 설명(desc): 갈비뼈와 가로막의 움직임으로 공기가 드나드는 호흡 운동 모형을 만들고, 폐포에서의 기체 교환을 관찰해요.
- 태그: 폐, 가로막, 호흡 운동, 폐포 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 호흡 기관 · 호흡 운동 모형 · 들숨과 날숨 · 기체 교환

### 설계
범위: 호흡계(코 → 기관 → 기관지 → 폐(폐포)), 폐는 근육이 없어 갈비뼈·가로막의 움직임으로 흉강 부피·압력이 변해 공기가 드나듦(들숨: 갈비뼈 올라가고 가로막 내려감 → 흉강 부피 증가·압력 감소 → 공기 들어옴; 날숨은 반대). 폐포 ↔ 모세 혈관 기체 교환(농도 차에 의한 확산: 산소 폐포→혈액, CO₂ 혈액→폐포). 호흡 운동 원리를 나타내는 모형 만들기.
탐구 질문: "근육이 없는 폐는 어떻게 부풀었다 줄어들까?"
① [관찰] 호흡 기관 — 공기 입자가 코→기관→기관지→폐포로 들어가는 경로 애니메이션, 이름 붙이기(manual).
② [모형] 호흡 운동 모형 — 페트병 + 고무풍선(폐) + 고무막(가로막) 모형: 고무막을 아래로 당기면 병 속 부피↑·압력↓ → 풍선 부풂(task: 당기기/놓기). 모형 부분 ↔ 몸 부분 짝짓기.
③ [설명] 들숨과 날숨 — 사람 몸 단면에서 갈비뼈·가로막을 끌어 움직이면 흉강 부피 게이지와 공기 흐름 화살표. 미션: 들숨 만들기(task), 퀴즈(들숨 때 가로막의 움직임).
④ [적용] 기체 교환 — 폐포 확대: 산소·CO₂ 입자가 농도 차에 따라 이동(확산). 미션: 운동 중(CO₂ 증가) 교환 관찰, 퀴즈(폐포가 많은 까닭: 표면적).
애니메이션: 고무막 탄성(spring), 풍선 부피 변화, 공기 입자 흐름, 확산 입자.

- 카드 설명(desc): 노폐물이 만들어져 콩팥에서 걸러지는 과정을 네프론 모형으로 보고, 여과·재흡수·분비를 모식도로 표현해요.

### 설계
범위: 노폐물(탄수화물·지방 → 이산화 탄소·물, 단백질 → 이산화 탄소·물·암모니아 → 간에서 요소로), 배설계(콩팥 → 오줌관 → 방광 → 요도), 콩팥 구조(겉질·속질·콩팥 깔때기, 네프론 = 사구체 + 보먼주머니 + 세뇨관), 오줌 생성: 여과(사구체 → 보먼주머니: 물·포도당·아미노산·요소·무기염류; 혈구·단백질은 여과 안 됨) → 재흡수(세뇨관 → 모세 혈관: 포도당·아미노산 전부, 물·무기염류 대부분) → 분비(모세 혈관 → 세뇨관). 노폐물 배설 과정을 모식도로 표현.
탐구 질문: "몸속 노폐물은 어떻게 오줌이 되어 나갈까?"
① [관찰] 노폐물 — 영양소 분해 결과 생기는 노폐물 분류(manual: CO₂·물 → 폐/콩팥, 암모니아 → 간에서 요소 → 콩팥), 퀴즈.
② [탐구] 콩팥 구조 — 콩팥 단면 확대 → 네프론. 부분 이름 탭(task), 퀴즈.
③ [모형] 오줌 생성 — 네프론 모형에 혈액 입자 흘리기: 사구체에서 크기에 따라 여과(큰 혈구·단백질은 남음), 세뇨관에서 포도당·아미노산 재흡수, 노폐물 분비. 미션: 필터 크기 조절해 올바른 여과(task), 퀴즈(건강한 사람 오줌에 포도당이 없는 까닭).
④ [적용] 모식도 — 여과·재흡수·분비 화살표를 모식도에 배치(manual), 배설 경로 순서 퀴즈.
애니메이션: 입자 흐름과 거름 필터(크기 판별), 재흡수 화살표 펄스.

- 태그: 세포호흡, 미토콘드리아, 기관계 통합 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 운동과 몸 · 세포호흡 · 통합 지도 · 적용

### 설계
범위(해설): 각 기관계의 자세한 구조·기능보다 에너지를 얻기 위한 통합적 관계에 중점. 세포호흡: 영양소(포도당) + 산소 → 이산화 탄소 + 물 + 에너지(미토콘드리아), 에너지는 근육 운동·체온 유지·생장 등에 사용.
탐구 질문: "달리기를 하면 왜 숨이 차고 심장이 빨리 뛸까?"
① [관찰] 운동과 몸 — 달리는 캐릭터의 운동 강도 슬라이더 → 심박수·호흡수·체온 게이지 증가. 미션: 강도 변화 관찰(task), 퀴즈.
② [설명] 세포호흡 — 근육 세포 확대 → 미토콘드리아에서 포도당 + 산소 → CO₂ + 물 + 에너지(빛나는 에너지) 애니메이션. 미션: 재료 넣어 에너지 만들기(task), 퀴즈(세포호흡과 호흡 운동의 차이).
③ [모형] 통합 지도 — 몸 지도에서 소화계(영양소 흡수) → 순환계(운반) ← 호흡계(산소 흡수) → 세포(세포호흡) → 순환계 → 호흡계(CO₂ 배출)·배설계(요소 등 배출) 연결선 완성(manual), 흐름 입자.
④ [적용] 퀴즈 — 한 기관계에 문제가 생기면?(예: 빈혈 → 산소 운반 감소 → 쉽게 피곤), 통합 설명.
애니메이션: 심박·호흡 리듬, 입자 경로 흐름, 미토콘드리아 에너지 글로우.
