고려 사항: 세 법칙은 추상성이 높으므로 모든 차시에 '입자 모형으로 보기' 돋보기(원자 공 모형)를 두어 시각적으로 접근.

## `m3-physical-chemical` · 🔥 물리 변화와 화학 변화
- 성취기준 [9과16-01] 물리 변화와 화학 변화의 의미를 알고, 화학 변화에서 새로운 물질이 생성됨을 관찰할 수 있다.
- 카드 설명(desc): 종이를 자를 때와 태울 때를 비교하고, 앙금·기체·색 변화 같은 증거로 새로운 물질이 생기는 화학 변화를 관찰해요.
- 태그: 물리 변화, 화학 변화, 새로운 물질 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 두 가지 변화 · 새 물질의 증거 · 입자 모형 · 분류하기

### 설계
범위: 물리 변화 = 물질의 모양·크기·상태만 변하고 성질은 변하지 않음(분자는 그대로, 배열·거리만 달라짐). 화학 변화 = 성질이 다른 새로운 물질이 생김(원자가 재배열되어 다른 분자가 됨).
새 물질이 생긴 증거: 앙금 생성, 기체 발생, 색 변화, 빛·열 발생, 냄새 변화. 화학 반응식은 다음 차시이므로 화학식은 모형 이름표 정도만.
탐구 질문: "종이를 자를 때와 태울 때, 무엇이 다를까?"
① [관찰] 두 가지 변화 — 종이 자르기(작아질 뿐 여전히 종이) vs 종이 태우기(재·연기, 다시 종이가 되지 않음), 설탕 녹이기 vs 설탕 가열(검게 타며 냄새). 미션: 네 가지 모두 해 보기(task), 퀴즈(새로운 물질이 생긴 것).
② [실험] 새 물질의 증거 — 실험대 4개: 마그네슘 리본 + 묽은 염산 → 기포(수소), 염화 나트륨 수용액 + 질산 은 수용액 → 흰색 앙금, 구리판 가열 → 검게 변함, 강철 솜 연소 → 빛과 열. 각 결과에 증거 스티커(기체/앙금/색/빛·열) 붙이기(manual), 퀴즈. 보안경 착용 안내 한 줄.
③ [모형] 입자 모형 — 같은 물로 비교: 물이 끓음(물리: 물 분자 그대로, 사이 거리만 멀어짐) vs 물의 전기 분해(화학: 물 분자 → 수소 분자 + 산소 분자, 원자 재배열). 원자 수 카운터(두 경우 모두 원자의 종류·수는 그대로). 미션: 두 변화를 실행해 분자 종류 비교(task), 퀴즈(화학 변화에서 변하는 것: 분자의 종류 / 변하지 않는 것: 원자의 종류와 수).
④ [적용] 분류하기 — 카드 10장을 물리/화학 상자로 끌기(manual): 철이 녹슨다(화), 얼음이 녹는다(물), 유리컵이 깨진다(물), 김치가 시어진다(화), 설탕이 물에 녹는다(물), 달걀을 삶는다(화), 드라이아이스가 작아진다(물), 과일이 익는다(화), 향수 냄새가 퍼진다(물), 양초 심지 위 불꽃(화). 퀴즈: 촛농이 녹아 흐름(물리) vs 양초가 탐(화학).
애니메이션: 종이가 가장자리부터 타들어 가며 오그라듦(불꽃 + 재), 기포 상승, 흰 앙금이 구름처럼 퍼짐, 원자 분리·재결합 tween, 카드 스냅.

## `m3-chemical-equation` · 🧩 화학 반응식
- 성취기준 [9과16-02] 간단한 화학 반응을 화학 반응식으로 표현하고, 화학 반응식에서 계수의 비를 입자 수의 비로 해석할 수 있다.
- 카드 설명(desc): 분자 모형을 조립해 반응 전후 원자 수를 맞추며 화학 반응식을 완성하고, 계수의 비가 입자 수의 비임을 알아내요.
- 태그: 화학 반응식, 계수, 입자 수의 비 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 반응 모형 · 원자 수 맞추기 · 반응식 완성 · 계수의 비

### 설계
범위: 간단한 화학 반응을 화학 반응식으로 표현 — 반응물 → 생성물, 화학식 앞 계수(1은 생략), 반응 전후 원자의 종류와 수가 같도록 계수 맞추기(화학식 자체는 바꿀 수 없음). 계수의 비 = 분자 수(입자 수)의 비.
다룰 반응: 2H₂ + O₂ → 2H₂O, C + O₂ → CO₂, 2H₂O → 2H₂ + O₂, N₂ + 3H₂ → 2NH₃, CH₄ + 2O₂ → CO₂ + 2H₂O. 다루지 않음: 상태 기호, 몰, 산화·환원, 질량 계산.
탐구 질문: "화학 반응을 누구나 알아볼 수 있게 기호로 간단히 나타내려면 어떻게 해야 할까?"
① [모형] 반응 모형 — 수소 분자와 산소 분자를 반응 용기에 넣고 점화 → 분자가 깨지고 원자가 다시 결합해 물 분자 생성(애니메이션), 단어식 '수소 + 산소 → 물'. 미션: 반응시키기(task), 퀴즈(반응물/생성물 구분).
② [탐구] 원자 수 맞추기 — 분자 모형 상자에서 H₂·O₂·H₂O 분자 수를 +/−로 조절, 반응 전/후 원자 수 막대(H, O)가 같아지면 저울이 수평. 미션: 원자 수 맞추기(task), 퀴즈(H₂O를 H₂O₂로 바꾸면 안 되는 까닭 → 다른 물질이 됨, 계수만 조절).
③ [설명] 반응식 완성 — 4단계 안내(단어로 → 화학식으로 → 계수 맞추기 → 1 생략)로 C + O₂ → CO₂, 2H₂O → 2H₂ + O₂, N₂ + 3H₂ → 2NH₃ 완성(manual: 계수 칸 선택), 퀴즈.
④ [적용] 계수의 비 — 2H₂ + O₂ → 2H₂O에서 수소 분자 6개와 반응하는 산소 분자 수·생기는 물 분자 수(입자 모형으로 확인, 남는 분자 표시), 메테인 연소 계수비 퀴즈.
애니메이션: 분자 결합 해체·재결합(spring), 원자 저울 기울기, 계수 숫자 롤링, 맞으면 burst + check.

## `m3-mass-conservation` · ⚖️ 질량 보존 법칙
- 성취기준 [9과16-03] 화학 반응에서 질량이 보존됨을 실험을 통해 추론할 수 있다.
- 카드 설명(desc): 앙금 생성, 기체 발생, 연소 반응 전후의 질량을 재어 비교하고, 원자의 배열만 바뀌므로 질량이 보존됨을 추론해요.
- 태그: 질량 보존 법칙, 앙금 생성, 기체 발생, 연소 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 앙금 생성 · 기체 발생 · 연소 · 원자 모형

### 설계
범위(해설): 화학 반응이 일어날 때 원자의 배열만 변하고, 원자의 종류와 수는 변하지 않음을 강조. 반응 전 물질의 총질량 = 반응 후 물질의 총질량(질량 보존 법칙, 라부아지에).
고려 사항: 기체의 질량을 측정할 때 부력이 영향을 줄 수 있음 → 부풀어 오르는 풍선 대신 단단한 밀폐 용기 사용(화면 안내 한 줄). 탐구 활동: 화학 반응 전후의 질량 변화 관찰하기.
자료(예시 값): 앙금 — 염화 나트륨 수용액 + 질산 은 수용액 → 염화 은(흰 앙금) + 질산 나트륨, 두 비커 합 150.0 g → 반응 후 150.0 g.
기체 발생 — 탄산 칼슘 2.5 g + 묽은 염산 → 염화 칼슘 + 물 + 이산화 탄소: 열린 용기 120.0 g → 118.9 g(이산화 탄소 1.1 g이 빠져나감), 닫힌 용기 120.0 g → 120.0 g, 뚜껑을 열면 118.9 g.
연소 — 강철 솜(철) 2.0 g을 공기 중에서 태우면 증가(예: 2.4 g, 결합한 산소만큼), 나무(종이)를 태우면 감소(이산화 탄소·수증기가 빠져나감), 밀폐 용기 속에서 태우면 일정.
탐구 질문: "물질이 타서 재만 남으면 질량은 사라진 걸까?"
① [실험] 앙금 생성 — 전자저울 위 두 비커를 섞기 → 흰 앙금, 질량 그대로. 입자 돋보기: 이온(원자) 짝만 바뀜. 미션: 섞고 질량 비교(task), 퀴즈.
② [실험] 기체 발생 — 열린 용기 vs 닫힌 용기 선택 → 열린 용기는 기포가 빠져나가며 질량 감소, 닫힌 용기는 일정, 뚜껑을 열면 감소. 미션: 두 용기 실험(task 2), 퀴즈(열린 용기에서 질량이 줄어든 까닭).
③ [실험] 연소 — 강철 솜(증가) vs 나무(감소) 연소, 마지막에 밀폐 용기 속 연소(일정). 산소 분자가 결합/이산화 탄소가 날아감을 입자로 표시. 미션: 두 연소 결과 예측 후 확인(task), 퀴즈.
④ [모형] 원자 모형 — 세 반응을 원자 공 모형으로 재생: 반응 전후 원자 개수 카운터가 같음 → 질량 보존 법칙. 미션: 원자 수 세어 확인(task), 적용 퀴즈 2개(밀폐 용기 속 양초 연소, 녹슨 철못의 질량).
애니메이션: 저울 숫자 롤링, 용액 붓기와 앙금 퍼짐, 기포와 이산화 탄소 분자가 용기 밖으로 빠져나감, 강철 솜 불꽃(Particles spark), 원자 카운터.

- 성취기준 [9과16-04] 화합물을 구성하는 성분 원소의 질량비가 일정함을 실험 자료를 해석하여 설명할 수 있다.
- 카드 설명(desc): 구리를 가열하는 실험 자료를 그래프로 해석해, 화합물을 이루는 성분 원소의 질량비가 항상 일정함을 설명해요.
- 태그: 일정 성분비 법칙, 질량비, 화학식 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 구리의 산화 · 질량비 그래프 · 입자 모형 · 적용

### 설계
범위: 화합물을 구성하는 성분 원소 사이에는 일정한 질량비가 성립(일정 성분비 법칙, 프루스트). 구리 : 산소 = 4 : 1(구리 4 g → 산화 구리(Ⅱ) 5 g), 마그네슘 : 산소 = 3 : 2(마그네슘 3 g → 산화 마그네슘 5 g), 물 수소 : 산소 = 1 : 8.
고려 사항: 일정 성분비 법칙은 화합물의 성분 원소를 화학식으로 일정하게 표현할 수 있는 근거(물은 언제나 H₂O). 여러 모둠의 데이터를 공유 플랫폼처럼 모아 분석('모둠 데이터 보드'). 혼합물(설탕물)은 성분비가 일정하지 않음과 대비. 다루지 않음: 몰, 원자량 계산식.
탐구 질문: "구리를 가열하면 산소와 아무 비율로나 결합할까?"
① [실험] 구리의 산화 — 도가니의 붉은 구리 가루를 가열하며 저어 주기 → 검게 변하고 질량 증가, 더 이상 늘지 않을 때까지 반복(구리 2.00 g → 2.50 g에서 일정). 미션: 질량이 일정해질 때까지 가열(task), 퀴즈(결합한 산소 0.50 g).
② [분석] 질량비 그래프 — 모둠 데이터 보드(구리 1.0·2.0·3.0·4.0 g → 산화 구리 약 1.25·2.5·3.75·5.0 g, 약간의 측정 오차 포함) → 구리 질량–결합한 산소 질량 그래프에 점 찍기 → 원점을 지나는 직선 → 구리 : 산소 = 4 : 1. 미션: 점 4개 찍기(task), 퀴즈.
③ [모형] 입자 모형 — 구리 원자 1개와 산소 원자 1개가 결합(CuO), 원자 1개의 질량이 정해져 있으므로 질량비도 일정. 구리 원자 6개 + 산소 분자 4개 → CuO 6개 + 산소 분자 1개 남음. 비교: 설탕물은 설탕을 얼마든지 섞을 수 있음(혼합물). 미션: 남는 입자 찾기(task), 퀴즈(일정 성분비 법칙이 화학식의 근거인 까닭).
④ [적용] — 마그네슘 연소(3 : 2)로 마그네슘 6 g → 산화 마그네슘 10 g, 물 생성(1 : 8)에서 수소 2 g + 산소 20 g → 물 18 g과 산소 4 g 남음. 퀴즈 3개.
애니메이션: 가열 불꽃(D.flame), 구리 가루 붉은색→검은색 전이(approach), 저울 숫자, 그래프 점이 날아와 꽂힘, 원자 짝짓기 snap.

## `m3-gas-volume` · 💨 기체 반응 법칙
- 성취기준 [9과16-05] 기체 반응에서 기체 부피 사이의 비가 일정함을 실험 자료를 해석하여 설명할 수 있다.
- 카드 설명(desc): 기체끼리 반응할 때 반응하고 생성되는 기체의 부피 사이에 간단한 정수비가 성립함을 실험 자료로 해석하고, 계수비와 연결해요.
- 태그: 기체 반응 법칙, 부피비, 계수비 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 수증기 생성 · 부피비 분석 · 분자 모형 · 적용

### 설계
범위: 일정한 온도와 압력에서 기체끼리 반응해 기체가 생성될 때 각 기체의 부피 사이에는 간단한 정수비가 성립(기체 반응 법칙, 게이뤼삭). 수소 : 산소 : 수증기 = 2 : 1 : 2, 질소 : 수소 : 암모니아 = 1 : 3 : 2, 수소 : 염소 : 염화 수소 = 1 : 1 : 2.
같은 온도·압력에서 같은 부피 속에는 기체의 종류와 관계없이 같은 수의 분자 → 부피비 = 분자 수의 비 = 반응식의 계수비. 질량과 달리 부피는 보존되지 않을 수 있음(2 + 1 → 2). 다루지 않음: 몰, 기체 상수, 질량 계산.
탐구 질문: "기체끼리 반응할 때 부피 사이에도 규칙이 있을까?"
① [실험] 수증기 생성 — 눈금 실린더형 반응 용기에 수소와 산소를 넣고 전기 불꽃 점화(100 °C 이상 유지, 생성된 물은 수증기) → 남은 기체 부피 측정. (20, 10) → 수증기 20, 남는 기체 없음 / (20, 20) → 산소 10 남음 / (30, 10) → 수소 10 남음. 미션: 남는 기체가 없는 조합 찾기(task), 퀴즈.
② [분석] 부피비 분석 — 실험 결과 표에서 반응한 부피만 골라 2 : 1 : 2 찾기, 암모니아·염화 수소 생성 자료 해석(manual), 퀴즈.
③ [모형] 분자 모형 — 같은 크기 칸 하나 = 분자 1개. 수소 2칸 + 산소 1칸 → 수증기 2칸, 원자는 쪼갤 수 없으므로 산소는 원자 2개짜리 분자여야 함. 2H₂ + O₂ → 2H₂O의 계수비 = 부피비. 미션: 칸 채우기(task), 퀴즈.
④ [적용] — 질소 10 mL + 수소 40 mL → 암모니아 20 mL, 수소 10 mL 남음(반응 전 50 mL → 후 30 mL: 부피는 줄었지만 질량은 보존). 퀴즈 2~3개(오개념: 기체 반응에서도 부피가 보존된다 X).
애니메이션: 피스톤 tween, 전기 불꽃 D.spark, 분자 칸 격자 재배열, 눈금 상승·하강 approach.
