## 개념 위계와 차시 흐름
선수: 중2 '동물과 에너지'(m2-cell-respiration), 중2 '식물과 에너지'(m2-photosynthesis, m2-plant-respiration, m2-plant-products), 통합과학1(h1-energy-exchange, h1-solar-energy, h1-enzyme), 생명과학 Ⅰ(hb-metabolism-atp), 앞 단원 56(소기관, 막 구조·능동 수송), 앞 단원 57(ATP와 에너지 공급 hy-atp-energy, 효소의 작용 기작·조절).
차시 흐름: ① 미토콘드리아의 구조(모형 제작, 구조와 기능) → ② 세포호흡의 4단계(해당 과정 → 피루브산 산화 → TCA 회로 → 전자 전달계, 장소와 투입·산출) → ③ 두 가지 인산화(기질 수준 vs 산화적 인산화·화학 삼투) → ④ 산소호흡과 발효(알코올·젖산 발효의 비교) → ⑤ 발효 실험과 사례 조사(실험 설계·수행, 조사 계획) → ⑥ 엽록체와 광합성 색소(구조 모형, 크로마토그래피) → ⑦ 명반응 → ⑧ 탄소 고정 반응과 두 반응의 관계 → ⑨ 전자 전달계 비교(세포호흡 vs 광합성) → ⑩ 광합성 연구의 역사(시각화 자료 제작).
'분해와 에너지 생성(①~⑤)' → '합성과 에너지 저장(⑥~⑧)' → '두 과정의 통합 비교(⑨)' → '과학사로 되돌아보기(⑩)' 순. 세포호흡을 먼저 하는 까닭: 화학 삼투와 전자 전달계를 호흡에서 먼저 익히고 광합성에서 같은 원리가 다른 방향으로 일어남을 비교하게 하기 위함. 단원 57의 hy-atp-energy 는 흐름 개요, 여기서는 단계별 특징.
고려 사항: 세포호흡과 광합성은 효소에 의해 조절되는 일련의 화학 반응이며, 호흡과 탄소 고정 반응에서 유기물의 분자 구조식은 다루지 않는다(탄소 개수를 나타내는 구슬로만 표현, 이름 옆에 '3탄소 화합물' 식으로 표기). 산화적 인산화는 화학 삼투로 ATP 가 합성된다는 수준까지. 전자 전달계 비교는 에너지, 효소, 산화·환원 중심. 미토콘드리아·엽록체 내부 구조는 가상 현실·증강 현실 느낌의 3D 회전 모형 도구로 제작(캔버스 3D 회전·단면 모드). 발효 사례와 광합성 과학사는 시각화 도구(연표·인포그래픽 구성)를 활용하는 활동으로 구성.

## `hy-mitochondria` · ⚙️ 미토콘드리아의 구조
- 성취기준 [12세포03-01] 미토콘드리아의 구조를 이해하고 생명체 내에서의 미토콘드리아의 기능을 추론할 수 있다.
- 카드 설명(desc): 미토콘드리아의 단면 모형을 직접 조립하고, 막과 기질의 구조가 세포호흡과 어떻게 연결되는지, 세포마다 개수가 다른 까닭을 추론해요.
- 태그: 미토콘드리아, 크리스타, 모형 제작, 구조와 기능 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 모형 조립 · 구조와 기능 · 표면적 · 세포 추론

### 설계
범위(해설): [12세포03-01] — 미토콘드리아의 구조를 이해하고 생명체 내에서의 기능을 추론. 탐구 활동 '미토콘드리아와 엽록체 내부구조 모형 제작하기' 중 미토콘드리아 부분(고려 사항: 다양한 도구·매체, 가상·증강 현실 활용 → 3D 회전·단면 모형). 세포호흡 단계의 상세는 다음 차시, 여기서는 '어느 구조에서 어떤 종류의 일이 일어나는지' 대응까지. 앞 차시들의 막(이중막), 소기관 분획(hy-organelles: 미토콘드리아는 10000 g 침전물), 원핵생물과 닮은 점(고리 DNA, 70S 리보솜 — hy-prok-euk 의 힌트)을 연결. 다루지 않음: 내부 공생설 상세, 미토콘드리아 DNA 유전, 세포 자살.
구조: 외막(매끈, 작은 분자 통과 쉬움), 막 사이 공간(두 막 사이, 화학 삼투 때 H⁺ 가 모이는 곳), 내막(안쪽으로 접혀 들어간 크리스타 cristae, 전자 전달계 단백질과 ATP 합성 효소가 박혀 있음, 선택적 투과성 높음), 기질(matrix, 내막 안쪽, 피루브산 산화·TCA 회로의 효소, 고리 모양 DNA, 70S 리보솜). 크기: 길이 1~2 μm, 지름 약 0.5 μm 의 소시지 모양(현미경 사진에서는 둥글게 보이기도 함).
기능: 세포호흡의 장소(해당 과정만 세포질, 이후 단계는 미토콘드리아: 기질에서 피루브산 산화 + TCA 회로, 내막에서 전자 전달과 ATP 합성). 일의 대응(개요): 기질 — 분해(CO₂ 생성, 전자 운반체 충전), 내막 — 에너지 전환(ATP 합성), 막 사이 공간 — H⁺ 저장소.
표면적 계산(모형): 외막이 원통(길이 2 μm, 지름 0.5 μm)이면 겉넓이 ≈ π × 0.5 × 2 + 2 × π × 0.25² ≈ 3.14 + 0.39 = 3.5 μm². 내막은 크리스타로 접혀 외막보다 훨씬 넓음: 크리스타 판 N 개이면 내막 표면적 ≈ 3.5 × (1 + 0.5 N)(판 하나당 단순 +50 %, N = 8 → 5배 ≈ 17.5 μm²). ATP 합성 효소 수 ∝ 내막 표면적(단순 가정) → 같은 부피에서 크리스타가 많으면 ATP 생산 능력 증가.
세포별 미토콘드리아(개략): 간세포 1000~2000개, 심장 근육 세포는 세포 부피의 약 30~40 %, 골격근 많음(운동 선수 증가), 정자는 꼬리 중편부에 나선형으로 감김, 갈색 지방 세포(체온 유지)는 크리스타가 매우 발달, 지방 저장 세포·피부 표피 각질층 세포는 적음, 사람 성숙 적혈구는 0개(산소를 운반하지만 미토콘드리아가 없어 자기 산소를 소비하지 않음, 포도당을 해당 과정으로만 분해).
탐구 질문: "미토콘드리아의 겉은 매끈한데 속은 왜 주름져 있을까? 모든 세포에 같은 수가 들어 있을까?"
① [모형] 모형 조립 — 3D 단면 모형: 외막 껍질, 내막 껍질, 크리스타, 기질, 막 사이 공간, DNA, 리보솜 부품 7개를 끌어다 맞추면 조각이 snap 되고 조립 중간에도 드래그로 360° 회전·단면 슬라이더로 절개. 부품마다 이름표. 미션: 부품 7개 조립(task), 단면 구조에 이름 붙이기(manual 5개), 퀴즈(미토콘드리아의 막은 몇 겹? 이중막이며 안쪽 막이 접혀 크리스타).
② [탐구] 구조와 기능 — 기능 위치 지도: 반응 카드 5개(해당 과정, 피루브산 산화, TCA 회로, 전자 전달과 ATP 합성, H⁺ 저장)를 세포질/기질/내막/막 사이 공간 중 알맞은 곳에 배치(manual, 개요 수준), 효소·전자 전달 단백질·ATP 합성 효소가 내막에 박혀 있는 모습 확대. 호흡 억제제 선택(시안화물 처리)에서 ATP 생산 중단과 산소 소비 정지 시연. 미션: 위치 지도 완성(manual), 퀴즈 2개(해당 과정이 미토콘드리아가 없는 세포에서도 일어나는 까닭: 세포질에서 진행, 미토콘드리아에 DNA 와 리보솜이 있다는 것으로 알 수 있는 것: 자체 단백질 일부를 합성).
③ [분석] 표면적 — 크리스타 수 슬라이더 N(0 ~ 12)에 따라 내막 표면적(3.5 × (1 + 0.5N)) 계산 표시, 내막에 박힌 ATP 합성 효소 점의 수와 ATP 생산 속도 게이지 변화. 같은 크기에서 N = 0 vs N = 8 비교. 미션: N = 8 일 때 표면적 계산(task: 약 17.5 μm²), ATP 생산을 3배로 하려면 필요한 N 찾기(task: N = 8 → 5배 이므로 3배는 N = 4), 퀴즈 2개(주름이 표면적을 늘리는 것의 의미: 단백질 복합체가 더 많이 들어감, 장 융털이나 허파꽈리가 같은 원리).
④ [적용] 세포 추론 — 세포 6종(심장 근육 세포, 지방 저장 세포, 정자, 간세포, 사람 성숙 적혈구, 갈색 지방 세포)의 단면 사진에 미토콘드리아 개수와 크리스타 밀도 그림을 보고 에너지 사용량 순서·하는 일 추론하여 연결(manual). 퀴즈 3개(운동을 꾸준히 한 사람의 근육 세포에서 변화: 미토콘드리아 증가, 적혈구에 미토콘드리아가 없는 것의 의미, 미토콘드리아가 손상되면 가장 먼저 영향을 받는 기능: ATP 생산).

## `hy-respiration-stages` · 🔄 세포호흡의 4단계
- 성취기준 [12세포03-02] 세포호흡 과정의 단계별 특징을 다양한 매체를 활용하여 협력적으로 소통할 수 있다.
- 카드 설명(desc): 포도당이 해당 과정, 피루브산 산화, TCA 회로, 전자 전달계를 거치며 탄소와 전자가 어디로 가는지 추적하고 친구에게 단계별로 설명해요.
- 태그: 해당 과정, TCA 회로, 전자 전달계, NADH / 단계 이름(steps → 각 STEP의 short와 맞출 것): 4단계 지도 · 산출물 계산 · 호흡 조절 · 릴레이 설명

### 설계
범위(해설): [12세포03-02] — 세포호흡 과정의 단계별 특징을 다양한 매체로 협력적으로 소통. 해설: 세포호흡은 효소에 의해 조절되는 일련의 화학 반응이며 유기물의 분자 구조식은 다루지 않음 → 탄소 개수 구슬(●)로만 표현하고 물질은 '6탄소 포도당', '3탄소 피루브산', '2탄소 아세틸 CoA' 처럼 표기. 산화적 인산화의 화학 삼투 원리는 다음 차시(여기서는 전자 전달계에서 ATP 가 많이 만들어진다는 결과까지). 발효는 다음 차시. 다루지 않음: 중간 물질 이름 전부와 효소 이름(총 약 20가지 효소 중 핵심만), 지방·단백질의 호흡 기질 이용 경로, 글루코스 수송.
전체 반응: 포도당(C₆H₁₂O₆) + 6O₂ → 6CO₂ + 6H₂O + 에너지(ATP 약 30, 나머지 열). 이화 과정이며 효소가 단계를 조절. 전자 운반체: NAD⁺ ⇄ NADH(수소 전자를 받으면 환원), FAD ⇄ FADH₂.
단계표(포도당 1분자 기준):
• 해당 과정 — 세포질, 산소 필요 없음. 6탄소 포도당 → 3탄소 피루브산 2분자. ATP 소비 2, 생성 4 → 순생산 2(기질 수준 인산화), NADH 2.
• 피루브산 산화(연결 반응) — 미토콘드리아 기질. 3탄소 피루브산 → 2탄소 아세틸 CoA + CO₂ (피루브산 2분자 → CO₂ 2, NADH 2).
• TCA 회로 — 미토콘드리아 기질. 2탄소 아세틸 CoA 1분자가 회로에 들어가 CO₂ 2분자를 내보내며 ATP 1, NADH 3, FADH₂ 1 생성. 포도당 1분자당 회로 2회전 → CO₂ 4, ATP 2, NADH 6, FADH₂ 2.
• 전자 전달계 + 화학 삼투 — 미토콘드리아 내막. NADH, FADH₂ 의 전자가 전달되며 최종 전자 수용체 O₂ 가 H₂O 로 환원, ATP 대량 합성(약 26~28). 환산: NADH 1개 → ATP 약 2.5, FADH₂ 1개 → 약 1.5 (단순 값). 합계 NADH 10 → 25, FADH₂ 2 → 3 → 28 ATP.
합계 확인: 탄소 6 = CO₂ 6(피루브산 산화 2 + TCA 4), ATP 직접 4(해당 2 + TCA 2) + 전자 전달 28 = 최대 약 32(실제 세포에서는 약 30~32로 소개). 산소 사용: 마지막 단계(전자 수용체)에서만 직접 쓰이나, 산소가 없으면 NADH 가 NAD⁺ 로 되돌아가지 못해 앞 단계들도 정지.
효소 조절 자료: 해당 과정의 핵심 효소(포스포프럭토키네이스, 이름만)는 ATP 가 많을수록 활성이 감소하고 ADP 가 많을수록 증가 → ATP 가 충분하면 호흡 속도를 늦추는 되먹임(앞 단원 hy-enzyme-regulation 연결). 근육 운동 시 ATP 소비↑ → ADP↑ → 호흡 속도↑.
탐구 질문: "포도당 한 알이 이산화 탄소와 물로 사라지는 동안 에너지는 어떤 길로 ATP 에 담길까?"
① [모형] 4단계 지도 — 세포 단면(세포질 + 미토콘드리아)에 단계 카드 4개를 배치: 포도당 구슬 6개가 세포질에서 3개씩 둘로 쪼개지고(해당), 미토콘드리아로 들어가 구슬 1개가 CO₂ 로 떨어져 나가 2개짜리(피루브산 산화), 회로에 들어가 2개 구슬이 모두 CO₂ 로 떨어져 나가며(TCA), NADH·FADH₂ 가 내막으로 가서 O₂ 와 만나 물이 되며 ATP 가 쏟아짐(전자 전달). 구슬 개수 추적: 6 → 3+3 → 2+2 (CO₂ 2) → CO₂ 4. 미션: 4단계 순서와 장소 배치(manual), 탄소 구슬 추적해 CO₂ 6개 세기(task), 퀴즈(이산화 탄소가 나오는 단계 2개: 피루브산 산화와 TCA 회로, 물이 생기는 단계: 전자 전달계).
② [분석] 산출물 계산 — 단계별 산출 카운터(ATP, NADH, FADH₂, CO₂): 각 단계 버튼을 누르면 값이 쌓이는 표 완성(입력 칸). 합계로 전자 전달계에서 만들 수 있는 ATP 환산(NADH × 2.5 + FADH₂ × 1.5). 총 ATP 약 32 중 직접 합성 4(12.5 %), 전자 전달계 28(87.5 %) 막대. 미션: 표 완성(task, 해당 NADH 2 / 피루브산 산화 NADH 2 / TCA NADH 6 FADH₂ 2 합계 NADH 10 FADH₂ 2), 환산 계산(task: 25 + 3 = 28), 퀴즈 2개(ATP 대부분이 만들어지는 단계: 전자 전달계, 포도당 1분자당 TCA 회로가 두 번 도는 까닭: 피루브산 2분자 → 아세틸 CoA 2분자).
③ [탐구] 호흡 조절 — 호흡 시뮬레이터: 산소 농도 슬라이더(정상 → 0), 시안화물 투여, ATP 농도(운동 ↔ 휴식)를 바꾸면서 각 단계의 흐름 속도(입자 흐름 굵기) 변화 관찰. 산소가 없으면 NADH 쌓임 → 전자 전달 정지 → 연쇄적으로 TCA·피루브산 산화까지 느려지고 해당 과정만 겨우 진행(발효는 다음 차시). ATP 많음 → 해당 과정 속도 감소(효소 조절). 미션: 산소 0 으로 하여 정지되는 단계 찾기(task), 휴식/운동에서 호흡 속도 비교(task), 퀴즈 2개(산소를 직접 쓰는 단계가 마지막인데도 산소가 없으면 TCA 회로가 멈추는 까닭: NAD⁺ 재생 불가, 휴식 중 호흡 속도가 줄어드는 까닭: ATP 증가로 효소 활성 감소).
④ [분석] 릴레이 설명 — 협력적 소통: 모둠 역할 카드 4장(해당 과정 담당, 피루브산 산화 담당, TCA 회로 담당, 전자 전달계 담당)을 한 단계씩 맡아 '장소 / 들어온 것 / 나가는 것 / 다음 사람에게 넘기는 것' 4칸을 채운 뒤 릴레이 설명 순서로 이어 붙여 '세포호흡 한 장 요약'(인포그래픽) 완성(manual). 디지털 매체 선택(애니메이션 카드, 그림표, 역할극 대본 중 선택). 퀴즈 3개(포도당의 탄소가 마지막에 가는 곳: CO₂, 포도당의 수소 전자가 마지막에 가는 곳: O₂ → 물, 단계 중 미토콘드리아가 필요 없는 단계: 해당 과정).
애니메이션: 탄소 구슬이 쪼개지고 CO₂ 로 떨어져 나가는 tween, NADH/FADH₂ 입자가 기질에서 내막으로 이동, 내막에서 ATP 불꽃이 터지는 burst, 산소 농도에 따른 흐름 굵기 변화, 표 카운터 count-up.

## `hy-phosphorylation` · ⚡ 두 가지 인산화
- 성취기준 [12세포03-03] 세포호흡 과정에서의 인산화 과정을 기질 수준의 인산화와 산화적 인산화 과정으로 구분할 수 있다.
- 카드 설명(desc): ATP가 만들어지는 두 가지 방법, 효소가 인산기를 직접 건네는 기질 수준 인산화와 H⁺가 ATP 합성 효소를 돌리는 산화적 인산화를 구분해요.
- 태그: 기질 수준 인산화, 산화적 인산화, 화학 삼투, ATP 합성 효소 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 기질 수준 · H⁺ 기울기 · 화학 삼투 · 구분하기

### 설계
범위(해설): [12세포03-03] — 세포호흡의 인산화를 기질 수준의 인산화와 산화적 인산화로 구분. 산화적 인산화는 '화학 삼투에 의해 ATP 가 합성된다는 수준 정도'까지만(전자 전달 복합체 Ⅰ~Ⅳ의 개별 반응, 양성자 펌핑 H⁺/e⁻ 수, P/O 비의 유도는 다루지 않음. 전자 전달 단백질은 '단백질 복합체'로만). 광인산화(광합성)는 단원 58 후반 차시에서 비교. 앞 차시의 단계별 산출물을 사용.
기질 수준 인산화: 효소가 인산기를 가진 고에너지 기질 분자에서 ADP 에 인산기를 직접 옮겨 ATP 를 만듦. 해당 과정(순 ATP 2, 총 생성 4)과 TCA 회로(회로당 1, 포도당당 2)에서 일어남, 합계 4. 산소 불필요, 미토콘드리아 막 불필요(해당 과정은 세포질).
산화적 인산화: NADH, FADH₂ 의 전자가 내막의 전자 전달계(단백질 복합체)를 통과하며 방출하는 에너지로 H⁺ 를 기질 → 막 사이 공간으로 펌프(막 사이 공간 H⁺ 농도↑, 약간 산성 pH 약 7.0, 기질 pH 약 8.0 → H⁺ 농도 약 10배 차 + 전하 차) → 이 농도 기울기를 따라 H⁺ 가 ATP 합성 효소의 통로를 지나 막 사이 공간 → 기질로 되돌아오며 효소가 돌아 ADP + Pi → ATP 합성(화학 삼투). 전자의 최종 수용체는 O₂(H⁺ 와 결합해 H₂O). 산소가 없으면 전자가 갈 곳이 없어 흐름이 멈추고 H⁺ 펌프도 멈춤 → ATP 합성 중단.
실험 자료: 짝풀림제(예: 2,4-디니트로페놀 DNP, 갈색 지방의 짝풀림 단백질) — 내막이 H⁺ 를 새게 하여 기울기 소실, 산소 소비는 오히려 증가하나 ATP 합성 감소, 열 발생 증가. 시안화물 — 전자 전달 차단 → H⁺ 펌프·ATP 합성 중단, 산소 소비 중단. ATP 합성 효소 차단제(올리고마이신) — H⁺ 통로 막음 → H⁺ 가 쌓이고 전자 전달도 느려짐, 산소 소비 감소. 가상 측정(미토콘드리아 현탁액, 상대값): 기본 산소 소비 100, ATP 합성 100, 열 100 → 시안화물: 0 / 0 / 낮음, 올리고마이신: 30 / 0 / 낮음, 짝풀림제: 180 / 20 / 높음.
ATP 수지 요약: 한 분자의 포도당에서 기질 수준 인산화로 4 ATP(약 12 %), 산화적 인산화로 약 28 ATP(약 88 %), 합계 약 32 ATP.
탐구 질문: "ATP 를 만드는 방법에는 효소가 인산기를 직접 건네는 방법만 있을까? 미토콘드리아 막은 왜 꼭 필요할까?"
① [분석] 기질 수준 — 해당 과정과 TCA 회로 일부를 확대: 고에너지 기질(인산기를 단 분자)이 효소에 결합하면 인산기가 ADP 로 직접 옮겨가 ATP 생성(블록 조작). 이 방식은 막이 없어도 가능한 반응(해당 과정은 세포질). 포도당 1분자에서 몇 번 일어나는지 세기(해당 4 + TCA 2 − 소비 2 구분 확인). 미션: 인산기 전달 4회 실행(task), 기질 수준 인산화가 일어나는 단계 고르기(manual), 퀴즈 2개(기질 수준 인산화에 산소가 필요한가: 아니오, 총 생성 4 에서 소비 2 를 빼면 해당 과정의 순 ATP 2).
② [모형] H⁺ 기울기 — 미토콘드리아 내막 확대: NADH 가 전자를 전달계에 건네면 전자가 단백질 복합체 3개를 차례로 지나며 에너지를 방출하고, 그 에너지로 H⁺ 가 기질에서 막 사이 공간으로 펌프됨(점 개수 증가), 전자는 O₂ 에 도착하여 물이 됨. 막 사이 공간과 기질의 H⁺ 농도 막대와 pH 눈금(약 7 vs 약 8). NADH 개수 슬라이더로 펌프 속도 비교, 산소 토글로 흐름 차단. 미션: NADH 공급해 H⁺ 기울기 만들기(task), 산소 없이 시험(task), 퀴즈(전자 전달계에서 전자의 최종 수용체: 산소, H⁺ 가 쌓이는 곳: 막 사이 공간).
③ [모형] 화학 삼투 — ATP 합성 효소를 수력 터빈 비유로: 막 사이 공간의 H⁺ 가 효소 통로를 통과해 기질로 흘러내릴 때 회전자가 돌며 ADP + Pi → ATP. 막을 새는 막으로 바꾸는 토글(짝풀림제), 효소 통로 막기(올리고마이신), 전자 전달 차단(시안화물)을 각각 시험하고 ATP 합성량·산소 소비·열 변화를 표에 기록. 미션: 세 가지 처리 시험(task), 결과표 완성(manual), 퀴즈 2개(ATP 합성에 필요한 힘: H⁺ 농도 기울기, 짝풀림제를 쓰면 체온이 오르는 까닭: 에너지가 열로 방출).
④ [분석] 구분하기 — 사례 카드 10장(해당 과정에서 ATP 2 순생산, TCA 회로의 ATP 1, 막 사이 공간 H⁺ 축적, ATP 합성 효소 회전, 산소 없는 근육에서 해당 과정으로 얻는 ATP, 시안화물 중독으로 ATP 급감, 효모가 발효할 때의 ATP, 갈색 지방의 열 생산, 전자 전달계 통과, 산소를 H₂O 로 환원)를 기질 수준 / 산화적 인산화로 분류(manual). ATP 수지 막대(4 vs 28) 보기. 퀴즈 3개(산소가 없는 환경에서 ATP 를 만들 수 있는 인산화: 기질 수준, 포도당 1분자에서 ATP 가 가장 많이 만들어지는 인산화: 산화적, 화학 삼투란 H⁺ 의 농도 기울기를 이용한 ATP 합성).

## `hy-fermentation` · 🍞 산소호흡과 발효
- 성취기준 [12세포03-04] 산소호흡과 발효의 공통점과 차이점을 이해하고, 실생활에서 발효를 이용한 사례 조사 계획을 세워 조사할 수 있다.
- 카드 설명(desc): 산소가 없을 때 세포가 NAD⁺를 되살려 ATP를 얻는 알코올 발효와 젖산 발효를 산소호흡과 비교하며 공통점과 차이점을 찾아요.
- 태그: 발효, 알코올 발효, 젖산 발효, NAD⁺ 재생 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 산소가 없을 때 · 두 가지 발효 · 호흡과 비교 · 사례 판별

### 설계
범위(해설): [12세포03-04] 앞부분 — 산소호흡과 발효의 공통점과 차이점 이해(실생활 발효 사례 조사 계획은 다음 차시). 발효는 알코올 발효와 젖산 발효 두 가지만. 유기물의 분자 구조식은 다루지 않음(탄소 구슬 사용). 앞 차시의 4단계와 두 가지 인산화를 알고 있다고 보고, 산소가 없을 때 무엇이 막히고 세포가 어떻게 해결하는지(NAD⁺ 재생)에 초점. 다루지 않음: 초산 발효·부티르산 발효 등 다른 발효, 코리 회로, 파스퇴르 효과의 신호 전달, 지방·단백질 발효.
공통: 포도당을 출발 물질로 해당 과정을 거침(세포질에서 포도당 → 피루브산 2분자, 순 ATP 2, NADH 2), 효소가 일련의 반응을 조절, 기질 수준 인산화로 ATP 합성, NADH → NAD⁺ 재생이 계속 필요(NAD⁺ 가 없으면 해당 과정 정지).
차이: 산소호흡 — 최종 전자 수용체 O₂, 피루브산이 미토콘드리아에서 CO₂ 와 H₂O 까지 완전 분해, ATP 약 30~32, 미토콘드리아 필요(진핵), 에너지 효율 약 32 %. 발효 — 최종 전자 수용체가 유기물(피루브산 또는 그 변환 물질), 피루브산이 부분 분해(에탄올 또는 젖산이 에너지를 아직 품은 채 남음), 순 ATP 2, 세포질에서만 진행, 효율 약 2 %(2 × 30.5 ÷ 2870).
발효 반응(탄소 구슬): 알코올 발효 — 3탄소 피루브산 → CO₂ 1 + 2탄소 아세트알데하이드 → NADH 를 NAD⁺ 로 되돌리며 2탄소 에탄올(효모, 포도당 1분자당 에탄올 2, CO₂ 2, ATP 2). 젖산 발효 — 3탄소 피루브산 + NADH → 3탄소 젖산 + NAD⁺ (젖산균, 근육 세포, 포도당 1분자당 젖산 2, ATP 2, CO₂ 없음).
비교 수치: 같은 ATP 30개를 얻기 위해 필요한 포도당 — 산소호흡 약 1분자, 발효 15분자. 효모가 산소가 있을 때와 없을 때(포도당 소비 속도 상대값): 산소 없음 100, 산소 있음 약 7(산소호흡이 약 15배 효율이므로 같은 ATP 요구량에 포도당 소비가 줄어드는 파스퇴르 효과의 현상만). 통성 혐기성 효모는 산소가 있으면 호흡. 사람 근육은 격렬한 운동으로 산소 공급이 부족하면 젖산 발효 병행. 사람 성숙 적혈구는 미토콘드리아가 없어 젖산 발효만.
탐구 질문: "산소가 없어도 세포는 어떻게 ATP 를 계속 만들까? 대신 무엇을 포기할까?"
① [모형] 산소가 없을 때 — 산소 토글: 산소가 있으면 NADH 가 전자 전달계에 전자를 건네 NAD⁺ 로 돌아가며 해당 과정이 이어짐. 산소를 끄면 NADH 가 쌓이고 NAD⁺ 는 바닥이 나서 해당 과정이 멈춤(게이지 ATP 생산 0). NAD⁺ 를 다시 만들어 줄 방법 찾기 안내. 미션: 산소 끄기 → 정지 확인(task), 퀴즈 2개(해당 과정이 계속되려면 필요한 것: NAD⁺, 산소가 없을 때 전자 전달계가 멈추는 까닭: 전자를 받을 최종 수용체 없음).
② [모형] 두 가지 발효 — 피루브산(3탄소 구슬)에 NADH 의 전자를 건네는 분자 장면 두 가지: 효모(알코올 발효: 피루브산 → CO₂ + 에탄올, CO₂ 기포 방출), 젖산균/근육 세포(젖산 발효: 피루브산 → 젖산). 어느 경우든 NADH → NAD⁺ 재생으로 해당 과정 재개, ATP 2 유지. 포도당 1분자 입력 카운터: 알코올 발효 에탄올 2, CO₂ 2, ATP 2, 젖산 발효 젖산 2, ATP 2. 미션: 두 발효 실행(task), 산물 카드 맞추기(manual: 에탄올, CO₂, 젖산 × 효모/젖산균), 퀴즈(젖산 발효에서 CO₂ 가 생기지 않는 까닭: 피루브산에 NADH 의 수소가 붙는 환원만, 탄소 3개 그대로).
③ [분석] 호흡과 비교 — 비교표 채우기(manual): 장소, 최종 전자 수용체, 포도당 분해 정도, 산물, ATP 양, 효율, 산소 필요. 벤 다이어그램 공통 칸(해당 과정, 포도당, 기질 수준 인산화, 효소, NAD⁺ 재생) 배치. 계산: 같은 30 ATP 를 위한 포도당 수 비교, 에너지 효율(32 % vs 2 %). 효모 산소 변화 그래프(파스퇴르 현상). 미션: 비교표 완성(manual), 포도당 필요량 계산(task: 30 ÷ 2 = 15 vs 약 1), 퀴즈 2개(발효 산물에 에너지가 많이 남아 있는 까닭: 불완전 분해, 에탄올이 연료로 쓰이는 것의 의미).
④ [적용] 사례 판별 — 카드 8장(빵 반죽 부풀기, 요구르트, 김치 익힘, 막걸리·와인, 격렬한 달리기 후 다리 근육 통증의 원인, 바이오 에탄올 연료, 사람 적혈구의 에너지, 치즈)을 알코올 발효 / 젖산 발효 / 산소호흡으로 분류(manual). 주의 안내: 일상에서 '발효'라고 부르는 낫토·된장은 미생물이 단백질을 분해하는 과정이 포함되어 있어 이 차시의 정의와는 구별됨. 퀴즈 2개(빵 반죽이 부풀어 오르는 이유: 효모의 알코올 발효로 CO₂ 생성, 젖산균 발효 식품이 신맛을 내는 까닭: 젖산 생성).
애니메이션: NADH/NAD⁺ 입자 게이지, 산소 토글에 따른 해당 과정 흐름 정지/재개, 효모 CO₂ 기포 방출, 젖산균 확대, 비교표 항목 snap, 효율 막대 grow.

## `hy-light-reaction` · ☀️ 광합성의 명반응
- 성취기준 [12세포03-06] 광합성의 명반응과 탄소 고정반응을 단계별로 구분하여 특징을 이해하고 두 반응의 상호 관계를 추론할 수 있다.
- 카드 설명(desc): 빛으로 들뜬 전자가 전자 전달계를 따라 이동하며 물이 분해되고 ATP와 NADPH가 만들어지는 명반응을 단계별로 따라가요.
- 태그: 명반응, 물의 광분해, NADPH, 광인산화 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 빛 흡수 · 물 분해 · ATP 생성 · 조건 변화

### 설계
범위(해설): [12세포03-06] 앞부분 — 광합성을 명반응과 탄소 고정 반응으로 구분하여 단계별 특징 이해(명반응 부분). 광합성은 효소에 의해 조절되는 일련의 반응이며 탄소 고정 반응에서 유기물 구조식은 다루지 않음. 광합성은 '물질 합성 및 에너지 저장 과정'에 중점. 명반응은 틸라코이드 막에서 일어나는 에너지 변환(빛에너지 → ATP·NADPH의 화학 에너지)으로 소개하고, 전자 전달계와 인산화 비교는 [12세포03-07] 차시에서. 광계 Ⅰ·Ⅱ 이름은 사용하되 반응 중심 색소 파장(P680, P700)과 Z 도식의 산화 환원 전위 수치는 다루지 않음. 순환적 전자 흐름은 개요 한 줄. 앞 차시 hy-chloroplast(틸라코이드 막의 색소), 앞 차시 세포호흡의 H⁺ 기울기·화학 삼투를 이어받음.
명반응(틸라코이드 막): ① 광계 Ⅱ의 엽록소가 빛을 흡수하여 전자가 높은 에너지 준위로 들뜸. ② 들뜬 전자는 전자 전달계(막의 단백질들)를 따라 이동하며 에너지를 방출, 이 에너지로 H⁺ 를 스트로마 → 틸라코이드 내부로 펌프. ③ 광계 Ⅱ가 잃은 전자는 물(광분해)에서 보충: 2H₂O → 4H⁺ + 4e⁻ + O₂ (O₂ 는 물에서 나옴, 틸라코이드 내부에 H⁺ 가 추가로 쌓임). ④ 전자가 광계 Ⅰ에 도달하면 다시 빛을 받아 재충전되고 전자 전달 후 NADP⁺ 에 전달되어 NADPH 합성(스트로마 쪽, 환원). ⑤ 틸라코이드 내부에 쌓인 H⁺ 가 농도 기울기를 따라 ATP 합성 효소를 통해 스트로마로 이동하며 ADP + Pi → ATP (광인산화, 화학 삼투). 산물: ATP, NADPH, O₂ (O₂ 는 기체로 방출).
계산 자료: 전자 1개를 물에서 NADPH 까지 보내려면 광계 두 곳에서 광자 2개 필요 → O₂ 1분자(전자 4개)당 광자 8개 이상. 2H₂O → O₂ 1분자 + 전자 4개 → NADPH 2개. 포도당 1분자를 만들 때 명반응 합계: H₂O 12분자 분해, O₂ 6분자, NADPH 12개, ATP 18개 (탄소 고정 반응이 소모, 다음 차시). 틸라코이드 내부 pH 약 5, 스트로마 pH 약 8 (H⁺ 농도 약 1000배 차, 호흡의 약 10배 차보다 큼).
순환적 전자 흐름(개요): 광계 Ⅰ의 전자가 NADP⁺ 로 가지 않고 전자 전달계로 되돌아와 H⁺ 만 펌프 → ATP 만 추가 생성(NADPH, O₂ 없음) — 탄소 고정 반응에서 ATP 가 더 필요할 때 보충.
