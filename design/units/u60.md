## 개념 위계와 차시 흐름
선수: 통합과학1(h1-transcription 전사·mRNA, h1-translation 번역·코돈·tRNA, h1-protein 단백질), 세포와 물질대사(hy-nucleic-acid DNA·RNA 비교, hy-protein 단백질 구조·기능, hy-secretory-pathway 단백질의 합성과 분비, hy-prok-euk 원핵·진핵세포), 생명과학 Ⅲ(hb-chromosome), 앞 단원 59(hg-gene-structure 유전자 구조, hg-mutation-disease 돌연변이, hg-dna-replication).
차시 흐름: ① 유전자 발현의 중심원리(전사 · RNA 가공 · 번역, 단백질 합성 모의실험) → ② 유전 부호와 코돈표 해독 → ③ 젖당 오페론(원핵생물의 전사 조절) → ④ 진핵생물의 발현 조절(원핵과 다른 점)
→ ⑤ 세포 분화와 유전자 발현 → ⑥ 초기 발생과 혹스 유전자 → ⑦ 발현 조절·발생 연구와 인류 복지 사례(AI 활용 조사 포함).
'정보가 단백질이 되는 과정(①~②)' → '언제 어디서 켜고 끌 것인가(③~④)' → '조절이 몸을 만든다(⑤~⑥)' → '연구가 사람에게 준 이익(⑦)'. 통합과학에서 한 전사·번역의 기본 흐름과 코돈 개념은 반복하지 않고 과정의 단계(개시·신장·종결)와 진핵 RNA 가공, 코돈표를 직접 다루는 해독, 조절의 논리로 심화.
고려 사항: 원핵생물의 전사 조절(젖당 오페론)을 주로 다루고 진핵생물은 원핵과 다른 점만 간략히. 발생은 초기 단계(초파리 모계 인자 → 분절 → 혹스)의 유전자 발현 조절만. 유전 부호표는 표준 코돈표 64칸. 후성 유전·비암호화 RNA 조절의 상세, 신호 전달 경로의 세부는 다루지 않음. 발생·유전자 발현 관련 역사적 사건은 짧은 영상형 카드(애니메이션)로 흥미 유발. 최신 연구 조사 활동에서 생명과학에 인공지능이 쓰이는 사례를 조사하고 AI 답변의 사실 확인 습관을 연습. 탐구 활동 '단백질 합성 과정 모의실험하기'는 hg-central-dogma에 포함.

## `hg-central-dogma` · 🏭 유전자 발현의 중심원리
- 성취기준 [12유전02-01] 전사와 번역 과정을 거쳐 유전자가 발현되는 중심원리를 이해하고, 모형을 이용하여 유전자 발현 과정을 설명할 수 있다.
- 카드 설명(desc): DNA에서 RNA, 단백질로 이어지는 중심원리를 전사와 RNA 가공, 번역의 단계별 모형으로 따라가며 직접 단백질을 합성해 봐요.
- 태그: 중심원리, 전사, RNA 가공, 번역 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 중심원리 · 전사 · 번역 · 합성 모의

### 설계
범위: 유전자 발현 = 유전자의 정보가 전사(DNA → RNA)와 번역(RNA → 단백질)을 거쳐 형질을 나타내는 과정. 중심원리: DNA →(복제)→ DNA, DNA →(전사)→ RNA →(번역)→ 단백질, 정보는 핵산에서 단백질로만 흐름(예외로 레트로바이러스의 역전사 RNA → DNA는 점선과 이름만). 탐구 활동: 단백질 합성 과정 모의실험하기. 통합과학 h1-transcription·h1-translation에서 한 기본 흐름·코돈 개념·염기 짝을 반복하지 않고 ① 전사의 개시·신장·종결과 주형 가닥/암호화 가닥 구분, ② 진핵 RNA 가공(5′ 캡, 폴리 A 꼬리, 스플라이싱 — 앞 단원 hg-gene-structure의 엑손·인트론 연결), ③ 번역의 개시·신장·종결과 리보솜 자리(A·P·E), 폴리리보솜, 원핵(전사–번역 동시) vs 진핵(핵 vs 세포질)으로 심화. mRNA는 5′ → 3′ 방향으로 읽는다는 표기만 사용. 다루지 않음: 개시·신장·종결 인자 이름, tRNA의 3차 구조, 번역 후 가공, 시그마 인자, 전사 인자(진핵 조절 차시), 유전 부호표 전체(다음 차시).
서열 자료: DNA 암호화(비주형) 가닥 5′-ATG GAA CCA TGG TTT AAA TAA-3′, 주형 가닥 3′-TAC CTT GGT ACC AAA TTT ATT-5′ → mRNA 5′-AUG GAA CCA UGG UUU AAA UAA-3′(암호화 가닥과 같고 T만 U) → Met–Glu–Pro–Trp–Phe–Lys–종결(아미노산 6개). 진핵 가공 예: 전구 mRNA 2700 nt(엑손 150 + 인트론 900 + 엑손 200 + 인트론 1200 + 엑손 250) → 스플라이싱 후 600 nt → 5′ 캡 + 폴리 A 꼬리(약 200 nt) 추가. 이 중 암호 부분 543 nt(코돈 181개 = 아미노산 180개 + 종결 코돈) → 단백질 180 아미노산. 번역 속도(예시): 원핵 약 20 아미노산/초 → 300 아미노산 단백질 약 15초, 진핵 약 5 아미노산/초 → 약 60초. 폴리리보솜: mRNA 한 분자에 리보솜 5개가 붙으면 단백질 5개가 동시에 만들어짐.
탐구 질문: "핵 속 DNA의 정보는 어떤 단계를 거쳐 세포질의 단백질이 될까? 각 단계는 무엇이 필요하고 어디서 일어날까?"
① [모형] 중심원리 — 세포 단면(원핵 / 진핵 토글): 복제, 전사, 번역 화살표에 이름 붙이기, 진핵은 핵(전사·가공)과 세포질(번역), 원핵은 핵막 없이 같은 공간. 점선 화살표(역전사)는 예외. 정보(DNA 서열) → 기능(단백질) → 형질 사슬. 미션: 화살표 3개 이름 붙이기(manual), 원핵과 진핵에서 번역이 시작되는 시점 비교(task), 퀴즈(정보 흐름의 방향, 단백질의 아미노산 서열이 DNA를 바꿀 수 없는 까닭).
② [모형] 전사 — RNA 중합 효소가 프로모터에 결합(개시) → DNA 이중 가닥이 풀리며 주형 가닥에 맞춰 RNA 뉴클레오타이드 연결(신장) → 종결 서열에서 떨어짐(종결). 주형 가닥/암호화 가닥 선택 스위치: mRNA 서열은 암호화 가닥과 같고 주형과 상보적. 진핵 전구 mRNA에서 5′ 캡 붙이기 → 인트론 제거 → 폴리 A 꼬리 붙이기 → 핵공 통과(앞 단원 엑손·인트론 연결). 미션: 주형 가닥을 지정해 mRNA 합성(task: AUGGAACCAUGGUUUAAAUAA), 가공 3단계 순서 맞추기(manual), 퀴즈(암호화 가닥과 같은 서열을 가진 RNA가 만들어지는 까닭, 인트론이 단백질이 되지 않는 이유).
③ [모형] 번역 — 리보솜 소단위체가 mRNA에 결합해 시작 코돈 AUG에서 개시 tRNA(Met)와 대단위체 조립(개시) → 리보솜 A 자리에 안티코돈이 맞는 tRNA 입장 → 펩타이드 결합 → 리보솜이 한 코돈 이동(P, E 자리) → 반복(신장) → 종결 코돈에서 사슬 방출(종결). 폴리리보솜: mRNA 하나에 리보솜 5개. 미션: 개시 복합체 조립 → 아미노산 3개 연결 → 종결 코돈에서 방출까지 완료(task), 퀴즈(안티코돈 3′-UAC-5′ 에 맞는 코돈 AUG, 폴리리보솜의 이점).
④ [탐구] 단백질 합성 모의실험 — 서열 3종(인트론 없음 / 인트론 포함 진핵 유전자 / 원핵 오페론 일부) 중 하나를 골라 DNA → 전사 → (가공) → 번역을 한 번에 실행하며 mRNA와 아미노산 서열 기록, 염기 1개를 바꿔 결과 비교(앞 단원 돌연변이 연결). 원핵 vs 진핵 단백질 한 분자 합성 시간 비교(300 아미노산, 15초 vs 60초). 미션: 서열 하나로 전 과정 완성(task), 퀴즈 2개(진핵 mRNA의 5′ 캡·폴리 A 꼬리가 번역 단계에 필요한 이유는 스스로 추론하되 정답은 '보호와 번역 효율', 성숙 mRNA 600 nt 중 암호 부분 543 nt에서 만들어지는 아미노산 수 180).
애니메이션: 효소가 DNA를 따라 이동하며 mRNA가 자라는 trail, 가공 중 캡이 붙고 인트론 고리가 빠져나가는 spring, 핵공 통과, 리보솜이 mRNA를 한 코돈씩 미끄러지고 tRNA가 들어와 snap, 폴리리보솜의 단백질 사슬이 동시에 길어지는 장면.

## `hg-genetic-code` · 🔤 유전 부호와 코돈표
- 성취기준 [12유전02-02] 유전 부호를 이해하고, 유전 부호 표를 사용하여 유전 정보를 해독할 수 있다.
- 카드 설명(desc): 니런버그의 인공 mRNA 실험으로 코돈의 뜻을 하나씩 알아내고, 코돈표를 사용해 DNA와 mRNA의 염기 서열을 아미노산 서열로 해독해요.
- 태그: 유전 부호, 코돈표, 축퇴성, 해독 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 부호 규명 · 코돈표 · 해독 연습 · 부호의 특징

### 설계
범위: 유전 부호 = mRNA 염기 3개(코돈)가 아미노산 1개를 지정하는 규칙. 4³ = 64가지 코돈 = 아미노산 지정 61 + 종결 3(UAA, UAG, UGA), 시작 코돈 AUG(Met). 특징: 축퇴성(한 아미노산에 코돈 여러 개, 한 코돈은 한 아미노산만 — 모호하지 않음), 보편성(거의 모든 생물이 같은 부호), 연속성(쉼표·겹침 없이 시작 코돈부터 3개씩, 읽기틀). 통합과학 h1-transcription에서 한 '3염기가 필요한 까닭(4 → 16 → 64 ≥ 20)'과 h1-translation의 간이 코돈표를 반복하지 않고 부호가 밝혀진 실험적 근거와 표준 코돈표 64칸을 이용한 해독에 집중. 다루지 않음: 흔들림 가설의 설명(셋째 염기 변이만 사실로 제시), 미토콘드리아 부호 차이(이름만), tRNA 종류 수.
표준 코돈표(첫째 염기 U/C/A/G · 셋째 염기 U/C/A/G 순서로 읽음): UUU·UUC Phe, UUA·UUG Leu / UCU·UCC·UCA·UCG Ser / UAU·UAC Tyr, UAA·UAG 종결 / UGU·UGC Cys, UGA 종결, UGG Trp // CUU·CUC·CUA·CUG Leu / CCU·CCC·CCA·CCG Pro / CAU·CAC His, CAA·CAG Gln / CGU·CGC·CGA·CGG Arg // AUU·AUC·AUA Ile, AUG Met(시작) / ACU·ACC·ACA·ACG Thr / AAU·AAC Asn, AAA·AAG Lys / AGU·AGC Ser, AGA·AGG Arg // GUU·GUC·GUA·GUG Val / GCU·GCC·GCA·GCG Ala / GAU·GAC Asp, GAA·GAG Glu / GGU·GGC·GGA·GGG Gly. 아미노산별 코돈 수: 6개 — Leu·Ser·Arg(3종), 4개 — Val·Pro·Thr·Ala·Gly(5종), 3개 — Ile, 2개 — Phe·Tyr·Cys·His·Gln·Asn·Lys·Asp·Glu(9종), 1개 — Met·Trp(2종) → 18 + 20 + 3 + 18 + 2 = 61.
부호 규명(니런버그·마태이, 1961): 세포 추출액 + 방사성 표지 아미노산 20종(시험관 20개, 한 번에 한 종류만 표지) + 인공 mRNA. poly-U(UUUU…) → 표지 페닐알라닌 시험관에서만 방사성 폴리펩타이드 → UUU = Phe. poly-A → Lys(AAA), poly-C → Pro(CCC), poly-G → Gly(GGG). 반복 서열 UCUCUC… → 세린과 류신이 번갈아(UCU Ser, CUC Leu, 두 코돈이 순서대로 읽힘 — 코호라나 접근, 가상 추론 문제).
해독 예: ① DNA 주형 3′-TAC GTT AGG CAT ACT-5′ → mRNA 5′-AUG CAA UCC GUA UGA-3′ → Met–Gln–Ser–Val–종결. ② mRNA 5′-GCAUGGGCAAAUAGCC-3′ → 첫 AUG(넷째 염기부터)에서 읽기틀 결정 → AUG GGC AAA UAG → Met–Gly–Lys–종결(앞의 GC와 뒤의 CC는 번역되지 않음). ③ Met–Trp–Lys를 만드는 mRNA는 몇 가지? Met 1 × Trp 1 × Lys 2 = 2가지(AUG UGG AAA / AUG UGG AAG).
수치(전수 조사): 종결 코돈을 뺀 61개 코돈의 셋째 염기를 다른 3가지로 바꾼 183가지 중 같은 아미노산을 만드는 경우 126가지(약 69 %), 모든 위치의 단일 염기 치환 549가지 중 같은 아미노산은 134가지(약 24 %) → 셋째 염기의 변이는 영향이 작은 경우가 많음.
탐구 질문: "mRNA의 A, U, G, C 네 글자는 어떤 사전으로 아미노산이 될까? 그 사전은 어떻게 만들어졌고 모든 생물에서 같을까?"
① [실험] 부호 규명 — 가상 니런버그 실험: 합성 mRNA(poly-U, poly-A, poly-C, poly-G)를 세포 추출액에 넣고, 20종 아미노산 시험관 중 방사성이 나타나는 시험관 찾기. 이어서 UCUCUC… 반복 mRNA의 결과(세린 + 류신)를 해석하는 추론 문제. 미션: 4가지 인공 mRNA 실험(task: UUU Phe, AAA Lys, CCC Pro, GGG Gly), 코돈표 빈칸 채우기(manual), 퀴즈(UUUU…에서 한 종류의 아미노산만 이어지는 까닭 → 같은 코돈이 반복됨).
② [모형] 코돈표 — 64칸 표 읽는 법(첫째 → 둘째 → 셋째 염기), 칸을 누르면 코돈과 아미노산 하이라이트, 시작·종결 코돈 표시, 아미노산별 코돈 수 막대(6/4/3/2/1). 미션: 코돈 5개 찾아 아미노산 입력(task), 퀴즈(코돈 UGA의 뜻, 오개념: 한 코돈이 여러 아미노산을 지정한다 X, 한 아미노산에 코돈이 여러 개는 O).
③ [적용] 해독 연습 — 해독 문제 3개: DNA 주형 가닥 → mRNA → 아미노산 서열, mRNA에서 시작 코돈을 찾아 읽기틀 정해 해독, 아미노산 서열에서 가능한 mRNA 수 구하기(축퇴성). 미션: 해독 3문제(task), 퀴즈(Met–Trp–Lys를 만드는 mRNA는 몇 가지인가 → 2가지).
④ [분석] 부호의 특징 — 같은 mRNA를 사람 세포 추출액과 대장균 추출액에 넣어 같은 펩타이드가 나오는 실험(보편성 → 사람 인슐린 유전자를 대장균에서 만들 수 있는 근거, 3단원 연결). 셋째 염기 치환 183가지 중 126가지 동의(약 69 %) vs 모든 위치 24 %를 막대로 비교. 앞 단원 돌연변이(침묵·과오·넌센스) 3개를 코돈표로 다시 분류. 미션: 보편성 실험 해석과 동의 비율 비교(manual), 퀴즈 2개(셋째 염기 변이가 형질을 덜 바꾸는 까닭, 유전 부호가 거의 모든 생물에서 같다는 사실이 알려 주는 것 → 공통 조상).
애니메이션: 시험관 20개 중 방사성 시험관이 반짝이며 poly-U 사슬 형성, 64칸 코돈표 행·열 하이라이트 sweep, mRNA가 코돈 창을 지나며 아미노산 칩이 줄지어 snap, 읽기틀 3칸 선이 시작 코돈에 맞춰 이동, 동의 비율 막대 grow.

## `hg-lac-operon` · 🥛 젖당 오페론
- 성취기준 [12유전02-03] 원핵생물과 진핵생물의 유전자 발현 조절 과정을 비교하기 위한 설명 자료를 다양한 매체를 활용하여 제작할 수 있다.
- 카드 설명(desc): 대장균이 젖당이 있을 때만 분해 효소를 만드는 까닭을 억제자와 작동 부위의 작용으로 설명하고, 돌연변이 대장균의 효소 활성을 예측해요.
- 태그: 젖당 오페론, 억제자, 유전자 발현 조절, 원핵생물 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 오페론 구조 · 젖당 없음 · 젖당 있음 · 돌연변이

### 설계
범위(해설): 원핵생물의 전사 조절 과정을 주로 다룸 — 젖당 오페론을 중심으로(유도 오페론), 트립토판 오페론은 비교 카드로만(억제 오페론). 진핵생물은 다음 차시. 앞 단원 hg-gene-structure의 오페론(한 프로모터 아래 여러 구조 유전자, 하나의 mRNA)과 hg-central-dogma의 전사·번역을 전제. 구성: 조절 유전자(lacI) → 억제자 단백질(항상 소량 생산), 오페론 = 프로모터(P) + 작동 부위(O) + 구조 유전자 lacZ(β-갈락토시데이스: 젖당 → 포도당 + 갈락토스), lacY(젖당 수송), lacA. 유도자 = 젖당 대사 산물(알로락토스). 포도당이 있으면 젖당이 있어도 발현이 낮아지는 조절은 CAP·cAMP 이름만(이중 성장 곡선으로 현상 제시). 다루지 않음: 부분 이배체(F′) 상보 실험, 감쇠 조절, 시그마 인자, 억제자의 3차원 구조.
작용: 젖당 없음 — 억제자가 작동 부위에 결합 → RNA 중합 효소가 구조 유전자로 진행하지 못함 → 전사 안 됨. 젖당 있음 — 알로락토스가 억제자에 결합해 모양이 바뀜 → 작동 부위에서 떨어짐 → 전사 → 효소 합성 → 젖당 분해 → 젖당이 소진되면 억제자가 다시 결합(되먹임). 의의: 필요할 때만 효소를 만들어 에너지·자원 절약.
자료(β-갈락토시데이스 상대 활성, 예시 값 — 젖당 없음 / 있음): 야생형 1 / 1000(약 1000배 유도), lacI⁻(억제자 결함) 1000 / 1000(항상 발현), lacOᶜ(작동 부위가 억제자와 결합 못함) 1000 / 1000, lacIˢ(억제자가 유도자와 결합 못함) 1 / 1, lacZ⁻(효소 유전자 결함) 0 / 0, P⁻(프로모터 결함) 1 / 1(배경 수준). 이중 성장: 포도당 + 젖당 배지에서 포도당 먼저 소비(성장 곡선 1단계) → 잠시 정체(lag, 효소 유도 중) → 젖당 소비(성장 2단계). 비교: 트립토판 오페론 — 트립토판이 있으면 억제자가 활성화되어 작동 부위에 결합 → 합성 효소 유전자 꺼짐(최종 산물이 억제하는 되먹임). 유도 시간(예시): 젖당 첨가 후 약 2분 내 mRNA 증가, 약 10분 후 효소 활성이 크게 상승.
탐구 질문: "대장균은 주변에 젖당이 있을 때만 젖당 분해 효소를 만든다. 세균은 어떻게 필요한 유전자만 켤까?"
① [모형] 오페론 구조 — 대장균 DNA 영역 확대: 조절 유전자(lacI)와 오페론(P, O, lacZ·lacY·lacA)의 위치. 구성 요소 이름표를 붙이고 기능 카드(억제자 생산, RNA 중합 효소 결합, 억제자 결합, 효소 정보)와 연결. 전사하면 3개 유전자가 한 mRNA로 만들어짐(앞 단원 연결). 미션: 구성 요소 이름표·기능 연결(manual), 퀴즈(조절 유전자는 오페론에 속하는가 → 아니오, 억제자가 항상 소량 만들어지는 까닭).
② [실험] 젖당 없을 때 — 포도당 배지에서 대장균을 키우며 현미경 확대: 억제자가 작동 부위에 붙어 RNA 중합 효소가 막힘, mRNA 0, 효소 활성 1 측정. 미션: 젖당 없는 조건에서 전사 시도와 효소 활성 측정(task), 퀴즈(억제자가 막는 것 → 전사 개시/RNA 중합 효소의 진행, 억제자가 단백질을 직접 분해하는 것이 아님).
③ [실험] 젖당 있을 때 — 젖당 투입 슬라이더: 알로락토스가 억제자에 결합 → 억제자가 작동 부위를 떠남 → 전사 → 효소 활성 그래프(1 → 약 1000, 약 10분). 젖당이 소진되면 억제자가 복귀해 활성이 감소. 포도당 + 젖당 이중 성장 곡선 해석. 미션: 젖당을 넣어 유도하고 활성이 오르는 시점 기록(task), 활성 곡선에서 젖당이 소진된 시점 읽기(task), 퀴즈(효소가 젖당이 있을 때만 만들어지는 적응적 의미, 젖당은 어떤 역할 → 유도자).
④ [탐구] 돌연변이 — 돌연변이 대장균 5종(lacI⁻, lacOᶜ, lacIˢ, lacZ⁻, P⁻)의 젖당 없음/있음 효소 활성(높음/낮음)을 먼저 예측한 뒤 실험으로 확인해 표 비교. 트립토판 오페론 카드로 유도와 억제 오페론 비교. 미션: 5종 예측(manual), 실제 결과와 대조(task), 퀴즈(젖당이 없어도 효소가 계속 만들어지는 돌연변이 2종 — lacI⁻, lacOᶜ — 의 차이는 무엇인가: 억제자 결함 vs 억제자가 붙을 자리 결함).
애니메이션: 억제자 단백질이 작동 부위에 붙었다 떨어지는 snap, RNA 중합 효소가 막히거나 지나가며 mRNA가 자라는 trail, 젖당 분자가 억제자에 결합해 모양이 변하는 morph, 효소 활성 그래프와 두 단계 성장 곡선 draw, 돌연변이 표 칸 점등.

## `hg-eukaryote-regulation` · 🎛️ 진핵생물의 발현 조절
- 성취기준 [12유전02-03] 원핵생물과 진핵생물의 유전자 발현 조절 과정을 비교하기 위한 설명 자료를 다양한 매체를 활용하여 제작할 수 있다.
- 카드 설명(desc): 진핵생물의 유전자 발현이 원핵생물과 어떻게 다른지 전사 인자와 인핸서, 여러 조절 단계로 비교하고 설명 자료를 직접 만들어요.
- 태그: 진핵생물, 전사 인자, 인핸서, 설명 자료 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 달라지는 점 · 전사 인자 · 여러 단계 · 설명 자료

### 설계
범위(해설): 진핵생물의 경우는 원핵생물의 전사 조절과의 '다른 점만' 간략하게 다룸(앞 차시 젖당 오페론이 중심). 다른 점 5가지: ① 핵막 때문에 전사(핵)와 번역(세포질)이 분리 → RNA 가공·수송 단계에서도 조절 ② 염색질이 히스톤에 감겨 있어 풀려야 전사 가능(히스톤·메틸화의 화학은 이름만) ③ 프로모터 + 멀리 떨어진 조절 서열(인핸서)에 여러 전사 인자가 조합해 결합 ④ 오페론이 없고 유전자마다 개별 프로모터 ⑤ 전사 이후에도 조절(mRNA 수명, 번역 효율, 단백질 분해). 호르몬 예: 스테로이드 호르몬이 세포 안 수용체와 결합 → 전사 인자로 작용. 다음 차시의 세포 분화와 연결. 다루지 않음: 후성 유전의 분자 기작, 마이크로 RNA, RNA 간섭의 기작, 염색질 리모델링 복합체. 협력적 소통: 다양한 매체로 설명 자료 제작.
정량 자료(예시 값): 정상 상태 mRNA 수 = 합성 속도 × 평균 수명. 합성 10개/시간, 수명 5시간 → 50개. 수명이 2배(10시간)이면 100개(단백질 양도 약 2배). 번역 효율을 2배로 하면 단백질 2배. 실제 예: β-글로빈 mRNA 수명은 10시간 이상, 일부 사이토카인 mRNA는 약 30분. 조합 조절: 활성화 전사 인자 3종(X, Y, Z)이 모두 인핸서에 결합해야 유전자가 켜짐(AND 논리) → 세포마다 가진 전사 인자 조합이 다르면 발현 유전자도 다름.
조절 단계 6곳: 염색질 접근 → 전사 개시 → RNA 가공 → mRNA 수송·수명 → 번역 → 단백질 활성·분해.
탐구 질문: "같은 유전자 발현인데, 핵막과 긴 DNA를 가진 진핵생물은 대장균보다 무엇이 더 복잡해질까?"
① [모형] 달라지는 점 — 원핵(대장균)과 진핵 세포의 유전자 발현을 나란히 보여 주는 화면: 장소(핵 / 세포질), 염색질 감김, 인트론과 가공, 오페론 없음. 다른 점 5곳의 핫스팟을 눌러 비교 카드 열기. 미션: 다른 점 5곳 찾기(task), 퀴즈(원핵생물에서는 한 번에 켜지는 여러 유전자가 진핵생물에서는 개별 프로모터를 갖는 배경).
② [모형] 전사 인자 — 히스톤에 감긴 염색질(닫힘) → 전사 인자가 결합해 풀림 → 기본 전사 인자와 RNA 중합 효소가 프로모터에 모임 → 인핸서가 DNA 고리를 만들어 프로모터에 닿아 전사 속도 증가. 활성화 인자 3종이 모두 있어야 켜지는 조합 조절. 미션: 인핸서 고리를 만들고 조합 켜기(task), 퀴즈(같은 유전체를 가진 세포에서 서로 다른 유전자가 켜지는 까닭 → 전사 인자 조합, 스테로이드 호르몬이 유전자 발현을 바꾸는 방식).
③ [분석] 여러 단계 — 유전자 X의 발현 슬라이더 4개(전사 속도, mRNA 수명, 번역 효율, 단백질 분해)를 조절해 mRNA 수와 단백질 양 변화 계산(10 × 5 = 50 → 수명 2배 시 100). 단계–사례 카드 연결(호르몬 → 전사 인자, 인트론 제거 방식 → 가공, 수명이 짧은 mRNA → 빠른 반응). 미션: 슬라이더로 단백질 양 목표치 맞추기(task), 단계–사례 연결(manual), 퀴즈(mRNA 수명이 짧을수록 유리한 상황).
④ [소통] 설명 자료 — 매체 선택(비교 도식 / 포스터 / 카드뉴스 / 영상 콘티 / 디지털 슬라이드) 후 원핵(젖당 오페론) vs 진핵 비교 자료를 구성: 필수 요소 6개(오페론 vs 개별 유전자, 장소, 염색질, 전사 인자·인핸서, 전사 후 조절, 예시 1개)를 칸에 배치. 체크리스트 자동 점검 후 부족한 요소 보완. 미션: 필수 요소 배치와 체크리스트 통과(manual), 퀴즈 2개(원핵과 진핵의 조절 차이를 한 문장으로, 설명 자료의 정확성 점검 항목).
애니메이션: 염색질이 풀리고 전사 인자가 결합해 인핸서 고리가 휘어 프로모터에 닿는 spring, 조합 조절의 LED 점등, mRNA 개수 통이 수명에 따라 쌓이는 approach, 조절 단계 6곳이 순서대로 하이라이트, 자료 칸 카드 snap.

## `hg-cell-differentiation` · 🧫 세포 분화와 유전자 발현
- 성취기준 [12유전02-04] 생물의 발생 과정에서 세포 분화가 유전자 발현 조절 과정을 통해 일어남을 추론할 수 있다.
- 카드 설명(desc): 몸의 세포가 모두 같은 유전자를 가졌는데도 다른 세포가 되는 까닭을 mRNA 검출과 핵 이식 실험의 증거로 추론해요.
- 태그: 세포 분화, 선택적 발현, 핵 이식, 전사 인자 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 같은 유전자 · 선택 발현 · 핵의 능력 · 분화 유도

### 설계
범위: [12유전02-04]의 앞부분 — 세포 분화가 유전자 발현 조절을 통해 일어남을 추론. 다세포 생물의 체세포는 모두 수정란이 체세포 분열(DNA 복제 후 분배)로 만들어 같은 유전체를 가지며, 세포마다 발현하는 유전자가 달라 단백질과 형태·기능이 달라짐. 앞 차시(진핵 전사 인자 조합)와 연결. 증거: ① 유전체 동일(모든 세포의 DNA에서 글로빈·인슐린·크리스탈린 유전자 검출) ② 선택적 발현(mRNA는 해당 세포에서만 검출) ③ 분화한 세포의 핵도 전체 정보 보유(핵 이식) ④ 마스터 조절 전사 인자가 분화를 일으킴. 줄기세포는 3단원. 다음 차시는 발생 초기 형태 형성. 다루지 않음: 세포 신호 전달 세부, 후성 유전의 기작, 조직별 유전자 목록 암기.
자료(가상 검출표 ○ 있음 / ✕ 없음): DNA — 적혈구 전구세포 · 이자 β세포 · 수정체 세포 모두 글로빈, 인슐린, 크리스탈린 유전자 ○ / mRNA — 적혈구 전구세포 글로빈 ○, 인슐린 ✕, 크리스탈린 ✕ / 이자 β세포 글로빈 ✕, 인슐린 ○, 크리스탈린 ✕ / 수정체 세포 글로빈 ✕, 인슐린 ✕, 크리스탈린 ○ / 세포호흡 효소·리보솜 단백질 mRNA(모든 세포 공통, 하우스키핑 유전자) 모두 ○. 사람 몸의 세포는 약 200종, 유전자는 약 2만 개.
핵 이식: 거던(1962) — 개구리 장 상피 세포(분화한 세포)의 핵을 핵을 없앤 난자에 넣으면 일부가 올챙이까지 발생. 복제 양 돌리(1996) — 유선 세포 핵을 이식: 이식한 난자 277개 → 초기 배아 29개 → 새끼 양 1마리(성공률 1/277 ≈ 0.4 %). 의미: 분화 세포에도 유전 정보가 모두 있고 분화는 유전자를 잃는 것이 아니라 발현이 다른 것. MyoD 실험(1987): 피부 결합 조직 섬유아세포에 전사 인자 MyoD 유전자를 넣으면 근육 세포 특이적 유전자(근육 액틴·미오신)가 켜지고 근육 세포로 변함.
탐구 질문: "수정란 하나가 나뉜 모든 세포가 같은 유전자를 갖는데, 어떻게 적혈구도 되고 신경 세포도 될까?"
① [관찰] 같은 유전자 — 적혈구 전구세포·이자 β세포·수정체 세포의 모양과 기능을 비교하고, 세포 3종의 DNA에서 글로빈·인슐린·크리스탈린 유전자를 검사하는 가상 검출(결과 모두 ○). 미션: DNA 검사 9칸 실행(task), 퀴즈(분화한 세포는 필요 없는 유전자를 잃었는가 → 아니오, 모든 세포가 같은 유전체).
② [분석] 선택적 발현 — 같은 세포 3종에서 mRNA를 검출(전기영동 밴드)해 표 완성: 세포 특이적 유전자(글로빈, 인슐린, 크리스탈린)와 모든 세포에서 켜진 유전자(세포호흡 효소, 리보솜 단백질) 구분. 미션: 밴드 읽어 표 완성(task), 세포 특이적/공통 유전자 분류(manual), 퀴즈(세포마다 단백질이 다른 이유, 인슐린 유전자는 적혈구 전구세포에 있지만 단백질은 없는 까닭).
③ [모형] 핵의 능력 — 거던의 개구리 핵 이식과 돌리 만들기를 단계별 모형으로 진행(분화 세포 핵 추출 → 핵을 없앤 난자에 이식 → 발생). 돌리의 성공률 계산(277개 중 1마리 ≈ 0.4 %). 해석: 분화한 핵도 전체 정보를 가짐, 난자 세포질이 핵의 발현 프로그램을 다시 쓴다. 미션: 핵 이식 모형 완성과 성공률 계산(task), 퀴즈(돌리가 분화 세포의 유전 정보가 온전하다는 증거인 까닭, 성공률이 낮은 것이 증거를 약하게 하는가).
④ [탐구] 분화 유도 — MyoD 모의: 섬유아세포에 MyoD 유전자를 넣으면 근육 특이적 유전자 mRNA가 연쇄적으로 켜지고 세포가 근관(근육 섬유)으로 변하는 장면. 전사 인자가 다른 유전자를 켜는 연쇄(앞 차시 인핸서·전사 인자 연결). 미션: MyoD 도입 후 mRNA 변화 확인(task), 퀴즈 2개(분화를 일으키는 직접 원인, 같은 유전체를 가진 두 세포가 서로 다른 세포가 되려면 무엇이 달라야 하는가).
애니메이션: 세포 3종 현미경 모양, DNA 검출 칸이 모두 점등되는 pulse, 전기영동 밴드가 나타나는 fade, 핵이 피펫으로 옮겨지는 tween, 섬유아세포가 길쭉한 근관으로 변하는 morph, 유전자 스위치 LED.

## `hg-embryo-patterning` · 🪰 초기 발생과 혹스 유전자
- 성취기준 [12유전02-04] 생물의 발생 과정에서 세포 분화가 유전자 발현 조절 과정을 통해 일어남을 추론할 수 있다.
- 카드 설명(desc): 초파리 배아에서 모계 인자의 농도 기울기가 분절 유전자와 혹스 유전자를 차례로 켜 체절의 정체성을 정하는 과정을 모형으로 따라가요.
- 태그: 초기 발생, 농도 기울기, 혹스 유전자, 호메오틱 돌연변이 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 모계 인자 · 분절 유전자 · 혹스 유전자 · 돌연변이

### 설계
범위(해설): 생물의 발생 초기 단계의 유전자 발현 조절 과정만 다룸 — 초파리 배아: 모계 효과 유전자(bicoid 등) → 간격 유전자(hunchback 등) → 쌍 규칙 유전자(줄무늬) → 체절(14개 단위) → 혹스(호메오) 유전자가 체절 정체성 결정. 발생 후기 기관 형성과 세포 신호 전달 경로는 다루지 않음. 앞 차시(세포 분화)에서 '같은 유전체인데 발현이 다름'을 확인했으므로 이 차시는 '위치에 따라 발현이 어떻게 다르게 시작되는가'. 분화 세포의 줄기세포 응용은 3단원. 다루지 않음: 신호 전달 경로(Notch, Wnt), 세포 사멸의 기작, 식물 호메오 유전자(ABC 모델), 후기 발생.
모계 인자: 난자 안에서 bicoid mRNA는 앞쪽 끝, nanos mRNA는 뒤쪽 끝에 위치. 수정 후 Bicoid 단백질이 번역되어 퍼지며 앞쪽이 높고 뒤쪽이 낮은 농도 기울기(교육용 단순화: 농도 C(x) = 100 × e^(−x/100 µm), x = 앞끝에서의 거리). 간격 유전자 hunchback은 Bicoid 농도 20 이상인 곳에서만 켜진다고 하면 경계 x = 100 × ln(100/20) ≈ 161 µm(배아 길이 500 µm의 약 1/3). 모계 bicoid 양이 2배(C₀ = 200)이면 경계 x = 100 × ln(200/20) ≈ 230 µm → 경계가 약 69 µm(= 100 ln 2) 뒤로 이동. bicoid 결함 어미의 배아는 머리·가슴 구조가 없고 앞쪽에도 꼬리 구조가 생김.
계층: 모계 인자 농도 기울기 → 간격 유전자(큰 구역으로 나눔) → 쌍 규칙 유전자(7개 줄무늬) → 체절 극성 유전자(체절 14개 단위) → 혹스 유전자(체절마다 다른 조합이 켜져 정체성 결정). 앞 단계의 산물(전사 인자)이 다음 단계 유전자의 발현을 조절.
혹스(호메오 박스) 유전자: 전사 인자 단백질을 만드는 유전자로 염색체 위의 배열 순서가 몸의 앞 → 뒤 발현 부위 순서와 같음(공선성). 초파리 8개(두 복합체), 사람 39개(4개의 클러스터 HOXA~D). 호메오틱 돌연변이: Antennapedia — 더듬이 자리에 다리가 생김(혹스 유전자가 머리 체절에서 잘못 켜짐), bithorax — 평균곤이 날개로 바뀌어 날개가 4개인 파리(셋째 가슴 체절이 둘째 가슴 체절처럼 발달). 기관의 구조 자체는 정상이고 '어디에 무엇을 만들지'의 정체성이 바뀜. 사람에서 HOXD13 이상이 손가락·발가락 기형의 원인이 되는 사례가 있음(한 줄).
탐구 질문: "수정란 속 물질이 한쪽에 치우쳐 있다는 사실만으로, 어떻게 머리와 꼬리가 구분되고 체절마다 다른 기관이 생길까?"
① [관찰] 모계 인자 — 초파리 난자 단면에서 bicoid mRNA(앞), nanos mRNA(뒤)의 위치를 보고, 수정 후 Bicoid 단백질이 앞→뒤로 퍼져 농도 기울기가 생기는 장면. bicoid 결함 어미의 배아 비교. 미션: 농도 기울기 만들고 위치별 농도 읽기(task), 퀴즈(모든 핵이 같은 유전체를 가지는데도 위치에 따라 켜지는 유전자가 달라지는 까닭 → 받은 Bicoid 농도 차이).
② [탐구] 분절 유전자 — 농도 문턱 20에서 hunchback이 켜지는 구역을 표시하고 경계 위치 계산(약 161 µm), bicoid 양을 2배로 하면 경계가 약 69 µm 뒤로 이동하는 예측과 확인. 유전자 계층(간격 → 쌍 규칙 줄무늬 7개 → 체절)을 순서대로 켜는 장면. 미션: 문턱 구역 표시와 경계 계산 입력(task), 2배 시 이동 거리 예측(task), 퀴즈(Bicoid가 많은 곳의 유전자 발현이 위치에 따라 정교해지는 까닭 → 앞 단계 산물이 다음 유전자를 조절).
③ [모형] 혹스 유전자 — 염색체 위 혹스 유전자 8개의 배열 순서와 배아 체절에서 켜지는 부위 순서가 같음을 연결(공선성), 체절마다 켜진 혹스 조합 읽기. 사람 혹스 4개 클러스터와 비교. 미션: 유전자–체절 연결(manual), 퀴즈(혹스 유전자 산물이 전사 인자인 까닭을 '여러 유전자를 켜고 끄는 스위치'로 설명).
④ [탐구] 돌연변이 — Antennapedia와 bithorax 변이를 만들어 혹스 발현 부위를 옮기면 더듬이 자리에 다리가 생기거나 날개가 4개가 되는 결과 예측 후 확인. 변이 파리 사진 카드를 보고 어떤 혹스 유전자 변이인지 연결. 미션: 변이 3종 예측(manual), 퀴즈 2개(호메오틱 돌연변이에서 기관의 구조가 비정상이 아니라 위치가 바뀐 것인 까닭, 사람의 혹스 유전자 이상이 몸의 형태에 영향을 줄 수 있는 이유).
애니메이션: 농도 기울기가 퍼지는 확산 입자와 색 변화, 구역별로 유전자 줄무늬가 켜지는 sweep, 염색체 위 유전자 배열과 체절 발현 대응선 draw, 변이 시 더듬이가 다리로 morph, 날개 두 쌍이 자라는 spring.

## `hg-expression-benefit` · 🌍 발현·발생 연구와 복지
- 성취기준 [12유전02-05] 생물의 유전자 발현 조절 및 발생에 대한 연구가 인류 복지에 기여한 사례를 조사하여 협력적으로 소통할 수 있다.
- 카드 설명(desc): 유전자 발현 조절과 발생 연구가 인슐린 생산, 암 진단, 재생 의학으로 이어진 사례를 조사하고, AI 도우미의 답을 사실 확인하며 모둠과 소통해요.
- 태그: 인류 복지, 사례 조사, 인공지능, 협력적 소통 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 사례 지도 · 조사 계획 · AI 활용 · 공유하기

### 설계
범위: 생물의 유전자 발현 조절과 발생에 대한 연구가 인류 복지에 기여한 사례를 조사하여 협력적으로 소통(정답이 하나인 문제가 아니라 조사·검증·공유 과정이 핵심). 앞 차시들(중심원리, 유전 부호, 젖당 오페론, 진핵 조절, 분화, 혹스)에서 배운 원리가 어떤 사례의 바탕이 되었는지 연결. 고려 사항: 최신 연구 조사 과정에서 생명과학 분야에 인공지능을 어떻게 이용할 수 있는지 조사 — AI의 답은 가설이므로 출처·사실 확인이 필요함을 연습. 모든 사례는 교육용 요약이며 의료 조언이 아님. 다루지 않음: 임상 시험 설계, 약물의 용량, 개별 질병의 치료 선택.
사례 카드 6장(바탕 원리): ① 재조합 인슐린 대량 생산 — 사람 인슐린 유전자를 대장균에 넣고 젖당 오페론의 프로모터로 발현을 켬(IPTG 같은 유도자로 필요할 때 켬), 인트론이 없는 cDNA 사용(유전 부호 보편성, 인트론). ② 유전자 발현 검사로 암 분류 — 종양 조직에서 발현하는 유전자 패턴(RNA 분석)으로 유형을 나눠 치료 선택에 활용(암은 유전자 발현 조절 이상). ③ 엽산과 신경관 결손 예방 — 임신 초기 엽산 섭취가 신경관 결손 위험을 낮춤(초기 발생 연구와 역학 조사). ④ 약물 안전성 — 탈리도마이드 사건(발생 시기 노출로 사지 기형) 이후 임신 중 약물 시험에서 배아 발생 영향을 검사, 제브라피시 배아 같은 모델 생물로 약물 독성 시험. ⑤ 유도만능줄기세포 — 체세포에 전사 인자 4종(Oct4, Sox2, Klf4, c-Myc)을 넣어 분화한 세포를 초기화(3단원 연결). ⑥ mRNA 백신 — 전사·번역 연구의 성과로 mRNA를 안정화하고 세포 안에서 단백질을 만들게 함. 각 카드: 해결된 문제 / 쓰인 지식 / 한계.
AI 활용 사례 카드: 단백질 구조 예측(아미노산 서열로 입체 구조 추정 — 약물 표적 탐색), 유전자 발현 데이터 분류(수천 개 유전자의 발현 패턴으로 암·질병 유형 분류), 조절 서열 예측(프로모터·인핸서 위치 예측), 논문 검색·요약(오류 가능, 원문 확인 필요). 가상 AI 답변 4개 중 2개가 오류: (참) '인슐린 유전자를 대장균에 넣을 때 인트론이 제거된 cDNA를 쓰는 까닭은 대장균이 인트론을 제거하지 못하기 때문이다.' / (오류) '대장균은 유전 부호가 사람과 달라서 사람 유전자를 넣어도 다른 아미노산이 이어진다.' / (참) '같은 유전체를 가진 체세포가 서로 다른 세포가 되는 것은 발현하는 유전자가 달라서이다.' / (오류) '젖당이 없어도 젖당 오페론의 억제자는 작동 부위에서 항상 떨어져 있다.'
