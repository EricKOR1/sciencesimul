## 개념 위계와 차시 흐름
선수: 통합과학2 h1-redox-oxygen(산소의 이동), h1-redox-electron(전자의 이동, 잃은 전자 수 = 얻은 전자 수 — 산화수는 다루지 않았음), h1-induction · h1-power-plant(전기 에너지), 화학 단원 34 hc-water-electrolysis(물의 전기 분해, 전극 반응식은 안 다룸) · hc-electronegativity(전기 음성도), 단원 33(몰 · 반응식 계수), 단원 53(약산 · 평형 — 염기성 용액이 아닌 산성 용액에서 쓰는 H⁺), 중3 m3-chemical-equation(반응식 계수 맞추기).
차시 흐름: ① 산화수와 산화·환원(전자 이동을 산화수 변화로 추적, 산화제·환원제의 상대성) → ② 산화·환원 반응식 완성(반쪽 반응식, 전자 수 맞추기) → ③ 화학 전지의 원리(다니엘 전지, 산화 전극 · 환원 전극, 염다리, 화학 에너지 → 전기 에너지) → ④ 실용 전지의 구조(발전 과정 조사, 구조적 공통점 추론, 효율적 전지의 조건)
→ ⑤ 표준 환원 전위(E°cell = E°(환원극) − E°(산화극)) → ⑥ 전기 분해의 원리(전지와 반대 방향, 용융 NaCl · NaCl 수용액 · 물) → ⑦ 도금과 산업 전기 분해(구리 도금 실험, 정련 · 알루미늄 제련 조사 발표) → ⑧ 생명과 전지 속 산화·환원(호흡 · 광합성 · 항산화제, 전지 물질의 역할, 미래 전지 설계).
'전자 장부를 산화수로 확장(①) → 식으로 균형(②) → 자발적 반응을 전기로 뽑아낸다(③④) → 전위차를 수치화(⑤) → 반대로 전기로 반응을 일으킨다(⑥⑦) → 생명과 미래 전지로 확장(⑧)'. 산화·환원은 항상 동시에 일어나며 산화제·환원제는 고정된 물질의 속성이 아니라 상대적 역할이라는 메시지를 ①⑤⑥에서 반복한다.
고려 사항: 해설에 따라 [02-01]에서 산화·환원이 동시에 일어남과 산화제·환원제의 '상대적 세기'를 강조, [02-03]은 화학 에너지 → 전기 에너지 전환 원리까지(전지 반응의 열역학 ΔG와 네른스트 식은 다루지 않음, 표준 상태 1 M · 1 기압 · 25 °C). 반쪽 반응식은 산성 수용액에서 H⁺ · H₂O로 균형을 맞추는 경우를 중심으로 하고(염기성 용액 보정은 제외), 전기 분해에서는 패러데이 법칙과 전하량(쿨롱) 계산을 하지 않으며 전자의 몰수 비(예: 전자 2몰 → Cu 1몰)로만 양적 관계를 다룬다. 조사 발표(02-02 · 02-04 · 02-05)는 동료 평가 루브릭을 쓴다. 화학 전지 만들기와 도금 실험 차시에는 보안경 · 장갑 착용, 중금속(구리 · 크로뮴) 폐액은 폐수 처리 기준에 따라 별도 수거한다는 안내를 단다.

## `hr-oxidation-number` · 🔢 산화수와 산화·환원
- 성취기준 [12반응02-01] 전자의 이동과 산화수 변화로 산화·환원 반응을 이해하고, 반쪽 반응식을 활용하여 산화·환원 반응식을 완성할 수 있다.
- 카드 설명(desc): 전자의 이동을 산화수로 계산해 산화와 환원을 판별하고, 같은 물질이 상대에 따라 산화제도 환원제도 되는 까닭을 알아봐요.
- 태그: 산화수, 산화제, 환원제, 상대적 세기 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 전자 장부 · 산화수 규칙 · 변화로 판별 · 산화제의 역할

### 설계
범위: [12반응02-01]의 앞부분 — 전자의 이동과 산화수 변화로 산화·환원 반응을 이해. 산화수 = 공유 결합에서는 공유 전자쌍을 전기 음성도가 큰 원자에게 모두 준 것으로 가정하고, 이온 결합에서는 이온의 전하로 정한 원자의 가상 전하. 규칙: 홑원소 물질 = 0, 단원자 이온 = 이온의 전하, 화합물 속 산화수 합 = 0, 다원자 이온 속 합 = 이온의 전하, 1족 +1, 2족 +2, 할로젠 −1, O −2(과산화물 H₂O₂는 −1), H +1. 산화 = 산화수 증가(전자를 잃음), 환원 = 산화수 감소(전자를 얻음). 산화수 증가 총량 = 감소 총량 = 이동한 전자 수. 산화제 = 다른 물질을 산화시키고 자신은 환원되는 물질, 환원제 = 자신이 산화되는 물질. 해설: 산화·환원은 동시에 일어나며 산화제 · 환원제는 정해져 있지 않고 상대적(H₂O₂, SO₂, Fe²⁺ 사례). 다루지 않음: 분수 산화수(Fe₃O₄), 불균등화 반응, 유기 화합물 탄소의 산화수(단원 55에서 시각적으로만).
자료: 산화수 계산 — H₂O(H +1, O −2), CO₂(C +4), NH₃(N −3), HNO₃(N +5), H₂SO₄(S +6), KMnO₄(Mn +7), K₂Cr₂O₇(Cr +6), MnO₄⁻(Mn +7), SO₄²⁻(S +6), NH₄⁺(N −3), H₂O₂(O −1). 산화·환원 반응 — Cu + 2Ag⁺ → Cu²⁺ + 2Ag (Cu 0 → +2 산화, Ag +1 → 0 환원, 전자 2개), CH₄ + 2O₂ → CO₂ + 2H₂O (C −4 → +4, O 0 → −2, 전자 8개), Fe₂O₃ + 3CO → 2Fe + 3CO₂ (Fe +3 → 0, C +2 → +4, 전자 6개). 산화·환원이 아닌 반응 — HCl + NaOH → NaCl + H₂O, CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂, AgNO₃ + NaCl → AgCl + NaNO₃ (산화수 변화 없음). 상대적 역할 — H₂O₂: 2I⁻ + H₂O₂ + 2H⁺ → I₂ + 2H₂O (O −1 → −2, 환원됨 = 산화제), 5H₂O₂ + 2MnO₄⁻ + 6H⁺ → 5O₂ + 2Mn²⁺ + 8H₂O (O −1 → 0, 산화됨 = 환원제). SO₂: SO₂ + 2H₂S → 3S + 2H₂O (S +4 → 0, 산화제), 5SO₂ + 2MnO₄⁻ + 2H₂O → 5SO₄²⁻ + 2Mn²⁺ + 4H⁺ (S +4 → +6, 환원제). Cu는 Ag⁺에게는 환원제, Zn에게 Cu²⁺는 산화제.
탐구 질문: "산소도 전자도 눈에 보이지 않는 반응에서, 어느 쪽이 전자를 잃고 얻었는지 어떻게 알아낼까?"
① [모형] 전자 장부 — 통합과학에서 한 Cu + Ag⁺ 반응을 다시 보며 전자 알갱이(노란 공)의 이동을 확인한 뒤, 공유 결합 물질에서는 전자가 완전히 이동하지 않아 '장부'가 필요함을 소개: H₂O 분자에서 공유 전자쌍이 O 쪽으로 쏠리는 그림(전기 음성도, 화학 단원 34 연결) → 전자쌍을 O에게 모두 주면 O −2, H +1. 미션: 전자쌍을 O 쪽으로 옮겨 산화수 확인(task), 퀴즈(산화수는 실제 전하와 같은가 → 공유 결합에서는 가상의 전하).
② [탐구] 산화수 규칙 — 규칙 카드 5장과 화합물 칸 채우기 게임: 미지 원자의 산화수 구하기(합 = 0 식). 목록: HNO₃의 N, KMnO₄의 Mn, K₂Cr₂O₇의 Cr, SO₄²⁻의 S, NH₄⁺의 N, H₂O₂의 O. 같은 원소도 화합물에 따라 산화수가 다르다는 점(N: −3 · 0 · +5)을 수직 눈금에 배치. 미션: 산화수 계산 4개(task), 눈금에 N 화합물 배치(manual), 퀴즈(H₂O₂에서 산소의 산화수가 −2가 아닌 까닭: O–O 결합 때문에 −1).
③ [분석] 변화로 판별 — 반응식 6개(Cu + Ag⁺, CH₄ 연소, Fe₂O₃ 제련, HCl + NaOH, CaCO₃ + HCl, AgNO₃ + NaCl)에서 원자별 산화수를 위에 붙여 증가(빨강 ↑) / 감소(파랑 ↓) / 변화 없음(회색)을 표시, 산화·환원 반응인지 판별. 증가 총량 = 감소 총량을 '전자 저울'로 확인(CH₄ 연소 8 = 8). 중화 · 앙금 반응은 산화수 변화가 없으므로 산화·환원이 아님. 미션: 6개 판별(manual), 이동한 전자 수 구하기(task: Fe₂O₃ + 3CO → 6개), 퀴즈(산화수가 증가한 물질이 산화된 것, 환원제가 되는 이유: 자신이 산화되면서 상대를 환원).
④ [설명] 산화제의 역할 — 산화제 · 환원제 이름표를 붙이는 연습 + 상대성: H₂O₂ 한 병을 KI 용액과 KMnO₄ 용액에 각각 넣는 모의실험 → 산화제로도 환원제로도 작용, SO₂도 H₂S와 KMnO₄에서 다른 역할. Cu가 Ag⁺와 만나면 환원제, Zn과 Cu²⁺가 만나면 Cu²⁺가 산화제. 미션: 이름표 붙이기 4개(manual), 같은 물질 두 역할 찾기(task), 퀴즈(오개념 '산화제는 항상 산화제다' X, 산화·환원은 어느 한쪽만 따로 일어나지 않음 → 환원제는 무엇에 대해 환원제인가를 물음).
애니메이션: 공유 전자쌍이 전기 음성도 큰 원자 쪽으로 미끄러지는 tween, 원자 위 산화수 숫자 롤링, 증가 ↑ 붉은 / 감소 ↓ 푸른 화살표, 전자 저울이 맞으면 burst, 같은 H₂O₂가 두 용액에서 다른 색 이름표로 바뀜.

### 설계

## `hr-galvanic-cell` · 🔋 화학 전지의 원리
- 성취기준 [12반응02-03] 화학 전지의 원리를 산화·환원 반응으로 설명하고, 표준 환원 전위를 이용하여 전위차를 구할 수 있다.
- 카드 설명(desc): 다니엘 전지를 직접 꾸며 산화 전극과 환원 전극, 염다리를 확인하고, 산화·환원 반응의 화학 에너지가 전기 에너지로 바뀌는 과정을 따라가요.
- 태그: 화학 전지, 다니엘 전지, 염다리, 에너지 전환 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 분리 반응 · 전지 구성 · 변화 분석 · 전극 조합

### 설계
범위: [12반응02-03]의 앞부분 — 화학 전지의 원리를 산화·환원 반응으로 설명(해설: 화학 에너지가 전기 에너지로 전환되는 원리). 산화·환원 반응을 두 반쪽 전지로 분리하고 외부 도선으로 전자를 이동시켜 전류를 얻음. 산화 전극((−)극, 전자를 내놓음) / 환원 전극((+)극, 전자를 받음), 전자는 도선을 따라 (−)극 → (+)극, 염다리의 이온은 전하 균형을 유지(음이온은 산화 전극 쪽으로, 양이온은 환원 전극 쪽으로). 전지식 Zn(s) | Zn²⁺(aq) ‖ Cu²⁺(aq) | Cu(s). 다루지 않음: 네른스트 식, 농도 전지, 전해질 농도에 따른 전압 변화, ΔG.
자료: 다니엘 전지 — (−)극 Zn → Zn²⁺ + 2e⁻ (Zn판 질량 감소, ZnSO₄ 용액 속 Zn²⁺ 증가), (+)극 Cu²⁺ + 2e⁻ → Cu (Cu판 질량 증가, CuSO₄ 용액의 푸른색 옅어짐), 전체 Zn + Cu²⁺ → Zn²⁺ + Cu. 염다리(KNO₃ 또는 Na₂SO₄) 사용 시 전압계 1.10 V(표준 상태), 염다리를 빼면 전압계 0 V. 질량 변화 예: 전자 0.20 mol이 이동하면 Zn 0.10 mol(6.5 g) 감소, Cu 0.10 mol(6.4 g) 증가. 같은 반응을 한 비커 안에서 직접 일으키면(Zn판을 CuSO₄ 용액에) 용액 온도가 올라가고 전기는 얻지 못함(화학 에너지 → 열에너지). 전극 조합과 전압(표준 상태): Zn–Cu 1.10 V, Cu–Ag 0.46 V, Zn–Ag 1.56 V.
탐구 질문: "같은 산화·환원 반응인데 비커 안에서는 열이 나고, 전지에서는 전기가 나온다. 무엇이 다를까?"
① [관찰] 분리 반응 — 한 비커(Zn판 + CuSO₄ 용액): Zn판 표면에 붉은 Cu가 석출되고 푸른색이 옅어지며 용액 온도계가 상승(열). 이어서 같은 반응에서 전자가 지나갈 길을 만들기 위해 Zn판과 Cu판을 서로 다른 비커에 넣고 도선 + 전구로 연결. 미션: 한 비커 반응에서 온도 변화 기록(task), 퀴즈(직접 반응의 에너지는 열로 나감 → 전자가 도선을 지나가도록 분리하면 전기 에너지로 이용 가능).
② [모형] 전지 구성 — 부품 상자(Zn판 · Cu판 · ZnSO₄ · CuSO₄ · 도선 · 전구 · 전압계 · 염다리)를 끌어 다니엘 전지 조립. 염다리 없이 연결하면 전압이 0으로 떨어지는 장면(한쪽 용액에 + 전하가 쌓여 반응이 멈춤) → 염다리를 연결하면 이온이 움직여 전하 균형 유지, 전압 1.10 V. 전지식 쓰기. 미션: 전지 조립 · 점등(task), 산화 전극 / 환원 전극 이름표(manual), 퀴즈(염다리의 역할: 전하 균형 유지, 전자가 지나가는 길이 아님).
③ [분석] 변화 분석 — 전류를 흘리는 시간 슬라이더(분)에 따라 Zn판 질량 감소 · Cu판 질량 증가 · 용액 이온 농도 변화 그래프와 입자 모형(전자 이동 · 이온 이동). 전자 0.20 mol → Zn 6.5 g 감소 · Cu 6.4 g 증가. 전자의 이동 방향과 전류의 방향이 반대임(전자 (−)극 → (+)극). 에너지 전환 도식(화학 에너지 → 전기 에너지 → 빛 · 열). 미션: 전극 질량 변화 예측 후 확인(task), 반쪽 반응식 쓰기(manual), 퀴즈(Cu판 질량이 늘어나는 까닭: Cu²⁺가 전자를 받아 Cu로 석출).
④ [예측] 전극 조합 — 금속판 Zn · Cu · Ag와 각 금속 이온 용액 중 두 개를 골라 전지를 만들 때 어느 금속이 (−)극인지 예측하고 전압을 읽음: Zn–Cu(Zn이 (−), 1.10 V), Cu–Ag(Cu가 (−), 0.46 V), Zn–Ag(Zn이 (−), 1.56 V). '전자를 내놓기 쉬운 쪽이 (−)극' 규칙과 전압 순서(Zn–Ag가 가장 큼)를 발견 → 다음 차시 전위 표의 필요성 예고. 미션: 세 조합 예측 후 실험(task), 퀴즈(Cu–Ag 전지에서 어느 쪽이 산화되나), 퀴즈(전지의 전압이 전극 크기와는 무관하다는 예고 질문).
애니메이션: 전자 알갱이(노란 공)가 도선을 따라 흐르며 전구 점등 · 밝기 approach, 염다리에서 이온 점이 양방향으로 이동, Zn판이 녹아 얇아지고 Cu판에 붉은 결정이 자람, 용액 색 전이, 에너지 흐름 화살표, 온도계 상승(한 비커).

탐구 질문: "우리가 쓰는 건전지, 자동차 배터리, 스마트폰 배터리는 모양이 전혀 다른데 속에는 무엇이 같을까?"
① [조사] 발전 과정 — 카드 6장(볼타 · 다니엘 · 망가니즈 건전지 · 알칼리 건전지 · 납 축전지 · 리튬 이온 전지)을 연대순으로 타임라인에 배열하고, 각 카드의 '이전 전지의 문제 → 개선' 쌍을 연결(예: 볼타의 분극 → 다니엘의 용액 분리, 일회용 → 충전 가능한 납 축전지, 무거움 → 가벼운 리튬 이온 전지). 미션: 연대순 배열(manual), 문제–개선 연결 3쌍(manual), 퀴즈(볼타 전지의 전압이 곧 떨어진 까닭).
② [분석] 구조 비교 — 세 전지(건전지 · 납 축전지 · 리튬 이온 전지)의 단면도 위에 (−)극 / (+)극 / 전해질 / 분리막 / 외부 회로를 색칠해 구조를 비교하고 공통점을 도출하는 표(요소 5칸 × 전지 3종) 완성. 공통점 문장 만들기(두 극의 활물질 + 전해질 + 분리 + 외부 회로). 전자가 외부 회로, 이온이 전해질을 지난다는 흐름 모식도. 미션: 단면 칠하기 3개(manual), 공통점 문장 완성(manual), 퀴즈(전해질이 없으면 전지가 작동하지 않는 까닭: 이온이 전하 균형을 맞춰야 함).
③ [탐구] 효율 탐색 — 금속판 쌍(Zn–Cu, Mg–Cu, Zn–Fe 등)과 전해질(증류수 / 소금물 / 진한 소금물 / 레몬즙)을 골라 전압계와 전구 전류를 측정, 극 사이 거리와 판의 크기 슬라이더. 결과: 전극 금속 쌍에 따라 전압이 달라지고(전압은 물질 조합이 결정), 전해질 이온이 많을수록·극 사이가 가까울수록 내부 저항이 작아 전류가 큼(R = 10 Ω 부하에서 r = 2 Ω 0.92 V vs 30 Ω 0.28 V). 효율적인 전지의 조건 카드 만들기(① 큰 전압의 전극 조합 ② 작은 내부 저항 ③ 충분한 활물질 ④ 안전한 분리 ⑤ 안정한 전해질). 미션: 변수 3개 바꿔 가며 전압 · 전류 기록(task 2), 조건 카드 선택(manual), 퀴즈(진한 소금물에서 전류가 큰 까닭: 이온이 많아 내부 저항이 작음).
④ [적용] 전지 분류 — 1차 전지(망가니즈 · 알칼리 건전지)와 2차 전지(납 축전지 · 리튬 이온 전지)를 방전 · 충전 반응 방향으로 구별: 충전은 외부 전원을 연결해 방전과 반대 방향으로 전자를 보내는 것(전기 분해와 같은 원리, ⑥차시 예고). 용도 카드(리모컨, 자동차 시동, 스마트폰, 전기 자동차, 시계)를 알맞은 전지에 연결. 미션: 방전 / 충전 전자 흐름 방향 화살표 맞추기(task), 용도 카드 연결(manual), 퀴즈(충전할 수 없는 1차 전지를 충전하면 위험한 까닭).

## `hr-standard-potential` · ⚡ 표준 환원 전위
- 성취기준 [12반응02-03] 화학 전지의 원리를 산화·환원 반응으로 설명하고, 표준 환원 전위를 이용하여 전위차를 구할 수 있다.
- 카드 설명(desc): 표준 수소 전극을 기준으로 정한 표준 환원 전위 표에서 값을 읽어 전지의 전위차 E°cell을 계산하고, 어떤 반응이 자발적으로 일어나는지 예측해요.
- 태그: 표준 환원 전위, E°cell, 전위차, 자발적 반응 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 기준 전극 · 전위 표 읽기 · 전위차 계산 · 반응 예측

### 설계
범위: [12반응02-03]의 뒷부분 — 표준 환원 전위를 이용해 전지의 전위차를 구함. 표준 환원 전위 E°: 표준 수소 전극(SHE, 2H⁺ + 2e⁻ → H₂, 0 V)을 기준으로 한 반쪽 전지의 환원 전위(1 M, 25 °C, 1 기압). E°가 클수록 환원되기 쉬움(센 산화제), 작을수록 산화되기 쉬움(센 환원제). 전지: E°cell = E°(환원 전극) − E°(산화 전극) > 0이면 자발적. 해설의 '산화제·환원제의 상대적 세기'를 이 표로 확인(같은 물질이 상대에 따라 산화제 또는 환원제). E°는 계수를 곱해도 변하지 않는 세기 성질. 다루지 않음: 네른스트 식, E°와 ΔG · K의 관계, 비표준 농도.
자료(E°, V): Li⁺/Li −3.04, Mg²⁺/Mg −2.37, Al³⁺/Al −1.66, Zn²⁺/Zn −0.76, Fe²⁺/Fe −0.44, 2H⁺/H₂ 0.00, Cu²⁺/Cu +0.34, Ag⁺/Ag +0.80, Cl₂/Cl⁻ +1.36, MnO₄⁻(+8H⁺)/Mn²⁺ +1.51. 계산: Zn–Cu = 0.34 − (−0.76) = 1.10 V, Cu–Ag = 0.80 − 0.34 = 0.46 V, Zn–Ag = 1.56 V, Mg–Cu = 0.34 − (−2.37) = 2.71 V, Fe–Cu = 0.78 V, Zn–SHE = 0 − (−0.76) = 0.76 V. 자발성: Zn + Cu²⁺ → Zn²⁺ + Cu E°cell = +1.10 V 자발, Cu + Zn²⁺ → … E°cell = −1.10 V 비자발. Zn + 2H⁺ → Zn²⁺ + H₂ +0.76 V(Zn은 묽은 산에 녹음), Cu + 2H⁺ → Cu²⁺ + H₂ −0.34 V(Cu는 녹지 않음), Cu + 2Ag⁺ → Cu²⁺ + 2Ag +0.46 V(계수 2를 곱하지 않음). 역할의 상대성: Cu²⁺는 Zn에게는 산화제, Ag⁺에게 Cu는 환원제.
탐구 질문: "전지의 전압은 어떻게 정해질까? 금속 이름만 알면 전압을 미리 계산할 수 있을까?"
① [모형] 기준 전극 — 한 반쪽 전지의 전위는 혼자서는 잴 수 없고 다른 반쪽 전지와 연결해야 전압이 나옴 → 기준으로 표준 수소 전극을 0 V로 약속. 전지 연결 실험: Zn–SHE 0.76 V (Zn이 (−)극), Cu–SHE 0.34 V (Cu가 (+)극). 부호 규칙: SHE보다 (−)극 쪽 금속은 E° 음수, (+)극 쪽은 양수. 미션: Zn · Cu를 SHE와 연결해 전압 · 극 방향 측정(task 2), 퀴즈(Zn의 E°가 −0.76 V인 까닭: SHE보다 환원되기 어려움 = 산화되기 쉬움).
② [설명] 전위 표 읽기 — 표를 세로 눈금으로 배열(위: 센 환원제 / 아래: 센 산화제), 위쪽 금속 Li · Mg · Al · Zn은 산화되기 쉽고 아래쪽 이온 Cu²⁺ · Ag⁺는 환원되기 쉬움. 규칙: 두 반쪽 전지를 고르면 E°가 큰 쪽이 환원 전극((+)극), 작은 쪽이 산화 전극((−)극). 미션: 두 반쪽 전지를 골라 환원극 / 산화극 판정(task 3), 퀴즈(가장 센 환원제 Li와 가장 센 산화제 MnO₄⁻의 위치).
③ [분석] 전위차 계산 — E°cell = E°(환원극) − E°(산화극) 식 칸에 값을 넣는 계산기: Zn–Cu 1.10 V, Cu–Ag 0.46 V, Zn–Ag 1.56 V, Mg–Cu 2.71 V, Fe–Cu 0.78 V. 이전 차시의 측정값(1.10 · 0.46 · 1.56)과 일치. 오개념 점검: 반응식 계수를 곱해 2 × 0.80 − 0.34로 쓰면 안 됨(Cu–Ag, 0.46 V). 미션: 전위차 계산 3개(task), 퀴즈(전위차가 가장 큰 조합 고르기), 퀴즈(계수가 2인 Ag⁺ 반쪽 전지의 E°를 두 배 하지 않는 까닭: 전위는 입자 한 개당 '전자를 끌어당기는 정도').
④ [예측] 반응 예측 — E°cell로 자발성 판단: Zn + Cu²⁺ (+1.10 V ○), Cu + Zn²⁺ (−1.10 V ×), Zn + 2H⁺ (+0.76 V ○ — 아연은 묽은 염산에 녹음), Cu + 2H⁺ (−0.34 V × — 구리는 묽은 염산에 안 녹음), Fe + Cu²⁺ (+0.78 V ○, 철못이 황산 구리 용액에서 구리로 덮임), Cu + 2Ag⁺ (+0.46 V ○). 산화제 · 환원제 상대성: Cu²⁺는 Zn에 대해 산화제, Cu는 Ag⁺에 대해 환원제. 미션: 반응 6개 가능 여부 판정(manual), 퀴즈(구리가 묽은 염산과 반응하지 않는 근거를 E°로 설명), 퀴즈(오개념 '환원제는 항상 환원제다' X, Cu의 두 역할).
애니메이션: 전위 표의 세로 눈금 위에 반쪽 전지 카드가 위아래로 이동, 두 카드를 고르면 높이 차이 막대가 E°cell 길이로 자람(approach), 전압계 바늘 spring, 자발적이면 전자 흐름 · 전구 점등 / 비자발이면 정지, 철못 표면에 구리가 석출.

## `hr-electrolysis` · 🔌 전기 분해의 원리
- 성취기준 [12반응02-04] 전기 분해의 원리를 산화·환원 반응으로 설명하고, 산업 현장에서 활용되는 전기 분해의 예를 조사하여 발표할 수 있다.
- 카드 설명(desc): 전지와 반대로 전기 에너지를 공급해 일어나는 전기 분해를 용융 NaCl, NaCl 수용액, 물에서 비교하고, 전극에서 어떤 반응이 일어나는지 설명해요.
- 태그: 전기 분해, 전극 반응, NaCl 수용액, 산화·환원 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 전지와 비교 · 용융 NaCl · 수용액 경쟁 · 전자 계산

### 설계
범위: [12반응02-04]의 앞부분 — 전기 분해의 원리를 산화·환원 반응으로 설명. 전기 에너지가 비자발적 산화·환원 반응을 일으킴(전기 에너지 → 화학 에너지). 전원의 (+)극에 연결한 전극에서 산화((+)극 = 산화 전극), (−)극에 연결한 전극에서 환원((−)극 = 환원 전극) — 전지에서는 (−)극이 산화 전극이라는 점과 대비. 전극 반응: ① 용융 NaCl: (+)극 2Cl⁻ → Cl₂ + 2e⁻, (−)극 Na⁺ + e⁻ → Na ② NaCl 수용액(탄소 전극): (+)극 2Cl⁻ → Cl₂ + 2e⁻, (−)극 2H₂O + 2e⁻ → H₂ + 2OH⁻ (Na⁺보다 물이 먼저 환원 — 환원 전위 비교: E°(Na⁺/Na) −2.71 V < E°(물, 염기성) 약 −0.83 V), 전체 2NaCl + 2H₂O → 2NaOH + H₂ + Cl₂ ③ 묽은 Na₂SO₄ 수용액으로 물 분해: (+)극 2H₂O → O₂ + 4H⁺ + 4e⁻, (−)극 2H₂O + 2e⁻ → H₂ + 2OH⁻, 전체 2H₂O → 2H₂ + O₂. 양극에서 Cl⁻가 물보다 먼저 산화되는 것은 실험 사실로 제시(과전압은 다루지 않음). 이동한 전자의 몰수와 생성물의 몰수 비만 사용: 전자 2 mol당 Na 2 mol · Cl₂ 1 mol, 전자 4 mol당 H₂ 2 mol · O₂ 1 mol. 다루지 않음: 패러데이 법칙 · 전하량 계산, 과전압, 이온화 경향 전체 순위표.
자료: 용융 NaCl(약 800 °C): Na⁺ → (−)극에서 은백색 Na 석출, Cl⁻ → (+)극에서 황록색 Cl₂ 기체 발생. 전자 2.0 mol 이동 시 Na 2.0 mol(46 g) + Cl₂ 1.0 mol(71 g). NaCl 수용액: (−)극 주변이 염기성(페놀프탈레인 붉은색), 두 극에서 H₂ : Cl₂ = 1 : 1 부피(Cl₂는 물에 일부 녹아 실제 관찰 부피는 약간 작음), (+)극 기체는 녹말-요오드화 칼륨 종이를 푸르게 변색. 물의 전기 분해: 전자 4.0 mol → H₂ 2.0 mol + O₂ 1.0 mol(부피비 2 : 1, 화학 단원 34에서 관찰한 사실의 전자 수준 설명). 충전 장면: 다니엘 전지(1.10 V)에 반대 방향으로 1.10 V보다 큰 전압(예: 2.0 V)을 걸면 Cu판이 녹고 Zn판에 Zn이 석출(전지 반응의 역반응).
탐구 질문: "전기를 흘려 주면 왜 소금물이 염소 기체와 수소 기체로 갈라질까? 전극에서는 어떤 일이 일어날까?"
① [관찰] 전지와 비교 — ③차시 다니엘 전지를 다시 꺼내 외부에 전원 장치를 반대로 연결: 전압 슬라이더 0 → 2.0 V에서 1.10 V 미만이면 전지가 계속 방전(전류 방향 그대로), 1.10 V보다 크면 전류 방향이 뒤집히며 Zn판이 두꺼워지고 Cu판이 얇아짐. 에너지 전환 방향 두 가지(전지: 화학 → 전기 / 전기 분해: 전기 → 화학). 미션: 전압을 올리며 전환점 찾기(task), 전지와 전기 분해 비교표(manual: (−)극 반응 종류, 에너지 전환), 퀴즈(충전은 전지 반응의 역반응을 전기 분해로 일으키는 것).
② [모형] 용융 NaCl — 탄소 전극 두 개를 용융 NaCl에 넣고 전원 연결: Na⁺는 (−)극 쪽, Cl⁻는 (+)극 쪽으로 이동하는 이온 모형, 전극에서 전자 주고받기(전자 장부: Cl⁻ 2개 → Cl₂ + 전자 2개 → 도선 → Na⁺ 2개가 받음). 전극 이름표(산화 전극 / 환원 전극) 붙이기와 전체 반응식. 미션: 이온의 이동 방향 맞추기(manual), 전극 반응식 쓰기(manual), 퀴즈((+)극에서 일어나는 반응이 산화인 까닭: 전자를 잃음).
③ [탐구] 수용액 경쟁 — NaCl 수용액을 같은 장치로 전기 분해: (−)극에서는 Na⁺와 물 중 어느 것이 환원될까 예측(보기 2개) → 환원 전위 표(E°)로 물이 더 쉽게 환원됨을 확인 → H₂ 발생과 OH⁻ 생성(페놀프탈레인 붉은색). (+)극에서 Cl₂ 발생(녹말-요오드화 칼륨 종이 청변). 용융 NaCl과 수용액의 생성물 비교표. 보안경 · 환기 · 폐액 처리 안내 한 줄. 미션: 극 반응 예측 후 확인(task 2), 생성물 비교표(manual), 퀴즈(NaCl 수용액을 전기 분해해도 나트륨 금속이 얻어지지 않는 까닭).
④ [적용] 전자 계산 — 전자 몰수와 생성물 몰수 비: 용융 NaCl에서 전자 2.0 mol → Na 46 g · Cl₂ 71 g, 물 전기 분해에서 전자 4.0 mol → H₂ 2.0 mol · O₂ 1.0 mol(부피비 2 : 1, 화학 단원 34 연결), 전자 0.20 mol일 때 생성물의 몰수 구하기. 전지 vs 전기 분해의 극 이름 규칙 정리(전지: (−)극 = 산화 / 전기 분해: (+)극 = 산화). 미션: 생성물 몰수 · 질량 계산 3개(task), 퀴즈(극 이름 규칙 비교), 퀴즈(물을 전기 분해할 때 순수한 물이 아니라 전해질을 넣는 까닭: 전류 운반 이온 공급).
애니메이션: 이온이 전극 쪽으로 끌려가며(속도 차이로 전하 부호 표시), 전극에서 Cl⁻가 전자를 내놓고 기포(Cl₂)로 변함, 전자 점이 도선을 따라 (+)극 → 전원 → (−)극, 페놀프탈레인 붉은 색이 (−)극 주변에서 퍼짐, 시험관에 기체가 모이며 수위 하강(수소 쪽이 더 빠르게), 충전 모드에서 판 두께 변화.

탐구 질문: "철 열쇠에 구리를 입히려면 전원의 어느 극에 무엇을 연결해야 할까? 공장에서는 이 원리를 어디에 쓸까?"
① [실험] 도금 실험 — 부품 상자(구리판 · 철 열쇠 · CuSO₄ 수용액 · 전원 장치 · 전류계)를 끌어 전기 도금 장치 조립. 극 연결을 직접 선택(열쇠를 (−)극에 연결해야 구리가 입혀짐), 잘못 연결하면 열쇠가 녹는 장면. 전극 반응 이름표(산화 / 환원)와 반쪽 반응식. 보안경 · 장갑, 구리 폐액은 중금속 폐액으로 따로 수거 안내. 미션: 올바르게 연결해 도금(task), 극 반응식 쓰기(manual), 퀴즈(도금될 물체를 (−)극에 연결하는 까닭: 환원 전극에서 Cu²⁺가 환원되어 석출).
② [분석] 석출 분석 — 전류 0.50 A에서 시간–석출 질량 그래프(0.05 · 0.10 · 0.15 · 0.20 g)를 그려 비례 관계 확인, 전류를 0.25 A로 바꿔 기울기 비교. 용액의 푸른색(Cu²⁺ 농도)이 그대로인 까닭을 입자 모형으로 확인((+)극에서 녹은 만큼 (−)극에서 석출). 구리 0.20 g의 몰수와 전자의 몰수(Cu²⁺ + 2e⁻ → Cu: 전자는 Cu의 2배). 미션: 그래프 그리기 · 비례 확인(task), 전자 몰수 계산(task: 6.3×10⁻³ mol), 퀴즈(전류를 두 배로 하면 같은 시간에 석출량이 두 배가 되는 까닭).
③ [조사] 산업 조사 — 사례 카드 4장(구리 정련, 알루미늄 제련, 염소 · 수산화 나트륨, 금속 도금)을 열어 전해질 · 전극 · 반응식 · 생성물 · 용도를 읽고 정보 틀에 채우기. 알루미늄 사례에서 '수용액이 아닌 용융 상태에서 전기 분해하는 까닭'(물이 먼저 환원)을 ⑥차시 환원 전위로 설명. 미션: 사례 2개의 극 반응식 완성(manual), 사례–용도 짝짓기(manual), 퀴즈(구리 정련에서 순동이 (−)극에 석출되는 까닭).
④ [적용] 발표 · 평가 — 사례 하나를 골라 발표 카드(원리 한 문장 · 반응식 · 쓰임 · 장단점/환경 · 질문 하나) 작성 후 동료 평가 루브릭(정확성 · 이해하기 쉬움 · 근거 · 창의)으로 별점 매기기(다른 학생 카드는 샘플 3개로 제공). 미션: 발표 카드 완성(manual), 동료 카드 평가(task), 퀴즈(전기 분해가 에너지를 많이 쓰는 이유와 재활용의 의미).

## `hr-redox-life` · 🌿 생명과 전지 속 산화·환원
- 성취기준 [12반응02-05] 생명 현상 및 화학 전지에서 이용되는 다양한 산화·환원 반응과 그 반응에 이용된 물질의 역할을 조사하여 화학의 신비로움을 느낄 수 있다.
- 카드 설명(desc): 호흡과 광합성의 전자 이동, 비타민 C 같은 항산화제, 리튬 이온 전지와 연료 전지 속 물질의 역할을 조사하고 지속 가능한 미래 전지를 설계해요.
- 태그: 세포 호흡, 광합성, 항산화제, 미래 전지 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 몸속 반응 · 광합성·항산화 · 전지 속 물질 · 미래 전지

### 설계
범위: [12반응02-05] — 생명 현상 및 화학 전지에서 이용되는 다양한 산화·환원 반응과 그 반응에 이용된 물질의 역할을 조사. 조사형 차시이므로 반응식을 암기시키지 않고 '누가 산화되고 누가 환원되는가, 전자를 나르는 물질은 무엇인가, 이 물질은 산화제인가 환원제인가'를 산화수와 전자 이동으로 분석한다. 탐구 활동: 지속가능한 발전을 위한 미래 전지 설계하기. 생체: 세포 호흡 C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O (포도당의 C 평균 0 → CO₂ +4 = 산화, O₂ 0 → H₂O −2 = 환원, 포도당 1분자에서 전자 24개), 전자 운반체 NAD⁺ + 2e⁻ + H⁺ → NADH(전자 셔틀), 전자 전달계에서 전자가 단계적으로 에너지가 낮은 전달체를 거쳐 O₂에 도달(한 번에 연소하면 열, 단계적이면 ATP 합성 — 약 30 ~ 40 %가 ATP에 저장), 광합성은 호흡과 반대 방향의 산화·환원(CO₂ 환원, H₂O 산화), 항산화제(비타민 C)는 활성 산소를 환원시키며 자신이 산화되는 환원제. 전지: 납 축전지 Pb + PbO₂ + 2H₂SO₄ ⇌ 2PbSO₄ + 2H₂O(Pb 0 → +2 산화, Pb +4 → +2 환원), 리튬 이온 전지 방전 시 (−)극 LiC₆ → C₆ + Li⁺ + e⁻ (Li 산화, 단순화), (+)극 CoO₂ + Li⁺ + e⁻ → LiCoO₂ (Co +4 → +3 환원), 수소 연료 전지 (−)극 H₂ → 2H⁺ + 2e⁻, (+)극 O₂ + 4H⁺ + 4e⁻ → 2H₂O, 전체 2H₂ + O₂ → 2H₂O(전기 분해의 역, 연료를 계속 공급, 촉매 Pt). 물질의 역할: 환원제 / 산화제 / 전해질(이온 통로) / 촉매 / 전자 운반체. 다루지 않음: 효소 반응 메커니즘의 세부, ATP 합성 효소의 구조, 전지의 정확한 전위 계산.
자료: 포도당 1분자 완전 산화 → 전자 24개(C 6개 × 4), 6 O₂ × 4 e⁻ = 24 e⁻로 일치. 광합성 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂: C +4 → 0(환원), O −2 → 0(H₂O의 산화). 사과 갈변: 폴리페놀의 산화, 비타민 C를 바르면 비타민 C가 대신 산화(통합과학 연결). 리튬 이온 전지 약 3.7 V, 수소 연료 전지 약 0.7 ~ 1.0 V/셀(실제 작동 전압), 납 축전지 셀당 약 2.0 V. 미래 전지 설계 카드 점수(10점 만점): 리튬 이온(에너지 밀도 9 · 안전성 6 · 자원 풍부 4 · 재활용 5), 나트륨 이온(7 · 7 · 9 · 6), 수소 연료 전지(8 · 6 · 7 · 7 — 수소의 생산 방법에 따라 다름), 납 축전지(3 · 7 · 6 · 9). 점수는 학습용 상대 평가임을 표시.
탐구 질문: "몸속에서 포도당이 '불꽃 없이' 천천히 타는 것과 전지가 전기를 만드는 것에는 어떤 공통점이 있을까?"
① [조사] 몸속 반응 — 포도당 → CO₂ + H₂O 반응을 산화수 표로 분석(C 평균 0 → +4, O 0 → −2, 전자 24개 이동). 같은 반응을 불에 태우면 열과 빛으로 한꺼번에 나오지만 세포에서는 NAD⁺가 전자를 받아 NADH로 나르고 전자 전달계를 계단처럼 내려가며 O₂까지 전달, 단계마다 에너지의 일부가 ATP로 저장. 미션: 산화수 표 채우기(task), 전자 흐름의 순서 배열(포도당 → NAD⁺ → 전달체 → O₂, manual), 퀴즈(NADH가 하는 일: 전자 운반 / 오개념: 산소가 포도당에게 전자를 준다 X).
② [분석] 광합성 · 항산화 — 광합성 장면(빛 에너지로 H₂O가 산화되어 O₂, CO₂가 환원되어 포도당)과 호흡을 나란히 비교해 반대 방향의 산화·환원임을 표시. 사과 단면과 비타민 C: 비타민 C가 먼저 산화되어 갈변이 늦어지는 시뮬레이션 + 항산화제는 자신이 산화되는 환원제. 미션: 광합성 · 호흡 산화 / 환원 물질 분류(manual), 항산화제 설명 고르기(manual), 퀴즈(광합성에서 환원되는 물질은 CO₂).
③ [분석] 전지 속 물질 — 전지 3종(납 축전지, 리튬 이온 전지, 수소 연료 전지)의 반응물에 역할 이름표(환원제 · 산화제 · 전해질 · 촉매)를 붙이고 산화수 변화 확인(Pb 0 → +2 / +4 → +2, Co +4 → +3, H 0 → +1, O 0 → −2). 방전 · 충전 방향에서 역할이 바뀌는지 토글: 충전 때는 반응이 거꾸로 되어 (−)극 물질이 환원(⑥차시 전기 분해와 연결). 연료 전지는 '반응물을 외부에서 계속 공급'하는 점이 다름. 수소 연료 전지 전체 반응이 물 전기 분해의 역반응임을 반응식으로 확인. 미션: 역할 이름표 붙이기 6개(manual), 산화수 변화 쓰기(task), 퀴즈(연료 전지가 충전이 필요 없는 까닭: 연료와 산소를 계속 공급).
④ [적용] 미래 전지 — 과제 3개(전기 자동차, 가정용 에너지 저장, 웨어러블 기기)에 대해 전지 후보 4종의 점수(에너지 밀도 · 안전성 · 자원 풍부 · 재활용)를 레이더 차트로 비교해 가장 적합한 전지 고르기, 보완해야 할 점 한 줄 쓰기(탐구 활동 '지속 가능한 발전을 위한 미래 전지 설계'). 동료 평가 카드 3개에 근거 · 창의성 별점. 미션: 과제별 전지 선택 + 근거 레이더 확인(task 2), 보완 아이디어 쓰기(manual), 퀴즈(나트륨 이온 전지가 지속 가능성 면에서 유리할 수 있는 까닭: 자원이 풍부).
애니메이션: 포도당 분자에서 전자 알갱이가 NAD⁺ 셔틀 → 계단식 전달체 → O₂로 흘러 가며 단계마다 ATP 구슬이 만들어짐, 광합성 장면의 반대 방향 화살표, 사과 단면의 갈변이 비타민 C로 늦춰짐(색 전이), 전지 단면에서 방전 / 충전 전환 시 전자 · 이온 흐름이 뒤집힘, 레이더 차트 tween.
