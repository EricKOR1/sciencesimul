## `m3-senses` · 👁️ 감각 기관과 자극의 전달
- 성취기준 [9과20-01] 감각기관의 구조와 기능을 이해하고, 실험을 통해 자극이 뇌로 전달되는 과정을 추론할 수 있다.
- 카드 설명(desc): 맹점 실험으로 눈의 구조를 추론하고, 눈·귀·코·혀·피부가 받아들인 자극이 감각 신경을 거쳐 뇌로 전달되는 과정을 따라가요.
- 태그: 감각 기관, 맹점, 자극의 전달 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 맹점 실험 · 눈의 조절 · 여러 감각 · 뇌로 전달

### 설계
범위(해설): 감각 기관의 구조는 간단히 언급하고, 자극이 감각 기관에서 뇌로 전달되는 과정을 중점적으로. 고려: 시각 실험은 현상을 관찰하고, 관찰한 사실을 바탕으로 눈의 구조를 추론. 탐구 활동: 맹점 확인 실험하기.
눈: 빛 → 각막 → 수정체 → 망막(시각 세포) → 시각 신경 → 대뇌. 홍채가 동공 크기 조절(밝으면 작게, 어두우면 크게), 섬모체가 수정체 두께 조절(가까운 곳: 두껍게, 먼 곳: 얇게). 맹점: 시각 신경이 모여 나가는 곳, 시각 세포가 없어 상이 맺혀도 보이지 않음.
귀: 소리 → 고막 → 귓속뼈 → 달팽이관(청각 세포) → 청각 신경 → 대뇌; 반고리관(회전), 전정 기관(기울기). 코: 기체 상태 물질 → 후각 세포 → 후각 신경 → 대뇌(쉽게 피로해짐). 혀: 액체 상태 물질 → 맛봉오리의 미각 세포 → 미각 신경 → 대뇌, 기본 맛 단맛·짠맛·신맛·쓴맛·감칠맛(매운맛은 통각). 음식 맛 = 미각 + 후각.
피부: 통점(가장 많음)·압점·촉점·냉점·온점, 부위마다 분포가 다름(손끝·입술에 많음). 공통 경로: 자극 → 감각 기관(감각 세포) → 감각 신경 → 뇌(대뇌).
탐구 질문: "눈으로 들어온 빛은 어떻게 '보는 것'이 될까?"
① [실험] 맹점 실험 — 화면의 +와 ● 카드로 실제 실험 안내(왼눈을 가리고 오른눈으로 +를 보며 화면과의 거리 바꾸기) + 가상 눈 모형에서 ●을 옮기면 상이 망막의 시각 신경 출구에 맺힐 때 사라짐. 미션: 사라지는 위치 찾기(task), 추론 퀴즈(그곳에 시각 세포가 없다).
② [탐구] 눈의 조절 — 밝기 슬라이더 → 홍채가 동공 크기 조절, 물체 거리 슬라이더 → 수정체 두께를 바꿔 망막에 선명한 상 맺기. 미션 2개(task), 퀴즈.
③ [관찰] 여러 감각 — 귀(소리 물결이 고막 → 귓속뼈 → 달팽이관), 코 막고 사과·양파 맛 구별(어려움 → 맛은 미각 + 후각), 두 점 구별 실험(손끝 vs 등). 미션: 자극을 받아들이는 곳 탭(task), 퀴즈.
④ [설명] 뇌로 전달 — 자극 카드(빛·소리·냄새·맛·온도)를 감각 기관 → 감각 세포 → 감각 신경 → 대뇌 순서로 연결(manual), 신경 신호 빛 펄스. 퀴즈(코가 막히면 맛을 덜 느끼는 까닭).
애니메이션: 눈 단면 광선 굴절과 상 맺힘, 동공 크기 approach, 수정체 두께 spring, 신경 펄스(glow 점 흐름), 소리 물결.

## `m3-neuron-reflex` · 🧠 뉴런과 신경계, 반응
- 성취기준 [9과20-02] 뉴런과 신경계의 구조와 기능을 이해하고, 자극에서 반응이 일어나기까지의 과정을 모형으로 설명할 수 있다.
- 카드 설명(desc): 뉴런과 신경계의 구조와 기능을 알아보고, 자 잡기 실험과 무릎 반사 모형으로 의식적 반응과 무조건 반사의 경로와 속도를 비교해요.
- 태그: 뉴런, 중추 신경계, 의식적 반응, 무조건 반사 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 뉴런 · 신경계 · 의식적 반응 · 무조건 반사

### 설계
범위: 뉴런(신경 세포) = 신경 세포체(핵), 가지 돌기(자극을 받아들임), 축삭 돌기(다른 뉴런·기관으로 전달) → 자극은 한 방향으로 전달. 감각 뉴런(감각 기관 → 중추), 연합 뉴런(뇌·척수, 판단·명령), 운동 뉴런(중추 → 근육).
신경계: 중추 신경계 — 대뇌(감각·기억·판단, 의식적 행동 명령), 소뇌(몸의 균형, 근육 운동 조절), 간뇌(체온·혈당량 등 항상성 조절), 중간뇌(눈의 움직임, 동공 크기 조절), 연수(심장 박동·호흡·소화 운동 조절; 기침·재채기·하품 반사), 척수(뇌와 몸 사이 신호 통로; 무릎 반사·회피 반사) / 말초 신경계 — 감각 신경, 운동 신경(자율 신경은 이름 정도만).
반응 경로: 의식적 반응(자극 → 감각 기관 → 감각 신경 → 대뇌 → 운동 신경 → 근육), 무조건 반사(대뇌를 거치지 않음: 척수·연수·중간뇌가 중추) → 빠름, 위험으로부터 몸을 보호.
고려: 실험으로 무조건 반사와 의식적 반응의 속도 차이를 측정하고 데이터 분석. 탐구 활동: 무조건 반사와 의식적 반응 실험하기.
자 잡기 실험: 화면의 자가 예고 없이 떨어지면 탭해서 잡기 → 실제 반응 시간(ms)과 낙하 거리 표시(환산표: 5 cm 0.10 s, 10 cm 0.14 s, 15 cm 0.17 s, 20 cm 0.20 s, 25 cm 0.23 s, 30 cm 0.25 s; 식은 보이지 않음, 중3 Ⅳ 자유 낙하 연결). 무릎 반사는 약 0.05초 이내(정성적 비교).
탐구 질문: "뜨거운 냄비에 손이 닿으면 '뜨겁다'고 생각하기도 전에 손을 떼는 까닭은 무엇일까?"
① [관찰] 뉴런 — 뉴런 모형에 자극 → 신호가 가지 돌기 → 신경 세포체 → 축삭 돌기 끝으로 이동, 감각–연합–운동 뉴런 연결. 미션: 신호를 끝까지 전달(task), 퀴즈(부분의 이름과 역할).
② [모형] 신경계 — 몸 실루엣의 중추·말초 신경, 뇌 부분 5곳 탭 → 기능 카드. 미션: 5곳 탐색(task), 상황–뇌 부위 짝짓기(manual: 균형→소뇌, 체온→간뇌, 동공→중간뇌, 심장 박동→연수, 문제 풀기→대뇌), 퀴즈.
③ [실험] 의식적 반응 — 자 잡기 3회 측정·평균, 경로 애니메이션(눈 → 감각 신경 → 대뇌 → 운동 신경 → 손가락 근육). 미션: 3회 측정(task), 퀴즈.
④ [탐구] 무조건 반사 — 무릎 반사 망치 → 척수 경로 펄스(대뇌를 거치지 않음), 뜨거운 냄비(척수)·재채기(연수)·동공 반사(중간뇌), 반응 시간 막대 비교(내 측정값 vs 반사). 미션: 반사 경로 순서 맞추기(manual), 퀴즈(반사가 빠른 까닭과 의미).
애니메이션: 신경 펄스(glow), 뇌 영역 하이라이트 fade, 자 낙하(중력 가속), 무릎 차기 spring.

## `m3-hormones` · 🩸 호르몬과 항상성
- 성취기준 [9과20-03] 우리 몸의 기능 조절에 호르몬이 관여함을 알고, 관련 자료를 조사하여 발표할 수 있다.
- 카드 설명(desc): 혈액을 따라 이동하며 몸의 기능을 조절하는 호르몬을 알아보고, 인슐린과 글루카곤으로 혈당량을 조절하는 게임으로 항상성을 체험해요.
- 태그: 호르몬, 혈당량 조절, 체온 조절, 항상성 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 호르몬 · 혈당량 조절 · 체온 조절 · 호르몬과 질병

### 설계
범위(해설): 호르몬의 종류는 성장 호르몬, 인슐린, 글루카곤, 티록신 정도만 언급하고, 신경계와 호르몬의 작용으로 몸을 최적의 상태로 유지함을 강조. 고려: 호르몬 관련 질병의 성별·연령별 발병 비율 자료 조사·분석.
호르몬: 내분비샘에서 혈액으로 분비되어 온몸을 돌다가 특정 기관에 작용, 적은 양으로 큰 효과, 부족하거나 많으면 이상. 뇌하수체 — 성장 호르몬(뼈·근육 생장 촉진), 갑상샘 — 티록신(세포 호흡 촉진, 체온 유지), 이자 — 인슐린(혈당량 낮춤: 포도당을 세포로 들여보내고 간에 글리코젠으로 저장), 글루카곤(혈당량 높임: 간의 글리코젠을 포도당으로 분해).
신경과 호르몬 비교: 신경(빠름, 좁은 범위, 짧게) / 호르몬(느림, 넓은 범위, 오래). 항상성: 몸 안팎의 환경이 변해도 체온·혈당량 등을 일정하게 유지, 간뇌가 조절 중추.
혈당량 정상 범위(단순화): 약 70~110 mg/dL. 체온 조절 — 추울 때: 피부 근처 혈관 수축(열 방출 ↓), 몸 떨림(열 발생 ↑), 티록신 분비 ↑ / 더울 때: 혈관 확장, 땀 분비 ↑.
질병: 당뇨병(인슐린 부족·작용 이상 → 혈당량 높음), 거인증·소인증(성장기 성장 호르몬 과다·결핍), 갑상샘 기능 항진증·저하증(티록신 과다·결핍). 성별·연령별 자료는 '예시 자료(경향을 단순화)'로: 당뇨병은 나이가 많을수록 증가, 갑상샘 질환은 여성에게 더 많음.
탐구 질문: "밥을 먹은 뒤나 오래 굶은 뒤에도 혈액 속 포도당의 양이 거의 일정한 까닭은 무엇일까?"
① [관찰] 호르몬 — 몸 실루엣의 뇌하수체·갑상샘·이자 탭 → 호르몬 카드, 호르몬 입자가 혈관을 타고 표적 기관으로 이동, 신경(빠른 전선) vs 호르몬(혈류 택배) 비교. 미션: 3곳 탐색(task), 퀴즈.
② [실험] 혈당량 조절 — 시간 진행(식사 → 운동 → 공복)에 따라 혈당 그래프가 변함, 인슐린/글루카곤 버튼으로 정상 범위 유지 → 마지막에 '건강한 몸의 자동 조절' 재생. 미션 2개(task: 식사 후 낮추기, 운동 후 높이기), 퀴즈.
③ [설명] 체온 조절 — 추운 날/더운 날 토글 → 간뇌가 감지 → 신경(혈관·떨림·땀) + 호르몬(티록신) 동시 작용, 체온 37 °C 유지. 미션: 추울 때 일어나는 반응 고르기(manual), 퀴즈(신경과 호르몬의 협력).
④ [분석] 호르몬과 질병 — 결핍·과다 카드 짝짓기, 예시 자료 막대그래프(연령별 당뇨병, 성별 갑상샘 질환) 해석 퀴즈 2~3개.
