## 개념 위계와 차시 흐름
선수: 초4 '지층과 화석'(지층의 생성·퇴적암·화석), 중2 Ⅱ '지권의 변화'(광물·화성암/퇴적암/변성암의 생성 과정·암석의 순환·판의 경계), 통합과학1 h1-plate-tectonics(판의 경계·맨틀 대류·해령 확장 속도 계산)·h1-silicate(규산염 광물)·h1-volcano-impact(화산 분출물)·h1-supernova-origin(태양계 형성 약 46억 년 전 연대표).
차시 흐름: ① 지층의 선후 관계(동일 과정의 원리 → 상대 연령) → ② 방사성 동위 원소와 절대 연령 [= 12지구02-01을 나눔] → ③ 퇴적 구조와 퇴적 환경 → ④ 지질시대와 화석(기 수준) → ⑤ 고기후 연구 방법 [③④⑤ = 12지구02-02를 나눔]
→ ⑥ 마그마의 생성과 화성암 [12지구02-03] → ⑦ 변성 작용과 변동대 → ⑧ 지질 구조와 암석의 순환 [⑦⑧ = 12지구02-04를 나눔] → ⑨ 한반도의 암석과 지질공원 [12지구02-05].
'지층이 쌓인 순서와 나이(시간 읽기) → 지질시대와 환경의 해석 → 암석을 만드는 변동대(화성·변성·구조·순환) → 우리 땅의 암석(한반도)'. 앞 차시의 도구(상대·절대 연령)를 화석·암석의 시간 해석에 쓰고, 변동대(통합과학1)에서 암석이 생기는 환경을 한반도의 실제 지질 명소와 연결한다.
고려 사항: 지사학의 법칙을 다루기 전에 '동일 과정의 원리'를 먼저 다룬다. 지질시대는 기(紀) 수준까지만 구분한다(세(世) 이하는 다루지 않음). 고기후 연구 방법은 '방법만 소개'하고 자세한 메커니즘은 다루지 않는다. 화성암의 종류보다 화성암이 생성되는 고유 환경의 의미에 중점을 두고 한반도의 대표 지형(제주·한탄강·북한산 등)과 연계한다. 퇴적암의 층리·점이층리·연흔, 화성암의 관입·포획·절리, 변성암의 습곡·단층의 생성 과정과 특징을 함께 다룬다. 국가지질공원은 모든 곳을 열거하지 않고 방문 시 관찰 가능한 대표 사례만 다룬다. 지질단면도·화석 분포 지도는 간략화한 예시 자료이며 암석 사진 대신 색·무늬·광물로 그린 모식 그림을 쓴다.

## `he-relative-age` · 🥞 지층의 선후 관계
- 성취기준 [12지구02-01] 지층 형성의 선후 관계를 결정짓는 법칙들을 활용하여 상대 연령을 비교하고, 방사성 동위 원소를 이용한 광물의 절대 연령 자료로 암석의 절대 연령을 구할 수 있다.
- 카드 설명(desc): 지층과 암석이 만들어진 순서를 알려 주는 여러 법칙으로 지질 단면도의 사건 순서를 정하고, 떨어진 지역의 지층을 대비해요.
- 태그: 동일 과정의 원리, 관입의 법칙, 부정합, 층서 대비 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 동일 과정 · 관입·포획 · 부정합 · 층서 대비

### 설계
범위(해설·고려): 지사학의 기본 원리인 동일 과정의 원리를 먼저 다룬 뒤, 지층 형성의 선후 관계를 결정짓는 법칙(수평퇴적의 법칙, 지층누중의 법칙, 동물군 천이의 법칙, 관입의 법칙, 부정합의 법칙)으로 상대 연령을 비교. 절대 연령(방사성 동위 원소)은 다음 차시. 퇴적 구조로 지층의 위·아래를 판단하는 방법은 12지구02-02 차시(퇴적 구조)에서. 단층·습곡은 지질 구조 차시에서 다루므로 여기서는 쓰지 않음. 탐구 활동: 지질단면도에서 층서 대비하기.
개념: 동일 과정의 원리 = 현재 관찰되는 지질 작용이 과거에도 같은 방식으로 일어났다('현재는 과거를 푸는 열쇠') → 현재 퇴적 속도로 과거를 가늠. 수평퇴적의 법칙 = 퇴적물은 중력으로 수평하게 쌓임 → 기울어진 지층은 쌓인 뒤 변형. 지층누중의 법칙 = 변형을 받지 않았다면 아래 지층이 위 지층보다 먼저 생성. 관입의 법칙 = 관입한 암석이 관입당한 암석보다 나중. 포획암 = 관입암 속 모암 조각 → 모암이 먼저(반대로 역암 속에 화성암 자갈이 들어 있으면 그 화성암이 먼저). 부정합의 법칙 = 부정합면 아래 지층이 위 지층보다 오래, 두 지층 사이에 퇴적이 없었던 시간(결층)이 있음. 부정합 형성 과정: 퇴적 → 융기 → 침식 → 침강 → 다시 퇴적. 종류: 평행 부정합(아래 지층 수평), 경사 부정합(아래 지층 경사), 난정합(아래가 화성암·변성암). 동물군 천이의 법칙 = 화석군이 일정한 순서로 바뀌므로 같은 화석을 가진 지층은 같은 시대 → 떨어진 지층을 대비. 층서 대비 방법: 암상 대비, 키층(화산재층 등 짧은 시간에 넓게 퍼진 층)·표준 화석 대비.
자료(예시 값): 퇴적 속도 — 심해 점토 1 mm/천 년(= 1 m/백만 년), 삼각주 모래 1 mm/년(= 1 m/천 년) → 심해 점토 30 m = 3천만 년, 삼각주 30 m = 3만 년(퇴적이 일정하지 않으므로 어림값). 단면도 A(아래 → 위): 셰일 → 사암 → 석회암(삼엽충) → 이 세 층이 구부러진 뒤 화성암 D가 세 층을 뚫고 올라옴(D 속에 셰일 조각) → 융기·침식으로 깎인 면(경사 부정합) → 역암 E(D의 자갈 포함) → 이암 F(암모나이트). 사건 순서: 셰일 < 사암 < 석회암 < (변형) < D 관입 < (침식) < E < F.
지역 대비 예시: 지역 1·2·3의 주상도에 응회암 키층(두께 1 m)과 삼엽충·암모나이트 화석층이 각각 산출. 지역 2에는 암모나이트층 아래에 부정합(결층)이 있어 그 사이 지층이 없음.
탐구 질문: "수억 년 전 일어난 일의 순서를 암석만 보고 어떻게 알아낼 수 있을까?"
① [관찰] 동일 과정 — 투명 퇴적 상자에서 자갈·모래·점토를 순서대로 흘려 넣어 수평 지층 만들기, 상자를 기울여도 지층이 쌓인 면은 수평 → 기울어진 지층은 나중에 변형됨. 현재 퇴적 속도 슬라이더(심해/삼각주)로 두께 → 걸린 시간 환산. 미션: 퇴적 순서대로 3층을 쌓아 위가 더 젊다는 것을 확인하고 퇴적 속도로 걸린 시간 계산(task: 30 m ÷ 1 mm/천 년 = 3천만 년), 퀴즈(동일 과정의 원리가 말하는 것, 퇴적 속도가 항상 일정하지는 않은 까닭).

## `he-absolute-age` · ⏳ 방사성 반감기와 연령
- 성취기준 [12지구02-01] 지층 형성의 선후 관계를 결정짓는 법칙들을 활용하여 상대 연령을 비교하고, 방사성 동위 원소를 이용한 광물의 절대 연령 자료로 암석의 절대 연령을 구할 수 있다.
- 카드 설명(desc): 방사성 동위 원소가 일정한 비율로 줄어드는 반감기를 이용해 암석과 유물의 절대 연령을 계산하고, 상대 연령과 함께 해석해요.
- 태그: 방사성 붕괴, 반감기, 절대 연령, 모원소·자원소 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 방사성 붕괴 · 반감기 · 연령 계산 · 연대 해석

### 설계
범위(해설): 절대 연령의 경우 방사성 동위 원소를 이용하는 원리를 설명하고 '간단한 계산'을 통해 적용. 반감기의 정수배(1·2·3 반감기)와 그래프 읽기 수준으로 계산하며 로그·지수 방정식 풀이는 하지 않음. 핵반응식·붕괴 계열은 다루지 않음. 상대 연령은 앞 차시.
개념: 절대 연령 = 지질 사건 이후 경과한 시간을 햇수로 나타낸 것. 방사성 동위 원소(모원소)가 일정한 속도로 붕괴하여 다른 원소(자원소)가 됨 — 온도·압력·화학 결합 상태로 붕괴 속도가 변하지 않음. 반감기 = 모원소가 처음 양의 절반이 되는 시간. n번 지나면 모원소 (1/2)ⁿ, 자원소 1 − (1/2)ⁿ → 모원소 : 자원소 = 1 : (2ⁿ − 1). 광물이 마그마에서 결정이 되는 순간(그 뒤로는 닫힌 계) 자원소가 0이라고 보고, 지금의 모원소 : 자원소 비로 연령 = n × 반감기를 구함. 개별 원자가 언제 붕괴할지는 예측할 수 없지만 많은 원자 전체는 일정한 비율로 줄어듦(확률).
자료(예시 값): ¹⁴C → ¹⁴N 반감기 5730년(유기물, 약 5만 년 이내) / ⁴⁰K → ⁴⁰Ar 12.5억 년 / ²³⁵U → ²⁰⁷Pb 7.0억 년 / ²³⁸U → ²⁰⁶Pb 44.7억 년(지르콘 등). 표: n = 0·1·2·3 → 모원소 100·50·25·12.5 %, 모 : 자 = 1:0·1:1·1:3·1:7.
시료: ① ¹⁴C 목탄, 모원소 25 % → n = 2 → 11460년 / ② ¹⁴C 뼈, 모원소 12.5 % → 17190년 / ③ ⁴⁰K 화강암 운모, 모 : 자 = 1 : 3 → 25억 년 / ④ ⁴⁰K 오래된 편마암, 모원소 12.5 % → 37.5억 년. 연령 범위 결정: 관입암 D 150 Ma(1억 5천만 년 전), 부정합 위의 용암 L 120 Ma; 부정합 바로 위 지층 E는 L 아래에 있고 D 관입 뒤에 쌓임 → 120 Ma < E의 연령 < 150 Ma. (퇴적암 속 광물은 원래 암석에서 온 알갱이라 그 연령이 퇴적 시기가 아님 → 퇴적암 연령은 화성암 연령으로 범위를 정함.)
탐구 질문: "수천만 년, 수억 년 전의 암석 나이를 어떻게 숫자로 알아낼 수 있을까?"
① [모형] 방사성 붕괴 — 광물 결정 속 원자 100개(모원소 파랑)가 시간이 지나며 무작위로 자원소(주황)로 변하는 입자 모형(🔍 입자 모형으로 보기), 온도·압력 슬라이더를 올려도 붕괴 비율이 변하지 않음. 미션: 1 반감기 뒤 남은 모원소 개수 세기(task), 온도·압력을 바꿔도 같은 결과 확인(task), 퀴즈(원자 하나는 언제 붕괴하는지 알 수 없으나 많은 원자는 일정 비율, 오개념: 두 반감기가 지나면 전부 사라진다 X → 25 %).
② [분석] 반감기 — 시간 눈금(반감기 단위)에 따른 모원소 비율 붕괴 곡선 그리기(점 4개), 동위 원소별 시간 눈금(¹⁴C 5730년 ~ ²³⁸U 44.7억 년) 비교. 미션: n = 0~3의 모원소 비율과 모 : 자 비 표 채우기(manual), 곡선에서 모원소 50·25·12.5 % 지점 읽기(task), 퀴즈(¹⁴C로 1억 년 된 암석을 잴 수 없는 까닭 → 이미 모원소가 거의 남지 않음).
③ [적용] 연령 계산 — 시료 ①~④의 모원소 비율 또는 모 : 자 비를 읽어 n을 구하고 연령 = n × 반감기 입력. 미션: 시료 4개 연령 계산(task, 값 입력), 퀴즈(모원소 : 자원소 = 1 : 7이면 몇 반감기인가 → 3).
④ [분석] 연대 해석 — 시료에 맞는 동위 원소 고르기(측정할 연령 규모와 반감기가 비슷해야 함), 단면도에서 관입암 D(150 Ma)와 용암 L(120 Ma)로 지층 E의 연령 범위 정하기(상대 연령 + 절대 연령). 미션: 동위 원소 선택 3문항(manual), E의 연령 범위 입력(task: 120~150 Ma), 퀴즈(퇴적암 속 광물의 방사성 연령을 그대로 퇴적 연령으로 쓸 수 없는 까닭, 화성암과 퇴적암 중 연령 측정에 유리한 쪽).
애니메이션: 원자 입자의 색 전이(파랑 → 주황) 확률적 붕괴, 붕괴 곡선 점이 날아와 꽂힘, 반감기 눈금 막대가 늘어남, 단면도에서 연령 범위 띠가 좁혀짐.

개념: 화석 = 지질시대 생물의 유해·흔적. 표준 화석 = 짧은 기간에 번성하고 넓은 지역에 분포하며 개체 수가 많아 지층의 시대를 알려 주는 화석(삼엽충·방추충·암모나이트·화폐석). 시상 화석 = 특정 환경에서만 사는 생물로 환경을 알려 주는 화석(산호: 따뜻하고 얕은 바다, 고사리: 따뜻하고 습한 육지, 조개: 얕은 바다·갯벌).
지질시대(대략 연대, 현재로부터, 기 수준): 선캄브리아시대 46억~5.4억 년 전(전체의 약 88 %) / 고생대 5.4억~2.5억 년: 캄브리아기 5.4억~4.9억(삼엽충·캄브리아기 생물 대폭발), 오르도비스기 4.9억~4.4억(앵무조개류·필석), 실루리아기 4.4억~4.2억(산호·최초 육상 식물), 데본기 4.2억~3.6억(어류의 시대·양서류 출현), 석탄기 3.6억~3.0억(양치식물 숲·방추충·파충류 출현), 페름기 3.0억~2.5억(방추충, 말기 최대 대멸종) / 중생대 2.5억~6600만 년: 트라이아스기 2.5억~2.0억(암모나이트·최초의 공룡과 포유류), 쥐라기 2.0억~1.45억(공룡 번성·시조새), 백악기 1.45억~6600만(공룡 번성 → 멸종, 속씨식물) / 신생대 6600만 년~현재: 팔레오기(옛 제3기 앞부분) 6600만~2300만(포유류 번성·화폐석), 네오기(옛 제3기 뒷부분) 2300만~260만, 제4기 260만~현재(인류 출현·빙기). 대멸종 5회(해양 생물 속 감소율 대략): 오르도비스기 말 85 %, 데본기 후기 75 %, 페름기 말 96 %, 트라이아스기 말 80 %, 백악기 말 76 %.
지질 시계(46억 년 = 24시간): 선캄브리아시대 21시 11분까지, 고생대 1시간 30분(22시 41분까지), 중생대 58분(23시 39분까지), 신생대 마지막 약 20분, 현생 인류 등장은 자정 5~6초 전.
한반도 화석(예시 지점): 강원 남부 태백·영월 — 조선누층군(캄브리아~오르도비스기) 삼엽충·앵무조개류 / 강원 태백·정선 — 평안누층군(석탄~트라이아스기) 방추충·양치식물 / 충남 보령 — 대동누층군(트라이아스~쥐라기) 식물 화석 / 경남 고성·전남 해남·경기 화성 — 경상누층군(백악기) 공룡 발자국·공룡알·새 발자국 / 경북 포항 — 신생대 네오기 식물·조개 화석 / 제주 서귀포 — 신생대 바다 조개 화석. (지점별 정확한 지층명·화석은 박물관·지질공원 누리집에서 확인하라는 안내 1줄.)
탐구 질문: "수억 년 전에 살았던 생물과 그곳의 환경을 화석 하나로 어떻게 알 수 있을까?"
① [관찰] 화석 — 화석 생성 조건(단단한 껍데기, 빠른 매몰) 애니메이션, 화석 카드 10장(산호, 고사리, 조개, 삼엽충, 방추충, 암모나이트, 화폐석, 공룡 발자국, 매머드, 필석)을 '표준 화석/시상 화석/둘 다 아님'으로 분류. 미션: 표준 화석 조건 3가지를 만족하는 카드 고르기(task), 시상 화석으로 환경 추론 3문항(manual), 퀴즈(산호 화석이 나온 지층의 환경, 표준 화석이 지층의 시대를 알려 주는 까닭).
② [모형] 지질시대 — 지질 시계(46억 년 = 24시간) 위에서 기(紀) 경계 12개를 끌어 맞추기, 선캄브리아시대가 약 88 %를 차지함을 확인, 막대 길이 비교(고생대 vs 중생대 vs 신생대). 미션: 12개 기 이름 순서 배열(manual), 시계에서 경계 위치 맞추기(task), 퀴즈(지질시대를 선캄브리아시대·고생대·중생대·신생대로 크게 나누는 기준, 인류가 등장한 때는 시계의 몇 초 전).
③ [해석] 생물 변천 — 가상 지층 주상도(아래 → 위)에서 화석 조합(삼엽충·산호, 방추충·양치식물, 암모나이트·공룡 뼈, 화폐석·포유류 뼈)으로 기를 판정, 대멸종 5회를 해양 생물 속 수 그래프에 표시. 미션: 화석 조합으로 기 판정 4개(task), 대멸종 5회 시기 표시(manual), 퀴즈(삼엽충과 공룡이 함께 살았다 X, 대멸종 후 새로운 생물군이 번성하는 까닭).
④ [분석] 한반도 화석 — 한반도 지도에 지점 카드 6장(태백 삼엽충, 정선 방추충, 보령 식물, 고성 공룡 발자국, 포항 식물, 서귀포 조개)을 놓아 화석 분포 지도 그리기, 화석으로 그 지점의 옛 환경 추론(바다/호숫가/육지). 미션: 6지점 시대 매칭과 환경 추론(manual), 퀴즈(같은 땅에서 고생대에는 바다, 중생대에는 호숫가였던 증거).
애니메이션: 지질 시계 바늘이 흐르며 기 경계가 켜짐, 화석이 퇴적물에 묻히는 과정, 생물 아이콘이 시대별로 번성·감소하는 곡선, 지도 위 화석 핀이 떨어져 꽂힘.

## `he-paleoclimate` · 🌲 고기후 연구 방법
- 성취기준 [12지구02-02] 지질시대를 기(紀) 수준에서 구분하고, 지층과 화석을 통해 지질시대의 생물과 환경 변화를 해석할 수 있다.
- 카드 설명(desc): 나이테, 화분, 산호, 빙하 코어, 해양 퇴적물 같은 기후 기록을 비교해 어떤 시기에 어떤 방법이 알맞은지 평가해요.
- 태그: 고기후, 나이테, 빙하 코어, 화분 화석 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 지질 기록 · 생물 기록 · 빙하·퇴적물 · 방법 평가

### 설계
범위(해설): 지구의 역사를 통해 기후가 어떻게 변해왔는지 고기후 연구 방법을 조사하여 설명하되 '방법만 소개'하고 자세한 메커니즘(동위 원소 분별 원리, 나이테 생장 모형 등)은 다루지 않음. 측정값은 '높을수록 추운 시기' 같은 판독 규칙으로만 제시. 탐구 활동: 고기후 연구 방법 비교·평가하기. 현재의 기후변화 원인은 12지구01-06 차시에서.
방법 비교표(예시): 역사 기록(조선왕조실록·측우기 1441년~): 수백~2천 년 / 일~연 / 지역 한정 / 기온·강수·가뭄 — 나이테: 수천~1만 년 / 연 / 온대 육상 / 폭이 넓으면 생장 좋은 해(따뜻하고 습함) — 산호 성장선: 수백~수천 년 / 월~연 / 열대 바다 / 수온 — 화분 화석(호수 퇴적물): 수만~수십만 년 / 수십~수백 년 / 육상 / 식생(소나무·참나무·벼과 비율) → 기온·강수 — 빙하 코어: 최대 약 80만 년 / 연~수십 년 / 극지·고산 / 얼음 속 기포의 CO₂ 농도, 얼음의 산소 동위 원소 비로 기온 추정 — 해양 퇴적물(유공충 껍질의 산소 동위 원소 비): 수백만~1억 년 / 수천 년 / 전 해양 / 높을수록 빙하가 많았던 추운 시기 — 지질 기록(빙하 퇴적물 빙퇴석, 석탄, 증발암, 산호초 석회암): 수억 년 / 만 년 이상 / 대륙 / 한랭·온난·건조 구분.
자료(예시): 나이테 폭 — 어떤 나무의 연륜 폭(mm) 1810~1820년 평균 2.0, 1816년 0.6(탐보라 화산 분출 이듬해 '여름이 없던 해') / 화분 비율 변화 — 약 2만 년 전 소나무·가문비 60 %·참나무 5 % → 약 8천 년 전 소나무 20 %·참나무 55 % → 따뜻해짐 / 빙하 코어 깊이–연령(눌려서 비선형, 예시): 500 m 2만 년, 1000 m 7만 년, 2000 m 30만 년, 3000 m 63만 년, 3270 m 80만 년.
탐구 질문: "아무도 기온을 재지 않았던 시대의 기후를 어떻게 알 수 있을까?"
① [탐구] 지질 기록 — 퇴적 단서 카드(빙퇴석, 석탄, 증발암(석고·암염), 산호초 석회암, 사막의 사층리)를 옛 기후(한랭·따뜻하고 습함·건조·따뜻한 바다)에 짝짓기, 대륙이 이동해 현재 위도와 다를 수 있음을 함께 표시. 미션: 단서-기후 카드 짝짓기 5장(manual), 퀴즈(석탄층이 나온 곳이 지금 추운 지방이어도 옛 기후는 따뜻하고 습했을 수 있는 까닭 → 대륙 이동).
② [탐구] 생물 기록 — (a) 나무 단면에서 나이테 세기와 폭 그래프 읽기(1816년의 좁은 나이테), (b) 호수 퇴적물 화분 비율 막대의 연령별 변화로 식생·기온 해석. 미션: 나이테 개수 세어 나이와 폭이 가장 좁은 해 찾기(task), 화분 비율로 따뜻해진 시기 고르기(manual), 퀴즈(나이테 폭이 좁다고 항상 추웠다고 단정할 수 없는 까닭 → 가뭄 등 다른 요인).
③ [분석] 빙하·퇴적물 — 빙하 코어 단면: 연층 세기, 기포 속 CO₂ 농도(ppm)와 기온 지표를 깊이별로 읽어 80만 년 그래프 완성, 해양 퇴적물 코어의 산소 동위 원소 비 곡선과 비교(빙기·간빙기 주기). 미션: 깊이–연령 대응으로 2만 년 전 깊이를 찾고 빙기 CO₂ 값(약 180 ppm) 읽기(task), 두 기록의 빙기·간빙기 시기 일치 확인(manual), 퀴즈(깊이가 깊을수록 연층이 얇아지는 까닭).
④ [평가] 방법 평가 — 비교표에서 시간 범위·시간 해상도·공간·알 수 있는 정보를 비교하고, 상황별로 가장 알맞은 방법 고르기: (a) 조선 시대 가뭄의 해, (b) 최근 80만 년의 CO₂ 농도, (c) 마지막 빙기 한반도 식생, (d) 2억 년 전 기후. 한계 비교 미션. 미션: 상황 4개별 방법 고르기(manual), 방법별 장단점 카드 짝짓기(manual), 퀴즈(한 가지 방법만 쓰지 않고 여러 방법의 결과를 교차 확인하는 까닭).
애니메이션: 나무 단면 나이테가 안쪽부터 한 겹씩 그려짐, 빙하 코어 시추 막대가 내려가며 기포 파티클, 퇴적물 코어의 색 띠, 그래프 곡선 두 개가 겹쳐 그려지며 일치하는 구간 하이라이트.

### 설계
범위(고려): 화성암의 종류를 외우기보다 화성암이 생성되는 고유 환경(변동대)의 의미를 이해하는 데 중점. 한반도의 대표 지형(제주 현무암 지형, 북한산·설악산 화강암 산)과 연계. 마그마 생성 3조건(압력 감소·물 첨가·열 공급)과 변동대, 마그마의 SiO₂ 함량에 따른 성질, 보웬 반응 계열(분별 정출), 화성암 분류표 6종. 화성암의 관입·포획·절리는 12지구02-04 차시에서. 다루지 않음: 상평형도, 미량 원소 지구 화학.
개념: 마그마 생성은 온도를 높이는 것이 아니라 주변 암석의 용융 조건을 바꾸는 것도 포함. (1) 압력 감소(감압 용융): 맨틀 물질이 상승하면 압력이 낮아져 용융 곡선보다 높은 온도가 되어 일부 용융 → 해령(발산 경계)·열점 → 현무암질 마그마. (2) 물 첨가: 섭입하는 판에서 방출된 물이 맨틀 쐐기에 들어가 용융 온도를 낮춤 → 섭입대 화산호 → 현무암질~안산암질 마그마. (3) 열 공급: 상승한 마그마가 지각 하부에 열을 전달해 지각 암석이 녹음 → 화강암질(유문암질) 마그마, 대륙 지각 아래에서.
자료(예시 값): 마른 맨틀 암석(감람암)이 녹기 시작하는 온도 — 깊이 0 km 1100 °C, 35 km 1250 °C, 100 km 1400 °C, 150 km 1500 °C / 물이 있으면 100 km에서 약 1000~1100 °C. 상승하는 맨틀의 온도(거의 일정): 150 km 1480 °C → 100 km 1455 °C → 50 km 1430 °C → 150 km: 1480 < 1500 고체, 100 km: 1455 > 1400 용융 시작, 50 km: 1430 > 1290 더 많이 용융(약 10~20 %). 섭입대 100 km 맨틀 쐐기 1200 °C: 마른 용융 온도 1400 °C보다 낮아 녹지 않으나 물이 들어오면 약 1050 °C → 용융. 지각 하부 30 km 온도 약 700 °C, 현무암질 마그마 1200 °C가 열을 공급하면 일부 용융.
마그마의 성질(SiO₂ 함량): 염기성 45~52 % — 온도 1000~1200 °C, 점성 작음(흐름 빠름, 순상 화산), 어두운색 / 중성 52~63 % — 800~1000 °C / 산성 63 % 초과 — 650~800 °C, 점성 큼, 폭발적, 밝은색. 화성암(SiO₂ × 산출 조직): 화산암(지표 부근에서 빨리 식어 세립·유리질) — 현무암(염기성)·안산암(중성)·유문암(산성) / 심성암(지하 깊은 곳에서 천천히 식어 조립) — 반려암·섬록암·화강암. 구성 광물: 염기성 감람석·휘석·Ca 사장석, 산성 석영·정장석·흑운모·Na 사장석, 유색 광물 비율 염기성 약 40 % 이상 > 중성 약 30 % > 산성 약 10~20 %.
보웬 반응 계열: 마그마가 식을 때 높은 온도에서 정출하는 광물부터 — 불연속 계열: 감람석 → 휘석 → 각섬석 → 흑운모, 연속 계열: Ca 사장석 → Na 사장석, 마지막에 정장석·백운모·석영. 먼저 생긴 결정이 가라앉아 분리되면 남은 마그마의 SiO₂ 함량이 높아짐(분별 정출 → 하나의 마그마에서 여러 종류가 생김). 계산: SiO₂ 50 %인 마그마에서 SiO₂ 40 %인 감람석 결정이 20 % 분리되면 남은 마그마의 SiO₂ = (50 − 0.2 × 40) ÷ 0.8 = 52.5 %(중성에 가까워짐).
한반도 연계: 제주 현무암 지형(염기성 용암의 분출, 기공이 많은 암석), 북한산·설악산의 화강암 산(중생대에 지하 깊은 곳에서 식은 심성암이 융기와 침식으로 지표에 노출).
탐구 질문: "마그마는 어디서 어떻게 만들어지고, 왜 화성암의 색과 결정 크기가 서로 다를까?"
① [모형] 마그마 생성 — 깊이–온도 그래프(용융 곡선 2개와 상승하는 맨틀 경로)와 단면(해령, 섭입대, 대륙 지각 하부). 상승 슬라이더로 맨틀을 올리면 용융 곡선과 만나는 지점에서 녹기 시작, 물 슬라이더로 용융 곡선 하강, 열 공급 화살표. 미션: 해령·섭입대·지각 하부 조건에서 각각 마그마 만들기(task: 3곳), 퀴즈(온도를 높이지 않았는데도 마그마가 생기는 두 경우의 까닭).
② [실험] 마그마 종류 — SiO₂ 슬라이더(45~70 %)에 따라 용암의 점성(흐르는 거리, 경사면에 흘려 비교), 온도, 가스 폭발성, 색 변화. 변동대와 마그마 짝짓기. 미션: 점성이 가장 큰 용암 만들기(task), 변동대–마그마 카드 짝짓기 4장(manual: 해령–현무암질, 섭입대 화산호–안산암질, 열점–현무암질, 대륙 하부 용융–화강암질), 퀴즈(점성이 큰 마그마가 폭발적인 까닭 → 가스가 빠져나가기 어려움).
③ [탐구] 분화 과정 — 마그마를 천천히 식히는 슬라이더(1300 → 700 °C)에 따라 광물이 보웬 반응 계열 순서대로 정출하고 무거운 결정이 가라앉으며 남은 마그마의 SiO₂ 함량이 오름. 미션: 정출 순서대로 광물 이름표 배치(manual), 감람석 20 % 분리 뒤 남은 SiO₂ 계산 입력(task: 52.5 %), 퀴즈(모든 광물이 동시에 정출하지 않는 까닭, 같은 마그마에서 서로 다른 화성암이 생기는 이유).
④ [적용] 화성암 분류 — SiO₂(염기성/중성/산성) × 조직(세립/조립) 6칸 표에 암석 카드 놓기, 시료 3개(어둡고 구멍 많은 세립 → 현무암, 밝고 석영이 보이는 조립 → 화강암, 중간색 세립 → 안산암)를 색·결정 크기·광물로 판정, 한반도 사례(제주 현무암, 북한산 화강암)의 생성 환경 추론. 미션: 표 완성(manual), 시료 3개 판정(manual), 퀴즈(결정이 큰 화성암일수록 식는 속도는 느리고 생성 깊이는 깊다, 화강암이 지표에 드러난 까닭).
애니메이션: 맨틀 암석 입자가 상승하며 색이 녹아 마그마 방울이 생김, 용융 곡선 교차점 pulse, 용암의 점성 차 흐름 비교, 결정이 자라며 가라앉음, 세립/조립 결정 성장.

## `he-metamorphism` · 🪨 변성 작용과 변동대
- 성취기준 [12지구02-04] 변성작용의 종류와 지각 변동에 따른 구조를 변동대와 관련지어 설명하고, 지구시스템에서 암석이 순환함을 추론할 수 있다.
- 카드 설명(desc): 열과 압력이 암석을 어떻게 바꾸는지 실험하고, 접촉 변성과 광역 변성이 일어나는 변동대와 변성암의 종류를 연결해요.
- 태그: 접촉 변성, 광역 변성, 엽리, 변동대 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 변성 작용 · 변성암 · 변성 환경 · 변동대

### 설계
범위: 변성작용의 종류(접촉 변성 작용·광역 변성 작용)와 변성암(점판암·편암·편마암·혼펠스·대리암·규암)의 특징을 변동대와 관련지어 설명. 지질 구조(습곡·단층)와 암석의 순환은 다음 차시. 다루지 않음: 변성 광물 상 도표의 세부, 열역학 계산. 압력은 P = ρgh 간단 계산만.
개념: 변성작용 = 암석이 고체 상태에서 열·압력·화학적으로 활발한 유체의 영향으로 광물 조성이나 조직이 변하는 것. 접촉 변성 작용 = 마그마가 관입하며 주변 암석을 가열(저압·고온, 변성대 폭 수 m~수 km로 관입체 주변에만) → 재결정으로 알갱이가 커지고 조직 치밀, 엽리 없음 → 혼펠스, 대리암(석회암), 규암(사암). 광역 변성 작용 = 넓은 지역에서 높은 열과 압력(조산대·섭입대) → 압력 방향에 수직으로 판상 광물이 배열한 엽리 발달: 셰일(이암) → 점판암 → 천매암 → 편암 → 편마암(변성도가 높아질수록 알갱이가 커지고 줄무늬가 거칠어짐, 편마암은 밝은색·어두운색 띠). 지시 광물(변성도): 녹니석(낮음) → 백운모 → 흑운모 → 석류석 → 규선석(높음).
자료(예시 값): 압력 P = ρgh, ρ = 2700 kg/m³, g = 10 m/s² → 1 km당 27 MPa. 깊이 10 km 270 MPa(2.7 kbar), 20 km 540 MPa. 지온 25 °C/km: 10 km 265 °C, 20 km 515 °C. 변성도–온도(대략): 점판암 200~300 °C, 편암 400~500 °C, 편마암 600 °C 이상. 변동대 3종: 섭입대 30 km 810 MPa·300 °C(고압·저온), 대륙 충돌대 40 km 1.08 GPa·700 °C(고압·고온), 접촉 변성 3.7 km 100 MPa·600 °C(저압·고온). 섭입대는 해구 쪽(고압·저온)과 화산호 쪽(저압·고온) 두 변성대가 나란히 만들어짐. 접촉 변성대 폭 예: 두께 50 m 암맥 → 수 m, 폭 수 km 마그마 방 → 수백 m~수 km.
탐구 질문: "같은 암석이 땅속 어디에서 어떤 힘을 받느냐에 따라 왜 다른 암석이 될까?"
① [실험] 변성 작용 — 퇴적암 속 광물 알갱이 모형(🔍 입자 모형으로 보기)에 열만 가하면 알갱이가 커지고 치밀해짐(재결정), 한 방향 압력을 함께 가하면 판 모양 광물이 압력에 수직으로 줄지어 엽리 형성. 미션: 열만 가해 재결정을 확인하고 압력을 가해 엽리 만들기(task), 퀴즈(엽리 방향과 압력 방향의 관계, 오개념: 변성 작용은 암석이 녹아서 일어난다 X).
② [분류] 변성암 — 원암(셰일·석회암·사암)에서 변성암으로 가는 변성도 사다리(점판암 → 천매암 → 편암 → 편마암), 엽리 있음/없음 분류(점판암·편암·편마암 vs 대리암·규암·혼펠스), 원암–변성암 짝짓기. 미션: 변성도 순서 정렬(manual), 엽리 유무 분류 6장(manual), 퀴즈(석회암이 변성되어 대리암이 될 때 엽리가 거의 없는 까닭, 사암 → 규암).
③ [모형] 변성 환경 — 마그마 관입체 단면에서 거리에 따른 변성도 감소(접촉 변성대 폭), 압력–온도 그래프 위 3개 환경(접촉 변성: 저압·고온, 섭입대: 고압·저온, 충돌대: 고압·고온) 점 찍기, 깊이로 압력 계산. 미션: 거리–변성도 그래프를 읽고 깊이 20 km 암석이 받는 압력 입력(task: 540 MPa), 환경–P-T 점 짝짓기(manual), 퀴즈(접촉 변성이 관입체 주변에만 나타나는 까닭).
④ [관련] 변동대 — 발산·수렴(섭입·충돌)·보존 경계 단면에서 변성 작용이 활발한 곳 표시(섭입대·충돌대 광역 변성, 마그마 관입 접촉 변성, 해령의 열수 변성은 약한 변성), 변성암이 지표에 드러나는 과정(융기와 침식). 미션: 판 경계 3종에서 변성암이 만들어지는 위치 고르기(manual), 변성암 분포로 옛 변동대 추정(task), 퀴즈(지금 판의 경계에서 먼 곳에도 편마암이 있는 까닭 → 과거 변동대의 흔적, 다음 차시 한반도 연결).
애니메이션: 알갱이가 자라며 맞물림(셀룰러), 판상 광물이 압력 화살표에 수직으로 회전·정렬(tween), 관입체 주변 색 번짐(접촉 변성대), P-T 점 이동, 지층이 융기하며 침식으로 드러남.

## `he-structures-cycle` · 🔄 지질 구조와 암석 순환
- 성취기준 [12지구02-04] 변성작용의 종류와 지각 변동에 따른 구조를 변동대와 관련지어 설명하고, 지구시스템에서 암석이 순환함을 추론할 수 있다.
- 카드 설명(desc): 관입과 절리, 습곡과 단층이 생기는 힘의 방향을 실험하고, 변동대에서 암석이 순환하는 경로를 지구시스템으로 추론해요.
- 태그: 절리, 습곡, 단층, 암석 순환 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 화성암 구조 · 습곡·단층 · 변동대 구조 · 암석 순환

### 설계
범위(고려): 화성암의 관입과 포획, 절리, 변성암의 습곡과 단층의 생성 과정과 특징을 함께 다루고(퇴적 구조는 앞 차시), 지각 변동에 따른 구조를 변동대와 관련지으며, 지구시스템에서 암석이 순환함을 추론. 다루지 않음: 지진파 해석, 응력 텐서, 단층 면 해(진원 기구).
개념: 관입암체 — 암맥(층리를 가로지름)·암상(층리와 나란)·저반(큰 심성암체). 포획암·접촉 변성대·냉각 가장자리. 절리 = 암석에 생긴 갈라진 틈(이동 없음): 주상절리(두꺼운 용암이 식으며 수축해 육각 기둥, 빨리 식을수록 가는 기둥, 제주·한탄강), 판상절리(지하 깊은 곳 암석이 위 지층이 깎여 압력이 줄며 팽창해 판 모양, 화강암 산·돔). 습곡 = 횡압력으로 지층이 휘어짐(배사: 위로 볼록, 중심부 지층이 가장 오래됨 / 향사: 아래로 오목, 중심부가 가장 젊음). 단층 = 지층이 끊어져 어긋난 것: 정단층(인장력, 상반이 내려감), 역단층(횡압력, 상반이 올라감), 주향 이동 단층(수평 어긋남, 변환 단층).
변동대와 구조: 발산 경계(해령·열곡대) — 인장력, 정단층, 현무암질 화산 / 수렴 경계(섭입대·충돌대) — 횡압력, 습곡 산맥, 역단층, 광역 변성, 화산·화강암 / 보존 경계 — 주향 이동 단층(산안드레아스 단층). 단층 이동 속도 예: 3 cm/년 × 100년 = 3 m, 3 cm/년 × 1000만 년 = 300 km.
암석 순환(지구시스템): 지구 내부 에너지(맨틀 대류·마그마 생성·변성·융기)와 태양 에너지(기권·수권에서 풍화·침식·운반·퇴적)가 함께 순환을 일으킴. 경로: 마그마 → 화성암 → (풍화·침식·운반·퇴적·속성) 퇴적암 → (열·압력) 변성암 → (융해) 마그마, 지름길: 화성암 → 변성암, 변성암 → 풍화, 퇴적암 → 퇴적암(재퇴적). 변동대의 역할: 섭입대는 퇴적물을 끌고 내려가 변성·용융, 충돌대·해령은 융기와 마그마. 암석 나이: 해양 지각 최대 약 2억 년(섭입으로 재순환), 가장 오래된 대륙 암석 약 40억 년.
탐구 질문: "산을 쪼개는 틈과 구부러진 지층, 끊어진 땅은 어떤 힘이 만들었고, 그 힘은 암석을 어디로 데려갈까?"
① [관찰] 화성암 구조 — 단면에서 마그마가 층을 따라(암상) 또는 가로질러(암맥) 관입, 관입암 속 포획암, 용암이 식으며 육각 기둥(주상절리) 생성(수축 균열이 선 성장), 지하 화강암이 압력을 잃고 판 모양으로 갈라짐(판상절리). 미션: 암맥과 암상을 구분하고 절리 생성 시나리오 짝짓기(manual: 주상 = 수축, 판상 = 압력 감소로 팽창), 퀴즈(절리와 단층의 차이 → 어긋남 유무).
② [모형] 습곡·단층 — 지층 블록 양쪽 끝에서 압축·인장·전단 힘을 가하면 습곡·정단층·역단층·주향 이동 단층 형성(애니메이션), 배사·향사 단면에서 중심부 지층의 나이 비교. 미션: 압축으로 습곡·인장으로 정단층·압축으로 역단층 만들기(task), 배사·향사 판별(manual), 퀴즈(정단층과 역단층에서 상반의 움직임과 힘의 방향).
③ [적용] 변동대 구조 — 판 경계 3종 단면에 구조 카드(정단층·열곡, 습곡 산맥·역단층, 주향 이동 단층)와 암석 카드(현무암, 화강암·변성암) 짝짓기, 단층 이동 속도 계산. 미션: 변동대–구조 짝짓기 6장(manual), 3 cm/년으로 100년 이동 거리 입력(task: 3 m), 퀴즈(히말라야 산맥에 역단층과 습곡이 많은 까닭).
④ [추론] 암석 순환 — 암석 순환도에 과정 이름표 6개(풍화·침식·운반 / 퇴적·속성 / 변성 / 융해 / 냉각·고결 / 융기)를 놓고 에너지원(태양·지구 내부) 표시, 단면 위 섭입대에서 퇴적물이 땅속으로 들어가 변성·용융되고 화산·융기로 되돌아오는 경로, 해양 지각 나이 분포(해령 0 → 해구 약 2억 년) 그래프. 미션: 순환 경로 5가지 만들기(task), 화강암이 변성암이 되는 조건 고르기(manual), 퀴즈(암석 순환이 계속되는 까닭 → 두 에너지원, 해양 지각이 대륙 지각보다 젊은 까닭).
애니메이션: 마그마 관입 색 전이와 균열 선 성장, 육각 기둥 형성, 힘 화살표에 따라 지층이 휘거나 끊김(spring), 단층면 어긋남 tween, 암석 입자 순환 trail.
