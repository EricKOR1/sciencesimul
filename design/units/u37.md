## `hb-life-traits` · 🧫 생물의 특성
- 성취기준 [12생과01-01] 생물 및 생명과학의 특성을 이해하고 생명과학의 성과를 협력적으로 소통할 수 있다.
- 카드 설명(desc): 생물과 비생물을 여섯 가지 특성으로 판정해 보고, 바이러스와 휴머노이드가 생물인지 모형으로 따져 본 뒤 생명과학이 다른 학문과 만나 낸 성과를 정리해요.
- 태그: 생물의 특성, 바이러스, 휴머노이드, 융합 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 생물과 비생물 · 바이러스 · 휴머노이드 · 융합 성과

### 설계
범위(해설): 생물과 비생물의 특성 비교가 중심. 생명과학 분야의 학문적 특징은 간략히(분자·세포·몸·생태·진화 다섯 관점 한 줄씩), 현대 생명과학의 성과가 여러 학문 분야의 성과와 결합되어 나타난다는 점에 초점. 생물의 특성 6가지: 세포로 구성 / 물질대사 / 자극에 반응·항상성 / 생장과 발생 / 생식과 유전 / 적응과 진화.
고려: 바이러스와 휴머노이드의 구조와 기능을 모식도·모형으로 설명(입자 모형 + 로봇-사람 대응 모식도). 다루지 않음: 바이러스 분류(DNA·RNA 바이러스 구분), 인공지능 알고리즘의 세부, 윤리 논쟁의 결론(생각해 볼 질문으로만).
자료(예시): 크기 — 인플루엔자 바이러스 지름 약 100 nm, 대장균 약 2 µm, 사람 세포 약 20 µm → 1 : 20 : 200(로그 눈금 막대). 바이러스 입자 구성: 단백질 껍질(캡시드) + 내부의 핵산(유전물질), 세포막·세포질·리보솜·효소 계통 없음. 숙주 세포 안에서 1개 → 새 바이러스 입자 수백 개(화면에 '예시 값' 표시).
탐구 질문: "움직이고 말하는 로봇과 움직이지 못하는 바이러스, 어느 쪽이 생물일까?"
① [관찰] 생물과 비생물 — 카드 8장(강아지, 효모 가루, 자동차, 불꽃, 소금 결정, 씨앗, 로봇 청소기, 이끼)을 생물 특성 6칸 검사판에 올려 점등 판정. 불꽃(커지고 열·빛을 내지만 세포 X, 유전 X), 소금 결정(물질이 표면에 쌓일 뿐 생장 X), 씨앗(휴면 중에도 세포로 구성, 발아 조건에서 생장). 미션: 8장 모두 검사(task), 판정 분류 상자 채우기(manual), 퀴즈("커지면 생물이다" 오개념 → 소금 결정).
② [모형] 바이러스 — 인플루엔자 바이러스 입자 모형을 돌려 보며 구조 이름표(캡시드, 핵산, 표면 단백질). 크기 비교 막대. 숙주 세포 밖(입자 상태: 물질대사·증식 X) ↔ 안(핵산 복제 + 숙주의 리보솜으로 단백질 합성 → 조립 → 방출). 6칸 검사판: 세포 구조 X, 독자적 물질대사 X, 숙주 안에서 증식·유전·변이 O → 생물과 비생물의 특성을 모두 가짐. 미션: 증식 5단계(흡착-침입-복제와 합성-조립-방출) 순서 맞추기(manual), 퀴즈("바이러스는 숙주 세포 밖에서도 혼자 증식한다" 오개념 → 숙주 세포 안에서만 증식, 밖에서는 입자 상태).
③ [모형] 휴머노이드 — 로봇(카메라·마이크 센서 → 프로세서 → 모터)과 사람(감각 기관 → 신경계 → 근육)을 선으로 연결하는 대응 모식도(manual). 에너지: 배터리 전기 vs 음식의 물질대사, 로봇은 스스로 생장·생식·진화하지 못함(설계도 복사는 유전이 아님), 학습 알고리즘은 적응처럼 보이지만 세포·물질대사가 없음. 6칸 검사판 비교표 완성. 미션: 대응 모식도 완성(manual), 검사판 비교(task), 퀴즈("대화하고 반응하니 생물이다" 오개념).
④ [적용] 생명과학 성과 — 현대 생명과학 성과 카드 6장(유전자 가위 기술: 생명과학 + 화학 + 정보, 인공지능 단백질 구조 예측: 생명과학 + 정보, 인공 장기·의수: 생명과학 + 공학, 웨어러블 건강 센서: 생명과학 + 전자, 생체 모방 소재: 생명과학 + 재료, 핵산 백신: 생명과학 + 화학 + 의학)를 만나는 학문 분야 태그와 연결(manual). 생명과학 5개 관점(분자·세포·몸·생태·진화) 중 해당 관점 고르기. 협력적 소통: 카드 1장을 골라 '해결할 문제 – 쓰인 기술 – 사회에 준 영향' 세 칸 문장을 완성해 가상 모둠 보드(3명)에 올리고, 모둠원 카드를 합쳐 '융합 지도' 완성. 퀴즈 1개(성과가 한 학문만으로 나오지 않는 까닭).
애니메이션: 검사판 6칸 점등(반짝), 불꽃·결정 성장 미니 장면, 바이러스 입자 3D 회전과 숙주 세포 속 조립(spring), 로봇과 사람 대응선 draw, 융합 지도에서 카드가 날아와 연결(snap).

### 설계
범위(해설): 세포로부터 개체, 생태계에 이르기까지 생물의 구성 단계가 구조적 체계를 이루고, 각 단계가 생명 시스템으로서 기능함. 동물: 세포 → 조직 → 기관 → 기관계 → 개체, 그 위로 개체군 → 군집 → 생태계. 식물(조직계가 있고 기관계가 없음)은 중1 '생물의 구성 단계'에서 다뤘으므로 비교 한 줄만.
핵심: 각 단계는 하위 구성 요소들이 상호작용해서 하위 단계에는 없던 기능이 나타나는 시스템(전체는 부분의 합 이상). 중1·중2에서 다룬 조직·기관 이름을 반복 암기하지 않고 '구성 요소 – 상호작용 – 새로 나타나는 기능'의 틀로 정리. 다루지 않음: 생물권, 세포 소기관 세부, 세포 이하 분자 단계.
자료(예시): 사례 한 줄기 — 심근 세포(지름 약 20 µm 크기의 세포) → 심장 근육 조직 → 심장(길이 약 12 cm) → 순환계(심장 + 혈관 + 혈액) → 사람 개체(약 1.7 m). 숲 사례 — 참나무 1그루(개체) → 참나무 개체군 → 숲의 모든 생물(군집) → 숲 + 빛·토양·공기(생태계). 로그 눈금 크기 표시: 10 µm · 1 mm · 10 cm · 1 m · 1 km.
창발 장면: 심근 세포 1개는 불규칙하게 떨릴 뿐이지만, 세포들이 연결되어 신호를 주고받는 조직은 한꺼번에 수축(박동) → 상위 단계의 새 기능.
탐구 질문: "수많은 세포가 모이면 왜 세포 하나와는 전혀 다른 일을 할 수 있을까?"
① [관찰] 세포~개체 — 확대·축소 슬라이더로 사람 → 순환계 → 심장 → 심장 근육 조직 → 심근 세포까지 내려가며 단계 이름표와 크기 눈금 표시. 각 단계에서 '하는 일' 한 줄. 미션: 세포 단계까지 확대(task), 단계 순서 카드 배열(manual), 퀴즈(심장은 어느 단계? → 기관, 소화계는 → 기관계).
② [분석] 개체~생태계 — 한 지역 숲 화면에서 같은 종끼리 묶으면 개체군, 모든 종을 묶으면 군집, 빛·토양까지 포함하면 생태계. 판정 카드 8장(위, 숲속 모든 참나무, 연못의 모든 생물, 연못과 물·햇빛, 사람의 소화계 …) 단계 상자로 분류(manual). 미션 + 퀴즈(개체군과 군집을 가르는 기준: 한 종 vs 여러 종, 생태계에 더해지는 것: 비생물 환경).
③ [설명] 시스템 — 각 단계의 구성 요소 · 상호작용 · 새 기능 3칸 표 채우기(manual: 세포 → 조직 → 기관 → 기관계 → 개체 → 개체군 → 군집 → 생태계, 예: 개체 – 기관계들의 협력 – 항상성 유지 / 군집 – 종 사이 먹이 관계 – 에너지 흐름). 박동 모의: 세포 연결 슬라이더를 올리면 불규칙 → 동기화된 박동. 미션: 연결 정도를 높여 박동 만들기(task), 퀴즈("세포가 많기만 하면 조직이다" 오개념 → 연결과 상호작용).
④ [적용] 설명 자료 만들기 — 사례(달리는 사람 / 숲) 중 하나를 골라 8단계 카드 배열 → 각 단계에 구성 요소·기능 문장 선택 → '확대 지도' 체계도 완성(저장 연출). 평가 체크: 단계 순서, 상위-하위 포함 관계, 새 기능 서술 3가지. 퀴즈 2개(식물에는 기관계가 없고 조직계가 있음, 개체 수준의 항상성).
애니메이션: 줌 인/아웃 중첩 장면(카메라 tween), 크기 눈금 막대, 세포 박동 동기화(원 pulse + 연결선 glow), 카드가 합쳐져 단계 블록 쌓임.

## `hb-metabolism-atp` · 🔋 물질대사와 ATP
- 성취기준 [12생과01-03] 물질대사 과정에서의 에너지 전환 과정을 바탕으로 다양한 생명 활동에서의 에너지 사용을 추론할 수 있다.
- 카드 설명(desc): 동화 작용과 이화 작용에서 에너지가 어떻게 바뀌는지 따라가고, 세포호흡의 에너지가 ATP에 저장되어 다양한 생명 활동에 쓰이는 과정을 추론해요.
- 태그: 물질대사, 동화·이화, ATP, 세포호흡 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 동화·이화 · 에너지 전환 · ATP 충전 · 활동과 에너지

### 설계
범위(해설): ATP 구조를 구체적으로 다루지 않음 → ATP는 '에너지를 저장하고 전달하는 물질'(충전·방전하는 배터리 비유)로만 제시하고, 인산 결합 구조식·고에너지 인산 결합 용어·ATP 수지 계산은 없음. 모든 살아 있는 세포는 물질대사 과정에서 에너지가 ATP로 저장되고 사용됨.
물질대사 = 생명체 안에서 일어나는 화학 반응(효소 관여). 동화 작용 = 간단한 물질 → 복잡한 물질(에너지 흡수: 광합성, 단백질·글리코젠·DNA 합성), 이화 작용 = 복잡한 물질 → 간단한 물질(에너지 방출: 세포호흡, 소화). 세포호흡: 포도당 + 산소 → 이산화 탄소 + 물 + 에너지. 표기: ATP ⇌ ADP + 인산(라벨만). 다루지 않음: 해당 과정·TCA 회로·전자 전달계 단계, 발효.
자료(단순화): 세포호흡에서 포도당에 저장된 에너지를 100이라 하면 약 40이 ATP에 저장, 약 60은 열(체온 유지)로 방출. 세포 속 ATP는 저장량이 매우 적어 계속 재합성(사람은 하루에 자기 몸무게와 비슷한 양의 ATP를 만들고 분해 — '약'으로 표시). 성인 하루 에너지 사용(예시, 2000 kcal 기준): 기초 대사 약 60~70 %, 활동 약 20~30 %, 음식 소화·흡수 약 10 %.
탐구 질문: "음식을 먹고 얻은 에너지는 몸속에서 어떤 모습으로 저장되었다가 쓰일까?"
① [관찰] 동화와 이화 — 식물 잎(이산화 탄소 + 물 → 포도당 + 산소, 빛에너지 흡수)과 근육 세포(포도당 + 산소 → 이산화 탄소 + 물 + 에너지) 분자 모형. 분자가 커지면 동화, 작아지면 이화. 카드 8장(광합성, 세포호흡, 소화, 아미노산 → 단백질, 포도당 → 글리코젠, 지방 분해, 녹말 합성, DNA 복제)을 동화/이화 상자로 분류(manual). 미션: 두 반응 실행(task), 분류(manual), 퀴즈(동화=에너지 흡수, 이화=에너지 방출).
② [분석] 에너지 전환 — 에너지 막대 도표: 포도당 100 → ATP 약 40 + 열 약 60 (운동 강도 슬라이더로 세포호흡 속도·체온 게이지 변화). 에너지는 사라지지 않고 형태가 바뀜(화학 에너지 → ATP의 화학 에너지 + 열). 미션: 운동 강도를 높여 열 방출 확인(task), 퀴즈(열로 나간 60 %의 쓸모: 체온 유지).
③ [모형] ATP 충전 — 'ATP 배터리 충전소' 모형: 세포호흡(미토콘드리아)에서 방출된 에너지로 ADP + 인산 → ATP '충전', 세포 활동 부위에서 ATP → ADP + 인산 '방전'하며 에너지를 건넴. 세균·식물·동물 세포 토글(모두 같은 ATP 사용). 호흡을 멈추면 ATP 저장량이 몇 초 안에 바닥남(저장량 작음 → 계속 재합성). 미션: 충전-방전 3회전(task), 퀴즈(ATP를 먹는 것이 아니라 음식으로 세포호흡 → ATP 합성).
④ [적용] 활동과 에너지 — 카드 7장(달리기 근수축, 반딧불이 발광, 전기뱀장어 발전, 신경 신호 전도, 단백질 합성, 세포 분열, 체온 유지)에 쓰이는 에너지 형태(역학·빛·전기·화학·열) 연결(manual). 추론: 운동 → ATP 소비↑ → 세포호흡↑ → 산소 소비·이산화 탄소 배출↑ → 호흡·심박↑(중2 연결). 퀴즈 2개(세포호흡을 막는 물질이 있다면 가장 먼저 영향받는 활동은?, 같은 ATP를 쓰는 서로 다른 생물 활동).
애니메이션: 분자 결합·분해 spring, 에너지 막대 approach, 배터리 충전 게이지와 에너지 불꽃, 근육·반딧불이 장면 glow.

## `hb-digest-enzyme` · 💊 소화제와 소화 효소
- 성취기준 [12생과01-04] 소화, 순환, 호흡, 배설 과정이 기관계의 통합적 작용으로 나타남을 신체의 생리적 변화와 연관지어 추론할 수 있다.
- 카드 설명(desc): 소화제 속 효소로 녹말, 단백질, 지방이 분해되는 정도를 비교하고 온도와 pH에 따른 차이를 분석해 소화가 물질대사의 출발점임을 확인해요.
- 태그: 소화 효소, 소화제, 영양소 분해, 실험 설계 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 소화제 성분 · 분해 실험 · 조건 비교 · 이어지는 길

### 설계
범위: [12생과01-04]의 첫 부분 — 탐구 활동 '소화제와 소화 효소를 이용한 영양소 분해 실험하기'. 소화는 기관계 통합의 출발점(영양소를 흡수 가능한 크기로 분해). 중2 '소화와 소화 효소'(침 아밀레이스 실험)와 통합과학1 '효소'(기질 특이성, 최적 온도·pH, 변성)를 반복하지 않고, 복합 소화제를 사용해 세 영양소를 한꺼번에 비교하는 변인 통제 실험과 결과 해석에 집중. 효소 구조식·반응 속도식은 없음. 실제 약 복용 조언처럼 보이지 않도록 '가상 소화제(복합 효소제)' 표시.
가상 소화제 성분: 아밀레이스(녹말), 프로테이스(단백질), 라이페이스(지방). 실험은 모두 가상 예시 값. 쓸개즙은 효소가 아니고 지방을 작게 쪼개(유화) 라이페이스 작용 면적을 넓힘.
검출: 녹말 — 아이오딘 반응(청람색 → 옅어짐), 단백질 — 삶은 달걀 흰자 조각(1 cm 정육면체)의 남은 크기, 지방 — 우유 + BTB 용액(지방산 생성 → 초록 → 노랑).
예시 결과(20분, 37 °C): 남은 녹말 — 물 100 %, 소화제 10 %, 끓인 소화제 100 %. 흰자 조각 남은 크기 — 물 100 %, 소화제 55 %, 끓인 소화제 100 %. 우유 BTB — 물 초록 유지, 소화제 노랑, 끓인 소화제 초록, 소화제 + 쓸개즙은 더 빨리 노랑. 온도별 남은 녹말 — 0 °C 85 %, 37 °C 10 %, 60 °C 95 %(변성). pH별 — pH 2 80 %, pH 7 10 %, pH 11 70 %.
탐구 질문: "소화제를 먹으면 왜 음식이 더 잘 소화될까? 소화제는 모든 영양소에 똑같이 작용할까?"
① [실험] 소화제 성분 — 가상 소화제 성분표(효소 3종)와 영양소 시료 3개(녹말 용액, 흰자 조각, 우유)가 든 시험관 세트. 각 영양소에 물 / 소화제 / 끓인 소화제를 넣고 37 °C 물중탕. 검출 도구(아이오딘, BTB, 자). 미션: 9개 시험관 세팅(task), 퀴즈(물만 넣은 시험관의 역할 → 대조군).
② [분석] 분해 실험 — 시간 가속 재생(20분) 후 영양소별 결과를 시간–남은 양 그래프로 비교. 결과에서 소화제의 효소가 영양소를 분해했고 끓인 소화제는 못 한다는 사실로 변성 확인. 효소별 기질 특이성 표 채우기(manual: 아밀레이스–녹말–엿당, 프로테이스–단백질–아미노산, 라이페이스–지방–지방산·모노글리세리드). 쓸개즙 추가 시험관 비교. 미션: 결과 해석표(manual), 퀴즈(끓인 소화제에서 분해가 일어나지 않은 까닭).
③ [탐구] 조건 비교 — 실험 설계: 온도(0·37·60 °C) 또는 pH(2·7·11) 중 하나를 바꿀 변인으로 선택, 나머지는 같게 유지(manual 판정). 실행해 그래프에서 최적 조건 찾기. 위액(pH 2)에서 장용 효소제가 어떻게 쓰일지 추론 퀴즈.
④ [적용] 이어지는 길 — 분해 산물(포도당, 아미노산, 지방산·모노글리세리드)이 소장 융털에서 흡수되어 순환계를 타고 온몸 세포로 가는 경로 따라가기(다음 차시 '기관계의 통합적 작용'으로 연결). 퀴즈 3개(소화제는 이미 있는 영양소의 소화를 돕는 것이지 에너지를 만들어 주는 것이 아님, 효소제를 뜨거운 물에 타 먹으면 안 되는 까닭, 지방이 많은 식사 후 쓸개즙이 하는 일).

### 설계
범위(해설): 기관계의 통합적 작용을 실제 인체 활동 과정에서 나타나는 생리적 변화의 사례(30분 달리기)를 바탕으로 설명. 각 기관계의 구조·기능은 중2에서 다뤘으므로 반복하지 않고 '연결과 협력'에 집중. 신경계·내분비계는 조절 기관계로 이름만(조절은 단원 38). 방법: 정보 그림(인포그래픽) 완성, 역할놀이 카드(각 기관계 역할 맡기기).
계산에 쓰는 식(고2 수준, 단순한 수): 심박출량(L/분) = 심박수(회/분) × 1회 박출량(mL) ÷ 1000. 산소 소비량(L/분) = 심박출량 × 동맥혈과 정맥혈의 산소 함량 차(혈액 100 mL당 mL) ÷ 100.
자료(예시, 단순화): 안정 시 — 심박수 70회/분, 1회 박출량 70 mL → 심박출량 약 4.9 ≈ 5 L/분, 호흡수 14회/분, 산소 함량 차 5 mL/100 mL → 산소 소비량 5 × 5 ÷ 100 = 0.25 L/분, 체온 37.0 °C. 달리기(30분) — 심박수 150회/분, 1회 박출량 130 mL → 약 19.5 ≈ 20 L/분, 호흡수 35회/분, 산소 함량 차 15 mL/100 mL → 20 × 15 ÷ 100 = 3.0 L/분(안정의 12배), 체온 약 38.5 °C. 혈류 분배(심박출량 중): 근육 안정 약 20 % → 운동 약 80 %, 소화관 약 25 % → 약 5 %. 땀 증가, 오줌 생성량 감소.
탐구 질문: "30분 달리는 동안 소화·순환·호흡·배설 기관계는 어떻게 힘을 합칠까?"

② [분석] 산소 운반 — 위 식으로 심박출량과 산소 소비량 계산(숫자 입력 칸, 정답이면 게이지 상승). 혈액이 산소를 실어 나르는 입자 모형(폐에서 산소 적재 → 근육에서 하차), 호흡수 증가가 산소 적재를 뒷받침함. 혈류 분배 막대(소화관 ↓, 근육 ↑). 미션: 안정/달리기 산소 소비량 계산(task 2), 퀴즈(심박수만 두 배가 되었다면 산소 소비량은?).
③ [모형] 통합 지도 — 정보 그림 완성: 소화계(영양소 흡수) → 순환계(운반) ← 호흡계(산소 흡수) → 근육 세포(세포호흡) → 순환계 → 호흡계(이산화 탄소 배출)·배설계(요소·물 배출), 피부(땀 배출·열 방출). 역할놀이: 기관계 카드를 고르고 '내가 맡은 일 – 받는 것 – 주는 것' 문장 완성(manual). 연결선 완성 후 물질 입자가 흐름. 미션: 지도 연결(manual), 역할 문장 완성(manual).

### 설계
범위(해설): 생태계를 하나의 살아 있는 유기체와 같은 개념으로 이해하고(생산자=양분 만들기, 분해자=재활용, 비생물=환경) 외부 환경 변화로 생태계 평형이 깨질 수 있음을 다룸. 통합과학2 '생태계의 구성요소', '먹이 관계와 생태 피라미드', '생태계 평형과 개체군 변동'을 반복하지 않고(피라미드 10 % 계산, 포식자–피식자 모의 제외) 물질의 '순환'과 에너지의 '흐름'을 구분하는 데 초점. 질소 순환 세부, 천이, 생태 효율 계산 문제는 다루지 않음. 탄소 순환만 자세히 다루고 물은 이름만.
자료(단순화 예시): 탄소 순환 — 대기 이산화 탄소 ↔ 생산자(광합성 흡수, 연간 120 상대 단위) / 생물 호흡·분해자 분해로 대기 방출(연간 120) → 균형 / 먹이 사슬로 생산자 → 소비자 → 분해자 / 화석 연료는 오랜 기간 묻힌 탄소 저장고, 연소 시 연간 약 9 단위가 대기로 추가 방출. 에너지 흐름(생산자가 고정한 화학 에너지를 1000이라 할 때): 생산자 호흡 열 300, 1차 소비자 섭취 100, 분해자로(낙엽·사체) 600 / 1차 소비자 100 → 호흡 열 50, 2차 소비자 섭취 10, 분해자로 40 / 2차 소비자 10 → 호흡 열 4, 분해자로 6 / 분해자 호흡 열 600 + 40 + 6 = 646. 열의 총합 300 + 50 + 4 + 646 = 1000 = 입력(에너지 보존, 모두 열로 방출).
탐구 질문: "탄소는 계속 돌고 도는데, 에너지는 왜 계속 새로 들어와야 할까?"
① [모형] 생태계 구조 — 초원 생태계(생산자 풀, 1차 소비자 메뚜기, 2차 소비자 개구리, 분해자 버섯·세균, 비생물: 햇빛·물·공기·토양)에서 물질 이동(실선)과 에너지 이동(주황 화살표)을 구분해 연결선 긋기(manual). 분해자를 빼 보면 사체·낙엽이 쌓이고 토양 양분이 줄어듦. 미션: 연결 완성(manual), 분해자 제거 실험(task), 퀴즈(분해자의 역할).
② [탐구] 탄소 순환 — 저장고 5개(대기, 생산자, 소비자, 분해자·토양, 화석 연료)와 5개 과정 이름표(광합성, 호흡, 먹이 섭취, 분해, 연소)를 화살표로 이어 순환 고리 완성(manual). 탄소 입자가 고리를 한 바퀴 돎. 연간 흡수 120 = 방출 120(평형), 화석 연료 연소 9가 추가되면 대기 탄소 막대가 해마다 증가하는 그래프. 미션: 순환 고리 완성(manual), 연소 추가 후 변화 관찰(task), 퀴즈(물질은 순환한다 — 같은 탄소 원자가 다시 쓰임).

④ [적용] 평형과 중요성 — 유기체 비유 카드(생산자 ↔ 양분 만드는 일, 분해자 ↔ 재활용, 비생물 ↔ 환경 조건). 교란 시나리오 5개(분해자 감소, 가뭄으로 생산자 감소, 포식자 제거, 외래종 도입, 대기 이산화 탄소 증가)를 골라 영향 연쇄(어디에서 어디로)를 화살표로 고르기(manual). 교란 크기 슬라이더로 '작으면 회복 / 한계를 넘으면 새 평형 또는 붕괴' 그래프. 생태계가 주는 혜택 카드(맑은 공기, 물 정화, 토양 비옥, 식량)로 구성 요소의 중요성 정리 → 생태전환교육. 퀴즈 2개.
애니메이션: 탄소 입자 순환 trail, 에너지 화살표 굵기가 단계마다 줄고 열 파동이 퍼짐, 대기 탄소 막대 approach, 교란 시 화면 채도 하락과 회복.

## `hb-population` · 🦌 개체군의 특성
- 성취기준 [12생과01-07] 개체군과 군집의 특성을 이해하고 이들의 상호작용의 예를 조사하여 발표할 수 있다.
- 카드 설명(desc): 표지 재포획법으로 개체 수를 추정하고, 생장 곡선과 연령 구조를 읽어 개체군이 어떻게 변하는지 알아본 뒤 개체군 안에서 일어나는 상호작용을 구분해요.
- 태그: 개체군, 생장 곡선, 연령 구조, 텃세·순위제 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 개체군 밀도 · 생장 곡선 · 연령 구조 · 개체군 내 관계

### 설계
범위(해설): 개체군 특성(밀도, 생장 곡선, 연령 구조)과 개체군 내 상호작용 — 텃세, 순위제, 리더제, 사회생활, 가족생활 5가지(군집 내 상호작용은 '군집 속 종간 관계' 차시). 통합과학2의 개체군 변동 모의실험(포식자–피식자)과 겹치지 않도록 한 종의 개체군에 집중. 다루지 않음: 로지스틱 방정식, 생명표·생존 곡선 세부.
식: 밀도 = 개체 수 ÷ 면적. 표지 재포획법: 전체 개체 수 N = (처음 표지한 수 M × 두 번째 포획 수 n) ÷ 재포획된 표지 개체 수 m (추정, 가정: 표지가 섞이고 이동·출생·사망이 없음).
자료(예시): 호수 2 km²에 붕어 600마리 → 밀도 300마리/km². 표지 재포획: M = 50, n = 40, m = 5 → N = 50 × 40 ÷ 5 = 400(여러 번 반복하면 추정값이 참값 근처에서 흩어짐). 짚신벌레 배양(먹이 한정, 개체 수/mL): 0일 10, 2일 25, 4일 60, 6일 130, 8일 250, 10일 380, 12일 450, 14일 490, 16일 500, 18일 500 → S자 곡선(환경 수용력 약 500), 먹이·공간이 무한하면 J자 곡선(이론). 환경 저항: 먹이 부족, 노폐물, 공간 부족, 포식.
연령 구조(예시, 생식 전 / 생식 / 생식 후 %): 개체군 A 45 / 35 / 20 → 피라미드형(증가), B 30 / 40 / 30 → 종형(안정), C 15 / 40 / 45 → 항아리형(감소).
개체군 내 상호작용: 텃세(영역을 독점·방어 — 은어, 호랑이), 순위제(서열이 정해지면 다툼 감소 — 닭의 모이 쪼기), 리더제(한 개체가 무리를 이끎 — 기러기, 코끼리), 사회생활(구성원이 일을 나눠 맡음, 분업 — 꿀벌, 개미), 가족생활(혈연 개체가 함께 생활 — 사자).
탐구 질문: "숲속 사슴이 몇 마리인지 다 세지 않고도 알아낼 수 있을까? 개체군은 어떻게 늘고 줄까?"
① [관찰] 개체군 밀도 — 호수를 격자로 나눈 화면에서 밀도 = 개체 수 ÷ 면적 계산. 표지 재포획 시뮬: 붕어를 그물로 잡아 표지(빨간 점) → 놓아주고 섞인 뒤 다시 잡기 → N 추정. 3회 반복하면 값이 조금씩 다름. 미션: 밀도 계산(task), 추정 N 구하기(task), 퀴즈(표지가 떨어져 버렸다면 추정값은? → 과대 추정).
② [분석] 생장 곡선 — 짚신벌레 배양 시간–개체 수 그래프 그리기. 먹이를 무한(J자) ↔ 한정(S자) 토글, 환경 수용력 점선, 환경 저항 표시, 출생률·사망률 막대가 같아지는 지점. 미션: 점 찍기(task), 퀴즈(S자 곡선에서 증가가 멈추는 까닭).
③ [분석] 연령 구조 — 개체군 A·B·C의 막대(생식 전·생식·생식 후)를 보고 피라미드형·종형·항아리형을 판정(manual)하고 앞으로 20년 개체 수 변화를 예측(증가·유지·감소). 퀴즈(생식 전 개체 비율이 높으면?).
④ [적용] 개체군 내 관계 — 장면 카드 5장(은어 영역, 닭 서열, 기러기 V자 비행, 꿀벌 집, 사자 무리)을 5가지 상호작용으로 분류(manual)하고 각각의 이점 고르기. 퀴즈 2개(텃세와 순위제의 차이, 사회생활과 가족생활을 가르는 기준: 분업 vs 혈연).
애니메이션: 그물 포획과 표지 점, 입자처럼 퍼지는 개체, 생장 곡선 draw, 개체 아이콘이 연령 막대에 쌓임, 장면 카드 확대(꿀벌 분업 애니메이션).

## `hb-quadrat` · 🌱 방형구법으로 군집 조사
- 성취기준 [12생과01-07] 개체군과 군집의 특성을 이해하고 이들의 상호작용의 예를 조사하여 발표할 수 있다.
- 카드 설명(desc): 가상 초지에 방형구를 설치해 식물의 밀도, 빈도, 피도를 구하고 중요치로 우점종을 찾아 군집의 특성을 분석해요.
- 태그: 군집, 방형구법, 우점종, 종 다양성 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 방형구 설치 · 밀도·빈도·피도 · 중요치 · 군집 해석

### 설계
범위: [12생과01-07]의 군집 특성 부분 — 탐구 활동 '방형구법으로 식물 군집 분석하기'. 군집 = 같은 지역에 사는 여러 종의 개체군 모임. 군집의 특성: 우점종, 종 다양성(통합과학2의 종 수 + 고른 정도), 수직 분포(층상 구조). 다루지 않음: 천이, 지수 계산(종 다양도 지수), 통계 검정.
방형구법: 초본 식물 조사에 1 m × 1 m 방형구를 무작위로 여러 곳에 설치. 식:
밀도 = 어떤 종의 개체 수 ÷ 전체 방형구 면적, 상대 밀도(%) = 그 종의 밀도 ÷ 모든 종의 밀도 합 × 100.
빈도 = 그 종이 출현한 방형구 수 ÷ 전체 방형구 수, 상대 빈도(%) = 그 종의 빈도 ÷ 모든 종의 빈도 합 × 100.
피도 = 그 종이 덮은 면적 ÷ 전체 조사 면적, 상대 피도(%) = 그 종의 피도 ÷ 모든 종의 피도 합 × 100.
중요치(IV) = 상대 밀도 + 상대 빈도 + 상대 피도(최대 300), 중요치가 가장 큰 종 = 우점종.
자료(가상 초지, 방형구 10개 = 10 m², 종: A 토끼풀, B 질경이, C 쑥, D 강아지풀): 방형구별 개체 수 — A [5,4,0,6,3,0,4,5,2,1] 합 30(출현 8곳), B [2,0,0,3,0,2,0,0,1,2] 합 10(5곳), C [0,0,2,0,0,0,1,0,0,2] 합 5(3곳), D [6,7,5,8,0,6,9,5,4,5] 합 55(9곳). 덮은 면적(m²) — A 4.0, B 1.0, C 3.0, D 2.0(합 10.0).
→ 상대 밀도 A 30, B 10, C 5, D 55 / 상대 빈도(빈도 0.8·0.5·0.3·0.9, 합 2.5) A 32, B 20, C 12, D 36 / 상대 피도 A 40, B 10, C 30, D 20 / 중요치 A 102, B 40, C 47, D 111(합 300) → 우점종 강아지풀(A와 근소한 차이).
종 수–방형구 수 곡선(누적 출현 종 수): 1개 2종, 3개 3종, 6개 4종, 10개 4종 → 더 이상 늘지 않음(조사 충분). 군집 비교(통합과학2 연결): 초지 X 개체 비율 55 : 30 : 10 : 5(한 종이 많음), 초지 Y 25 : 25 : 25 : 25 → 같은 4종이어도 Y의 종 다양성이 높음. 수직 분포 예: 교목층 – 아교목층 – 관목층 – 초본층, 바닥 도달 빛 약 15 %.
탐구 질문: "넓은 초지의 식물을 일일이 세지 않고도 어떤 식물이 우점하는지 알아낼 수 있을까?"
① [실험] 방형구 설치 — 가상 초지(항공 시점)에 1 m² 방형구를 무작위 좌표 10곳에 설치(편의로 마음에 드는 곳만 고르면 편향 경고). 방형구를 확대해 식물 종별로 개체 수를 세고 덮은 면적을 읽어 기록표에 입력. 미션: 방형구 10개 설치(task), 한 방형구 세기(task), 퀴즈(무작위로 설치하는 까닭).
② [기록] 밀도·빈도·피도 — 기록표에서 종별 합계를 구해 밀도(마리/m²), 빈도, 피도를 계산(manual 입력 확인). 예: A 밀도 30 ÷ 10 = 3.0/m². 미션: 4종 밀도·빈도·피도 입력(manual), 퀴즈(개체 수는 많지만 한 곳에 몰려 있는 종 vs 골고루 퍼진 종 → 밀도와 빈도의 차이).
③ [분석] 중요치 — 상대값 3가지를 계산해 합치고 우점종 막대그래프에서 찾기(manual). 쑥은 개체 수가 적어도 큰 잎 때문에 피도가 높음. 미션: 중요치 계산(task), 우점종 선택(manual), 퀴즈(우점종을 정할 때 개체 수만 쓰면 안 되는 까닭).
④ [적용] 군집 해석 — 종 수–방형구 수 곡선으로 조사 충분성 판단(방형구를 더 늘려야 하나?), 초지 X·Y의 종 다양성 비교, 숲 수직 분포 모식도 이름표 붙이기(manual). 퀴즈 2개(개체 수가 같아도 종 다양성이 다른 군집, 우점종 변화가 환경 변화의 단서가 될 수 있음).
애니메이션: 항공 시점 초지 카메라 줌, 방형구 사각형이 통통 튀며 착지, 식물 아이콘이 흔들림(바람), 표 숫자 롤링, 막대그래프 approach, 곡선 draw.

### 설계
범위(해설): 군집 내 상호작용 — 종간 경쟁, 분서, 공생, 기생, 포식과 피식(개체군 내 상호작용은 앞 차시). 공생은 상리 공생(두 종 모두 이익)과 편리 공생(한 종만 이익, 다른 종은 이익도 손해도 없음), 기생은 한쪽 이익·다른 쪽 손해. 포식–피식의 개체 수 변동 모의는 통합과학2에서 했으므로 여기서는 그래프 읽기와 사례 분류. 다루지 않음: 생태적 지위의 수식 모형, 경쟁 배타 원리 이름의 정식 정의(결과 현상만).
자료(예시, 짚신벌레 배양, 개체 수/mL): 단독 배양은 두 종 모두 S자 곡선. 같은 먹이·공간에서 혼합 배양 — 종 P1 10→ 약 200으로 증가 후 유지, 종 P2 10→ 약 80까지 늘다가 16일째 0 (경쟁에서 밀려남). 서식 공간이 다른 종 P2와 P3(위·아래 서로 다른 곳을 주로 이용)를 혼합 배양하면 두 종 모두 유지(공존) → 분서. 포식–피식 그래프(가상): 피식자 정점 다음 약 2~3년 뒤 포식자 정점, 약 10년 주기.
이익·손해 표(+ 이익, 0 이익도 손해도 없음, − 손해): 상리 공생(+ +), 편리 공생(+ 0), 기생(+ −), 종간 경쟁(− −), 포식(+ −). 사례: 상리 공생 — 콩과 식물과 뿌리혹박테리아(질소 양분 제공 ↔ 양분 제공), 말미잘과 흰동가리 / 편리 공생 — 빨판상어와 상어, 따개비와 고래 / 기생 — 겨우살이와 참나무, 회충과 사람, 벼룩과 개 / 분서 — 서로 다른 높이에서 먹이를 구하는 새들, 몸 크기가 다른 먹이를 먹는 육식 동물.
탐구 질문: "같은 곳에 사는 여러 종은 어떻게 서로 영향을 주고받으며 함께 살아갈까?"
① [모형] 경쟁과 분서 — 배양 병 3개(단독 / 같은 먹이 혼합 / 공간을 나눈 혼합)에서 시간 가속으로 개체 수 그래프 비교. 자원 겹침 슬라이더(0~100 %): 겹침이 클수록 한 종이 사라짐, 겹침을 줄이면 공존(분서). 미션: 세 병 실행(task), 겹침 낮춰 공존시키기(task), 퀴즈(경쟁과 분서의 차이).
② [분석] 포식과 피식 — 피식자·포식자 개체 수 그래프에서 증가·감소 순서에 번호 붙이기(피식자 증가 → 포식자 증가 → 피식자 감소 → 포식자 감소). 정점의 시차 읽기. 사례 카드(사자–얼룩말, 무당벌레–진딧물, 올빼미–쥐)에서 포식자·피식자 지정하고 한 생물이 포식자이자 피식자일 수 있는 예 찾기(manual). 미션 + 퀴즈(포식자가 사라지면 피식자는 계속 늘까?).
③ [모형] 공생과 기생 — 이익·손해 표(+ / 0 / −)를 사례 카드 8장에 맞춰 상리 공생·편리 공생·기생으로 분류(manual). 입자 확대(🔍): 뿌리혹박테리아가 질소 양분 제공, 식물이 양분 제공(두 방향 화살표) vs 기생충이 숙주 양분 흡수(한 방향). 퀴즈(공생과 기생의 차이, 상리와 편리의 차이).
④ [적용] 관계 발표 — 가상 군집 카드(사바나, 산호초, 숲 토양)에서 관계 쌍 6개를 찾아 '종 A – 종 B – 관계 유형 – 근거' 발표문을 구성(manual)하고, 한 종이 사라졌을 때 군집이 어떻게 변할지 추론(예: 산호초에서 흰동가리와 말미잘). 퀴즈 2개(개체군 내 vs 군집 내 상호작용 구분, 조사 발표 자료의 출처 표기).
애니메이션: 배양 병 속 개체 입자 증식·감소, 위·아래 서식 구역 분리선, 포식자가 피식자를 추격하는 입자 장면, 공생 양방향 화살표 pulse와 기생 흡수 흐름.
