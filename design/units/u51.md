## 개념 위계와 차시 흐름
선수: 중3 m3-reaction-heat(발열·흡열 반응, 온도 변화), 중1 m1-specific-heat(Q = cmΔT)·m1-state-change-heat(상태 변화와 열), 중3 m3-chemical-equation(반응식·계수), 통합과학2 h1-energy-exchange(에너지의 흡수와 방출 — 열화학 반응식·엔탈피는 다루지 않았음), h1-neutralization(중화 반응과 온도 변화), 일반선택 화학 hc-equation-mole·hc-stoich-calc(반응식의 몰수비·양적 계산), hc-dynamic-eq·hc-le-shift(화학 평형 — 발열·흡열은 정성적으로만 다뤘음), 단원 49(분자 간 힘·상태 변화), 단원 50(용해와 용액 — 용해의 열 출입).
차시 흐름: ① 엔탈피 변화와 열화학 반응식(ΔH 부호, 열량계 q = cmΔT, 반응식 쓰기·계수·역반응) → ② 연료의 효율 비교(수소·에탄올 vs 화석 연료의 단위 질량·단위 부피당 반응 엔탈피) → ③ 헤스 법칙(경로가 달라도 ΔH 합은 같음, 반응식 조작) → ④ 중화 반응으로 확인하는 헤스 법칙(탐구 실험)
→ ⑤ 엔트로피(배열의 경우의 수, 정성적) → ⑥ 엔탈피와 엔트로피로 설명하는 자발성(네 가지 경우, 자발성 ≠ 빠름).
'열의 출입을 숫자로(①) → 숫자의 활용(②) → 직접 재기 어려운 것을 계산으로(③④) → 열 출입만으로는 방향이 정해지지 않는 변화(⑤⑥)'. ⑥은 ①의 ΔH 부호와 ⑤의 엔트로피를 합쳐 "발열 반응이면 늘 자발적인가?"라는 오개념을 정리한다.
고려 사항: 해설에 따라 엔탈피는 '화학 반응에서 열의 출입(반응열)'에 관련된 내용으로 제한한다. 즉 ΔH = 반응이 일정 압력에서 방출·흡수하는 열(발열 ΔH < 0, 흡열 ΔH > 0)이고, 열역학 함수로서의 엔탈피(H = U + PV, 상태 함수 증명, 일·내부 에너지 구분)는 다루지 않는다. 헤스 법칙은 엔탈피 변화 그림·열화학 반응식을 해석하는 활동으로 다룬다(표준 생성 엔탈피·결합 에너지 표 계산은 없음). 엔트로피는 정성적으로만 다루고 깁스 자유 에너지(ΔG = ΔH − TΔS)와 엔트로피 값 계산은 하지 않는다. 자발성은 '엔탈피 감소(주위로 열 방출)'와 '엔트로피 증가' 두 요인으로 설명하고 온도의 영향도 정성적으로(온도가 높을수록 엔트로피 증가의 효과가 커진다). 열량계 실험·연료 연소 실험에는 보호 장구·폐수 처리 안내를 단다. 열의 단위 kJ, 물의 비열 4.18 J/(g·°C), 용액의 밀도 1.0 g/mL 가정.

## `hx-thermochem` · 📈 엔탈피와 열화학 반응식
- 성취기준 [12물에03-01] 엔탈피의 의미를 알고, 엔탈피를 이용하여 열화학 반응식을 표현할 수 있다.
- 카드 설명(desc): 열량계로 반응열을 재서 엔탈피 변화 ΔH 의 부호와 크기를 읽고, 물질의 상태와 계수를 맞춰 열화학 반응식을 써요.
- 태그: 엔탈피 변화, 열량계, 열화학 반응식, 발열·흡열 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 열의 출입 · 열량계 · 반응식 쓰기 · ΔH 다루기

### 설계
범위: 엔탈피(H)는 물질이 가진 에너지의 한 척도로 소개하고, 반응 전후의 차 ΔH = H(생성물) − H(반응물) 가 일정한 압력에서 반응이 출입시키는 열(반응열)과 같다는 수준으로 다룸 — 발열 반응 ΔH < 0 (계의 엔탈피 감소, 열을 주위로 방출), 흡열 반응 ΔH > 0. 해설: 열역학 함수로서의 엔탈피(H = U + PV, 일·내부 에너지, 상태 함수 증명)는 다루지 않음 → '엔탈피 도표(반응물 수준과 생성물 수준의 높이 차)'와 열량 측정만 사용. 열화학 반응식 = 균형 반응식 + 물질의 상태(s, l, g, aq) + ΔH(kJ, 25 °C·1 atm 기준, 식 그대로 1회 반응할 때의 열).
다루지 않음: 표준 생성 엔탈피 표, 결합 에너지로 ΔH 계산, 반응 엔탈피의 온도 의존, 열역학 제1법칙. (중3·통합과학2에서는 열화학 반응식·엔탈피를 다루지 않았음 → 이 차시가 처음이므로 발열·흡열 사례에서 출발.)
자료: 열량계(스타이로폼 컵 + 뚜껑 + 온도 센서), q = c·m·ΔT (c = 4.18 J/g·°C, 수용액 밀도 1.0 g/mL), ΔH = −q ÷ n (발열이면 q는 용액이 얻은 열).
- 중화: 1.0 M HCl 50 mL + 1.0 M NaOH 50 mL (n = 0.050 mol), 22.0 °C → 28.5 °C (ΔT = 6.5) → q = 100 × 4.18 × 6.5 = 2717 J → ΔH = −2.717 kJ ÷ 0.050 = −54 kJ/mol (이론 약 −57 kJ/mol, 차이는 열 손실).
- 흡열: NH₄Cl 5.35 g(0.100 mol)을 물 100 g에 용해 22.0 °C → 18.5 °C (ΔT = −3.5) → q = 105 × 4.18 × 3.5 = 1.54 kJ → ΔH = +15 kJ/mol.
열화학 반응식: H₂(g) + ½O₂(g) → H₂O(l) ΔH = −286 kJ. 2H₂(g) + O₂(g) → 2H₂O(l) ΔH = −572 kJ (계수 2배 → ΔH 2배). 2H₂O(l) → 2H₂(g) + O₂(g) ΔH = +572 kJ (역반응 → 부호 반대). H₂(g) + ½O₂(g) → H₂O(g) ΔH = −242 kJ (생성물이 수증기이면 H₂O(l)보다 44 kJ 덜 방출: H₂O(l) → H₂O(g) ΔH = +44 kJ). C(s) + O₂(g) → CO₂(g) ΔH = −394 kJ. CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l) ΔH = −890 kJ. N₂(g) + 3H₂(g) → 2NH₃(g) ΔH = −92 kJ. NH₄Cl(s) → NH₄⁺(aq) + Cl⁻(aq) ΔH = +15 kJ.
계산: 수소 5.0 g(2.5 mol)이 H₂O(l)로 연소 → 방출 열 2.5 × 286 = 715 kJ. 메테인 8.0 g(0.50 mol) 연소 → 445 kJ. 질소 1 mol과 수소 3 mol이 완전 반응 → 92 kJ 방출(암모니아 2 mol당).
탐구 질문: "화학 반응에서 나오거나 들어가는 열을 어떻게 숫자로 나타내고 반응식에 적을 수 있을까?"
① [관찰] 열의 출입 — 반응 용기 3개(중화, 산화 칼슘 + 물, NH₄Cl 용해)에서 온도 변화와 열 화살표. 같은 반응을 엔탈피 도표로 그리는 법: 반응물 수준에서 생성물 수준으로 내려가면 ΔH < 0(주위로 열 방출), 올라가면 ΔH > 0(주위에서 열 흡수). 미션: 세 반응을 도표에 놓기(manual: 높낮이 선택), 퀴즈(ΔH < 0 이면 용기의 온도 변화는? → 상승 / 오개념: 발열 반응은 ΔH가 양수 X).
② [실험] 열량계 — 위 두 반응을 열량계에서 측정: 온도–시간 그래프, ΔT 읽기, q = cmΔT → ΔH = −q/n 계산 칸(manual 입력: 단위 kJ/mol 확인). 이론값과의 차이는 열 손실(뚜껑 유무 비교 슬라이더). 미션: 중화 ΔH 측정(task), NH₄Cl 용해 ΔH 측정(task), 퀴즈(NH₄Cl 용해에서 용액의 온도가 내려가는데 ΔH가 양수인 까닭 → 용액이 열을 잃고 반응이 열을 흡수).
③ [표기] 열화학 반응식 쓰기 — 4단계 안내: 균형 반응식 → 각 물질 상태 기호 → ΔH 값(kJ) → 계수에 맞는 값. H₂ 연소, C 연소, N₂ + 3H₂ → 2NH₃ 완성(manual: 칸 선택). 생성물이 H₂O(l)인지 H₂O(g)인지에 따라 ΔH가 다른 까닭(상태 변화 열 44 kJ). 미션: 반응식 3개 완성(manual), 퀴즈(상태 기호를 빼면 안 되는 까닭).
④ [분석] ΔH 다루기 — 계수를 2배로, 반응 방향을 거꾸로, 반응물 질량으로: 수소 5.0 g → 715 kJ, 메테인 8.0 g → 445 kJ, 2NH₃ 분해 ΔH 구하기(+92), 도표에서 ΔH의 크기 읽기. 퀴즈 2개(2H₂ + O₂ → 2H₂O의 ΔH는 H₂ + ½O₂ → H₂O의 몇 배? / 오개념: 계수를 바꿔도 ΔH는 그대로 X). 미션: 질량 → 열 계산 2개(task).
애니메이션: 용기 색 전이와 열 화살표(주위로 나감/들어옴), 엔탈피 도표에서 반응물 구가 아래/위 수준으로 이동하며 ΔH 화살표 길이 변화, 열량계 온도 그래프가 그려지며 ΔT 하이라이트, 반응식 칸이 채워질 때 도장 효과.

## `hx-fuel-enthalpy` · ⛽ 연료의 효율 비교
- 성취기준 [12물에03-01] 엔탈피의 의미를 알고, 엔탈피를 이용하여 열화학 반응식을 표현할 수 있다.
- 카드 설명(desc): 수소·에탄올과 메테인·휘발유의 연소 엔탈피를 단위 질량과 단위 부피로 바꿔 비교하며 어떤 연료가 어떤 쓰임에 알맞은지 판단해요.
- 태그: 대체 연료, 화석 연료, 연소 엔탈피, 효율 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 질량당 열량 · 부피당 열량 · 연소 실험 · 연료 선택

### 설계
범위: 열화학 반응식의 활용 탐구 — 대체 연료(수소, 에탄올 등 간단한 물질)와 화석 연료(메테인, 옥탄(휘발유 대표), 탄소(석탄 대표))를 연소 시 단위 질량(kJ/g)·단위 부피(kJ/L 또는 kJ/mL)당 반응 엔탈피로 비교해 연료의 효율성을 판단(고려 사항). 몰당 ΔH → 몰질량으로 kJ/g, 밀도 또는 기체 몰 부피(25 °C, 1 atm에서 24.5 L/mol)로 kJ/부피. 부가 판단 자료: 같은 열 1000 kJ당 이산화 탄소 발생량.
다루지 않음: 열효율 이론(카르노), 연료 전지 전압, 생산 공정의 에너지 수지(한 줄 언급은 가능). 실제 연료는 혼합물이므로 대표 물질로 단순화(화면 안내 한 줄).
자료(연소 ΔH, 생성물 H₂O(l), kJ/mol → 크기; 실험용으로 메탄올 CH₃OH(l) −726, M = 32 → 22.7 kJ/g도 사용): H₂(g) −286, M = 2 → 143 kJ/g, 기체 25 °C·1 atm 11.7 kJ/L. CH₄(g) −890, M = 16 → 55.6 kJ/g, 36.3 kJ/L. ## `hx-hess-law` · 🪜 헤스 법칙
- 성취기준 [12물에03-02] 측정하기 어려운 화학 반응의 엔탈피를 헤스 법칙으로 구하여 화학 법칙의 유용성을 인식할 수 있다.
- 카드 설명(desc): 반응이 여러 단계로 나뉘어도 전체 엔탈피 변화가 같음을 엔탈피 도표와 열화학 반응식으로 확인하고, 직접 재기 어려운 ΔH를 계산해요.
- 태그: 헤스 법칙, 엔탈피 도표, 반응식 더하기 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 경로와 ΔH · 식 조작 · CO의 ΔH · 퍼즐 풀기

### 설계
범위: 헤스 법칙 — 반응의 엔탈피 변화는 반응물과 생성물의 종류·상태만으로 정해지고 중간 경로에 무관 → 단계별 ΔH의 합 = 전체 ΔH. 측정하기 어려운 반응(직접 반응시키면 부산물이 생기는 반응)의 ΔH를 측정 가능한 반응들로 구한다. 해설·고려 사항: 엔탈피 변화 그림(도표)과 열화학 반응식 등 다양한 자료를 활용해 헤스 법칙을 해석. 반응식 조작 3가지: 반응식을 거꾸로 하면 ΔH 부호 반대, 계수를 n배 하면 ΔH도 n배, 두 식을 더하면 ΔH도 더함(상쇄되는 물질 소거).
다루지 않음: 표준 생성 엔탈피 표, 결합 에너지 표, 엔탈피의 상태 함수 증명. 
자료: ① C(s) + O₂(g) → CO₂(g) ΔH₁ = −394 kJ. 직접 반응으로 CO를 정확히 만들기 어려움(C + ½O₂ → CO 에서 CO₂도 섞여 생김). CO(g) + ½O₂(g) → CO₂(g) ΔH₂ = −283 kJ → C(s) + ½O₂(g) → CO(g) ΔH = ΔH₁ − ΔH₂ = −394 − (−283) = −111 kJ.
② N₂(g) + O₂(g) → 2NO(g) ΔH = +181 kJ, 2NO(g) + O₂(g) → 2NO₂(g) ΔH = −115 kJ → N₂(g) + 2O₂(g) → 2NO₂(g) ΔH = +181 + (−115) = +66 kJ.
③ C(흑연) + O₂(g) → CO₂(g) ΔH = −394 kJ, C(다이아몬드) + O₂(g) → CO₂(g) ΔH = −396 kJ → C(흑연) → C(다이아몬드) ΔH = +2 kJ.
④ 도표 해석용: 수소 연소 H₂(g) + ½O₂(g) → H₂O(g) −242 kJ, H₂O(g) → H₂O(l) −44 kJ → H₂(g) + ½O₂(g) → H₂O(l) −286 kJ.
퍼즐 자료: 퍼즐 A — (i) S(s) + O₂(g) → SO₂(g) −297 kJ, (ii) 2SO₂(g) + O₂(g) → 2SO₃(g) −198 kJ ⇒ 2S(s) + 3O₂(g) → 2SO₃(g) = 2×(−297) + (−198) = −792 kJ. 퍼즐 B — 위 ③ 흑연 → 다이아몬드(+2 kJ). 퍼즐 C — 연소열 C(s) −394, H₂(g) −286 (H₂O(l) 생성), CH₄(g) −890 으로 C(s) + 2H₂(g) → CH₄(g) = −394 + 2×(−286) − (−890) = −76 kJ (반응식 3개를 뒤집기·곱하기·더하기).
탐구 질문: "직접 실험하기 어려운 반응의 열을 다른 반응의 열로 계산할 수 있을까?"
① [모형] 경로와 ΔH — 엔탈피 도표 계단: C(s)+O₂ 수준에서 CO₂ 수준까지 직접(−394) vs CO를 거쳐 두 계단(−111, −283). 높이 차는 경로에 상관없이 같음(산 아래에서 정상까지 오르는 길에 비유). 미션: 두 경로의 ΔH를 도표에서 읽기(task), 퀴즈(두 경로의 ΔH 합이 같은 까닭 / 오개념: 단계가 많으면 열이 더 많이 나온다 X).
② [탐구] 식 조작 — 반응식 카드 3장을 거꾸로 뒤집기/계수 곱하기/더하기 도구로 조작하며 ΔH 칸이 자동 갱신되는 장치. 규칙 3가지를 완성(manual). 미션: 뒤집기·곱하기 규칙 확인(task), 퀴즈(반응식을 거꾸로 쓰면 ΔH 부호는? 계수를 3배로 하면 ΔH는?).
③ [분석] CO의 ΔH — 직접 측정하기 어려운 C(s) + ½O₂ → CO 의 ΔH를 ① 흑연 연소 −394, ② CO 연소 −283 로 구하기(식 ① + 식 ②의 역반응). 소거되는 CO₂ 확인. 두 번째 사례 N₂ → 2NO₂(+66). 미션: CO 생성 ΔH 구하기(task: −111), NO₂ 생성 ΔH 구하기(task), 퀴즈(식 ②를 거꾸로 더할 때 부호가 바뀌어 −283 → +283).
④ [적용] 퍼즐 풀기 — 목표 반응식과 재료 반응식 2~3개가 주어지고 학생이 뒤집기·곱하기 조합을 선택해 목표 ΔH를 계산: 퍼즐 A SO₃ 생성(−792), 퍼즐 B 흑연 → 다이아몬드(+2), 퍼즐 C 메테인 생성 C + 2H₂ → CH₄ (−76). 퀴즈 2개(헤스 법칙이 필요한 이유, 최종 합이 틀렸을 때 확인 방법).
애니메이션: 엔탈피 도표의 계단 구가 두 경로로 이동하며 높이 차 합, 반응식 카드가 뒤집히며 ΔH 부호가 반전, 두 식을 더할 때 같은 물질이 소거되며 날아감, 목표 ΔH 칸이 채워질 때 체크.

## `hx-hess-experiment` · 🧊 중화 반응과 헤스 법칙
- 성취기준 [12물에03-02] 측정하기 어려운 화학 반응의 엔탈피를 헤스 법칙으로 구하여 화학 법칙의 유용성을 인식할 수 있다.
- 카드 설명(desc): 수산화 나트륨의 용해, 고체 수산화 나트륨과 염산의 반응, 용액끼리의 중화 반응 열을 재어 헤스 법칙이 성립하는지 확인해요.
- 태그: 헤스 법칙, 중화 반응, 열량계, 실험 오차 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 실험 계획 · 온도 측정 · ΔH 계산 · 결론·오차

### 설계
범위: 탐구 활동 '중화 반응으로 헤스 법칙을 확인하는 실험하기'. 세 반응의 ΔH₁, ΔH₂, ΔH₃ 를 컵 열량계로 측정하고 ΔH₂ = ΔH₁ + ΔH₃ 임을 확인(헤스 법칙). 열량 계산 q = c·m·ΔT (c = 4.18 J/g·°C), ΔH = −q ÷ n. 앞 차시(hx-hess-law, hx-thermochem)의 도구를 실험 데이터에 적용.
반응: (1) NaOH(s) → Na⁺(aq) + OH⁻(aq) ΔH₁ . (2) NaOH(s) + H⁺(aq) + Cl⁻(aq) → Na⁺(aq) + Cl⁻(aq) + H₂O(l) ΔH₂ . (3) Na⁺(aq) + OH⁻(aq) + H⁺(aq) + Cl⁻(aq) → Na⁺(aq) + Cl⁻(aq) + H₂O(l) ΔH₃ (= 중화). 도표: NaOH(s)+HCl(aq) 수준 → 직접(ΔH₂) 또는 NaOH(aq)+HCl(aq) 수준을 거쳐(ΔH₁ 다음 ΔH₃).
안전: NaOH(s)는 부식성 → 보안경·장갑, 습기를 빨아들이므로 빨리 잰다, 폐액은 중화 후 폐수 처리. 
다루지 않음: 열량계 열용량 정밀 보정(단순히 열 손실 보정만 제시), 이온 활동도.
자료(예시 측정값; 이론값 ΔH₁ ≈ −44, ΔH₂ ≈ −102, ΔH₃ ≈ −57 kJ/mol): (1) NaOH(s) 2.0 g(0.050 mol)을 물 100 g에 → 질량 102 g, ΔT = 4.9 °C → q = 102 × 4.18 × 4.9 = 2089 J → ΔH₁ = −41.8 kJ/mol. (2) NaOH(s) 2.0 g을 0.50 M HCl 100 mL(0.050 mol)에 → 질량 102 g, ΔT = 11.4 °C → q = 4861 J → ΔH₂ = −97.2 kJ/mol. (3) 1.0 M NaOH 50 mL + 1.0 M HCl 50 mL → 질량 100 g, ΔT = 6.5 °C → q = 2717 J → ΔH₃ = −54.3 kJ/mol. 확인: ΔH₁ + ΔH₃ = −41.8 + (−54.3) = −96.1 kJ/mol vs ΔH₂ = −97.2 → 차이 1.1 kJ(약 1 %) → 오차 범위 안에서 헤스 법칙 성립. 네 모둠 평균 비교 자료(ΔH₂ 측정값 −97.2, −95.0, −99.5, −93.8)도 제공해 오차 폭 확인.
오차 요인: 열 손실(컵 뚜껑·단열), 온도 센서 응답 시간, NaOH(s)가 공기 중 수분을 흡수하여 질량이 실제보다 큼, 초기 온도 불일치, 용액 밀도·비열을 물과 같다고 가정, 열량계가 흡수한 열. 보정: 온도–시간 그래프의 냉각 구간을 혼합 시각으로 외삽하여 ΔT 보정(외삽 ΔT는 읽은 값보다 약 0.2 °C 큼).
탐구 질문: "세 가지 서로 다른 반응의 열을 따로 재면 헤스 법칙이 정말 맞을까?"
① [계획] 실험 계획 — 세 반응을 엔탈피 도표로 연결해 '무엇을 비교할지' 가설 세우기(ΔH₂ ≈ ΔH₁ + ΔH₃), 반응마다 필요한 시약·양·변인 통제(같은 초기 온도, 같은 물/용액 양, 질량·부피 기록)와 안전 점검 카드(보안경, 장갑, 뚜껑) 선택. 미션: 가설 문장 완성(manual), 통제 변인 고르기(manual), 퀴즈(NaOH(s)를 오래 공기 중에 두면 안 되는 까닭).
② [실험] 온도 측정 — 컵 열량계에서 세 반응을 차례로 수행. 센서의 온도–시간 그래프에 혼합 시각, 최고 온도, 냉각 구간 직선 외삽 표시. 용액 질량·초기 온도·최고 온도 자동 기록(record). 미션: 세 반응 수행(task 3), 외삽으로 ΔT 보정 확인(task), 퀴즈(반응이 끝난 뒤 온도가 서서히 내려가는 까닭).
③ [분석] ΔH 계산 — 각 반응의 q = cmΔT, 몰수 n, ΔH = −q/n 을 계산 칸에 입력(manual), 이론값과의 차이(%) 표시. 세 ΔH를 막대로 쌓아 ΔH₁ + ΔH₃ 와 ΔH₂ 비교. 미션: ΔH₁, ΔH₂, ΔH₃ 계산(task 3), 퀴즈(발열이므로 ΔH가 음수가 되는 부호 처리 실수 찾기).
④ [결론] 결론·오차 — 결과 해석: 차이 1.1 kJ(1 %) → 헤스 법칙 확인. 모둠 4개의 ΔH₂ 값을 점도표로 비교해 오차 폭과 원인 목록(열 손실 등) 중 가장 큰 요인 고르기, 개선 방법(뚜껑, 더 큰 열량 사용). 일반화 질문: "헤스 법칙은 왜 유용한가". 미션: 결과 판정(manual), 오차 원인 2개 선택(manual), 퀴즈(측정한 ΔH₁ + ΔH₃의 절댓값이 ΔH₂보다 작게 나온 까닭 → 열 손실로 각각 작게 측정).
애니메이션: NaOH 알갱이가 물에 풀리며 비커 색이 주황으로 전이, 온도계 액주와 실시간 그래프 외삽선(점선), 막대 쌓기 비교, 결과 도장.

## `hx-entropy` · 🎲 엔트로피
- 성취기준 [12물에03-03] 엔트로피의 의미를 이해하고, 엔탈피와 엔트로피의 변화로 화학 변화의 자발성을 설명할 수 있다.
- 카드 설명(desc): 입자가 놓일 수 있는 배열의 수로 엔트로피를 이해하고, 상태 변화·용해·기체 생성에서 엔트로피가 늘어나는 방향을 예측해요.
- 태그: 엔트로피, 무질서도, 배열의 수, 확산 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 저절로 일어남 · 배열의 수 · 증가 조건 · 부호 예측

### 설계
범위: 엔트로피(S)의 의미를 정성적으로 이해 — 계에서 입자가 취할 수 있는 배열(미시 상태)의 수가 많을수록(흔히 무질서한 정도가 클수록) 엔트로피가 크다. 엔트로피가 증가하는 경향: ① 상태 변화 고체 → 액체 → 기체, ② 온도 상승(입자 운동이 다양해짐), ③ 부피 팽창·기체 혼합·용해(퍼짐), ④ 반응에서 기체 몰수 증가·입자 수 증가. 해설: 엔트로피는 정성적으로만 다룸 → S = k ln W 식, 엔트로피 값 표·ΔS 계산, 깁스 자유 에너지는 쓰지 않음. '경우의 수 세기'는 배열 수의 직관을 위한 수 세기 활동(확률은 비율로만).
자료: 용기를 두 칸(왼/오른)으로 나눈 모형. 입자 4개 → 왼쪽 개수 0~4 별 배열 수 1, 4, 6, 4, 1 (총 16). 입자 10개 → 모두 한쪽 칸에 모일 배열은 전체 1024가지 중 1가지(약 0.1 %). 입자 100개 → 모두 한쪽에 있을 확률 약 10⁻³⁰(사실상 0). 실제 1 mol(6×10²³개)에서는 고르게 퍼짐이 압도적.
엔트로피 증가 사례 카드: H₂O(s) → H₂O(l) → H₂O(g), 설탕이 물에 녹음, 잉크가 물에 퍼짐, 기체의 부피 팽창(진공 쪽으로), 두 기체의 혼합, CaCO₃(s) → CaO(s) + CO₂(g), 2H₂O₂(l) → 2H₂O(l) + O₂(g), 고체 가열 / 감소 사례: H₂O(g) → H₂O(l), 물이 얼음으로, N₂(g) + 3H₂(g) → 2NH₃(g) (기체 몰수 4 → 2), 2H₂(g) + O₂(g) → 2H₂O(l), 소금 결정 석출.
탐구 질문: "뜨거운 커피는 저절로 식고 잉크는 저절로 퍼지는데, 반대 방향은 왜 저절로 일어나지 않을까?"
① [관찰] 저절로 일어남 — 4가지 장면: 잉크가 물에 퍼짐, 칸막이를 열면 기체가 양쪽으로 퍼짐, 방이 어질러짐, 뜨거운 물과 찬물이 섞여 미지근해짐. 각 장면의 역과정은 에너지 보존에는 어긋나지 않지만 (기체가 한쪽으로 모이는 것은 에너지 변화 없음) 관찰된 적이 없음 → 에너지만으로는 변화의 방향을 설명할 수 없다는 문제 제기. 영상 되감기 비교. 미션: 4 장면 재생 후 역방향 재생 가능한지 판정(task), 퀴즈(칸막이를 열면 기체가 저절로 한쪽으로 모일 수 있나 → 이론상 가능하지만 확률이 극히 작음).
② [모형] 배열의 수 — 두 칸 용기에 입자(N = 4, 10, 20)를 넣고 칸막이를 여닫으며 왼쪽 입자 수 분포 히스토그램이 가운데가 높은 종 모양으로 쌓임(반복 시행 버튼). N=4 배열표(1,4,6,4,1) 직접 세기 후 N이 커질수록 한쪽에 몰릴 배열의 비율이 급감함을 확인. 엔트로피 S = 가능한 배열 수가 많은 정도(정성). 미션: N=4 배열 수 세기(manual: 표 칸 입력), N=10에서 한쪽에 모이는 횟수 시험(task), 퀴즈(엔트로피가 큰 상태 = 배열이 많은 상태 / 오개념: 엔트로피는 에너지의 다른 이름 X).
③ [탐구] 증가 조건 — 입자 모형 상자에서 조건을 바꿔 가며 입자의 배열(자유도)이 늘어나는 방향 확인: 상태 변화(고체 격자 → 액체 → 기체), 온도 올리기, 부피 팽창, 용해(소금 격자 → 이온이 물에 퍼짐), 반응 중 분자 수 증가(2H₂O₂ → 2H₂O + O₂). 각 조건에서 '배열 수 막대'가 늘어나거나 줄어듦. 미션: 4가지 조건에서 배열 수 증가 확인(task), 퀴즈(같은 물질 1 mol 중 엔트로피가 가장 큰 상태 → 기체).
④ [예측] 부호 예측 — 반응·변화 카드 12장의 ΔS(계의 엔트로피 변화) 부호 예측 '증가(+)/감소(−)' 상자에 분류(manual): 기체 몰수 변화, 상태 변화, 용해 등을 근거로. 감소하는 사례가 일어나는 까닭은 다음 차시에서 주위 포함해 설명한다는 예고. 퀴즈 3개(N₂ + 3H₂ → 2NH₃의 ΔS 부호, 물이 얼 때 ΔS 부호, 소금 용해 ΔS 부호).
애니메이션: 칸막이 슬라이드와 입자 확산(trail), 히스토그램 막대 쌓임, 격자 → 액체 → 기체 morph와 배열 수 막대 증가, 잉크 퍼짐, 분류 카드 snap.

## `hx-spontaneity` · ⚖️ 화학 변화의 자발성
- 성취기준 [12물에03-03] 엔트로피의 의미를 이해하고, 엔탈피와 엔트로피의 변화로 화학 변화의 자발성을 설명할 수 있다.
- 카드 설명(desc): 발열이어도, 흡열이어도 저절로 일어나는 변화를 보고 엔탈피 감소와 엔트로피 증가라는 두 요인으로 자발성을 판단해요.
- 태그: 자발성, 엔탈피, 엔트로피, 온도의 영향 / 단계 이름(steps → 각 STEP의 short와 맞출 것): 발열이면 자발? · 두 가지 요인 · 네 가지 경우 · 사례 판정

### 설계
범위: 화학 변화(및 물리 변화)의 자발성 = 외부의 지속적 개입 없이 일어나는 경향. 자발성은 두 요인으로 설명: (a) 엔탈피 요인 — 발열(ΔH < 0)이면 주위로 열을 내보내 주위의 엔트로피를 늘려 자발적 쪽으로 기여, (b) 엔트로피 요인 — 계의 엔트로피 증가(ΔS > 0)가 자발적 쪽으로 기여. 네 경우: ΔH < 0 & ΔS > 0 → 모든 온도에서 자발, ΔH < 0 & ΔS < 0 → 낮은 온도에서 자발, ΔH > 0 & ΔS > 0 → 높은 온도에서 자발, ΔH > 0 & ΔS < 0 → 모든 온도에서 비자발. 온도의 영향은 '온도가 높을수록 엔트로피 증가 요인의 영향이 커진다'로 정성적으로만. 자발적 ≠ 빠름, 비자발적 ≠ 불가능(외부 에너지 공급으로 가능).
해설: 깁스 자유 에너지는 다루지 않음 → ΔG = ΔH − TΔS 식, 수치 계산, 전이 온도 계산 없음. 부호 판단과 그림(저울)으로만. 
자료(각 경우의 사례): (−, +) 2H₂O₂(aq) → 2H₂O(l) + O₂(g) ΔH = −196 kJ, 기체 생성. 2KClO₃(s) → 2KCl(s) + 3O₂(g) 발열 + 기체 생성. 종이(셀룰로스)의 연소(기체 CO₂·수증기 생성, 기체 몰수 증가). (−, −) H₂O(l) → H₂O(s) ΔH = −6.0 kJ/mol, 0 °C 아래에서 자발(물이 어는 겨울). N₂ + 3H₂ → 2NH₃ ΔH = −92 kJ, 기체 4 → 2몰: 낮은 온도에서 자발(그러나 상온에서 너무 느려 촉매·고온·고압 사용; 평형 단원과 연결). (+, +) H₂O(s) → H₂O(l) ΔH = +6.0 kJ/mol, 0 °C 위에서 자발(얼음이 실온에서 녹음). NH₄NO₃(s) 용해 ΔH ≈ +26 kJ/mol(냉각 팩), Ba(OH)₂·8H₂O + 2NH₄Cl → BaCl₂ + 2NH₃ + 10H₂O (실온에서 자발, 발생 NH₃ 기체·액체 증가). CaCO₃(s) → CaO(s) + CO₂(g) ΔH = +178 kJ, 실온 비자발·약 800 °C 이상 자발(석회 가마). (+, −) 3O₂(g) → 2O₃(g) ΔH = +285 kJ, 기체 3 → 2몰: 어떤 온도에서도 비자발(오존은 번개·자외선 같은 에너지 공급으로만 생성).
자발성과 속도: 수소와 산소 혼합 기체는 상온에서 자발적이나 불꽃이 없으면 반응하지 않음, 다이아몬드 → 흑연도 자발적이나 사실상 일어나지 않음(속도는 다음 단원의 활성화 에너지). 비자발적 변화의 예: 물의 전기 분해(전기 에너지), 광합성(빛에너지).
탐구 질문: "발열 반응은 항상 저절로 일어날까? 흡열인데도 저절로 일어나는 변화는 왜 있을까?"
① [관찰] 발열이면 자발? — 카드 6장: 연소, 중화(발열 자발), 얼음이 실온에서 녹음, 냉각 팩 NH₄NO₃ 용해, Ba(OH)₂·8H₂O + NH₄Cl(젖은 나무판에 얼어붙음 — 흡열이지만 자발), 물이 어는 겨울날. 발열이면 자발적이라는 가설 시험: 흡열 자발 사례 3개와 발열 자발 사례 3개를 분류 후 온도 센서로 확인(task). 퀴즈(흡열 반응은 저절로 일어날 수 없다 X: 실온에서 얼음이 녹음).
② [모형] 두 가지 요인 — 두 접시 저울: 왼쪽 '엔탈피 요인(열이 주위로 나가는가)', 오른쪽 '엔트로피 요인(계의 배열 수가 늘어나는가)'. 각 접시에 반응 카드를 놓으면 두 요인의 방향(▲ 자발에 기여/▼ 방해)이 표시되고, 온도 슬라이더를 올리면 엔트로피 요인 접시의 추가 무게(스프링 막대)만 커짐(수식 없이 그림으로). 같은 반응(얼음 ↔ 물)이 0 °C 아래·위에서 반대 방향이 되는 것을 확인. 미션: 얼음이 녹는 온도(0 °C)를 슬라이더로 찾기(task), 퀴즈(온도가 높아지면 더 커지는 요인은 → 엔트로피 요인).
③ [분석] 네 가지 경우 — 2×2 표(ΔH 부호 × ΔS 부호)에 반응 카드를 끌어 놓고 자발 온도 조건('모든 온도/낮은 온도/높은 온도/없음') 선택(manual). 사례: H₂O₂ 분해 (−,+), 물 응고·NH₃ 합성 (−,−), 얼음 녹기·CaCO₃ 분해 (+,+), 오존 생성 (+,−). 미션: 표 완성(manual), 퀴즈(ΔH > 0, ΔS > 0 인 반응이 높은 온도에서 자발적인 까닭).
④ [적용] 사례 판정 — 판정 문제 4개: 석회석 가열 온도 선택(왜 가마가 고온인가), 암모니아 합성의 자발성(낮은 온도 유리)과 반응 속도(느림)의 충돌 → 촉매·400~500 °C 타협(다음 단원 예고), 오존이 자연적으로 만들어지지 않는 까닭, 겨울 호수가 어는 온도. 오개념 점검 퀴즈: 자발적 = 빠르다 X, 비자발적 = 불가능 X. 미션: 판정 문제 3개 이상 정답(task), 퀴즈(자발적이지만 일어나지 않는 것처럼 보이는 예 → 수소+산소 혼합).
애니메이션: 저울이 두 요인에 따라 기울고 온도 올리면 엔트로피 쪽 접시 스프링이 늘어남, 얼음–물 입자 모형이 임계 온도에서 방향 전환, 2×2 표 칸이 채워질 때 체크, 석회 가마 CO₂ 기체 방출.
