# 차시 설계 문서

이 폴더는 시뮬레이션을 만들 때 쓰는 **설계 자료**입니다. 웹사이트 화면에는 나타나지 않아요.

| 폴더·파일 | 내용 |
|---|---|
| `units/u01.md` ~ `u23.md` | 단원별 교육과정 원문, 개념 위계와 차시 흐름, 차시별 설계(탐구 질문, 4단계, 미션, 애니메이션) |
| `detail/` | 일부 차시의 더 자세한 설계 |
| `BUILD_SPEC.md` | 시뮬레이션 제작 규칙(화면 구성, 애니메이션 품질, 점검 방법) |
| `curriculum/` | 2022 개정 과학과 교육과정(중학교) 성취기준·해설 텍스트 |
| `src/` | 설계 원본과 목록 생성 스크립트 |

설계를 고친 뒤에는 저장소 맨 위 폴더에서 아래 명령으로 차시 목록(`assets/js/catalog.js`)과 설계 문서를 다시 만들어요.

```
python3 design/src/gen_all.py && node design/src/merge_catalog.js design/src/plans_all.json
```
