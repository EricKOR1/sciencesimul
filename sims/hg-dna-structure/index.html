보는 방법

표의 줄을 눌러도 종을 고를 수 있어요. 수치는 근사 예시 값이에요.

찾은 규칙
어떤 생물(가상)의 DNA에서 A = 31 %일 때

A + T + G + C = 100 %. 샤가프 규칙(A와 T, G와 C가 같은 양)으로 예측해요.

📏 눈금자 두 개

사진 오른쪽 동그란 손잡이를 위아래로 끌어 선을 층선(점이 늘어선 가로줄)에 맞춰요. 놓으면 가까운 줄에 붙어요.

측정 기록
    한 바퀴(3.4 nm)에 염기쌍은 몇 개?

    반복 거리를 서로 나눠 봐요: 3.4 nm 와 0.34 nm.

    🧩 틈 폭 2 nm에 맞는 짝은?

    아래 염기 블록을 끌어서(또는 눌러서 고른 뒤 틈을 눌러) 왼쪽·오른쪽 자리에 놓아요. 두 줄에서 짝을 찾아봐요. 블록을 누르면 치워져요.
