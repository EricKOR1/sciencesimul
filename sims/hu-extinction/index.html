색 초과 E(B − V)
(등급)
1.24 등급

그림 속 별빛 알갱이(파랑·빨강)가 티끌 구름을 지나가는 모습을 보면서, 그래프 아래 필터 단추를 눌러 줄어든 밝기를 재요.

소광 A_V
(등급)

A_V ≈ 3.1 × E(B − V)

보정한 거리 d
(pc 단위)

d = 10^((m − M − A_V + 5) / 5)

초록 점은 실제 별의 위치, 빨간 점은 소광을 무시했을 때의 착각이에요. A_V를 입력하면 두 점이 가까워져요.

카드를 눌러 고른 뒤 상태 줄을 눌러 넣어요. 넣은 카드를 다시 누르면 빠져요.
