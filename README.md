# 🔬 중학 과학 시뮬레이션 게임

2022 개정 교육과정(교육부 고시 제2022-33호 [별책 9] 과학과 교육과정) **중학교 과학 1~3학년군**의
성취기준에 맞춘 게임형 과학 시뮬레이션 모음입니다. 태블릿 수업에 맞춰 만들었습니다.
[PhET Interactive Simulations](https://phet.colorado.edu/ko/)에서 아이디어를 얻었습니다.

## 사용 방법

- **바로 열기**: `index.html`을 브라우저로 열면 됩니다. (설치 필요 없음, 글꼴만 온라인에서 불러옴)
- **GitHub Pages로 공개**: 저장소 → Settings → Pages에서 이 브랜치와 `/ (root)` 폴더를 지정하면
  `https://<아이디>.github.io/sciencesimul/` 주소로 접속할 수 있습니다.
- **태블릿**: 가로·세로 모두 한 화면에 맞게 나옵니다. 머리글의 ⛶ 버튼으로 전체 화면을 쓸 수 있습니다.

## 학습 구조

```
학년 → 단원(교육과정 순서) → 차시(시뮬레이션 1개 = 성취기준 1개) → 탐구 단계(STEP)
```

- **차시**: 한 시뮬레이션은 성취기준 하나만 다룹니다. 화면에는 그 개념에 꼭 필요한 것만 나옵니다.
  단원 안의 차시는 순서대로 이어지고, 차시를 마치면 **다음 차시** 버튼이 나옵니다.
- **탐구 단계**: 각 차시는 3~4단계로 진행됩니다.
  **👀 관찰 → 🧪 실험(🔎 탐구) → 💡 설명 → 🏠 적용**
  - 단계를 시작할 때 앞 단계와의 연결(🔗)과 이번에 새로 열리는 도구(🔓)를 보여 줍니다.
  - 단계마다 미션 2~3개(실험 미션 + 오개념을 짚는 퀴즈)를 풀고, 성공하면 "왜 그럴까?" 설명이 나옵니다.
  - 단계를 마칠 때마다 ⭐ 별을 받고, 정리 내용이 **📘 배운 내용** 공책에 쌓입니다.
- 첫 단계와 배운 내용 공책에는 **성취기준 원문**과 **단원 학습 순서**가 표시됩니다.
- 진행 기록(별·점수·단계)은 각 기기의 브라우저(localStorage)에 저장됩니다.

### 전체 단원 (교육과정 내용 순서)

- **1학년 (과학 1)**: Ⅰ 과학과 인류의 지속가능한 삶 · Ⅱ 생물의 구성과 다양성 · Ⅲ 열 · Ⅳ 물질의 상태 변화 · Ⅴ 힘의 작용 · Ⅵ 기체의 성질 · Ⅶ 태양계
- **2학년 (과학 2)**: Ⅰ 물질의 특성 · Ⅱ 지권의 변화 · Ⅲ 빛과 파동 · Ⅳ 물질의 구성 · Ⅴ 식물과 에너지 · Ⅵ 동물과 에너지 · Ⅶ 전기와 자기 · Ⅷ 별과 우주
- **3학년 (과학 3)**: Ⅰ 화학 반응의 규칙성 · Ⅱ 날씨와 기후변화 · Ⅲ 수권과 해수의 순환 · Ⅳ 운동과 에너지 · Ⅴ 자극과 반응 · Ⅵ 생식과 유전 · Ⅶ 재해·재난과 안전 · Ⅷ 과학과 나의 미래

> 교과서(출판사)에 따라 단원 순서가 다를 수 있습니다.

## 폴더 구조

```
index.html               메인(학년 → 단원 → 차시 목록)
assets/css/common.css    공통 스타일 (태블릿 우선 레이아웃)
assets/css/hub.css       메인 페이지 스타일
assets/js/common.js      공통 엔진 (단계·미션·별·배운 내용 공책·효과음·캔버스 도우미)
assets/js/catalog.js     학년·단원·차시 목록과 성취기준  ← 새 시뮬레이션을 등록하는 곳
assets/js/hub.js         메인 페이지 동작
sims/<차시 ID>/          시뮬레이션별 폴더 (index.html + sim.js)
```

## 새 시뮬레이션 추가하기

1. `sims/<새 ID>/`에 `index.html`, `sim.js`를 만듭니다. (비슷한 차시 폴더를 복사해 시작하면 편합니다)
   `index.html`은 `common.js` → `catalog.js` → `sim.js` 순서로 불러옵니다.
2. `sim.js`에서 `SciSim.game({ simId: '<새 ID>', levels: [...] })`로 단계를 정의합니다.
   각 단계에는 `title`, `short`, `phase`(관찰/실험/탐구/설명/적용 등), `intro`, `features`, `recap`, `summary`, `missions`를 씁니다.
   HTML 요소에 `data-feature="이름"`을 달면 그 도구가 열리는 단계까지 자동으로 숨겨집니다.
3. `assets/js/catalog.js`에서 해당 단원의 `sims` 배열에 차시 순서대로 항목(성취기준 `std`, `stdText` 포함)을 추가하면
   메인 화면과 "다음 차시" 연결에 자동으로 반영됩니다.
