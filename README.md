# 🔬 중학 과학 시뮬레이션 게임

2022 개정 교육과정 **중학교 과학 1~3학년** 단원별 게임형 시뮬레이션 모음입니다.
[PhET Interactive Simulations](https://phet.colorado.edu/ko/)에서 아이디어를 얻어, 학생이 **직접 조작 → 미션 해결 → 원리 정리** 순서로 과학 개념을 익히도록 만들었습니다.

## 사용 방법

- **바로 열기**: `index.html`을 브라우저로 열면 됩니다. (설치·인터넷 연결 불필요, 글꼴만 온라인에서 불러옴)
- **GitHub Pages로 공개**: 저장소 → Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 지정하면
  `https://<아이디>.github.io/sciencesimul/` 주소로 접속할 수 있습니다.

## 게임 구성

각 시뮬레이션은 같은 틀로 되어 있습니다.

| 구성 | 내용 |
| --- | --- |
| 🧪 실험 화면 | 끌기·슬라이더로 자유롭게 조작하며 관찰 |
| 🎯 미션 | 3개 레벨 × 3~4개 미션 (실험 미션 + 퀴즈), 성공하면 "왜 그럴까?" 설명 |
| ⭐ 별·점수 | 레벨을 깰 때마다 별 1개, 힌트를 안 쓰고 한 번에 맞히면 높은 점수 |
| 📘 핵심 원리 | 단원의 핵심 개념·공식 정리 |

진행 기록(별·점수)은 각 기기의 브라우저(localStorage)에 저장됩니다.

| 학년 | 단원 | 시뮬레이션 | 핵심 개념 |

### 전체 단원 (2022 개정 교육과정 내용 체계 순서)

- **1학년 (과학 1)**: Ⅰ 과학과 인류의 지속가능한 삶 · Ⅱ 생물의 구성과 다양성 · Ⅲ 열 · Ⅳ 물질의 상태 변화 · Ⅴ 힘의 작용 · Ⅵ 기체의 성질 · Ⅶ 태양계
- **2학년 (과학 2)**: Ⅰ 물질의 특성 · Ⅱ 지권의 변화 · Ⅲ 빛과 파동 · Ⅳ 물질의 구성 · Ⅴ 식물과 에너지 · Ⅵ 동물과 에너지 · Ⅶ 전기와 자기 · Ⅷ 별과 우주
- **3학년 (과학 3)**: Ⅰ 화학 반응의 규칙성 · Ⅱ 날씨와 기후변화 · Ⅲ 수권과 해수의 순환 · Ⅳ 운동과 에너지 · Ⅴ 자극과 반응 · Ⅵ 생식과 유전 · Ⅶ 재해·재난과 안전 · Ⅷ 과학과 나의 미래

> 단원 순서는 교육과정 기준이며, 출판사별 교과서 순서와 다를 수 있습니다.

## 폴더 구조

```
index.html               메인(학년·단원별 목록)
assets/css/common.css    공통 스타일
assets/css/hub.css       메인 페이지 스타일
assets/js/common.js      공통 엔진 (미션·별·효과음·캔버스 도우미)
assets/js/catalog.js     학년·단원·시뮬레이션 목록  ← 새 실험 등록하는 곳
assets/js/hub.js         메인 페이지 동작
sims/<실험 ID>/          시뮬레이션별 폴더 (index.html + sim.js)
```

## 새 시뮬레이션 추가하기

1. `sims/<새 ID>/` 폴더에 `index.html`, `sim.js`를 만듭니다. (기존 실험 폴더를 복사해 시작하면 편해요)
2. `sim.js`에서 `SciSim.game({ simId: '<새 ID>', levels: [...] })`로 미션을 정의합니다.
3. `assets/js/catalog.js`에서 해당 단원의 `sims` 배열에 항목을 추가하면 메인 화면에 자동으로 나타납니다.
